🧠 Key Concepts Deep Dive
🌀 The K-Means Algorithm — Step by Step CORE ALGORITHM
K-Means is the most widely used clustering algorithm. It's simple, fast, and effective. The algorithm alternates between two steps until nothing changes: assign each point to the nearest centroid, then move each centroid to the mean of its assigned points.
1
Initialise
Place K centroids randomly (or pick K random data points)
2
Assign
Each point → nearest centroid (by Euclidean distance)
3
Update
Move each centroid to the mean of its assigned points
4
Converge
Repeat steps 2–3 until no point changes its cluster
// Distance from point (x1,y1) to centroid (cx,cy) =SQRT(([@Feature1]-cx)^2 + ([@Feature2]-cy)^2) // Assign each point to the nearest centroid (K=3) // Dist_C1, Dist_C2, Dist_C3 = distances to centroids 1, 2, 3 =IF(MIN([@Dist_C1],[@Dist_C2],[@Dist_C3])=[@Dist_C1],1, IF(MIN([@Dist_C1],[@Dist_C2],[@Dist_C3])=[@Dist_C2],2,3)) // Or use MATCH for cleaner code =MATCH(MIN([@Dist_C1],[@Dist_C2],[@Dist_C3]), CHOOSE({1,2,3},[@Dist_C1],[@Dist_C2],[@Dist_C3]),0) // Update centroid (recalculate mean per cluster) New_C1_Feature1 = AVERAGEIF(Cluster_col, 1, Feature1_col) New_C1_Feature2 = AVERAGEIF(Cluster_col, 1, Feature2_col)
📐 The Elbow Method — Finding Optimal K CHOOSE K CORRECTLY
K-Means requires you to specify K upfront. Too few clusters = oversimplified segments. Too many = meaningless micro-groups. The Elbow Method plots Within-Cluster Sum of Squares (WCSS) for K=1 to 8. The "elbow" — where WCSS stops dropping steeply — is the optimal K.
// Within-Cluster Sum of Squares (WCSS) for one cluster // = sum of squared distances from each point to its centroid WCSS_C1 = SUMPRODUCT((Cluster_col=1)*[@Dist_C1]^2) WCSS_C2 = SUMPRODUCT((Cluster_col=2)*[@Dist_C2]^2) WCSS_C3 = SUMPRODUCT((Cluster_col=3)*[@Dist_C3]^2) Total_WCSS = WCSS_C1 + WCSS_C2 + WCSS_C3 // Build elbow table: K | WCSS // K=1 → all points in one cluster → max WCSS // K=2 → big drop in WCSS // K=3 → another drop, but smaller // K=4 → marginal improvement — this might be the elbow // K=5+ → diminishing returns // Plot WCSS vs K as a line chart → look for the "kink" // Rule: K where the drop from K-1 to K is at least 2× the drop from K to K+1
⚖️ Why You MUST Scale Before Clustering CRITICAL PRE-STEP
K-Means uses Euclidean distance. A feature with range 0–10,000 (Income) will completely dominate a feature with range 0–10 (Rating). Without scaling, K-Means clusters on Income alone and ignores everything else. Always Min-Max or Z-Score scale ALL features before clustering.
// BEFORE clustering — scale ALL features to same range // Min-Max scaling (0 to 1) Age_scaled = ([@Age] - MIN(Age_col)) / (MAX(Age_col) - MIN(Age_col)) Income_scaled = ([@Income] - MIN(Income_col)) / (MAX(Income_col) - MIN(Income_col)) Spend_scaled = ([@Spend] - MIN(Spend_col)) / (MAX(Spend_col) - MIN(Spend_col)) // Run K-Means on SCALED features → get cluster labels // Profile clusters using ORIGINAL (unscaled) values // (Never interpret scaled values directly — meaningless to stakeholders) // Verify scaling worked =MIN(Age_scaled) → 0.000 ✓ =MAX(Age_scaled) → 1.000 ✓
📦 RFM Analysis — The Gold Standard of Customer Segmentation BUSINESS IMPACT
RFM stands for Recency (when did they last buy?), Frequency (how often do they buy?), and Monetary (how much do they spend?). It's the most used segmentation framework in e-commerce, banking, and retail — simple, interpretable, and directly actionable.
🏆 Champions — Low R, High F, High M
💤 At-Risk — High R, was High F/M
🌱 New Customers — Low R, Low F, Low M
// R = Recency: days since last purchase (LOWER = better) Recency = TODAY() - LastPurchaseDate // F = Frequency: total number of orders Frequency = Order_Count // M = Monetary: total amount spent Monetary = Total_Spend // Score each 1–5 using PERCENTILE (5 = best) // For Recency: LOWER is better → invert the scoring R_Score = IF(Recency <= PERCENTILE(R_col, 0.2), 5, IF(Recency <= PERCENTILE(R_col, 0.4), 4, IF(Recency <= PERCENTILE(R_col, 0.6), 3, IF(Recency <= PERCENTILE(R_col, 0.8), 2, 1)))) // For Frequency and Monetary: HIGHER is better F_Score = IF(Frequency >= PERCENTILE(F_col, 0.8), 5, IF(Frequency >= PERCENTILE(F_col, 0.6), 4, ...)) // RFM Segment label RFM_Segment = TEXTJOIN("", TRUE, R_Score, F_Score, M_Score) → e.g. "553"

📐 Distance Matrix + First K-Means Iteration
Build the Euclidean distance engine and run the first assign-update cycle manually
Theory + Build
▼
The best way to understand K-Means is to run it by hand — once. You'll calculate distances, assign clusters, and update centroids for K=3, then watch the clusters shift. After this, the automated iterations in Task 2 will make complete sense.
1
Create Day8_Clustering.xlsx. In sheet "KMeans", build a 25-row customer dataset: CustomerID, Age, Annual_Spend, Purchase_Frequency. Make the data naturally group-able — e.g., young/low-spend, middle/medium-spend, older/high-spend clusters.
2
Scale all 3 features first (mandatory):
Age_s: =([@Age]-MIN(Age_col))/(MAX(Age_col)-MIN(Age_col))
Spend_s: =([@Annual_Spend]-MIN(Spend_col))/(MAX(Spend_col)-MIN(Spend_col))
Freq_s: =([@Purchase_Frequency]-MIN(Freq_col))/(MAX(Freq_col)-MIN(Freq_col))
Verify: MIN of each scaled column = 0, MAX = 1.
3
Set initial centroids (pick 3 random rows — rows 1, 9, and 17 work well). In a separate "Centroids" table, copy their scaled feature values as C1, C2, C3. These are your starting positions.
4
Calculate distances to each centroid:
Dist_C1: =SQRT(([@Age_s]-$N$2)^2+([@Spend_s]-$O$2)^2+([@Freq_s]-$P$2)^2)
Dist_C2: =SQRT(([@Age_s]-$N$3)^2+([@Spend_s]-$O$3)^2+([@Freq_s]-$P$3)^2)
Dist_C3: =SQRT(([@Age_s]-$N$4)^2+([@Spend_s]-$O$4)^2+([@Freq_s]-$P$4)^2)
($N$2:$P$4 = your Centroids table with absolute refs)
5
Assign each point to nearest centroid:
=MATCH(MIN([@Dist_C1],[@Dist_C2],[@Dist_C3]),CHOOSE({1,2,3},[@Dist_C1],[@Dist_C2],[@Dist_C3]),0)
This returns 1, 2, or 3 — the cluster number for each customer.
6
Update centroids (Iteration 1 → Iteration 2 values):
New C1_Age_s: =AVERAGEIF(Cluster_col, 1, Age_s_col)
New C1_Spend_s: =AVERAGEIF(Cluster_col, 1, Spend_s_col)
New C1_Freq_s: =AVERAGEIF(Cluster_col, 1, Freq_s_col)
Repeat for C2 and C3. Paste these as the new centroid values. This completes Iteration 1.
// Min-Max scale (do this FIRST, before any distances) =([@Age]-MIN(Age_col))/(MAX(Age_col)-MIN(Age_col)) // 3D Euclidean distance to centroid C1 =SQRT(([@Age_s]-$N$2)^2+([@Spend_s]-$O$2)^2+([@Freq_s]-$P$2)^2) // Assign cluster (1, 2, or 3) =MATCH(MIN([@D1],[@D2],[@D3]),CHOOSE({1,2,3},[@D1],[@D2],[@D3]),0) // Update centroid C1 (mean of all points assigned to cluster 1) =AVERAGEIF(Cluster_col, 1, Age_s_col) =AVERAGEIF(Cluster_col, 1, Spend_s_col) =AVERAGEIF(Cluster_col, 1, Freq_s_col)
⚠️
Never skip scaling. Without it, Annual_Spend (range: £500–£50,000) completely overwhelms Age (range: 18–65). K-Means will effectively cluster only on spend and ignore age and frequency entirely. Scaled distances treat all features equally — this is non-negotiable.
3 features scaled (0–1)
MIN=0, MAX=1 verified
3 initial centroids set
3 distance columns built

🔄 K-Means Iterations Until Convergence
Repeat assign-update 5 times and watch clusters stabilise
Practice
▼
K-Means converges when no point changes cluster between iterations. For a 25-row dataset, this typically happens in 3–7 iterations. You'll track cluster assignments across iterations to see exactly when stability is reached — this is what "training" an unsupervised model looks like.
1
Create a Convergence Tracker table: columns for Iteration 1, 2, 3, 4, 5. Each row = one customer. In Iteration 1, paste the cluster assignments from Task 1 as values (Ctrl+C → Paste Special → Values — freeze them so they don't change).
2
Iteration 2: Paste the updated centroids from Task 1 into your Centroids table. The distance and cluster columns update automatically. Copy the new cluster assignments into the Iteration 2 column of your Convergence Tracker (paste as values again).
3
Update centroids again using AVERAGEIF on the new cluster assignments. Paste → distances update → cluster assignments update. This is Iteration 3. Copy into Iteration 3 column.
4
Continue through Iterations 4 and 5. After each one, add a "Changes" row at the bottom of your tracker: =SUMPRODUCT((B2:B26<>C2:C26)*1) (compares Iteration n to Iteration n-1). When Changes = 0, K-Means has converged.
5
Apply conditional formatting to highlight cells that changed between iterations: Select Iteration 2 column → New Rule → Use formula → =B2<>C2 → orange fill. This visually shows which customers "moved" clusters between iterations.
6
Once converged, add cluster labels to your original data. Apply colour fills: Cluster 1 = orange row, Cluster 2 = blue row, Cluster 3 = green row. Build a cluster size summary: =COUNTIF(Cluster_col, 1) for each cluster. Are the clusters roughly balanced?
// Paste cluster assignments as values to freeze each iteration // Ctrl+C → Ctrl+Alt+V → Values → OK (prevents formula drift) // Count changes between consecutive iterations =SUMPRODUCT((Iter1_col <> Iter2_col)*1) → 0 = converged ✓ // Cluster size per cluster =COUNTIF(Cluster_col, 1) → count of customers in cluster 1 =COUNTIF(Cluster_col, 2) =COUNTIF(Cluster_col, 3) // Should sum to 25 (total customers) // Conditional format cells that changed (Iteration 2 vs Iteration 1) // Formula: =B2<>C2 → orange fill on changed cells
💡
K-Means is not deterministic. Different random starting centroids can lead to different final clusters. Run it 3 times from different starting points and compare Total WCSS. The run with the lowest WCSS is the best solution — this is why sklearn's n_init=10 default runs K-Means 10 times and picks the best.

📊 Elbow Method + Cluster Profiling
Find the optimal K, then describe each cluster in business language
Practice
▼
Choosing K is as much art as science — and the Elbow Method provides the data-driven starting point. After finding the right K, profiling turns math into meaning: Cluster 2 isn't "centroid at (0.6, 0.4)" — it's "High-Value Loyal Customers aged 35–50 spending £3,200/year."
1
Create sheet "ElbowMethod". Build the WCSS for K=1 through K=6 manually. For K=1: centroid = mean of all points. WCSS = sum of squared distances from every point to the single centroid. For K=2 and K=3: run your K-Means from Tasks 1–2 and record WCSS. For K=4,5,6: set up 4/5/6 centroids and estimate (approximate values are fine for the elbow chart).
2
WCSS formula per cluster:
=SUMPRODUCT((Cluster_col=1)*Dist_C1_col^2) + SUMPRODUCT((Cluster_col=2)*Dist_C2_col^2) + SUMPRODUCT((Cluster_col=3)*Dist_C3_col^2)
This sums the squared distance of each point to its own centroid across all 3 clusters.
3
Build the Elbow Chart: Select K (1–6) and WCSS columns → Insert → Line Chart → 2D Line. Title: "Elbow Method — Optimal K". Add data labels. The line should drop steeply from K=1 to K=2, then less steeply, then flatten. The "kink" is your optimal K.
4
Create sheet "ClusterProfile". For each cluster (1, 2, 3) build a profile using AVERAGEIF on the original unscaled values:
Avg Age: =AVERAGEIF(Cluster_col, 1, Age_col)
Avg Spend: =AVERAGEIF(Cluster_col, 1, Annual_Spend_col)
Avg Frequency: =AVERAGEIF(Cluster_col, 1, Frequency_col)
Count: =COUNTIF(Cluster_col, 1)
5
Name each cluster based on its profile. Use descriptive business names — not "Cluster 1":
Example: Cluster 1: "🌱 Casual Shoppers — Young, low spend, infrequent"
Cluster 2: "⭐ Core Customers — Mid-age, moderate spend, regular"
Cluster 3: "💎 VIP Spenders — Older, high spend, very frequent"
Write one sentence of recommended marketing strategy per cluster.
6
Add a radar chart (spider chart) showing normalised averages per cluster. Insert → Other Charts → Radar. Each spoke = one feature. Each cluster = one series. This visually summarises the "shape" of each segment — more intuitive than a table of numbers for stakeholder presentations.
// Total WCSS for K=3 model =SUMPRODUCT((Cluster_col=1)*Dist_C1^2) +SUMPRODUCT((Cluster_col=2)*Dist_C2^2) +SUMPRODUCT((Cluster_col=3)*Dist_C3^2) // Cluster profile using ORIGINAL values (not scaled) Avg_Age_C1 = AVERAGEIF(Cluster_col, 1, Age_col) Avg_Spend_C1 = AVERAGEIF(Cluster_col, 1, Spend_col) Avg_Freq_C1 = AVERAGEIF(Cluster_col, 1, Freq_col) Count_C1 = COUNTIF(Cluster_col, 1) // Max within cluster for range description Max_Age_C1 = MAXIFS(Age_col, Cluster_col, 1) Min_Age_C1 = MINIFS(Age_col, Cluster_col, 1)
🎯
The name is the deliverable. A data scientist's job isn't done when K-Means converges. It's done when the clusters have names that a marketing team can act on. "Cluster 1: mean Age=24, mean Spend=£420" is math. "Casual Young Shoppers: budget-conscious 18–28 year olds who buy once at Christmas" is insight. Always translate numbers into narratives.

📦 RFM Analysis — Customer Scoring Model
Score every customer on Recency, Frequency, Monetary and map to actionable segments
RFM Scoring
▼
RFM is the most actionable customer segmentation model ever built. Used by Amazon, Netflix, Spotify, and every serious e-commerce company. You score each customer 1–5 on three dimensions — then the combination tells you exactly who to target, retain, win back, or let go.
1
Create sheet "RFM". Build a 30-row customer transaction table: CustomerID, LastPurchaseDate, OrderCount, TotalSpend. Make dates realistic — some customers bought last week, some 18 months ago. Convert to Table named RFMData.
2
Calculate R, F, M raw values:
Recency (days): =TODAY()-[@LastPurchaseDate] (lower = better — bought more recently)
Frequency: =[@OrderCount]
Monetary: =[@TotalSpend]
3
Score Recency 1–5 (lower recency = higher score — 5 means bought very recently):
=IF([@Recency]<=PERCENTILE(RFMData[Recency],0.2),5,IF([@Recency]<=PERCENTILE(RFMData[Recency],0.4),4,IF([@Recency]<=PERCENTILE(RFMData[Recency],0.6),3,IF([@Recency]<=PERCENTILE(RFMData[Recency],0.8),2,1))))
4
Score Frequency 1–5 (higher frequency = higher score):
=IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.8),5,IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.6),4,IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.4),3,IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.2),2,1))))
Do the same for Monetary score.
5
Create RFM Segment String and Label:
RFM_String: =TEXT([@R_Score],"0")&TEXT([@F_Score],"0")&TEXT([@M_Score],"0") → e.g., "554"
RFM_Segment: =IF([@R_Score]>=4,"Champion",IF(AND([@R_Score]>=3,[@F_Score]>=3),"Loyal",IF([@R_Score]<=2,"At Risk","Promising")))
6
Segment summary table: Count customers per segment using COUNTIF. Calculate avg Monetary per segment using AVERAGEIF. Format as a business report. The segment with highest avg Monetary = your VIP group. The "At Risk" group = priority for win-back campaigns.
// Recency = days since last purchase (lower = better) =TODAY() - [@LastPurchaseDate] // R Score — 5 = bought most recently (bottom 20th percentile of recency days) =IF([@Recency]<=PERCENTILE(RFMData[Recency],0.2),5, IF([@Recency]<=PERCENTILE(RFMData[Recency],0.4),4, IF([@Recency]<=PERCENTILE(RFMData[Recency],0.6),3, IF([@Recency]<=PERCENTILE(RFMData[Recency],0.8),2,1)))) // F Score — 5 = most frequent buyer (top 20th percentile) =IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.8),5, IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.6),4, IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.4),3, IF([@Frequency]>=PERCENTILE(RFMData[Frequency],0.2),2,1)))) // RFM segment label =IF([@R_Score]>=4,"🏆 Champion", IF(AND([@R_Score]>=3,[@F_Score]>=3),"⭐ Loyal", IF([@R_Score]<=2,"⚠ At Risk","🌱 Promising")))
💡
RFM in the real world: Champions (high R, F, M) = reward with exclusive access. Loyal Customers = upsell and cross-sell. At-Risk = send win-back campaign with discount. New Customers (high R, low F, low M) = onboarding sequence. Can't Lose Them (was champion, now low R) = urgent personal outreach. Each segment demands a different action.

Project
▼
Combine everything from today into an executive-ready segmentation dashboard. Stakeholders don't care about centroids — they care about: "Which customers do we focus on this month?" Your dashboard answers that question in one view with clear segment names, sizes, and recommended actions.

3
RFM panel: For each RFM segment show: Segment Name (Champion/Loyal/At Risk/Promising), Count, Avg Monetary Value, % of total revenue (=SUMIF(segment,seg,monetary)/SUM(monetary)), and recommended campaign. 6
Save as Day8_Complete.xlsx. Your segmentation model is complete — K-Means for behavioural clustering, RFM for purchase-based scoring, and a dashboard that translates both into business actions.
// Revenue contribution per K-Means cluster =SUMIF(KMeans_Cluster_col, 1, Annual_Spend_col) / SUM(Annual_Spend_col) // RFM revenue per segment =SUMIF(RFMData[RFM_Segment], "🏆 Champion", RFMData[TotalSpend]) / SUM(RFMData[TotalSpend]) // Count per segment =COUNTIF(RFMData[RFM_Segment], "🏆 Champion") // At-Risk count (flag for urgent action) =COUNTIF(RFMData[RFM_Segment], "⚠ At Risk") // Segment action lookup using SWITCH =SWITCH([@RFM_Segment], "🏆 Champion", "Reward & retain — VIP programme", "⭐ Loyal", "Upsell & cross-sell campaign", "⚠ At Risk", "Win-back: personal outreach + discount", "🌱 Promising", "Onboarding sequence — nurture")

If yes — your model has business value.

Day 8 Pro Tip — Scale Before You Cluster. Name After You Cluster.
Two rules that never fail: Always scale features before K-Means — un-scaled data gives numerically dominated, meaningless clusters. And always name your clusters in plain business language after K-Means — "Cluster 2" is not a deliverable, "High-Value Loyal Customers aged 35–50" is. The math gets you the groups. The names make the groups actionable. Both steps are equally important.

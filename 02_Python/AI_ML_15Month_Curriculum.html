💡 How to Follow This Curriculum
📅
Study 5 days a week — take weekends off OR use them for review & practice.
📚
Each "Day" = one HTML file lesson with Lesson + Real World + Task + Quiz. Take it seriously.
🔁
First day of every new week = 30-minute recap of last week. Don't skip this.
🏗️
Every month ends with a project. Build it even if it's small. Projects are your portfolio.
📓
Keep a physical notebook. Write formulas, diagrams, and your own explanations.
💾
Download libraries/datasets at home with WiFi. Copy to USB. Use at institute.
🚫
Don't rush. Understanding beats speed every time. A confused foundation destroys everything built on top.
📘 Phase 1 — Foundation (Months 1–3)
MONTH 1
Python Programming Mastery
Variables → Functions → OOP → File I/O
✓ DONE ▾
WEEK 1
Python Basics
variablesdata typesprint()input()if/else
Learn how to store data, make decisions, and interact with the user. The absolute building blocks of every AI program ever written.
WEEK 2
Loops, Lists & Data Structures
for loopwhile looplisttuplesetdict
Iterate over data, store collections, and understand when to use which structure. AI datasets are essentially giant lists of dictionaries.
WEEK 3
Functions & Modules
defparametersreturnlambdaimportmodules
Write reusable code. Every ML model is fundamentally a function. Understanding this makes advanced concepts much easier.
WEEK 4
File I/O, Error Handling & OOP Basics
open/read/writetry/exceptclassobjectsmethods
Read datasets from files, handle errors gracefully, and understand Object-Oriented Programming — the foundation of all ML libraries.
🏗️Month 1 Project: Build a Student Grade Management System — takes student names and marks, calculates averages, reads/writes to a file, handles errors.
🐍 Python 3 📝 IDLE / VS Code
MONTH 2
Math for ML & Data Libraries
NumPy · Pandas · Statistics · Linear Algebra
✓ DONE ▾
WEEK 1
NumPy — Fast Number Crunching
np.arrayshapeindexingbroadcastingmath ops2D arrays
NumPy arrays are the foundation of all ML. Every dataset, every model weight, every prediction is stored as an array. Master it early.
WEEK 2
Pandas — Working With Real Data
DataFrameread_csvfilteringgroupbymergemissing values
Load, clean, and explore real datasets. 80% of an ML engineer's time is spent on data. Pandas is the main tool for this stage.
WEEK 3
Matplotlib & Seaborn — Visualisation
bar chartscatter plothistogramheatmapcorrelationseaborn
Data you can see is data you understand. You'll use visualisation before every model to understand distributions, outliers, and relationships.
WEEK 4
Statistics & Linear Algebra Essentials
mean/median/stdprobabilityvectorsmatricesdot productderivatives
You need just enough math to understand why ML algorithms work. This week gives you that foundation without overwhelming theory.
🏗️Month 2 Project: Exploratory Data Analysis on a real dataset (Titanic/Iris) — load, clean, visualise, find 5 insights, present findings.
🔢 NumPy 🐼 Pandas 📊 Matplotlib 📈 Seaborn

🤖 Phase 2 — Classical ML Mastery (Months 4–6)
MONTH 4
Supervised Learning Algorithms
Regression · SVM · Naive Bayes · Ensemble Methods
upcoming ▾
WEEK 1
Logistic Regression & Advanced Linear Models
logistic regressionlog-lossregularisationRidgeLassoElasticNet
Logistic Regression is used in millions of real applications. Ridge and Lasso fix overfitting in linear models. Master these before moving to complex models.
WEEK 2
Support Vector Machines (SVM)
hyperplanemarginkernel trickRBF kernelSVCSVR
SVMs are still used in production for text classification, image recognition and biomedical tasks. The kernel trick is one of the most elegant ideas in ML.
WEEK 3
Naive Bayes & Probabilistic Models
Bayes theoremprior/posteriorGaussianNBMultinomialNBspam filter
Naive Bayes trains in milliseconds and works extremely well for text. Understanding Bayes theorem is essential for probabilistic ML and Bayesian deep learning.
WEEK 4
Gradient Boosting — XGBoost & LightGBM
boostingXGBoostLightGBMlearning rateearly stoppingfeature importance
XGBoost wins more Kaggle competitions than any other algorithm. LightGBM is faster. These are the most powerful classical ML algorithms for structured data.
🏗️Month 4 Project: Credit Card Fraud Detector — imbalanced dataset, compare SVM vs XGBoost vs Random Forest, evaluate with precision/recall/F1.
⚙️ Scikit-learn 🚀 XGBoost ⚡ LightGBM
MONTH 5
Unsupervised Learning
Clustering · Dimensionality Reduction · Anomaly Detection
upcoming ▾
WEEK 1
K-Means & Hierarchical Clustering
K-Meanscentroidselbow methodDBSCANdendrogramsilhouette score
Group data without labels. Used for customer segmentation, document clustering, and image compression. DBSCAN handles arbitrary shapes that K-Means can't.
WEEK 2
PCA & Dimensionality Reduction
PCAexplained variancet-SNEUMAPfeature compression2D visualisation
Reduce 100 features to 2 without losing the patterns. t-SNE and UMAP make high-dimensional data visible. Essential for understanding what your model sees.
WEEK 3
Autoencoders & Anomaly Detection
encoder/decoderlatent spacereconstruction errorIsolationForestLOF
Autoencoders compress data and reconstruct it — anything that reconstructs badly is an anomaly. Used in fraud detection, quality control, and network security.
WEEK 4
Recommender Systems
collaborative filteringcontent-basedcosine similaritymatrix factorisationSVD
Netflix, Spotify, Amazon — all use recommender systems. Build one from scratch using collaborative filtering and matrix factorisation.
🏗️Month 5 Project: Customer Segmentation System — real retail dataset, K-Means clustering, PCA visualisation, business recommendations report.
⚙️ Scikit-learn 📊 UMAP
MONTH 6
ML Engineering & Feature Engineering
Pipelines · Tuning · Feature Engineering · Data Cleaning
upcoming ▾
WEEK 1
Feature Engineering Deep Dive
one-hot encodinglabel encodingscalingpolynomial featuresinteraction termsbinning
Features are everything. A simple model with great features beats a complex model with bad features. This is where real ML engineering skill is built.
WEEK 2
Data Cleaning & Missing Values
missing valuesimputationoutliersduplicatesdata leakagetrain-test consistency
Real data is always messy. You need strategies for missing values, outliers, and data leakage — the most dangerous and common mistake in ML.
WEEK 3
Pipelines & Cross-Validation
Pipeline()ColumnTransformerk-fold CVStratifiedKFoldcross_val_score
Pipelines bundle preprocessing + model into one clean object. Cross-validation gives much more reliable accuracy estimates than a single train/test split.
WEEK 4
Hyperparameter Tuning
GridSearchCVRandomizedSearchCVOptunaBayesian optimisationearly stopping
Systematically find the best model configuration. Optuna is the modern standard — it learns from previous trials to make smarter next guesses.
🏗️Month 6 Project: House Price Predictor — complete pipeline with feature engineering, missing value imputation, XGBoost + hyperparameter tuning, MAE below target.
⚙️ Scikit-learn 🔍 Optuna 🚀 XGBoost
🧠 Phase 3 — Advanced Deep Learning (Months 7–9)
MONTH 7
Recurrent Networks & Sequences
RNNs · LSTMs · GRUs · Time Series · Text Generation
upcoming ▾
WEEK 1
RNNs — Processing Sequences
hidden statesequence inputSimpleRNNvanishing gradientBPTT
RNNs process data point by point — ideal for text, audio, and time series. Understanding the vanishing gradient problem motivates LSTMs.
WEEK 2
LSTMs & GRUs
cell stateforget gateinput gateoutput gateGRUbidirectional
LSTMs solve the vanishing gradient problem with gates that control memory. They're used in Google Translate, speech recognition, and music generation.
WEEK 3
Time Series Forecasting
sliding windowstationarityARIMALSTM forecasterstock pricestemperature prediction
Predict future values from historical data. Stock prices, weather, energy demand — all time series problems solvable with LSTMs.
WEEK 4
Text Generation & Sequence Models
character-level modeltemperaturesamplingencoder-decoderseq2seq
Build a model that generates Shakespeare-style text, or translates sentences from Urdu to English. This is where AI starts feeling magical.
🏗️Month 7 Project: Stock Price Forecaster — LSTM on real stock data, rolling window preprocessing, MAE evaluation, interactive prediction chart.
🔥 TensorFlow🧠 Keras LSTM
MONTH 8
Transformers & NLP at Scale
Attention · BERT · GPT · HuggingFace · Fine-tuning
upcoming ▾
WEEK 1
Attention Mechanism & Transformer Architecture
self-attentionmulti-head attentionpositional encodingencoder/decoderlayer normalisation
The paper "Attention is All You Need" (2017) changed everything. Understanding transformers is now essential for any serious AI work.
WEEK 2
BERT — Bidirectional Language Understanding
BERTmasked LMnext sentence predictionCLS tokenfine-tuningHuggingFace
BERT understands context from both directions. Fine-tune it in minutes for any text classification task. HuggingFace makes this accessible to everyone.
WEEK 3
GPT Models & Prompt Engineering
autoregressivezero-shotfew-shotchain-of-thoughtsystem promptstemperature
GPT generates text by predicting one token at a time. Learn prompt engineering — the skill of writing instructions that get AI to do exactly what you want.
WEEK 4
Text Classification & Named Entity Recognition
sentimenttopic classificationNERtoken classificationspaCyBERT fine-tune
Apply transformers to real business problems — classify customer reviews, extract person names and locations from text, categorise support tickets.
🏗️Month 8 Project: News Article Classifier + Summariser using BERT — multi-class topic classification + extractive summarisation. Full Flask web interface.
🤗 HuggingFace🔥 PyTorch🐍 spaCy
MONTH 9
Generative AI — GANs & Diffusion Models
GANs · VAEs · Stable Diffusion Concepts · Image Generation
upcoming ▾
WEEK 1
Generative Adversarial Networks (GANs)
generatordiscriminatoradversarial trainingmode collapseDCGAN
Two networks competing — one creates, one judges. This tension produces remarkably realistic outputs. GANs power deepfakes, art generation, and data augmentation.
WEEK 2
Training GANs on MNIST & CIFAR
training looploss balancebatch normalisationfake vs realFID score
Train a GAN that generates handwritten digits — from random noise to realistic-looking numbers. See the progression epoch by epoch.
WEEK 3
Variational Autoencoders (VAEs)
latent distributionreparameterisationKL divergenceELBO lossinterpolation
VAEs learn a smooth latent space you can navigate — morph between images, generate new examples. Foundational to modern image synthesis.
WEEK 4
Diffusion Models & Stable Diffusion Concepts
noise scheduledenoisingU-NetCLIPtext-to-imageDALL-E concept
The math behind Stable Diffusion, DALL-E, and Midjourney. You won't train one (needs massive GPUs) but you'll understand exactly how they work.
🏗️Month 9 Project: Face Generator GAN — train DCGAN on a face dataset, generate synthetic faces, interpolate in latent space, save training gif.
🔥 PyTorch🧠 Keras
🚀 Phase 4 — Advanced AI & Deployment (Months 10–12)
MONTH 10
Reinforcement Learning
Q-Learning · DQN · Policy Gradient · OpenAI Gym
upcoming ▾
WEEK 1
RL Fundamentals — Agents, Environments, Rewards
MDPstate/action/rewardpolicyvalue functionepisode
RL is how AlphaGo, ChatGPT RLHF, and game-playing AIs are built. The framework is simple — the applications are profound.
WEEK 2
Q-Learning & Temporal Difference
Q-tableBellman equationepsilon-greedyexplorationTD learning
Implement Q-learning from scratch on a grid world. Watch an agent learn to navigate a maze by trial and error — no programming of rules.
WEEK 3
Deep Q-Networks (DQN)
neural Q-functionexperience replaytarget networkCartPoleOpenAI Gym
Replace the Q-table with a neural network — now the agent can handle millions of states. This is how Atari-playing AIs were built.
WEEK 4
Policy Gradient Methods
REINFORCEactor-criticPPOreward shapingentropy bonus
Policy gradients directly optimise the policy. PPO (Proximal Policy Optimisation) is used in ChatGPT's RLHF training. Conceptually important even at high level.
🏗️Month 10 Project: Train an agent to play CartPole and LunarLander using DQN — plot reward curves, demonstrate trained agent video.
🎮 OpenAI Gym🔥 PyTorch

MLOps & Model Deployment
Flask · FastAPI · Docker · CI/CD · Model Monitoring
upcoming ▾
WEEK 1
Building ML APIs with Flask & FastAPI
REST APIPOST endpointJSONmodel servingFastAPISwagger docs
A model sitting on your hard drive helps nobody. Wrap it in an API and anyone can use it. FastAPI generates automatic documentation.
WEEK 2
Docker & Containerisation
Dockerfiledocker build/runcontainersimagesdocker-composeport mapping
Docker ensures your model runs identically on any machine. Package your model + code + dependencies into one container that deploys anywhere.
WEEK 3
Streamlit — ML Web Apps Without Frontend
Streamlitslidersfile uploadchartsmodel inferenceshare URL
Build a full interactive ML web app in 30 minutes of Python. Upload an image, get a prediction, show a chart — all without touching HTML or JavaScript.
WEEK 4
Model Monitoring, Drift & Retraining
data driftconcept driftEvidently AIloggingalertsretraining pipeline
Models degrade over time as data changes. Set up monitoring to detect when your model's performance drops and trigger automatic retraining.
🏗️Month 11 Project: Deploy a Disease Prediction API — FastAPI + Docker + Streamlit frontend. A working product accessible via URL that anyone can use.

arxivpaper structureGitHub READMEproject writeupsdemo videosLinkedIn

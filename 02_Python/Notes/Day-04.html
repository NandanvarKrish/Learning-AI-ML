📖 Lesson

For Loops & While Loops

In AI, a for loop processes every row in a dataset, every pixel in an image, every word in a sentence. Loops are how computers handle scale — doing millions of operations automatically.

Python
# For loop — iterate over a sequence scores = [85, 42, 91, 37, 76] for score in scores: if score >= 50: print(f"{score} → Pass ✅") else: print(f"{score} → Fail ❌") # range() — repeat N times for i in range(5): # 0,1,2,3,4 print(f"Epoch {i+1}") # range(start, stop, step) for n in range(0, 100, 10): # 0,10,20,...,90 print(n)
⏳ While Loop
Python
# While loop — repeats while condition is True epoch = 1 loss = 10.0 while loss > 0.1: # keep training until loss is small loss = loss * 0.7 # loss decreases each epoch print(f"Epoch {epoch}: loss = {loss:.4f}") epoch += 1 # ALWAYS update counter!
💡break and continue: break exits the loop immediately. continue skips the current iteration and goes to the next. Both are used heavily in ML training loops.
🌍 Real World

How an AI Model Trains — It's a Loop!

Neural network training IS a loop. Every epoch, the loop runs the model on the data, calculates error, and updates weights. What you learn today is literally the structure of every AI training process.

Python — simplified training loop
dataset = [10, 20, 30, 40, 50] # 5 data points weight = 1.0 lr = 0.01 # learning rate for epoch in range(3): # 3 training epochs for data_point in dataset: # each sample prediction = weight * data_point error = prediction - 100 weight -= lr * error print(f"Epoch {epoch+1}: weight = {weight:.4f}")

QUESTION 1 OF 3
What does range(2, 10, 2) produce?
✅ Correct! range(start, stop, step). Starts at 2, stops BEFORE 10, steps by 2. Output: 2, 4, 6, 8. ❌ Wrong. range(2, 10, 2) starts at 2, stops before 10, steps by 2 → 2, 4, 6, 8. Note: stop value is never included.
QUESTION 2 OF 3
What is the danger of a while loop without updating the counter?
✅ Correct! If the condition never becomes False, the while loop runs forever. Always ensure the counter or condition changes inside the loop. ❌ Wrong. Without updating the counter, the while condition stays True forever → infinite loop → program freezes. Always update!
QUESTION 3 OF 3
What does 'break' do inside a loop?
✅ Correct! break immediately exits the entire loop. continue skips just the current iteration. Both are essential in training loops. ❌ Wrong. break exits the loop completely. continue (not break) skips one iteration.

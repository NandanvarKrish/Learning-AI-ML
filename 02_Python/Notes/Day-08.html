📖 Lesson

*args, **kwargs & Lambda — Advanced Functions

These three patterns appear constantly in ML library source code. Once you understand them, reading sklearn, Pandas, and Keras source code becomes easy. They are not complicated — just new syntax for flexible functions.

📦
*args
Accept any number of positional arguments. Collected into a tuple.
f(1, 2, 3, 4, 5) ✅
🏷️
**kwargs
Accept any number of keyword arguments. Collected into a dict.
f(n=100, depth=5) ✅
📦 *args — Any Number of Positional Arguments
Python — *args
# *args collects all positional args into a TUPLE def average(*args): print(f"Received: {args}") # it's a tuple return sum(args) / len(args) print(average(80, 90, 70)) # 80.0 print(average(85, 92, 78, 95, 88)) # 87.6 print(average(100, 50)) # 75.0 # Mix regular param + *args def report(title, *scores): print(f"\n=== {title} ===") for i, s in enumerate(scores, 1): print(f" Student {i}: {s}") print(f" Average: {sum(scores)/len(scores):.1f}") report("Class A", 88, 45, 72, 91)
🏷️ **kwargs — Any Number of Keyword Arguments
Python — **kwargs
# **kwargs collects keyword args into a DICT def model_config(**kwargs): print("Model Configuration:") for key, val in kwargs.items(): print(f" {key} = {val}") # Pass ANY combination of keyword args model_config(n_estimators=100, max_depth=5, random_state=42) model_config(learning_rate=0.01, epochs=50) # Combine *args and **kwargs def train_model(name, *datasets, **params): print(f"\nTraining: {name}") print(f"Datasets: {len(datasets)}") print(f"Params: {params}") train_model("RandomForest", "train.csv", "val.csv", n_estimators=100, max_depth=5)
💡**kwargs is inside every sklearn call you'll ever make. When you write RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42) — that function uses **kwargs internally to accept any configuration you choose to pass.
⚡ Lambda — One-Line Functions

A lambda is an anonymous (no-name) function written in a single line. Perfect for short, throw-away operations — especially when passing a function as an argument to another function.

Python — Lambda Functions
# Lambda syntax: lambda params: expression square = lambda x: x ** 2 add = lambda a, b: a + b grade = lambda s: "Pass" if s >= 50 else "Fail" normalise = lambda x, mn, mx: (x - mn) / (mx - mn) print(square(5)) # 25 print(add(3, 4)) # 7 print(grade(75)) # Pass print(normalise(50,0,100)) # 0.5 # Lambda with sorted() — most common use students = [ {"name":"Ali", "marks":85}, {"name":"Sara", "marks":92}, {"name":"Usman", "marks":78}, ] # Sort by marks descending — lambda as key ranked = sorted(students, key=lambda s: s["marks"], reverse=True) for s in ranked: print(f"{s['name']}: {s['marks']}")
🔁 map() and filter() with Lambda

map() applies a function to every item. filter() keeps only items where the function returns True. Both use lambdas as their function argument.

Python — map() and filter()
scores = [85, 45, 72, 33, 91] # map() — apply function to EVERY item normalised = list(map(lambda s: s / 100, scores)) print(normalised) # [0.85, 0.45, 0.72, 0.33, 0.91] # filter() — keep only items where function is True passed = list(filter(lambda s: s >= 50, scores)) print(passed) # [85, 72, 91] # Chain them: normalise only passing scores result = list(map( lambda s: s/100, filter(lambda s: s>=50, scores) )) print(result) # [0.85, 0.72, 0.91] # Lambda table — common patterns ops = { "double" : lambda x: x * 2, "relu" : lambda x: max(0, x), "sigmoid" : lambda x: 1 / (1 + 2.718**(-x)), "threshold" : lambda x: 1 if x > 0.5 else 0 } for name, fn in ops.items(): print(f"{name}(0.7) = {fn(0.7):.4f}")
💡Lambda + sorted() appears everywhere in data work. Pandas .sort_values() and .apply() use this exact pattern. df.apply(lambda x: x*2) — you're already thinking like a data scientist.
🌍 Real World Example

How Pandas .apply() Uses Lambda

Pandas' most powerful method — .apply() — takes a function (usually a lambda) and applies it to every row or column. This is the pattern you'll use every single day in Month 2.

Python — Simulating Pandas .apply() with lambda
# Without Pandas — manual apply() using map + lambda dataset = [ {"name":"Ali", "marks":88, "attendance":92}, {"name":"Sara", "marks":45, "attendance":60}, {"name":"Usman", "marks":72, "attendance":85}, ] # Apply grade lambda to every student grade_fn = lambda r: "A" if r["marks"]>=80 else "B" if r["marks"]>=60 else "F" eligible = lambda r: r["marks"]>=50 and r["attendance"]>=75 for s in dataset: print(f"{s['name']:8} Grade:{grade_fn(s)} Eligible:{eligible(s)}") # Month 2 equivalent (Pandas): # df["grade"] = df.apply(grade_fn, axis=1) # df["eligible"] = df.apply(eligible, axis=1)

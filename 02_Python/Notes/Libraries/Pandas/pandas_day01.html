What is Pandas & Why Every Data Scientist Uses It

The Excel of Python — but infinitely more powerful

Pandas (Panel Data + Python Data Analysis) is an open-source library built on top of NumPy. Created by Wes McKinney in 2008, it provides two core data structures — Series and DataFrame — that make working with labelled, structured data fast and intuitive.

💡 NumPy vs Pandas — When to Use Which
  • NumPy → raw numbers, matrices, maths, ML algorithms internals
  • Pandas → labelled data, tables, CSV files, mixed types, data cleaning, grouping, merging
  • They work together — Pandas uses NumPy arrays internally, and you can convert between them freely

What Makes Pandas Special

FeatureWhat It MeansReal-World Use
Labelled AxesRows and columns have names, not just numbersAccess df['Age'] not arr[:,2]
Mixed TypesEach column can have its own dtypeName=str, Age=int, Salary=float in one table

File I/ORead/write CSV, Excel, JSON, SQL, ParquetOne line loads any data source

Pandas Series — 1D Labelled Array

A powerful NumPy array with a custom index — the DNA of a DataFrame column

A Series is a one-dimensional array-like object with an associated array of labels called the index. Think of it as a column from a spreadsheet — values paired with row labels.

📊 Series Structure
Index → Values
0 → 10
1 → 20
2 → 30
Index can be integers (default), strings, dates, or any hashable type. Values can be any dtype.

Creating a Series — 6 Ways

PYTHON
import pandas as pd
import numpy  as np

# 1. From Python list (default integer index)
s1 = pd.Series([10, 20, 30, 40, 50])
print(s1)
# 0    10
# 1    20
# 2    30
# 3    40
# 4    50
# dtype: int64

# 2. With custom index
s2 = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s2['b'])   # 20  ← access by label

# 3. From dictionary (keys become index!)
s3 = pd.Series({'Alice': 92, 'Bob': 78, 'Carol': 85})
print(s3['Alice'])   # 92

# 4. From NumPy array
s4 = pd.Series(np.arange(1, 6) * 10)

# 5. Scalar — broadcasts to fill the index
s5 = pd.Series(5.0, index=['x', 'y', 'z'])
print(s5)
# x    5.0
# y    5.0
# z    5.0

# 6. With explicit dtype
s6 = pd.Series([1, 2, 3], dtype=np.float32, name='scores')

Series Attributes

PYTHON
s = pd.Series({'Alice':92, 'Bob':78, 'Carol':85, 'Dave':91}, name='Scores')

print(s.index)     # Index(['Alice', 'Bob', 'Carol', 'Dave'], dtype='object')
print(s.values)    # [92 78 85 91]  ← NumPy array underneath!
print(s.dtype)     # int64
print(s.shape)     # (4,)
print(s.size)      # 4
print(s.name)      # Scores
print(s.ndim)      # 1
print(s.is_unique()) # True (no duplicate values)

Series Indexing & Slicing

PYTHON
s = pd.Series({'Alice':92, 'Bob':78, 'Carol':85, 'Dave':91, 'Eve':67})

# By label
print(s['Alice'])               # 92
print(s[['Alice', 'Carol']])    # two rows

# By position (integer)
print(s.iloc[0])               # 92  ← first element
print(s.iloc[-1])              # 67  ← last element
print(s.iloc[1:4])             # Bob, Carol, Dave

# By label with loc (INCLUSIVE of both ends!)
print(s.loc['Bob':'Dave'])     # Bob, Carol, Dave (includes Dave!)

# Boolean filtering
print(s[s > 80])               # Alice:92, Carol:85, Dave:91
print(s[s.between(80, 90)])    # Carol:85

Series Operations

PYTHON
s = pd.Series([10, 20, 30, 40, 50])

# Arithmetic — vectorised like NumPy
print(s + 5)     # [15, 25, 35, 45, 55]
print(s * 2)     # [20, 40, 60, 80, 100]
print(s ** 2)    # [100, 400, 900, 1600, 2500]

# Statistics
print(s.sum())    # 150
print(s.mean())   # 30.0
print(s.median()) # 30.0
print(s.std())    # 15.81
print(s.min())    # 10
print(s.max())    # 50
print(s.describe())  # full stats summary

# Auto-alignment on index — KEY Pandas feature
a = pd.Series({'x':1, 'y':2, 'z':3})
b = pd.Series({'y':10, 'z':20, 'w':30})
print(a + b)
# w     NaN   ← 'w' not in a
# x     NaN   ← 'x' not in b
# y    12.0   ← 2 + 10
# z    23.0   ← 3 + 20

# Value counts — frequency of each value
grades = pd.Series(['A','B','A','C','B','A','D'])
print(grades.value_counts())
# A    3
# B    2
# C    1
# D    1

# Apply custom function
s.apply(lambda x: x * 2 if x > 25 else x)

DataFrame — The 2D Labelled Table

The central data structure — rows × columns with labels on both axes

A DataFrame is a 2D table where each column is a Series (sharing the same index). Think of it as an Excel spreadsheet or a SQL table — but in Python memory and infinitely more powerful.

Each column is a Series. All columns share the same row Index (0,1,2,3,4).

Selecting Data — loc, iloc, and Column Access

The most important skill: knowing exactly how to get the data you need

🎯 The Golden Rule
df.loc[row_label, col_label] ← by NAME (inclusive)
df.iloc[row_pos, col_pos] ← by NUMBER (exclusive)
loc uses LABELS. iloc uses INTEGER POSITIONS (like Python list indexing). Never mix them up!

Selecting Columns

PYTHON
# Single column → returns a Series
ages = df['Age']
ages = df.Age         # dot notation (only works for simple names)

# Multiple columns → returns a DataFrame
subset = df[['Name', 'Salary']]   # double brackets!
subset = df[['Name', 'Age', 'Dept']]

# Select columns by dtype
num_cols = df.select_dtypes(include='number')
str_cols = df.select_dtypes(include='object')

# Select columns by name pattern
df.filter(like='Sal')           # columns containing 'Sal'
df.filter(regex='^S')           # columns starting with 'S'

loc — Label-Based Selection

PYTHON
# df.loc[row_selector, column_selector]
# Both selectors are LABEL-based; slices are INCLUSIVE

# Single row by label
print(df.loc[0])          # row with index 0 (all columns)
print(df.loc[2, 'Name'])  # row 2, Name column → 'Carol'

# Slice rows — INCLUSIVE on both ends
print(df.loc[1:3])         # rows 1, 2, 3 (3 rows — includes 3!)

# Rows + specific columns
print(df.loc[0:2, ['Name', 'Salary']])

# All rows, specific columns
print(df.loc[:, 'Age':'Dept'])    # Age through Dept (inclusive)

# Boolean condition in loc
print(df.loc[df['Salary'] > 80000])
print(df.loc[df['City'] == 'Mumbai', ['Name','Salary']])

iloc — Position-Based Selection

PYTHON
# df.iloc[row_position, col_position]
# EXCLUSIVE on end (like Python slicing)

# Single cell
print(df.iloc[0, 0])      # first row, first col → 'Alice'
print(df.iloc[-1, -1])    # last row, last col

# Row slicing — exclusive on end
print(df.iloc[1:4])        # rows 1, 2, 3 (NOT 4)
print(df.iloc[::2])        # every 2nd row
print(df.iloc[::-1])       # all rows reversed

# Rows + columns
print(df.iloc[0:3, 1:4])   # rows 0-2, cols 1-3
print(df.iloc[:, [0,3]])   # all rows, cols 0 and 3

# Fancy integer array
print(df.iloc[[0,2,4]])     # rows 0, 2, 4 (1st, 3rd, 5th)
⚠️ loc vs iloc — The Critical Difference
  • loc[1:3] → rows with LABELS 1, 2, 3 (3 rows — includes 3!)
  • iloc[1:3] → rows at POSITIONS 1, 2 (2 rows — excludes 3!)
  • When index is integers (default), they look the same but work differently at the boundary.
  • For named indices (like 'Alice':'Carol'), only loc makes sense.

Filtering & Boolean Indexing

Selecting rows based on conditions — the workhorse of data analysis

Single Condition

PYTHON
# Create boolean mask
mask = df['Salary'] > 80000   # True/False Series
print(mask)
# 0     True
# 1    False
# 2     True
# 3     True
# 4    False

# Apply mask to filter rows
high_earners = df[mask]
high_earners = df[df['Salary'] > 80000]   # one-liner

# Other comparison operators
df[df['Age'] == 29]          # exact match
df[df['Dept'] != 'Marketing']  # not equal
df[df['Age'] >= 30]           # greater or equal

Multiple Conditions

PYTHON
# AND — use & (not 'and'), wrap each condition in ()
result = df[(df['Salary'] > 80000) & (df['Age'] < 35)]

# OR — use | (not 'or')
result = df[(df['City'] == 'Mumbai') | (df['City'] == 'Delhi')]

# NOT — use ~ (not 'not')
result = df[~(df['Dept'] == 'Marketing')]

# Combined
result = df[
    (df['Salary'] > 70000) &
    (df['Age'] < 40) &
    (df['Dept'] != 'Management')
]

Pandas-Specific Filter Methods

PYTHON
# isin() — match any of a list of values
df[df['City'].isin(['Mumbai', 'Delhi', 'Bangalore'])]

# between() — inclusive range
df[df['Age'].between(28, 35)]     # 28 ≤ Age ≤ 35

# str methods — filter on string patterns
df[df['Name'].str.startswith('A')]
df[df['Dept'].str.contains('Eng')]
df[df['City'].str.len() > 5]

# query() — SQL-like string syntax (clean & readable)
df.query('Salary > 80000 and Age < 35')
df.query('City == "Mumbai" or City == "Pune"')
df.query('Dept in ["Engineering", "Management"]')

# Use Python variable in query with @
min_sal = 75000
df.query('Salary > @min_sal')

# notna() / isna() — filter by null status
df[df['Salary'].notna()]   # rows where Salary is NOT null
df[df['Age'].isna()]       # rows where Age IS null
⚠️ Always Use & | ~ Not and or not
Python's and, or, not work on single values. For element-wise operations on Series, you MUST use &, |, ~. Also always wrap each condition in parentheses to avoid precedence errors.

import pandas as pd
import numpy  as np

rng = np.random.default_rng(42)

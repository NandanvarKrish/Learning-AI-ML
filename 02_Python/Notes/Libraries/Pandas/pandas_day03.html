GroupBy — Split, Apply, Combine

The single most powerful pattern in data analysis

GroupBy implements the "Split-Apply-Combine" pattern: split your data into groups based on a key, apply a function to each group independently, then combine the results back together.

🔀 Split → Apply → Combine
1. SPLIT → data grouped by 'Dept'
2. APPLY → mean() computed per group
3. COMBINE → results merged into one table
This is exactly what SQL's GROUP BY does — but with the full power of Python.

Basic GroupBy Operations

PYTHON
import pandas as pd

df = pd.DataFrame({
    'Dept'  :['Eng','Eng','HR','HR','Mktg','Mktg','Eng'],
    'Name'  :['Alice','Bob','Carol','Dave','Eve','Frank','Grace'],
    'Salary':[90000,85000,60000,65000,70000,72000,95000],
    'Bonus' :[9000,8500,3000,3250,3500,3600,9500]
})

# Create a groupby object (lazy — nothing computed yet)
grouped = df.groupby('Dept')
print(type(grouped))   # DataFrameGroupBy object

# Apply an aggregation
print(grouped['Salary'].mean())
# Dept
# Eng     90000.0
# HR      62500.0
# Mktg    71000.0

# One-liner (most common pattern)
print(df.groupby('Dept')['Salary'].mean())
print(df.groupby('Dept')['Salary'].sum())
print(df.groupby('Dept')['Salary'].count())
print(df.groupby('Dept')['Salary'].max())
print(df.groupby('Dept').size())   # row count per group (all cols)

# Group by MULTIPLE columns
df.groupby(['Dept', 'Name'])['Salary'].sum()

# Iterate over groups
for dept, group_df in df.groupby('Dept'):
    print(f"\n{dept}:")
    print(group_df)

# Get a specific group
eng_group = df.groupby('Dept').get_group('Eng')

Aggregating Multiple Columns / Multiple Functions

PYTHON
# Aggregate ALL numeric columns with one function
df.groupby('Dept').mean(numeric_only=True)

# Multiple statistics on one column with .agg()
df.groupby('Dept')['Salary'].agg(['mean', 'min', 'max', 'std', 'count'])
#         mean    min    max     std   count
# Eng    90000  85000  95000  5000.0      3
# HR     62500  60000  65000  3535.5      2
# Mktg   71000  70000  72000  1414.2      2

# Different functions per column — dict syntax
df.groupby('Dept').agg({
    'Salary': ['mean', 'max'],
    'Bonus' : 'sum',
    'Name'  : 'count'
})

# Named aggregation — clean column names in output (RECOMMENDED)
df.groupby('Dept').agg(
    avg_salary  = ('Salary', 'mean'),
    max_salary  = ('Salary', 'max'),
    total_bonus = ('Bonus', 'sum'),
    headcount   = ('Name', 'count')
).reset_index()

# Custom function with .agg()
df.groupby('Dept')['Salary'].agg(lambda x: x.max() - x.min())  # range per group

transform() vs apply() vs agg()

MethodOutput ShapeUse Case
agg()One row per group (shrinks)Summary statistics per group
transform()Same shape as original (broadcasts back)Add group stat as new column, keep all rows
apply()Flexible — can be eitherComplex custom group operations
filter()Subset of original rowsKeep only groups matching a condition
PYTHON
# transform() — add group-level stat back to EVERY row
df['DeptAvgSalary'] = df.groupby('Dept')['Salary'].transform('mean')
print(df[['Name','Dept','Salary','DeptAvgSalary']])
# Alice  Eng  90000   90000.0
# Bob    Eng  85000   90000.0   ← same avg for all Eng rows!
# Carol  HR   60000   62500.0
# ...

# Common use: how much above/below department average?
df['SalaryVsDeptAvg'] = df['Salary'] - df['DeptAvgSalary']

# filter() — keep only groups matching a condition
big_depts = df.groupby('Dept').filter(lambda g: len(g) >= 2)  # depts with 2+ people

# apply() — full custom logic per group
def top_earner(group):
    return group.nlargest(1, 'Salary')

top_per_dept = df.groupby('Dept').apply(top_earner)
💡 agg() vs transform() — The Key Difference
groupby('Dept')['Salary'].agg('mean') returns 3 rows (one per department). groupby('Dept')['Salary'].transform('mean') returns 7 rows (same as original data) — the group mean repeated for every row in that group. Use transform() when you want to add a group stat as a new column.

Merging DataFrames — SQL-Style Joins

Combine two datasets based on common columns

pd.merge() combines two DataFrames based on common key columns — exactly like SQL JOIN. This is essential when your data is split across multiple tables (customers table, orders table, products table).

The 4 Join Types — Visual Guide

INNER
Only rows with matching keys in BOTH tables
LEFT
All rows from left + matches from right (NaN if no match)
RIGHT
All rows from right + matches from left
OUTER
ALL rows from both — NaN where no match

Merge in Practice

PYTHON
customers = pd.DataFrame({
    'CustID': [1, 2, 3, 4],
    'Name'  : ['Alice','Bob','Carol','Dave']
})

orders = pd.DataFrame({
    'OrderID': [101,102,103,104],
    'CustID' : [1, 2, 2, 5],       # note: CustID 5 doesn't exist in customers!
    'Amount' : [500, 750, 300, 200]
})

# INNER join (default) — only matching CustIDs
print(pd.merge(customers, orders, on='CustID', how='inner'))
#    CustID   Name  OrderID  Amount
# 0       1  Alice      101     500
# 1       2    Bob      102     750
# 2       2    Bob      103     300
# (Carol and Dave have no orders — excluded. Order 104's CustID=5 excluded.)

# LEFT join — keep ALL customers, even without orders
print(pd.merge(customers, orders, on='CustID', how='left'))
#    CustID   Name  OrderID  Amount
# 0       1  Alice    101.0   500.0
# 1       2    Bob    102.0   750.0
# 2       2    Bob    103.0   300.0
# 3       3  Carol      NaN     NaN   ← Carol kept, no order
# 4       4   Dave      NaN     NaN   ← Dave kept, no order

# RIGHT join — keep ALL orders, even unmatched customers
pd.merge(customers, orders, on='CustID', how='right')

# OUTER join — everything from both sides
pd.merge(customers, orders, on='CustID', how='outer')

# Different column names on each side
pd.merge(customers, orders, left_on='CustID', right_on='CustID')

# Merge on multiple keys
pd.merge(df1, df2, on=['Year', 'Month'])

# Merge on the index
pd.merge(df1, df2, left_index=True, right_index=True)

# Suffix control for overlapping column names
pd.merge(df1, df2, on='ID', suffixes=('_old', '_new'))

# indicator=True — shows which side each row came from
merged = pd.merge(customers, orders, on='CustID', how='outer', indicator=True)
print(merged['_merge'].value_counts())   # both / left_only / right_only

join() — Merge on Index (Shortcut)

PYTHON
df1 = pd.DataFrame({'A':[1,2,3]}, index=['x','y','z'])
df2 = pd.DataFrame({'B':[10,20]}, index=['x','y'])

# join() merges on the INDEX by default
print(df1.join(df2))            # left join by default
print(df1.join(df2, how='inner'))
⚠️ Always Verify Merge Results
A common bug: unexpected row multiplication. If CustID 2 appears twice in orders, merging duplicates Bob's row for each order. Always check len(merged) against expectations, and use validate='one_to_many' parameter to catch unexpected duplicates.

Concatenating DataFrames

Stack DataFrames vertically or horizontally — no key matching needed

Use pd.concat() when you want to simply stack DataFrames together — like combining monthly sales files into one yearly file. Unlike merge, concat doesn't match on keys; it just glues data together.

PYTHON
jan = pd.DataFrame({'Product':['A','B'], 'Sales':[100,200]})
feb = pd.DataFrame({'Product':['A','B'], 'Sales':[150,180]})

# Vertical stack (axis=0, default) — combine rows
combined = pd.concat([jan, feb], ignore_index=True)
print(combined)
#   Product  Sales
# 0       A    100
# 1       B    200
# 2       A    150   ← Feb data continues
# 3       B    180

# Keep track of source with keys
combined2 = pd.concat([jan, feb], keys=['Jan', 'Feb'])
print(combined2)   # MultiIndex: (Jan,0), (Jan,1), (Feb,0), (Feb,1)

# Horizontal stack (axis=1) — combine columns side by side
df_a = pd.DataFrame({'X':[1,2,3]})
df_b = pd.DataFrame({'Y':[4,5,6]})
print(pd.concat([df_a, df_b], axis=1))
#    X  Y
# 0  1  4
# 1  2  5
# 2  3  6

# Concat with mismatched columns
df_x = pd.DataFrame({'A':[1,2], 'B':[3,4]})
df_y = pd.DataFrame({'B':[5,6], 'C':[7,8]})
print(pd.concat([df_x, df_y]))       # outer join by default — fills NaN for missing cols
print(pd.concat([df_x, df_y], join='inner'))  # only keeps common column 'B'

# Real pattern: combine 12 monthly CSVs
import glob
all_files = glob.glob('sales_2024_*.csv')
all_months = pd.concat([pd.read_csv(f) for f in all_files], ignore_index=True)

Pivot Tables — Excel-Style Summarisation

Reshape long data into a summary grid — the Pandas equivalent of Excel PivotTables

pivot_table() — Aggregating Grid View

PYTHON
sales = pd.DataFrame({
    'Region'  :['North','North','South','South','North','South'],
    'Product' :['A','B','A','B','A','A'],
    'Quarter' :['Q1','Q1','Q1','Q1','Q2','Q2'],
    'Revenue' :[1000,1500,800,1200,1100,900]
})

# Basic pivot: Region as rows, Product as columns, mean Revenue as values
pivot = pd.pivot_table(sales,
                       values='Revenue',
                       index='Region',
                       columns='Product',
                       aggfunc='sum')
print(pivot)
# Product     A       B
# Region
# North    2100.0  1500.0
# South    1700.0  1200.0

# Multiple index levels
pd.pivot_table(sales, values='Revenue',
                index=['Region','Quarter'], columns='Product', aggfunc='sum')

# Multiple aggregations at once
pd.pivot_table(sales, values='Revenue', index='Region',
                columns='Product', aggfunc=['sum','mean','count'])

# Fill missing combinations with 0 instead of NaN
pd.pivot_table(sales, values='Revenue', index='Region',
                columns='Product', aggfunc='sum', fill_value=0)

# Add row/column totals
pd.pivot_table(sales, values='Revenue', index='Region',
                columns='Product', aggfunc='sum', margins=True, margins_name='Total')

pivot() — Reshape Without Aggregation

PYTHON
# pivot() requires UNIQUE index+columns combinations (no aggregation)
# Use when each (row, col) pair has exactly ONE value

wide = sales.pivot(index='Region', columns='Quarter', values='Revenue')
# Raises error if duplicates exist for same Region+Quarter — use pivot_table instead

# crosstab — frequency counts between two categorical columns
pd.crosstab(sales['Region'], sales['Product'])
# Product  A  B
# Region
# North    2  1
# South    2  1

# crosstab with normalisation (percentages)
pd.crosstab(sales['Region'], sales['Product'], normalize='index')  # row %

Melt, Stack & Unstack — Wide ↔ Long

Reshape between wide format (many columns) and long/tidy format (few columns, many rows)

🔃 Wide vs Long Format
WIDE: Name | Q1 | Q2 | Q3 | Q4
LONG: Name | Quarter | Value
Wide is good for viewing. Long/"tidy" format is required for most plotting libraries (Seaborn) and statistical models.

melt() — Wide to Long

PYTHON
wide_df = pd.DataFrame({
    'Name': ['Alice', 'Bob'],
    'Q1'  : [100, 150],
    'Q2'  : [120, 130],
    'Q3'  : [140, 160],
    'Q4'  : [160, 170]
})

# Melt: turn Q1-Q4 columns into rows
long_df = pd.melt(wide_df,
                  id_vars='Name',               # column(s) to KEEP as-is
                  value_vars=['Q1','Q2','Q3','Q4'],  # columns to MELT
                  var_name='Quarter',           # name for the new label column
                  value_name='Revenue')         # name for the new value column
print(long_df)
#     Name Quarter  Revenue
# 0  Alice      Q1      100
# 1    Bob      Q1      150
# 2  Alice      Q2      120
# 3    Bob      Q2      130
# ... 8 rows total (2 names × 4 quarters)

# Shortcut — melts everything except id_vars automatically
pd.melt(wide_df, id_vars='Name')

pivot() — Long to Wide (Reverse of Melt)

PYTHON
# Go back from long to wide
back_to_wide = long_df.pivot(index='Name', columns='Quarter', values='Revenue')
print(back_to_wide)
# Quarter   Q1   Q2   Q3   Q4
# Name
# Alice    100  120  140  160
# Bob      150  130  160  170

# Reset to make Name a column again
back_to_wide = back_to_wide.reset_index()

stack() & unstack() — MultiIndex Reshaping

PYTHON
# stack() — columns become an inner index level (wide → long)
df = pd.DataFrame({'Q1':[100,150], 'Q2':[120,130]},
                  index=['Alice','Bob'])

stacked = df.stack()
print(stacked)
# Alice  Q1    100
#        Q2    120
# Bob    Q1    150
#        Q2    130
# dtype: int64   ← now a Series with MultiIndex

# unstack() — reverse: inner index level becomes columns
unstacked = stacked.unstack()
print(unstacked)   # back to original wide DataFrame

# unstack on a groupby result — very common pattern!
sales_grouped = sales.groupby(['Region','Product'])['Revenue'].sum()
print(sales_grouped.unstack())    # turns Product index level into columns
# (equivalent to pivot_table in this case)

Real-World Task — Multi-Table Sales Analytics

Estimated time: 85–100 minutes  |  Difficulty: ⭐⭐⭐⭐

📋 Project Brief

You are a BI Analyst at RetailPlus. The company's data lives in 3 separate tables (like a real database): Customers, Products, and Orders. Your job is to merge everything into one analytical dataset, then use groupby and pivot tables to answer executive questions about sales performance.

1

Phase 1 — Build the 3 Related Tables

~15 min ▼
1
Create Customers, Products, and Orders Tables
STARTER CODE
import pandas as pd
import numpy  as np

rng = np.random.default_rng(7)

# Table 1: Customers (30 customers)
customers = pd.DataFrame({
    'CustID' : range(1, 31),
    'Name'   : [f'Customer_{i}' for i in range(1,31)],
    'City'   : rng.choice(['Mumbai','Delhi','Bangalore','Pune'], 30),
    'Segment': rng.choice(['Retail','Wholesale','Online'], 30)
})

# Table 2: Products (10 products)
products = pd.DataFrame({
    'ProductID': range(101, 111),
    'ProductName': ['Laptop','Mouse','Keyboard','Monitor','Headset',
                     'Webcam','Desk','Chair','Cable','Charger'],
    'Category' : ['Electronics','Electronics','Electronics','Electronics','Electronics',
                     'Electronics','Furniture','Furniture','Accessories','Accessories'],
    'UnitPrice': [65000,800,2500,12000,3500,2000,8000,15000,300,1200]
})

# Table 3: Orders (500 orders) — some CustIDs deliberately invalid (churned customers)
n_orders = 500
orders = pd.DataFrame({
    'OrderID'  : range(1001, 1001+n_orders),
    'CustID'   : rng.choice(list(range(1,33)), n_orders),  # 31,32 don't exist!
    'ProductID': rng.choice(range(101,111), n_orders),
    'Quantity' : rng.integers(1, 6, n_orders),
    'OrderDate': pd.to_datetime('2024-01-01') + pd.to_timedelta(rng.integers(0,365,n_orders), unit='D')
})

print(f"Customers: {customers.shape}, Products: {products.shape}, Orders: {orders.shape}")

Phase 2 — Merge Into One Master Table

~20 min ▼
1
Build the Master Analytical Table

Merge Orders + Customers + Products into a single wide table. Decide carefully which join type to use — you want to KEEP all orders even if the customer record is missing (to catch data quality issues).

CODE
# Merge orders with customers (LEFT join — keep all orders)
master = orders.merge(customers, on='CustID', how='left', indicator='cust_match')

# Check for orders with no matching customer (data quality issue!)
missing_cust = master[master['cust_match'] == 'left_only']
print(f"Orders with invalid CustID: {len(missing_cust)}")
print(missing_cust['CustID'].unique())

# Merge with products
master = master.merge(products, on='ProductID', how='left')
master = master.drop(columns=['cust_match'])

# Add computed Revenue column
master['Revenue'] = master['Quantity'] * master['UnitPrice']

print(f"Master table: {master.shape}")
master.info()

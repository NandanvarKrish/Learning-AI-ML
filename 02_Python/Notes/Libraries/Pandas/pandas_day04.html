Working with Dates & Times

pd.Timestamp, pd.to_datetime, and datetime attributes

Pandas has first-class datetime support built on top of NumPy's datetime64. The Timestamp object represents a single point in time, and Timedelta represents a duration.

Creating and Parsing Dates

PYTHON
import pandas as pd

# Single timestamp
ts = pd.Timestamp('2024-03-15')
print(ts)              # 2024-03-15 00:00:00
print(ts.year, ts.month, ts.day)   # 2024 3 15
print(ts.day_name())   # Friday

# Parse a Series of date strings — handles many formats
dates = pd.to_datetime(['2024-01-15', '2024-02-20', '15/03/2024'])
print(dates)

# Explicit format for speed & correctness
pd.to_datetime('15-03-2024', format='%d-%m-%Y')

# Bad dates → NaT instead of crashing
pd.to_datetime(['2024-01-15', 'not a date'], errors='coerce')

# Date ranges — generate sequences of dates
pd.date_range(start='2024-01-01', end='2024-01-10')         # daily
pd.date_range(start='2024-01-01', periods=12, freq='MS')     # 12 month starts
pd.date_range(start='2024-01-01', periods=10, freq='B')      # business days
pd.date_range(start='2024-01-01', periods=5, freq='W')       # weekly

The .dt Accessor — Extract Date Components

PYTHON
df = pd.DataFrame({'OrderDate': pd.to_datetime(['2024-01-15','2024-06-20','2024-12-25'])})

df['Year']     = df['OrderDate'].dt.year
df['Month']    = df['OrderDate'].dt.month
df['MonthName']= df['OrderDate'].dt.month_name()
df['Day']      = df['OrderDate'].dt.day
df['DayName']  = df['OrderDate'].dt.day_name()
df['Quarter']  = df['OrderDate'].dt.quarter
df['WeekOfYear']=df['OrderDate'].dt.isocalendar().week
df['IsWeekend']= df['OrderDate'].dt.dayofweek >= 5   # Sat=5, Sun=6
df['DaysInMonth']=df['OrderDate'].dt.days_in_month

print(df)

# Timedelta arithmetic
df['NextWeek'] = df['OrderDate'] + pd.Timedelta(days=7)
df['LastMonth'] = df['OrderDate'] - pd.DateOffset(months=1)

# Difference between dates
delivery = pd.to_datetime(['2024-01-20','2024-06-25','2025-01-02'])
df['DaysToDeliver'] = (delivery - df['OrderDate']).dt.days

DatetimeIndex — Dates as the Index

The foundation of all time series operations

To unlock resampling, rolling windows, and easy date slicing, set your date column as the DataFrame's index. This turns the DataFrame into a proper time series.

PYTHON
rng_dates = pd.date_range('2024-01-01', periods=10, freq='D')
df = pd.DataFrame({'Date': rng_dates, 'Sales': [100,120,90,150,130,110,160,140,125,135]})

# Set Date as index
df = df.set_index('Date')
print(df.index)   # DatetimeIndex(['2024-01-01', ...], dtype='datetime64[ns]')

# Slice by DATE STRING — extremely convenient!
print(df.loc['2024-01-05'])              # single day
print(df.loc['2024-01-03':'2024-01-07']) # date range (inclusive!)

# Slice by partial date — whole month/year at once
sales_2024 = pd.DataFrame({'Sales':range(365)},
    index=pd.date_range('2024-01-01', periods=365))
print(sales_2024.loc['2024-03'])       # all of March
print(sales_2024.loc['2024'].shape)   # all of 2024

# between_time — filter by time of day (needs actual timestamps)
# at_time — filter for a specific time each day

# asfreq — convert to a fixed frequency (introduces NaN if data missing)
sales_2024.asfreq('W')   # resample to weekly index, keeping only matching dates
💡 Timezone Handling
df.tz_localize('Asia/Kolkata') assigns a timezone to naive timestamps. df.tz_convert('UTC') converts between timezones. Always be explicit about timezones when working with international data.

Resampling — Changing Time Frequency

Aggregate daily data into weekly/monthly, or expand sparse data

Resampling changes the frequency of time series data. Downsampling (daily→monthly) aggregates multiple periods into one. Upsampling (monthly→daily) creates more periods, needing fill logic.

🔃 resample() vs groupby()
resample('M').sum() → groups by calendar month, aggregates
resample() is groupby() specialised for time — it understands calendar rules (months have different lengths, etc).
PYTHON
rng_daily = pd.date_range('2024-01-01', periods=90, freq='D')
sales = pd.DataFrame({'Revenue': np.random.randint(1000,5000,90)}, index=rng_daily)

# DOWNSAMPLE: daily → weekly (sum revenue per week)
weekly = sales.resample('W').sum()
print(weekly.head())

# DOWNSAMPLE: daily → monthly, multiple stats
monthly = sales.resample('M').agg(['sum','mean','min','max'])
print(monthly)

# Different aggregations per column
sales['Orders'] = np.random.randint(10,50,90)
sales.resample('M').agg({'Revenue':'sum', 'Orders':'mean'})

# UPSAMPLE: monthly → daily (need to fill the gaps)
monthly_data = pd.DataFrame({'Value':[100,200,150]},
    index=pd.date_range('2024-01-01', periods=3, freq='MS'))
daily_upsampled = monthly_data.resample('D').ffill()   # forward fill gaps
daily_interp    = monthly_data.resample('D').interpolate()  # smooth interpolation

Rolling & Expanding Windows

Moving averages, trend smoothing, and cumulative windows

rolling() — Fixed-Size Sliding Window

PYTHON
prices = pd.Series([100,102,98,105,110,108,115,112,120,118],
                   index=pd.date_range('2024-01-01', periods=10))

# 3-day Simple Moving Average
print(prices.rolling(window=3).mean())
# First 2 values are NaN (not enough data yet for a 3-window)

# Common technical indicators
sma_5  = prices.rolling(5).mean()      # 5-day moving average
std_5  = prices.rolling(5).std()       # 5-day rolling volatility
max_5  = prices.rolling(5).max()       # 5-day rolling high
min_5  = prices.rolling(5).min()       # 5-day rolling low

# Bollinger Bands (common finance indicator)
sma_20 = prices.rolling(5).mean()
std_20 = prices.rolling(5).std()
upper_band = sma_20 + 2 * std_20
lower_band = sma_20 - 2 * std_20

# min_periods — allow partial windows at the start
prices.rolling(window=5, min_periods=1).mean()   # no leading NaN

# Custom function on rolling window
prices.rolling(3).apply(lambda x: x.max() - x.min())   # rolling range

# Rolling on time-based window (not row count!)
prices.rolling('3D').mean()   # mean over the trailing 3 calendar days

expanding() — Growing Cumulative Window

PYTHON
# expanding() includes ALL prior data, growing each step
print(prices.expanding().mean())
# Day1: mean(100)
# Day2: mean(100,102)
# Day3: mean(100,102,98)
# ... window keeps growing, never resets

# Common use: cumulative running average, year-to-date totals
sales_ytd = prices.expanding().sum()    # running total
max_so_far = prices.expanding().max()  # all-time high up to each point

# Comparison: cumsum/cummax do similar simple jobs
prices.cumsum()    # running total (like expanding().sum())
prices.cummax()    # running maximum
prices.cummin()    # running minimum
prices.cumprod()   # running product

# Exponentially Weighted Moving Average — recent data matters more
ema = prices.ewm(span=5).mean()
print(ema)

Shift, Lag & Percentage Change

Compare a value to its past or future — the core of trend analysis

PYTHON
sales = pd.Series([100,110,105,120,130],
                  index=pd.date_range('2024-01-01', periods=5, freq='MS'))

# shift() — move values forward/backward by n periods
print(sales.shift(1))    # [NaN, 100, 110, 105, 120]  ← previous month's value
print(sales.shift(-1))   # [110, 105, 120, 130, NaN] ← next month's value

# Common use: Month-over-Month change
mom_change = sales - sales.shift(1)
mom_pct    = sales.pct_change()          # % change vs previous period — built-in!
print(mom_pct)
# Jan    NaN
# Feb    0.1000  ← 10% growth
# Mar   -0.0455  ← -4.5% decline
# Apr    0.1429
# May    0.0833

# Year-over-Year comparison (shift by 12 for monthly data)
# yoy_change = monthly_sales - monthly_sales.shift(12)

# diff() — difference from n periods ago
print(sales.diff())        # same as sales - sales.shift(1)
print(sales.diff(periods=2))   # difference from 2 periods ago

# Shift the INDEX instead of values (time shift)
sales.shift(1, freq='MS')   # shifts dates forward by 1 month, values stay aligned
✅ pct_change() is a One-Liner for Growth Rates
Instead of manually computing (current - previous) / previous, just use series.pct_change(). Use periods=12 for year-over-year growth on monthly data, or periods=4 for quarterly YoY.

MultiIndex — Hierarchical Indexing

Multiple index levels for richer, more structured data

A MultiIndex allows a DataFrame to have multiple levels of row (or column) labels — useful for grouped time series, panel data, and pivot table outputs.

PYTHON
# Creating a MultiIndex DataFrame
df = pd.DataFrame({
    'Region' :['North','North','South','South'],
    'Quarter':['Q1','Q2','Q1','Q2'],
    'Revenue':[1000,1200,800,950]
}).set_index(['Region','Quarter'])

print(df)
#                 Revenue
# Region Quarter
# North  Q1          1000
#        Q2          1200
# South  Q1           800
#        Q2           950

# Access outer level
print(df.loc['North'])          # all North rows

# Access specific combination
print(df.loc[('North', 'Q1')])   # single row → Series
print(df.loc[[('North','Q1'), ('South','Q2')]])

# xs() — cross-section, select by inner level across all outer groups
print(df.xs('Q1', level='Quarter'))   # Q1 for BOTH North and South

# Swap level order
df_swapped = df.swaplevel()
print(df_swapped.sort_index())

# Flatten MultiIndex back to columns
flat = df.reset_index()

# MultiIndex columns (from pivot_table with multiple aggfuncs)
pivot = pd.pivot_table(flat, values='Revenue', index='Region',
                       columns='Quarter', aggfunc=['sum','mean'])
print(pivot.columns)   # MultiIndex: [('sum','Q1'), ('sum','Q2'), ('mean','Q1'), ...]
print(pivot['sum']['Q1'])   # access nested column levels

# Flatten MultiIndex columns to single strings
pivot.columns = ['_'.join(col) for col in pivot.columns]
💡 Where MultiIndex Comes From
MultiIndex naturally appears from: groupby() with multiple keys, set_index() with multiple columns, and pivot_table() with multiple aggregation functions or index/column levels. Use reset_index() anytime you want to flatten it back to regular columns.

📋 Project Brief

You are a Quant Analyst at Meridian Capital. Build a complete time-series analysis pipeline for 2 years of daily stock data across 3 companies — covering resampling, moving averages, trend detection, and a full MultiIndex report.

Phase 1 — Generate Time Series Data

~15 min▼
1
Build a Daily Multi-Stock Dataset
STARTER CODE
import pandas as pd
import numpy  as np

rng = np.random.default_rng(11)
dates = pd.date_range('2023-01-01', '2024-12-31', freq='B')  # business days
companies = ['TechCo', 'HealthX', 'EnergyPlus']
start_prices = {'TechCo':500, 'HealthX':250, 'EnergyPlus':180}

frames = []
for co in companies:
    returns = rng.normal(0.0004, 0.015, len(dates))
    prices  = start_prices[co] * np.cumprod(1 + returns)
    volume  = rng.integers(10000, 500000, len(dates))
    frames.append(pd.DataFrame({'Date':dates, 'Company':co, 'Price':prices, 'Volume':volume}))

stocks = pd.concat(frames, ignore_index=True)
print(f"Shape: {stocks.shape}")
stocks.info()

stocks['GoldenCross'] = (stocks.groupby('Company')['AboveCross'].diff() == True)
print(stocks[stocks['GoldenCross']][['Date','Company','Price']])

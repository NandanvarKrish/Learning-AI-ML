Understanding & Detecting Missing Values

NaN, None, NaT — know your missing data before fixing it

Real datasets almost always have missing data. Pandas represents missing values as NaN (Not a Number for floats), None (for objects), and NaT (Not a Time for dates). Learning to detect, measure, and handle them is the #1 data cleaning skill.

⚠️ Why Missing Data Matters
Most statistical functions (mean, std, correlation) silently ignore NaN — which can give misleading results. ML models crash or produce wrong predictions on NaN. You MUST understand and handle missing data before any analysis.

Detecting Missing Values

PYTHON
import pandas as pd
import numpy  as np

df = pd.DataFrame({
    'Name'  :['Alice', 'Bob', None, 'Dave', 'Eve'],
    'Age'   :[28, np.nan, 29, 42, 31],
    'Salary':[85000, 72000, np.nan, 105000, 68000],
    'City'  :['Mumbai','Delhi','Bangalore', np.nan,'Pune'],
    'Rating':[4.5, np.nan, 3.8, 4.9, np.nan]
})

# ── Detection methods ──────────────────────────────
print(df.isnull())           # True/False per cell
print(df.isna())             # same (alias)
print(df.notnull())          # opposite — True where NOT null

# Count per column
print(df.isnull().sum())
# Name      1
# Age       1
# Salary    1
# City      1
# Rating    2

# Percentage missing per column
miss_pct = df.isnull().mean() * 100
print(miss_pct.round(1))

# Total missing in whole DataFrame
print(df.isnull().sum().sum())   # 6

# Rows with ANY missing value
rows_with_nan = df[df.isnull().any(axis=1)]
print(f"Rows with at least 1 NaN: {len(rows_with_nan)}")  # 4

# Columns with ANY missing value
cols_with_nan = df.columns[df.isnull().any()]
print(cols_with_nan)

# Rows where ALL values are missing
all_null_rows = df[df.isnull().all(axis=1)]

Dropping Missing Values & Duplicates

When to remove data entirely — and how to do it precisely

dropna() — Remove Rows or Columns with NaN

PYTHON
# Drop rows with ANY NaN (default)
df_clean = df.dropna()
print(f"Before: {len(df)}, After: {len(df_clean)}")   # 5 → 1 (only Alice!)

# Drop rows only if ALL values are NaN
df.dropna(how='all')

# Drop rows with NaN in SPECIFIC columns only
df.dropna(subset=['Age', 'Salary'])   # only drop if Age OR Salary is null

# Require at least N non-null values to keep the row
df.dropna(thresh=4)   # keep rows with at least 4 non-null values

# Drop COLUMNS with any NaN
df.dropna(axis=1)             # axis=1 means columns
df.dropna(axis='columns')    # same

# inplace — modify original instead of returning new
df.dropna(subset=['Salary'], inplace=True)

# IMPORTANT: Pandas returns a copy by default
# Use inplace=True OR reassign: df = df.dropna()

Handling Duplicate Rows

PYTHON
df = pd.DataFrame({
    'Name'  :['Alice','Bob','Alice','Carol','Bob','Dave'],
    'Dept'  :['Eng','HR','Eng','Mktg','HR','Eng'],
    'Salary':[90000,60000,90000,75000,60000,95000]
})

# Detect duplicates
print(df.duplicated())              # True where row is a duplicate
print(df.duplicated().sum())       # 2 (Alice+Eng+90k and Bob+HR+60k)

# Show the duplicate rows
print(df[df.duplicated()])

# Show ALL versions (first + duplicates)
print(df[df.duplicated(keep=False)])

# Drop duplicates (keep first occurrence by default)
df_unique = df.drop_duplicates()
print(f"After drop: {len(df_unique)}")   # 4

# Keep last occurrence
df.drop_duplicates(keep='last')

# Drop duplicates based on SUBSET of columns only
df.drop_duplicates(subset=['Name'])        # unique names only
df.drop_duplicates(subset=['Name','Dept']) # unique Name+Dept combos

# Drop specific rows by index label
df.drop(index=[0, 2])          # drop rows 0 and 2
df.drop(index=df[df['Salary'] < 65000].index)  # drop low earners

# Drop specific columns
df.drop(columns=['Salary'])           # drop Salary column
df.drop(columns=['Dept','Salary'])   # drop multiple
⚠️ Dropping Too Aggressively
dropna() with default settings drops ANY row with a single NaN — which can delete most of your data! Always check what you'll lose first: df.isnull().sum() and df.dropna().shape before committing.

Filling & Imputing Missing Values

Replace NaN intelligently — the smarter alternative to dropping

fillna() — The Primary Tool

PYTHON
df = pd.DataFrame({
    'Name'  :['Alice','Bob',None,'Dave','Eve'],
    'Age'   :[28, np.nan, 29, 42, 31],
    'Salary':[85000, 72000, np.nan, 105000, 68000],
    'Dept'  :['Eng','HR',None,'Eng','HR']
})

# Fill with a constant
df['Name'].fillna('Unknown')
df['Age'].fillna(0)

# Fill with column mean (best for numeric data)
df['Age'].fillna(df['Age'].mean())
df['Salary'].fillna(df['Salary'].median())  # median for skewed data

# Fill with column mode (best for categorical)
df['Dept'].fillna(df['Dept'].mode()[0])    # mode()[0] = most common

# Fill multiple columns at once with a dict
df.fillna({
    'Name'  : 'Unknown',
    'Age'   : df['Age'].mean(),
    'Salary': df['Salary'].median(),
    'Dept'  : 'Not Assigned'
})

Forward Fill & Backward Fill — For Sequential Data

PYTHON
sales = pd.Series([100, np.nan, np.nan, 150, np.nan])

# Forward fill — carry last valid value forward
print(sales.ffill())    # [100, 100, 100, 150, 150]

# Backward fill — carry next valid value backward
print(sales.bfill())    # [100, 150, 150, 150, NaN]

# Limit how many consecutive NaNs to fill
print(sales.ffill(limit=1))  # [100, 100, NaN, 150, 150]  ← only 1 consecutive

# On a DataFrame — fill along rows or columns
df.ffill(axis=0)   # fill down each column
df.ffill(axis=1)   # fill across each row

# Old syntax (still works)
sales.fillna(method='ffill')
sales.fillna(method='bfill')

Data Type Conversion — astype & to_numeric

Fix wrong dtypes — the silent destroyer of correct analysis

Wrong dtypes are extremely common when reading CSV files. A column of numbers stored as strings will give you string concatenation instead of addition! Always check df.dtypes and fix them early.

astype() — Convert Column Type

PYTHON
df = pd.DataFrame({
    'ID'    : ['1', '2', '3'],        # should be int
    'Age'   : ['28', '34', '29'],      # should be int
    'Salary': ['85000.0', '72000', '91000'],  # should be float
    'Active': ['True', 'False', 'True'],   # should be bool
    'Score' : [92.5, 78.3, 85.0]           # already float — convert to int
})

print(df.dtypes)   # all 'object' — classic CSV problem!

# Convert individual columns
df['ID']     = df['ID'].astype(int)
df['Age']    = df['Age'].astype(int)
df['Salary'] = df['Salary'].astype(float)
df['Score']  = df['Score'].astype(int)       # 92.5 → 92 (truncates!)
df['Active'] = df['Active'].astype(bool)     # ⚠️ 'False' str → True! (non-empty)

# Better boolean conversion
df['Active'] = df['Active'].map({'True':True, 'False':False})

# Convert to category — saves memory for repeated strings
df['Dept'] = df['Dept'].astype('category')

# Convert all at once with a dict
df = df.astype({'ID':int, 'Age':int, 'Salary':float})

pd.to_numeric() — Handles Errors Gracefully

PYTHON
messy = pd.Series(['100', '200', 'N/A', '300', 'abc', '400'])

# astype(float) would CRASH on 'N/A' and 'abc'
# pd.to_numeric with errors='coerce' converts bad values to NaN
clean = pd.to_numeric(messy, errors='coerce')
print(clean)
# 0    100.0
# 1    200.0
# 2      NaN   ← 'N/A' coerced to NaN
# 3    300.0
# 4      NaN   ← 'abc' coerced to NaN
# 5    400.0

# errors options:
#  'raise'  → default — raises ValueError on bad input
#  'coerce' → bad values become NaN  ← use this for messy data
#  'ignore' → bad values stay as-is (string remains)

# pd.to_datetime() — parse date strings
dates = pd.Series(['2024-01-15', '15/01/2024', 'Jan 15 2024'])
print(pd.to_datetime(dates))                        # auto-detect format
print(pd.to_datetime(dates, format='%Y-%m-%d'))      # explicit format
print(pd.to_datetime(dates, errors='coerce'))         # NaT for unparseable

# Downcasting — save memory with smaller dtypes
df['Age'] = pd.to_numeric(df['Age'], downcast='integer')  # int64→int8 if fits

String Cleaning with .str Accessor

Fix messy text — trim whitespace, fix case, split, extract, replace

The .str accessor lets you apply string methods to every element of a Series at once — no loops needed. It's one of Pandas' most powerful features for text cleaning.

Essential String Operations

PYTHON
names = pd.Series(['  alice ', 'BOB', 'Carol  ', '  DAVE', 'eve'])

# ── Case ──────────────────────────────────────────
print(names.str.lower())      # ['  alice ', 'bob', 'carol  ', '  dave', 'eve']
print(names.str.upper())      # ['  ALICE ', 'BOB', ...]
print(names.str.title())      # ['  Alice ', 'Bob', ...]
print(names.str.capitalize()) # first char upper only

# ── Whitespace ────────────────────────────────────
print(names.str.strip())      # remove leading AND trailing spaces
print(names.str.lstrip())     # remove leading spaces only
print(names.str.rstrip())     # remove trailing spaces only

# ── Combining (chain operations) ──────────────────
clean = names.str.strip().str.title()
print(clean)   # ['Alice', 'Bob', 'Carol', 'Dave', 'Eve'] ✅

# ── Finding & Checking ─────────────────────────────
emails = pd.Series(['alice@gmail.com', 'bob@company.org', 'invalid'])
print(emails.str.contains('@'))         # [True, True, False]
print(emails.str.startswith('alice'))   # [True, False, False]
print(emails.str.endswith('.com'))      # [True, False, False]
print(emails.str.len())                 # [15, 15, 7]

# ── Replace ───────────────────────────────────────
phones = pd.Series(['(022) 1234-5678', '(011) 9876-5432'])
clean_phones = phones.str.replace('[()\\- ]', '', regex=True)
print(clean_phones)   # ['02212345678', '01198765432']

# ── Splitting ─────────────────────────────────────
full_names = pd.Series(['Alice Smith', 'Bob Jones', 'Carol Brown'])
split = full_names.str.split(' ', expand=True)  # expand=True → DataFrame
print(split)
#         0       1
# 0   Alice   Smith
# 1     Bob   Jones
# 2   Carol   Brown

df['FirstName'] = full_names.str.split(' ').str[0]  # 'Alice', 'Bob', 'Carol'
df['LastName']  = full_names.str.split(' ').str[1]  # 'Smith', 'Jones', 'Brown'

# ── Extracting with Regex ─────────────────────────
data = pd.Series(['ID:1001 Name:Alice', 'ID:1002 Name:Bob'])
print(data.str.extract(r'ID:(\d+)'))       # extract the ID number
print(data.str.extract(r'Name:(\w+)'))     # extract the name

# ── Padding ───────────────────────────────────────
ids = pd.Series(['1', '22', '333'])
print(ids.str.zfill(5))      # ['00001', '00022', '00333']
print(ids.str.pad(5, side='left', fillchar='0'))  # same

Replacing Values, Renaming & Reindexing

Fix inconsistent values, rename columns, reset the index

replace() — Fix Inconsistent Values

PYTHON
df = pd.DataFrame({
    'Gender':['M','F','Male','Female','m','f','MALE'],
    'Status':['Active','active','1','Inactive','0','Yes','No'],
    'Score' :[-1, 85, 999, 72, 91, -99, 88]   # -1 and 999 = error codes
})

# Replace single value
df['Gender'].replace('M', 'Male')

# Replace multiple values with a dict
df['Gender'] = df['Gender'].replace({
    'M':'Male', 'm':'Male', 'MALE':'Male',
    'F':'Female', 'f':'Female'
})

# Cleaner: normalise case first, then replace
df['Gender'] = df['Gender'].str.lower().replace({'m':'Male', 'f':'Female',
                                                     'male':'Male', 'female':'Female'})

# Replace error codes with NaN
df['Score'] = df['Score'].replace([-1, -99, 999], np.nan)

# Replace in whole DataFrame at once
df.replace({'Status': {'1':'Active', '0':'Inactive',
                        'active':'Active', 'Yes':'Active', 'No':'Inactive'}})

# Replace with regex
df.replace(r'^\s*$', np.nan, regex=True)  # empty strings → NaN

Renaming Columns & Index

PYTHON
# Rename specific columns with dict
df.rename(columns={'Name':'FullName', 'Dept':'Department'})

# Rename all columns with a list (must match count)
df.columns = ['id', 'full_name', 'age', 'salary', 'dept']

# Clean column names: lowercase + replace spaces with underscore
df.columns = df.columns.str.lower().str.replace(' ', '_').str.strip()

# Apply function to all column names
df.rename(columns=str.upper)    # ALL CAPS
df.rename(columns=str.lower)    # all lowercase

# Rename index
df.rename(index={0:'first', 1:'second'})

# Reset index — make existing index a column, reset to 0,1,2...
df.reset_index()                  # old index becomes a column
df.reset_index(drop=True)         # old index discarded

# Set a column as the index
df.set_index('EmpID')             # EmpID becomes the row labels
df.set_index(['EmpID','Name'])   # MultiIndex

Adding Columns, Sorting & Applying Functions

Create derived features, sort your data, apply transformations

Adding & Modifying Columns

PYTHON
df = pd.DataFrame({
    'Name'    :['Alice','Bob','Carol','Dave'],
    'Salary'  :[85000, 72000, 91000, 105000],
    'YearsExp':[5, 3, 7, 12],
    'Dept'    :['Eng','HR','Eng','Mgtm']
})

# 1. Simple assignment
df['Bonus'] = df['Salary'] * 0.10          # 10% bonus
df['TotalComp'] = df['Salary'] + df['Bonus']

# 2. Conditional column with np.where
df['Senior'] = np.where(df['YearsExp'] >= 7, 'Senior', 'Junior')

# 3. Multiple conditions with np.select
conditions = [
    df['Salary'] >= 100000,
    df['Salary'] >= 80000,
    df['Salary'] >= 60000
]
choices = ['High', 'Mid', 'Low']
df['SalaryBand'] = np.select(conditions, choices, default='Entry')

# 4. Using pd.cut — bin continuous into categories
df['AgeBand'] = pd.cut(df['YearsExp'],
                       bins=[0, 3, 7, 15],
                       labels=['Junior','Mid','Senior'])

# 5. pd.get_dummies — one-hot encode categorical column
dummies = pd.get_dummies(df['Dept'], prefix='dept')
df = pd.concat([df, dummies], axis=1)

# 6. assign() — method chaining friendly
df = df.assign(
    Bonus     = lambda x: x['Salary'] * 0.1,
    TotalComp = lambda x: x['Salary'] + x['Bonus'],
    SeniorFlag= lambda x: x['YearsExp'] >= 7
)

apply() — Row or Column Transformations

PYTHON
# apply() on a column (Series)
df['Grade'] = df['Salary'].apply(lambda x: 'A' if x > 90000 else 'B')

# apply() on each ROW (axis=1) — access multiple columns
def score_employee(row):
    score = row['Salary'] / 10000 + row['YearsExp'] * 2
    return round(score, 1)

df['Score'] = df.apply(score_employee, axis=1)

# map() — fastest for element-wise Series transformation
dept_codes = {'Eng':1, 'HR':2, 'Mgtm':3}
df['DeptCode'] = df['Dept'].map(dept_codes)

Sorting Data

PYTHON
# Sort by single column — ascending (default)
df.sort_values('Salary')
df.sort_values('Salary', ascending=False)   # highest first

# Sort by multiple columns
df.sort_values(['Dept', 'Salary'], ascending=[True, False])
# Sort by Dept A→Z, then within each Dept sort Salary high→low

# Sort index

df.sort_index(ascending=False)

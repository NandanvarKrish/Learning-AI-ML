What is SciPy?

NumPy's scientific computing companion

SciPy ("Scientific Python") builds on NumPy's array foundation to provide algorithms for optimization, integration, interpolation, linear algebra, signal processing, and statistics — the tools of scientific and engineering computation.

🔬 SciPy's Submodules
scipy.stats → probability distributions, hypothesis tests
scipy.optimize → root finding, curve fitting, minimization
scipy.interpolate → filling gaps between known data points
scipy.linalg → advanced linear algebra (beyond numpy.linalg)
scipy.signal → filtering, spectral analysis, convolution
scipy.integrate → numerical integration, differential equations
Each submodule must be imported explicitly — `import scipy` alone does NOT give you access to scipy.stats.
PYTHON
# Install
pip install scipy

# CORRECT — import the specific submodule you need
from scipy import stats
from scipy import optimize
from scipy import interpolate

# INCORRECT — this does NOT give you scipy.stats automatically
import scipy
scipy.stats.norm   # ❌ AttributeError in many scipy versions!

# Standard combo for statistical work
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt
⚠️ Always Import Submodules Explicitly
Unlike some libraries, plain import scipy does NOT automatically expose all submodules like scipy.stats or scipy.optimize. Always use from scipy import stats or import scipy.stats as stats to guarantee access.

scipy.stats — The Statistics Powerhouse

Every distribution follows the same consistent interface

Every distribution object in scipy.stats (normal, binomial, Poisson, etc.) shares the SAME set of methods — learn the pattern once, apply it to 100+ distributions.

📊 The Universal Distribution Interface
.pdf(x) → Probability Density Function (continuous) — height of the curve at x
.pmf(x) → Probability Mass Function (discrete) — exact probability at x
.cdf(x) → Cumulative Distribution — P(X ≤ x)
.ppf(q) → Percent Point Function — the INVERSE of cdf (given probability, get x)
.rvs(size) → Random Variates — generate random samples
.mean(), .std(), .var() → summary statistics of the theoretical distribution
PYTHON
from scipy import stats
import numpy as np

# Create a normal distribution object: mean=100, std=15 (like IQ scores)
dist = stats.norm(loc=100, scale=15)   # loc=mean, scale=std for norm

# PDF — height of the bell curve at a specific point
print(dist.pdf(100))    # peak density, at the mean

# CDF — what fraction of the distribution is ≤ 115?
print(dist.cdf(115))    # ~0.841 → about 84.1% of people score ≤ 115

# PPF — the INVERSE question: what score is the 90th percentile?
print(dist.ppf(0.90))   # ~119.2 → 90% of scores fall below ~119.2

# RVS — generate 1000 random samples from this distribution
sample = dist.rvs(size=1000, random_state=42)

# Distribution's theoretical properties
print(dist.mean(), dist.std(), dist.var())   # 100.0  15.0  225.0
💡 CDF vs PPF — Inverses of Each Other
cdf(x) answers "given a value, what's the probability of being ≤ it?". ppf(q) answers the OPPOSITE: "given a probability, what value corresponds to it?". If cdf(115) = 0.841, then ppf(0.841) = 115 — they undo each other.

Continuous Distributions

Normal, uniform, exponential — modeling real-valued data

Normal
stats.norm
Uniform
stats.uniform
Exponential
stats.expon
PYTHON
# NORMAL — the bell curve, for naturally symmetric data (heights, measurement errors)
norm_dist = stats.norm(loc=0, scale=1)   # standard normal: mean=0, std=1

# UNIFORM — equal probability across a range (random number generators, fair dice-like continuous data)
uniform_dist = stats.uniform(loc=0, scale=10)   # range [0, 10] — NOTE: scale = WIDTH, not the max value

# EXPONENTIAL — time between independent events (customer arrivals, equipment failure)
expon_dist = stats.expon(scale=5)   # scale = 1/rate, mean wait time = 5

# Plotting a distribution's PDF
import matplotlib.pyplot as plt
x = np.linspace(-4, 4, 200)
plt.plot(x, norm_dist.pdf(x))
plt.title('Standard Normal PDF')

# T-distribution — like normal but heavier tails, used for small-sample inference
t_dist = stats.t(df=10)   # df = degrees of freedom; lower df = heavier tails

# Chi-squared — sum of squared normal variables, used in variance tests and goodness-of-fit
chi2_dist = stats.chi2(df=5)

Discrete Distributions

Binomial, Poisson — modeling counts and successes

PYTHON
# BINOMIAL — number of successes in n independent trials (coin flips, A/B test conversions)
binom_dist = stats.binom(n=20, p=0.3)    # 20 trials, 30% success probability each

print(binom_dist.pmf(5))     # P(exactly 5 successes out of 20)
print(binom_dist.cdf(8))     # P(8 or fewer successes)
print(1 - binom_dist.cdf(10))   # P(MORE than 10 successes)

# POISSON — number of events in a fixed interval (calls per hour, defects per batch)
poisson_dist = stats.poisson(mu=4)     # average rate = 4 events per interval

print(poisson_dist.pmf(0))    # P(exactly 0 events)
print(poisson_dist.pmf(6))    # P(exactly 6 events)

# BERNOULLI — single trial, special case of binomial with n=1
bernoulli_dist = stats.bernoulli(p=0.5)   # fair coin flip
DistributionModelsKey Parameter
NormalContinuous, symmetric natural dataloc (mean), scale (std)
UniformEqual likelihood across a rangeloc (start), scale (width)
ExponentialTime between random eventsscale (mean wait time)
BinomialSuccesses in n fixed trialsn (trials), p (success prob)
PoissonEvent counts in fixed intervalmu (average rate)
💡 PMF vs PDF
Discrete distributions (binomial, Poisson) use .pmf() — Probability MASS Function — since exact values have real, nonzero probability. Continuous distributions (normal, exponential) use .pdf() — Probability DENSITY Function — since any exact single value has technically zero probability; only ranges (via cdf) have meaningful probability.

Descriptive Statistics with scipy.stats

Beyond NumPy's basics — skewness, kurtosis, and more

PYTHON
data = np.array([23,45,12,67,34,89,21,56,78,90,15,44])

# One call, ALL the key descriptive stats at once
result = stats.describe(data)
print(result)
# DescribeResult(nobs=12, minmax=(12,90), mean=47.83, variance=..., skewness=..., kurtosis=...)

# Individual measures
print(stats.skew(data))       # asymmetry: 0=symmetric, >0=right-tailed, <0=left-tailed
print(stats.kurtosis(data))   # "tailedness": 0=normal-like, >0=heavier tails, <0=lighter tails

# Mode — most frequent value
print(stats.mode(data, keepdims=True))

# Z-scores — how many std devs each point is from the mean
z_scores = stats.zscore(data)
print(z_scores)

# Percentile / IQR helpers
print(stats.iqr(data))         # interquartile range (Q3 - Q1) in one call
print(np.percentile(data, [25,50,75]))
📈 Reading Skewness & Kurtosis
Skewness > 0 → right tail longer (e.g., income distribution)
Skewness < 0 → left tail longer (e.g., age at retirement)
Kurtosis > 0 → heavier tails than normal (more extreme outliers)
Kurtosis < 0 → lighter tails than normal (fewer extreme values)

Fitting Distributions to Real Data

Which theoretical distribution best matches your sample?

PYTHON
# Generate some sample data (pretend this is real, unknown-distribution data)
np.random.seed(1)
sample_data = np.random.normal(50, 10, 500)

# .fit() estimates the BEST parameters for a given distribution shape to match your data
mu_fit, std_fit = stats.norm.fit(sample_data)
print(f"Fitted normal: mean={mu_fit:.2f}, std={std_fit:.2f}")

# Visualize the fit against the actual data histogram
plt.hist(sample_data, bins=30, density=True, alpha=0.6, label='Data')
x = np.linspace(sample_data.min(), sample_data.max(), 200)
plt.plot(x, stats.norm.pdf(x, mu_fit, std_fit), 'r-', linewidth=2, label='Fitted Normal')
plt.legend()

# Goodness-of-fit test: does the data ACTUALLY look normal? (Day 2 covers this deeper)
statistic, p_value = stats.shapiro(sample_data)
print(f"Shapiro-Wilk p-value: {p_value:.4f}")
# p > 0.05 typically suggests data is CONSISTENT with normality

# Q-Q plot — visual check of normality (points should follow the diagonal line)
stats.probplot(sample_data, dist='norm', plot=plt)
💡 Q-Q Plots — A Visual Normality Check
A Quantile-Quantile (Q-Q) plot compares your data's quantiles against a theoretical distribution's quantiles. If points fall roughly along the diagonal reference line, the data matches that distribution well. Systematic curves or S-shapes indicate deviations (skewness, heavy tails).

Real-World Task — Call Center Staffing Model

Estimated time: 75–90 minutes  |  Difficulty: ⭐⭐⭐

📋 Project Brief

You are an Operations Analyst at a customer service center. Use SciPy's statistical distributions to model call arrival patterns, wait times, and staffing requirements.

1

Phase 1 — Model Call Arrivals with Poisson

~25 min▼
1
Set Up the Poisson Model
STARTER CODE
from scipy import stats
import numpy as np
import matplotlib.pyplot as plt

# Historical data: call center averages 12 calls per 10-minute window
calls_per_window = stats.poisson(mu=12)

# Q1: What's the probability of EXACTLY 12 calls in a window?
print("P(exactly 12):", calls_per_window.pmf(12))

# Q2: What's the probability of MORE THAN 20 calls (a surge)?
print("P(more than 20):", 1 - calls_per_window.cdf(20))

# Q3: What call volume represents the 95th percentile (staffing safety margin)?
print("95th percentile:", calls_per_window.ppf(0.95))

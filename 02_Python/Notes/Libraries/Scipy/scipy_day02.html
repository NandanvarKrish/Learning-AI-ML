The Hypothesis Testing Framework

The logic behind every statistical test you'll ever run

Every hypothesis test follows the SAME logical structure, regardless of which specific test you use.

🧪 The Universal Framework
H₀ (Null Hypothesis) → "There is NO real difference/effect" (the default assumption)
H₁ (Alternative) → "There IS a real difference/effect"
p-value → P(seeing data this extreme or more) IF H₀ were actually true
α (alpha, usually 0.05) → the threshold below which we "reject" H₀
Decision rule: if p-value < α, reject H₀ (result is "statistically significant"). Otherwise, fail to reject H₀ (not enough evidence).
💡 What a p-value Does NOT Mean
A p-value is NOT "the probability H₀ is true." It's the probability of observing data this extreme (or more) ASSUMING H₀ is true. A small p-value means "this data would be unusual if there were truly no effect" — evidence AGAINST H₀, not proof of H₁.
PYTHON
from scipy import stats
import numpy as np

# Every SciPy hypothesis test returns the SAME pattern: a statistic and a p-value
statistic, p_value = stats.ttest_ind(group_a, group_b)

if p_value < 0.05:
    print("Statistically significant — reject H0")
else:
    print("Not statistically significant — fail to reject H0")

T-Tests — Comparing Means

One-sample, two-sample independent, and paired variants

PYTHON
# ── ONE-SAMPLE t-test: is the sample mean different from a KNOWN value? ──
sample = np.array([98.2,98.6,99.1,98.4,98.9,98.3,99.0])
t_stat, p_val = stats.ttest_1samp(sample, popmean=98.6)   # H0: mean == 98.6 (normal body temp)

# ── TWO-SAMPLE INDEPENDENT t-test: are TWO separate groups' means different? ──
group_a = np.random.normal(50, 10, 40)   # e.g., Control group scores
group_b = np.random.normal(55, 10, 40)   # e.g., Treatment group scores

t_stat, p_val = stats.ttest_ind(group_a, group_b)                     # assumes EQUAL variances (default)
t_stat, p_val = stats.ttest_ind(group_a, group_b, equal_var=False)   # Welch's t-test — safer, doesn't assume equal variance

# ── PAIRED t-test: SAME subjects measured twice (before/after) ──
before = np.array([72,68,75,70,74])
after  = np.array([68,65,70,66,70])
t_stat, p_val = stats.ttest_rel(before, after)   # "related"/paired samples
TestWhen to Use
ttest_1sampCompare ONE sample's mean to a known/hypothesized value
ttest_indCompare means of TWO INDEPENDENT/separate groups
ttest_relCompare means of the SAME subjects measured twice (before/after, paired)
⚠️ Default to Welch's t-test (equal_var=False)
Standard Student's t-test (equal_var=True, the SciPy default) assumes both groups have equal variance — an assumption often violated in practice. Welch's t-test (equal_var=False) doesn't require this assumption and performs nearly as well when variances ARE equal, making it the generally SAFER default choice.
📈

ANOVA — Comparing 3+ Group Means

One test instead of many pairwise t-tests

ANOVA (Analysis of Variance) tests whether AT LEAST ONE group's mean differs from the others, across 3 or more groups — without inflating false-positive risk from running many separate t-tests.

PYTHON
# One-way ANOVA: comparing 3+ independent groups
method_a = np.random.normal(75, 8, 30)    # Teaching Method A scores
method_b = np.random.normal(78, 8, 30)    # Teaching Method B scores
method_c = np.random.normal(82, 8, 30)    # Teaching Method C scores

f_stat, p_val = stats.f_oneway(method_a, method_b, method_c)

if p_val < 0.05:
    print("At least one method differs significantly — but WHICH ones?")
    # ANOVA tells you THAT a difference exists, but not WHICH pairs differ —
    # for that, you need a POST-HOC test (e.g., Tukey's HSD, available in statsmodels)
⚠️ Why Not Just Run Many t-tests Instead?
Running separate t-tests for every pair (A vs B, A vs C, B vs C) inflates the overall false-positive rate — with enough comparisons, you're increasingly likely to find a "significant" result purely by chance. ANOVA tests all groups simultaneously with proper error control, answering "is there ANY difference among these groups?" in one test.

Chi-Squared Tests — Categorical Data

Testing relationships and goodness-of-fit for counts/categories

PYTHON
# ── Chi-squared TEST OF INDEPENDENCE: are 2 categorical variables related? ──
# Example: is there a relationship between Department and Promotion status?
#                Promoted   NotPromoted
# Engineering      45           105
# Sales            38            82
# Marketing        20            60
observed = np.array([[45,105], [38,82], [20,60]])

chi2_stat, p_val, dof, expected = stats.chi2_contingency(observed)
print(f"p-value: {p_val:.4f}")
print("Expected counts under independence:", expected)
# p < 0.05 → department and promotion status are likely NOT independent (some relationship exists)

# ── Chi-squared GOODNESS OF FIT: does observed data match an EXPECTED distribution? ──
# Example: is a die fair? Rolled 60 times, expect 10 of each face
observed_rolls = [8, 12, 9, 11, 7, 13]
expected_rolls = [10, 10, 10, 10, 10, 10]

chi2_stat, p_val = stats.chisquare(observed_rolls, f_exp=expected_rolls)
# p < 0.05 → the die's roll pattern deviates significantly from fair/uniform expectations
FunctionQuestion Answered
chi2_contingencyAre TWO categorical variables related/associated? (independence test)
chisquareDoes observed count data match an EXPECTED theoretical distribution? (goodness-of-fit)

Non-Parametric Tests

When your data doesn't meet normality assumptions

Non-parametric tests don't assume the data follows any specific distribution (like normal) — safer choices when data is skewed, has outliers, or is ordinal rather than truly numeric.

Comparing 2 independent groups, non-normal data?stats.mannwhitneyu()
Comparing paired/before-after, non-normal data?stats.wilcoxon()
Comparing 3+ independent groups, non-normal data?stats.kruskal()
Checking if a sample IS normally distributed?stats.shapiro()
PYTHON
# Mann-Whitney U — non-parametric alternative to ttest_ind
stat, p_val = stats.mannwhitneyu(group_a, group_b)

# Wilcoxon signed-rank — non-parametric alternative to ttest_rel
stat, p_val = stats.wilcoxon(before, after)

# Kruskal-Wallis — non-parametric alternative to one-way ANOVA
stat, p_val = stats.kruskal(method_a, method_b, method_c)

# ALWAYS check normality FIRST to decide which family of test to use
stat, p_val = stats.shapiro(sample_data)
if p_val > 0.05:
    print("Consistent with normal — use t-test/ANOVA")
else:
    print("NOT consistent with normal — use Mann-Whitney/Kruskal instead")
💡 Parametric vs Non-Parametric — The Decision Path
Check normality (Shapiro-Wilk or Q-Q plot) first. If data looks normal AND sample sizes are reasonable, parametric tests (t-test, ANOVA) have more statistical power. If data is skewed, has outliers, is ordinal, or sample sizes are small, non-parametric tests are the SAFER, more robust choice.
🔗

Correlation Tests

Pearson vs Spearman — testing relationships between numeric variables

PYTHON
# Pearson correlation — measures LINEAR relationship strength, assumes roughly normal data
r, p_val = stats.pearsonr(hours_studied, exam_scores)
print(f"Pearson r={r:.3f}, p={p_val:.4f}")

# Spearman correlation — measures MONOTONIC relationship (not necessarily linear),
# uses RANKS instead of raw values — robust to outliers and non-linear (but monotonic) trends
rho, p_val = stats.spearmanr(hours_studied, exam_scores)
print(f"Spearman rho={rho:.3f}, p={p_val:.4f}")

# Kendall's Tau — another rank-based correlation, more robust for small samples with many ties
tau, p_val = stats.kendalltau(hours_studied, exam_scores)
MethodDetectsSensitive to Outliers?
Pearson (r)Linear relationships onlyYes — uses raw values
Spearman (ρ)Any monotonic relationship (linear or curved)No — uses ranks
Kendall (τ)Monotonic, better for small/tied dataNo — uses ranks
💡 Correlation ≠ Causation, and p-value ≠ Effect Size
A tiny p-value with a huge sample size can arise from a correlation coefficient (r) that's statistically significant but PRACTICALLY tiny (e.g., r=0.05). Always report and interpret both the correlation COEFFICIENT (strength/direction) and the p-value (statistical confidence) together — never one alone.

📋 Project Brief

You are a Data Scientist at a healthtech company. Analyze a website A/B test AND a clinical trial dataset using the full range of hypothesis testing tools.

1

Phase 1 — A/B Test: Conversion Rate Comparison

~25 min▼
1
Analyze Conversion Data with Chi-Squared
STARTER CODE
from scipy import stats
import numpy as np

# A/B test: Control (old design) vs Treatment (new design)
#              Converted   NotConverted
# Control         180          1820
# Treatment       225          1775
conversion_table = np.array([[180,1820], [225,1775]])

chi2_stat, p_val, dof, expected = stats.chi2_contingency(conversion_table)
print(f"Chi2 p-value: {p_val:.4f}")
print(f"Control rate: {180/2000:.1%}, Treatment rate: {225/2000:.1%}")

Interpret the result: is the conversion rate improvement statistically significant at α=0.05?

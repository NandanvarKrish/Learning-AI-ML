Box Plots — Five-Number Summary Visualised

Compare distributions and spot outliers at a glance

A box plot (box-and-whisker plot) visualises the five-number summary: minimum, Q1, median, Q3, maximum — plus outliers. It's the fastest way to compare spread across multiple groups.

📦 Box Plot Anatomy
Whisker (min) — Q1 |■■■ median ■■■| Q3 — Whisker (max)
Outliers shown as individual dots beyond the whiskers
Box = IQR (Q1 to Q3). Whiskers extend to 1.5×IQR by default. Points beyond = outliers.
PYTHON
import matplotlib.pyplot as plt
import numpy as np

np.random.seed(1)
dept_a = np.random.normal(70000, 12000, 100)
dept_b = np.random.normal(85000, 18000, 100)
dept_c = np.random.normal(60000, 8000,  100)

fig, ax = plt.subplots(figsize=(8,6))

# Single box plot
ax.boxplot(dept_a)

# Multiple box plots side by side (comparison)
data = [dept_a, dept_b, dept_c]
ax.boxplot(data,
           labels=['Engineering','Sales','Support'],
           patch_artist=True,          # enables fill color
           showmeans=True,             # show a mean marker too
           notch=True)                 # notched box = confidence interval around median

# Custom colors for each box
bp = ax.boxplot(data, labels=['Eng','Sales','Support'], patch_artist=True)
colors = ['#6EE7B7', '#93C5FD', '#FDBA74']
for patch, color in zip(bp['boxes'], colors):
    patch.set_facecolor(color)

# Horizontal box plots
ax.boxplot(data, labels=['Eng','Sales','Support'], vert=False)

ax.set_title('Salary Distribution by Department')
ax.set_ylabel('Salary (₹)')
💡 Reading a Box Plot
  • Box height (IQR) → how spread out the middle 50% of data is
  • Line inside box → the median
  • Whiskers → typical range (1.5×IQR from the box edges)
  • Dots beyond whiskers → statistical outliers
  • Notch width → if notches of two boxes DON'T overlap, medians are likely significantly different

Violin Plots — Box Plot + Distribution Shape

See the full density shape, not just quartile summaries

A violin plot combines a box plot with a rotated kernel density estimate (KDE), showing the FULL shape of the distribution — including bimodal patterns a box plot would hide.

PYTHON
fig, ax = plt.subplots(figsize=(8,6))

# Basic violin plot
parts = ax.violinplot(data, showmeans=True, showmedians=True)

# Style the violin bodies
for pc, color in zip(parts['bodies'], colors):
    pc.set_facecolor(color)
    pc.set_edgecolor('black')
    pc.set_alpha(0.8)

ax.set_xticks([1,2,3])
ax.set_xticklabels(['Engineering','Sales','Support'])
ax.set_title('Salary Distribution Shape by Department')

# Bimodal example — violin reveals what box plot would hide
bimodal = np.concatenate([np.random.normal(50,5,200), np.random.normal(80,5,200)])
fig2, (ax1,ax2) = plt.subplots(1,2, figsize=(10,5))
ax1.boxplot(bimodal)
ax1.set_title('Box Plot — hides bimodal shape!')
ax2.violinplot(bimodal)
ax2.set_title('Violin Plot — reveals TWO peaks')
💡 When to Choose Violin over Box
Use violin plots when the SHAPE of the distribution matters (bimodal, skewed, multi-peaked data). Use box plots when you only need the summary statistics and outliers — box plots are more compact and easier to read in dense dashboards.

Pie & Donut Charts

Part-to-whole relationships — use sparingly and correctly

PYTHON
segments = ['Enterprise','SMB','Startup','Individual']
revenue  = [450, 280, 150, 70]

fig, ax = plt.subplots(figsize=(7,7))

# Basic pie chart
ax.pie(revenue, labels=segments, autopct='%1.1f%%')

# Fully styled pie chart
colors = ['#047857','#10B981','#6EE7B7','#D1FAE5']
explode = [0.08, 0, 0, 0]   # "explode" (pull out) the first slice

ax.pie(revenue,
       labels=segments,
       colors=colors,
       explode=explode,
       autopct='%1.1f%%',        # show percentage on each slice
       startangle=90,             # rotate starting point
       shadow=True,
       textprops={'fontsize':11})
ax.set_title('Revenue Share by Segment')
ax.axis('equal')     # ensures the pie is a perfect circle, not an oval

# DONUT chart — pie with a hole in the middle
fig, ax = plt.subplots(figsize=(7,7))
wedges, texts, autotexts = ax.pie(revenue, labels=segments, colors=colors,
                                    autopct='%1.1f%%', pctdistance=0.85)
# Draw a white circle in the center to create the "donut hole"
centre_circle = plt.Circle((0,0), 0.6, fc='white')
fig.gca().add_artist(centre_circle)
ax.text(0,0, f'Total\n₹{sum(revenue)}L', ha='center', va='center', fontsize=14, fontweight='bold')
⚠️ When NOT to Use Pie Charts
Humans are bad at comparing angles/areas. Avoid pie charts when: there are more than 5-6 categories, slices are similar in size (hard to tell which is bigger), or you need to compare exact values precisely. A sorted bar chart is almost always easier to read correctly.

Heatmaps — 2D Data as Color

Correlation matrices, confusion matrices, activity grids

PYTHON
# Correlation matrix heatmap
data_matrix = np.random.rand(5,5)
data_matrix = (data_matrix + data_matrix.T) / 2   # make symmetric like a correlation matrix
np.fill_diagonal(data_matrix, 1.0)

labels = ['Price','Sqft','Bedrooms','Age','Rating']

fig, ax = plt.subplots(figsize=(7,6))
im = ax.imshow(data_matrix, cmap='RdBu_r', vmin=-1, vmax=1)

# Set tick labels
ax.set_xticks(range(len(labels)))
ax.set_yticks(range(len(labels)))
ax.set_xticklabels(labels, rotation=45, ha='right')
ax.set_yticklabels(labels)

# Annotate each cell with its value
for i in range(len(labels)):
    for j in range(len(labels)):
        text_color = 'white' if abs(data_matrix[i,j]) > 0.5 else 'black'
        ax.text(j, i, f'{data_matrix[i,j]:.2f}',
                ha='center', va='center', color=text_color, fontsize=10)

fig.colorbar(im, ax=ax, label='Correlation')
ax.set_title('Feature Correlation Matrix')
fig.tight_layout()

# pcolormesh — better for continuous/irregular grid data
X, Y = np.meshgrid(np.linspace(0,10,50), np.linspace(0,10,50))
Z = np.sin(X) * np.cos(Y)
fig, ax = plt.subplots()
mesh = ax.pcolormesh(X, Y, Z, cmap='viridis', shading='auto')
fig.colorbar(mesh, ax=ax)
FunctionBest For
ax.imshow()Discrete grid data, matrices, images — snaps to pixel grid
ax.pcolormesh()Continuous data on possibly irregular grids, faster for large data
ax.contourf()Smooth filled contour regions from continuous functions

Contour Plots — 3D Data in 2D

Topographic-style maps of a function's surface

PYTHON
# Build a grid and evaluate a function at every point
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = np.exp(-(X**2 + Y**2)) * np.cos(2*X)   # any 2-variable function

fig, ax = plt.subplots(figsize=(7,6))

# Line contours — outlined levels, like elevation lines on a map
cs = ax.contour(X, Y, Z, levels=10, cmap='viridis')
ax.clabel(cs, inline=True, fontsize=8)   # label each contour line with its value

# Filled contours — solid colored regions between levels
fig, ax = plt.subplots(figsize=(7,6))
cf = ax.contourf(X, Y, Z, levels=20, cmap='RdYlBu_r')
fig.colorbar(cf, ax=ax)
ax.set_title('Filled Contour Plot')

# Combine both: filled + outlined for extra clarity
fig, ax = plt.subplots(figsize=(7,6))
cf = ax.contourf(X, Y, Z, levels=20, cmap='viridis', alpha=0.8)
cs = ax.contour(X, Y, Z, levels=10, colors='black', linewidths=0.5)
fig.colorbar(cf, ax=ax)

3D Plots — Surfaces, Scatter & Bars

Visualising three-dimensional relationships

PYTHON
from mpl_toolkits.mplot3d import Axes3D   # registers 3D projection

# 3D scatter
fig = plt.figure(figsize=(8,7))
ax = fig.add_subplot(111, projection='3d')   # the key parameter!

x = np.random.rand(100)
y = np.random.rand(100)
z = x**2 + y**2
ax.scatter(x, y, z, c=z, cmap='viridis')
ax.set_xlabel('X'); ax.set_ylabel('Y'); ax.set_zlabel('Z')

# 3D surface plot
fig = plt.figure(figsize=(9,7))
ax = fig.add_subplot(111, projection='3d')

x = np.linspace(-5,5,50)
y = np.linspace(-5,5,50)
X, Y = np.meshgrid(x,y)
Z = np.sin(np.sqrt(X**2+Y**2))

surf = ax.plot_surface(X, Y, Z, cmap='coolwarm', edgecolor='none', alpha=0.9)
fig.colorbar(surf, ax=ax, shrink=0.5)

# Rotate the viewing angle
ax.view_init(elev=25, azim=45)   # elevation and azimuth angles in degrees

# 3D bar chart
fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
xpos, ypos = np.meshgrid([0,1,2],[0,1])
xpos, ypos = xpos.ravel(), ypos.ravel()
heights = [3,5,2,4,6,1]
ax.bar3d(xpos, ypos, 0, 0.8, 0.8, heights, shade=True)
⚠️ Use 3D Sparingly
3D plots are visually striking but often HARDER to read precisely than 2D equivalents (occlusion, perspective distortion, angle-dependent interpretation). Prefer a 2D heatmap/contour plot for most analytical work — reserve 3D for genuinely 3D physical data or presentations where visual impact matters more than precision.

You are a Quality Analyst at Precision Manufacturing Co. Build a complete statistical visualization report analysing product defect rates, dimensional tolerances, and machine performance across production lines — using box plots, violin plots, heatmaps, and contour analysis.

import numpy as np

np.random.seed(3)

# Part dimension measurements (mm) - target is 50.0mm

# Correlation matrix: which factors relate to defect rate?
factors = ['Temp','Speed','Pressure','Humidity','DefectRate']
corr = np.array([
    [1.00, 0.65, 0.20, -0.10, 0.72],
    [0.65, 1.00, 0.15, -0.05, 0.58],
    [0.20, 0.15, 1.00,  0.30, 0.25],
    [-0.10,-0.05, 0.30,  1.00, 0.15],

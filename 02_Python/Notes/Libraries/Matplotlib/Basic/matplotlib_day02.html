Styling — Instant Professional Look

Two functions, whole-chart makeover

plt.style.use(style_name)
Applies a built-in visual theme globally to every chart made afterward.
Popular values: 'ggplot', 'seaborn-v0_8-whitegrid', 'fivethirtyeight', 'dark_background'
💼 Real-world use

A data team sets plt.style.use('seaborn-v0_8-whitegrid') once at the top of every notebook to keep all charts across the company visually consistent.

ax.spines['top'].set_visible(False)
Removes a chart border line for a cleaner, modern look.
PYTHON
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
# removing the top/right border box lines is a common "modern dashboard" touch

Multi-Panel Layouts

Showing several charts together, cleanly

fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(12,8))
Creates a GRID of Axes in one Figure — a mini-dashboard.
axes becomes a 2D array — access individual panels via axes[0,0], axes[0,1], etc.
💼 Real-world use

An executive dashboard showing 4 KPIs at once: revenue trend, top products, regional split, and customer growth — all in one screenshot.

PYTHON
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(12,8))

axes[0,0].plot(months, revenue)
axes[0,0].set_title('Revenue Trend')

axes[0,1].bar(products, sales)
axes[0,1].set_title('Top Products')

fig.suptitle('Q3 Executive Dashboard', fontsize=16, fontweight='bold')
fig.tight_layout()   # auto-fixes overlapping titles/labels between panels — call this almost always
⚠️ Always Call fig.tight_layout() with Multiple Subplots
Without it, titles and axis labels from adjacent panels commonly overlap each other. It's a single line that fixes 90% of spacing complaints.
📦

ax.boxplot() — Compare Distributions Across Groups

Median, spread, and outliers at a glance

ax.boxplot(data_list, labels=, patch_artist=True)
Draws a box (25th–75th percentile) with a median line and whiskers; dots beyond whiskers are outliers.
data_list = a list of arrays, one per group  |  labels = names for each group  |  patch_artist=True enables fill colors
💼 Real-world use

HR comparing salary spread across 3 departments to spot which one has the widest pay range or unusual outliers.

PYTHON
eng_salaries = [70000,85000,95000,78000,130000]
sales_salaries = [55000,62000,58000,70000,60000]

fig, ax = plt.subplots(figsize=(7,5))
ax.boxplot([eng_salaries, sales_salaries], labels=['Engineering','Sales'], patch_artist=True)
ax.set_ylabel('Salary (₹)')
🎻

ax.violinplot() — Full Distribution Shape

Like a box plot, but shows the actual shape too

ax.violinplot(data_list, showmeans=True)
Draws a smoothed density curve mirrored around a vertical axis, per group.
💼 Real-world use

A survey team checking if customer satisfaction scores are bunched around one value or actually SPLIT into two distinct groups (happy customers + unhappy customers) — a box plot alone would hide this "two-peak" pattern, but a violin plot reveals it visually.

PYTHON
fig, ax = plt.subplots(figsize=(7,5))
ax.violinplot([eng_salaries, sales_salaries], showmeans=True)
ax.set_xticks([1,2])
ax.set_xticklabels(['Engineering','Sales'])
ChartBest For
Box plotQuick summary stats (median, quartiles, outliers) — compact, easy to compare many groups
Violin plotSeeing the FULL shape — reveals if data is bunched, spread, or split into multiple peaks

ax.imshow() — Heatmaps for Correlation/Matrix Data

Turning a grid of numbers into color

ax.imshow(matrix, cmap='coolwarm', vmin=-1, vmax=1)
Displays a 2D array as a grid of colored cells.
cmap = colormap ('coolwarm' good for -1 to 1 correlation data)  |  vmin/vmax = fix the color scale range explicitly
💼 Real-world use

A finance analyst checking which financial metrics move together (correlation matrix) before building a forecasting model — instantly spotting the strongest relationships by color intensity.

PYTHON
import numpy as np
corr_matrix = np.array([[1.0,0.8,0.2],[0.8,1.0,0.1],[0.2,0.1,1.0]])
labels = ['Revenue','AdSpend','Rainfall']

fig, ax = plt.subplots(figsize=(6,5))
im = ax.imshow(corr_matrix, cmap='coolwarm', vmin=-1, vmax=1)
ax.set_xticks(range(3)); ax.set_xticklabels(labels)
ax.set_yticks(range(3)); ax.set_yticklabels(labels)
fig.colorbar(im, ax=ax, label='Correlation')   # the color-to-value legend strip

# Annotate each cell with its exact number — very common addition
for i in range(3):
    for j in range(3):
        ax.text(j, i, f'{corr_matrix[i,j]:.2f}', ha='center', va='center')
⚠️ Always Add fig.colorbar() to a Heatmap
Without it, viewers have no idea what the COLORS actually mean numerically. The colorbar is the "legend" that translates color intensity into actual values — never skip it.

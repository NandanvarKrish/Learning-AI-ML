Universal Functions (ufuncs)

Vectorised C-speed functions that operate on entire arrays instantly

A ufunc (universal function) is a function that operates element-by-element on an array. Instead of writing a Python loop, one ufunc call processes millions of elements using compiled C/Fortran — making them 10–100× faster than explicit loops.

💡 Key Rule
If you are about to write for x in arr: to apply a math function, STOP — there is almost certainly a NumPy ufunc that does it faster in one line.

Arithmetic ufuncs

PYTHON
import numpy as np

a = np.array([4, 9, 16, 25, 36])
b = np.array([2, 3,  4,  5,  6])

# All operators are ufuncs under the hood
print(np.add(a, b))        # [ 6 12 20 30 42]  same as a + b
print(np.subtract(a, b))   # [ 2  6 12 20 30]  same as a - b
print(np.multiply(a, b))   # [ 8 27 64 125 216]
print(np.divide(a, b))     # [2. 3. 4. 5. 6.]
print(np.power(a, 2))      # [16 81 256 625 1296]
print(np.mod(a, 3))        # [1 0 1 1 0]
print(np.floor_divide(a,b)) # [2 3 4 5 6]
print(np.absolute(np.array([-3, -1, 0, 2, -5])))  # [3 1 0 2 5]

Comparison & Logical ufuncs

PYTHON

print(np.logical_or(x, y))   # [T T T F]
print(np.logical_not(x))     # [F T F T]

Handling NaN and Infinity

PYTHON
data = np.array([1.0, np.nan, 3.0, np.inf, 5.0, -np.inf])

# Detect special values
print(np.isnan(data))    # [F T F F F F]
print(np.isinf(data))    # [F F F T F T]
print(np.isfinite(data)) # [T F T F T F]

# Clean the data
clean = np.nan_to_num(data, nan=0.0, posinf=999, neginf=-999)
print(clean)  # [1.   0.   3.  999.  5. -999.]

# NaN-safe aggregations (ignore NaN values)
data2 = np.array([10.0, np.nan, 30.0, np.nan, 50.0])
print(np.nanmean(data2))  # 30.0  ← ignores NaN
print(np.nansum(data2))   # 90.0  ← ignores NaN
print(np.nanmax(data2))   # 50.0
print(np.nanstd(data2))   # 16.33
⚠️ NaN Contaminates Everything
np.mean([1, np.nan, 3]) returns nan. Always check for NaN in real datasets before computing statistics. Use np.nanmean(), np.nanstd() etc. to safely ignore NaN values.

Deep Statistical Analysis

Descriptive statistics, percentiles, correlation, covariance, and cumulative ops

Core Statistical Functions

PYTHON
heights = np.array([162, 175, 158, 180, 171, 169, 185, 163, 177, 174])

# Central tendency
print(np.mean(heights))    # 171.4  ← arithmetic mean
print(np.median(heights))  # 172.5  ← middle value (sorted)

# Spread
print(np.std(heights))     # 8.12   ← standard deviation
print(np.var(heights))     # 65.9   ← variance = std²
print(np.ptp(heights))     # 27     ← peak-to-peak (max - min)

# Percentiles — split data into parts
print(np.percentile(heights, 25))   # 164.25  ← Q1 (25th percentile)
print(np.percentile(heights, 50))   # 172.5   ← Q2 = median
print(np.percentile(heights, 75))   # 176.5   ← Q3 (75th percentile)

# Interquartile Range (IQR) — measure of spread
q1 = np.percentile(heights, 25)
q3 = np.percentile(heights, 75)
iqr = q3 - q1
print(f"IQR: {iqr}")       # 12.25

# Outlier detection using IQR
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
outliers = heights[(heights < lower) | (heights > upper)]
print(f"Outliers: {outliers}")
📐 Key Statistical Formulas
Mean (μ) = Σx / n
Variance = Σ(x - μ)² / n
Std Dev (σ) = √Variance
IQR = Q3 - Q1
NumPy uses population std (ddof=0) by default. Use ddof=1 for sample std.

Population vs Sample Standard Deviation

PYTHON
data = np.array([10, 20, 30, 40, 50])

# Population std (ddof=0) — use when you HAVE the entire population
print(np.std(data, ddof=0))   # 14.14  ← divides by N

# Sample std (ddof=1) — use when data is a SAMPLE from a larger group
print(np.std(data, ddof=1))   # 15.81  ← divides by N-1 (Bessel's correction)

Correlation & Covariance

Correlation measures how strongly two variables move together (-1 to +1). Covariance measures the direction of their relationship but is scale-dependent.

PYTHON
study_hours  = np.array([2, 4, 6, 8, 10, 3, 7, 5])
exam_scores  = np.array([50, 65, 75, 85, 95, 55, 80, 70])

# Correlation matrix (2×2 for two variables)
corr_matrix = np.corrcoef(study_hours, exam_scores)
print(corr_matrix)
# [[1.         0.998...]    ← study vs study (always 1)
#  [0.998...   1.        ]] ← 0.998 = very strong positive correlation!

# Extract just the correlation value
r = corr_matrix[0, 1]
print(f"Correlation: {r:.3f}")   # 0.998

# Covariance matrix
cov_matrix = np.cov(study_hours, exam_scores)
print(cov_matrix)

# Interpretation of r:
#  0.9 to 1.0  → Very strong positive
#  0.7 to 0.9  → Strong positive
#  0.4 to 0.7  → Moderate positive
#  0.0 to 0.4  → Weak
# -1.0 to -0.9 → Very strong NEGATIVE

Cumulative Functions

PYTHON
sales = np.array([100, 200, 150, 300, 250])

# Running total — cumsum

# Running product — cumprod

Random Module & Probability Distributions

Simulating real-world randomness with statistical distributions

In data science, you often need to simulate data — stock prices, customer arrivals, test scores, dice rolls. Each scenario uses a different probability distribution.

The Modern Random Generator (NumPy 1.17+)

PYTHON
# Old style (still works but less flexible)
np.random.seed(42)
np.random.rand(5)

# New style — use a Generator object (recommended)
rng = np.random.default_rng(seed=42)
print(rng.random(5))         # 5 uniform floats [0, 1)
print(rng.integers(1, 101, size=10))  # 10 integers [1, 100]

1. Uniform Distribution

Every value in a range has an equal chance of being chosen. Like rolling a fair die.

PYTHON
# Floats between 0 and 1
u1 = rng.random(1000)

# Floats between any two values: uniform(low, high, size)
u2 = rng.uniform(low=50, high=100, size=500)
print(f"Mean: {u2.mean():.1f}")   # ~75  (midpoint)

# Simulate dice rolls (1 to 6)
dice = rng.integers(1, 7, size=10)
print(dice)  # [3 1 6 2 4 6 1 5 3 4]

2. Normal (Gaussian) Distribution

Bell-curve shape. Most real-world measurements (height, IQ, errors) follow this. Defined by mean (μ) and standard deviation (σ).

PYTHON
# normal(mean, std, size)
heights = rng.normal(loc=170, scale=10, size=1000)

print(f"Mean:   {heights.mean():.1f}")   # ~170
print(f"Std:    {heights.std():.1f}")    # ~10
print(f"Min:    {heights.min():.1f}")
print(f"Max:    {heights.max():.1f}")

# 68-95-99.7 Rule (empirical rule)
within_1sd = np.sum(np.abs(heights - 170) < 10) / 1000
within_2sd = np.sum(np.abs(heights - 170) < 20) / 1000
within_3sd = np.sum(np.abs(heights - 170) < 30) / 1000
print(f"Within 1σ: {within_1sd:.1%}")   # ~68%
print(f"Within 2σ: {within_2sd:.1%}")   # ~95%
print(f"Within 3σ: {within_3sd:.1%}")   # ~99.7%

3. Binomial Distribution

Models number of successes in n trials, each with probability p. Like flipping a coin 10 times.

PYTHON
# binomial(n, p, size)
# n = number of trials, p = probability of success

# Simulate: flip a fair coin 10 times, run 1000 experiments
coin_flips = rng.binomial(n=10, p=0.5, size=1000)
print(f"Avg heads per 10 flips: {coin_flips.mean():.1f}")  # ~5

# Simulate: 30% customer click rate — 1000 customers
# How many click ads?
clicks = rng.binomial(n=1, p=0.30, size=1000)
print(f"Total clicks: {clicks.sum()}")   # ~300
print(f"Click rate:   {clicks.mean():.1%}")  # ~30%

4. Poisson Distribution

Models the number of events in a fixed time period when events occur at a known average rate. Used for customer arrivals, server requests, accidents.

PYTHON
# poisson(lam, size)  — lam = average rate (λ)

# A coffee shop gets 12 customers per hour on average
# Simulate arrivals for 24 hours
arrivals = rng.poisson(lam=12, size=24)
print(arrivals)
print(f"Busiest hour: {arrivals.max()} customers")
print(f"Quietest:     {arrivals.min()} customers")
print(f"Daily total:  {arrivals.sum()} customers")

5. Other Useful Distributions

PYTHON
# Exponential — time between events (waiting time)
wait_times = rng.exponential(scale=5, size=100)  # avg wait: 5 min

# Beta — probabilities/proportions (between 0 and 1)
conversion = rng.beta(a=2, b=8, size=1000)  # skewed towards low values

# Shuffle an array in-place
arr = np.arange(1, 11)
rng.shuffle(arr)
print(arr)   # [7 3 1 9 5 2 8 4 10 6] (shuffled)

# Choose random samples without replacement
items = np.array(['A','B','C','D','E','F','G','H','I','J'])
sample = rng.choice(items, size=5, replace=False)
print(sample)  # e.g. ['D' 'G' 'A' 'J' 'C']

Sorting & Searching

Order data, find positions, and efficiently search arrays

Sorting Arrays

PYTHON
scores = np.array([72, 55, 88, 91, 60, 78, 45, 95])

# Sort ascending (returns NEW sorted array)
print(np.sort(scores))          # [45 55 60 72 78 88 91 95]

# Sort descending
print(np.sort(scores)[::-1])   # [95 91 88 78 72 60 55 45]

# argsort — get the INDICES that would sort the array
idx = np.argsort(scores)
print(idx)   # [6 1 4 0 5 2 3 7]  ← positions in ascending order

# Rank students: who came 1st, 2nd, 3rd?
ranked = np.argsort(scores)[::-1]  # descending
for rank, i in enumerate(ranked, 1):
    print(f"Rank {rank}: Student {i+1} — {scores[i]}")

# Sort a 2D array by a specific column
data = np.array([[3, 80], [1, 95], [2, 70], [4, 88]])
sorted_by_score = data[np.argsort(data[:, 1])[::-1]]
print(sorted_by_score)
# [[1 95]  ← sorted by col 1 (score) descending
#  [4 88]
#  [3 80]
#  [2 70]]

Searching Arrays

PYTHON
arr = np.array([10, 20, 30, 40, 50, 30, 60, 30])

# np.where — find indices where condition is True
idx = np.where(arr == 30)
print(idx)         # (array([2, 5, 7]),)  ← 30 appears at index 2, 5, 7

# np.where with replacement — conditional assignment
result = np.where(arr > 30, 'High', 'Low')
print(result)   # ['Low' 'Low' 'Low' 'High' 'High' 'Low' 'High' 'Low']

# np.searchsorted — find where to INSERT a value in a sorted array
sorted_arr = np.array([10, 20, 30, 40, 50])
pos = np.searchsorted(sorted_arr, 35)
print(pos)   # 3  ← insert 35 before index 3 to keep sorted order

# np.nonzero — indices of non-zero (True) elements
mask = np.array([0, 5, 0, 3, 0, 8])
print(np.nonzero(mask))    # (array([1, 3, 5]),)  ← indices of non-zero

# np.any / np.all — quick boolean checks
print(np.any(arr > 55))    # True   ← at least one element > 55
print(np.all(arr > 5))     # True   ← ALL elements > 5
print(np.all(arr > 15))    # False  ← not all > 15 (10 isn't)

Set Operations

Treat arrays like mathematical sets — find unique values, unions, intersections

PYTHON
a = np.array([1, 2, 3, 4, 5, 2, 3])
b = np.array([3, 4, 5, 6, 7])

# Unique values (removes duplicates + sorts)
print(np.unique(a))              # [1 2 3 4 5]

# unique with counts
vals, counts = np.unique(a, return_counts=True)
print(vals)    # [1 2 3 4 5]
print(counts)  # [1 2 2 1 1]  ← 2 appears twice, 3 appears twice

# Union — all values from both (unique)
print(np.union1d(a, b))     # [1 2 3 4 5 6 7]

# Intersection — values in BOTH
print(np.intersect1d(a, b)) # [3 4 5]

# Difference — values in a but NOT in b
print(np.setdiff1d(a, b))   # [1 2]

# Symmetric difference — in EITHER but NOT both
print(np.setxor1d(a, b))    # [1 2 6 7]

# Check membership — is each element of a in b?
print(np.in1d(a, b))        # [F F T T T F T]

# Real-world use: find customers who bought both products
product_A_buyers = np.array([101,102,103,104,105])
product_B_buyers = np.array([103,105,106,107])
both = np.intersect1d(product_A_buyers, product_B_buyers)
print(f"Bought both: Customer IDs {both}")  # [103 105]
🎯 Real-World Applications
  • np.unique() → Find unique product categories in sales data
  • np.intersect1d() → Customers who appear in two different datasets
  • np.setdiff1d() → Items in old stock but NOT new stock (discontinued)
  • np.in1d() → Filter a large array to rows matching allowed IDs

Generate Realistic Stock Prices

Stock prices follow a random walk — each day's price = yesterday's price × (1 + random daily return). Use normal distribution with small mean and std.

STARTER CODE
import numpy as np

rng = np.random.default_rng(seed=2024)

companies = ['TechCo', 'HealthX', 'EnergyPlus', 'FinBank', 'RetailMart']

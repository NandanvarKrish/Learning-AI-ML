What is Seaborn & Why It Matters

Statistical visualization, built for tidy DataFrames

Seaborn is a statistical data visualization library built on top of Matplotlib, created by Michael Waskom. While Matplotlib gives you full control over every pixel, Seaborn gives you beautiful defaults and DataFrame-native syntax for common statistical questions.

🌊 Matplotlib vs Seaborn
Matplotlib: ax.scatter(df['x'], df['y']) ← manual column access
Seaborn: sns.scatterplot(data=df, x='x', y='y', hue='category')
Seaborn understands "tidy" DataFrames directly — pass column NAMES, not raw arrays. hue/size/style auto-map extra dimensions.

Themes & Contexts

Global styling that transforms every chart instantly

set_style() — The Visual Theme

PYTHON
# 5 built-in styles
sns.set_style('darkgrid')    # default — gray bg, white gridlines
sns.set_style('whitegrid')   # white bg, gray gridlines — good for print
sns.set_style('dark')        # gray bg, no gridlines
sns.set_style('white')       # clean white bg, no gridlines — minimal
sns.set_style('ticks')       # white bg with tick marks — classic/scientific

# Fine-tune specific style elements
sns.set_style('whitegrid', {'grid.linestyle': '--'})

# Temporarily apply a style (reverts after the 'with' block)
with sns.axes_style('darkgrid'):
    fig, ax = plt.subplots()
    sns.lineplot(data=flights, x='year', y='passengers', ax=ax)

# Remove specific spines cleanly
sns.despine()                    # removes top & right spines (default)
sns.despine(left=True)         # also remove left spine
sns.despine(offset=10, trim=True)   # offset spines from the plot, trim to data range

set_context() — Scale for the Medium

PYTHON
# Context controls the SCALE of plot elements (font, lines, markers)
# for different output media — NOT the color/style
sns.set_context('paper')      # smallest — for academic papers
sns.set_context('notebook')   # default — for Jupyter notebooks
sns.set_context('talk')       # larger — for presentations/talks
sns.set_context('poster')     # largest — for printed posters

# Scale up/down from a context with font_scale
sns.set_context('talk', font_scale=1.2)

# set_theme() — the all-in-one modern setup call (style + context + palette)
sns.set_theme(style='whitegrid', context='notebook', palette='deep', font_scale=1.1)
💡 sns.set_theme() — Do This First, Every Time
Modern Seaborn code should start with one sns.set_theme(...) call that configures style, context, and palette together. This single line replaces separate calls and is the current best-practice entry point (introduced in Seaborn 0.11+).

# Named qualitative palettes
sns.set_palette('deep')       # default Seaborn palette

sns.color_palette('Blues', as_cmap=True)

sns.color_palette('RdBu', as_cmap=True)

custom = sns.color_palette(['#BE185D','#0891B2','#D97706'])

# Generate N evenly-spaced colors from a continuous colormap
palette_5 = sns.color_palette('viridis', n_colors=5)

# Preview any palette
sns.palplot(sns.color_palette('deep'))

# Apply directly to a specific plot (overrides global palette)
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='day', palette='Set2')

Figure-Level vs Axes-Level Functions

Seaborn's most important architectural concept

Every Seaborn plotting function is either axes-level (draws onto one Matplotlib Axes, like ax.plot()) or figure-level (manages its own Figure, can create multi-panel grids automatically).

📊 The Critical Distinction
Axes-level: sns.scatterplot(), sns.lineplot(), sns.boxplot()
Figure-level: sns.relplot(), sns.displot(), sns.catplot()
Figure-level functions accept `col=` / `row=` to auto-create grids (facets) of subplots. Axes-level functions accept `ax=` to plot into an existing Matplotlib Axes you control.
PYTHON
# AXES-LEVEL — plots onto a specific ax, integrates with existing Matplotlib code
fig, ax = plt.subplots(figsize=(7,5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='time', ax=ax)
ax.set_title('Bill vs Tip')   # customize freely with matplotlib methods after

# FIGURE-LEVEL — manages the whole figure, can facet into a grid
g = sns.relplot(data=tips, x='total_bill', y='tip', hue='time',
                col='day',           # creates ONE subplot per unique 'day' value automatically!
                kind='scatter')
# relplot with col='day' produces 4 side-by-side charts, one per day — no manual subplots needed

g.set_axis_labels('Total Bill (₹)', 'Tip (₹)')
g.fig.suptitle('Tips by Day', y=1.03)   # access the underlying Figure via .fig
Figure-LevelFamilykind= options
relplot()Relationships'scatter', 'line'
displot()Distributions'hist', 'kde', 'ecdf'
catplot()Categorical'strip', 'box', 'violin', 'bar', 'count'
lmplot()Regression(scatter + regression line)
pairplot()Pairwise relationships(grid of all variable pairs)
⚠️ Don't Pass ax= to Figure-Level Functions
Figure-level functions (relplot, displot, catplot) manage their OWN figure and don't accept an ax= parameter — they return a Grid object (like FacetGrid), not an Axes. If you need to plot into an existing subplot, use the axes-level equivalent instead (scatterplot, histplot, boxplot).

relplot() & scatterplot() — Relationships

Exploring how two numeric variables relate

PYTHON
# Basic scatter — axes-level
sns.scatterplot(data=tips, x='total_bill', y='tip')

# Encode extra dimensions — hue, size, style all in ONE call
sns.scatterplot(data=tips,
                x='total_bill', y='tip',
                hue='day',        # color by category
                size='size',       # marker size by party size
                style='time',       # marker shape by Lunch/Dinner
                palette='deep',
                sizes=(30, 200))    # min/max marker size range

# Figure-level with automatic faceting into a grid
sns.relplot(data=tips,
            x='total_bill', y='tip',
            hue='smoker',
            col='time',       # separate subplot per Time value (Lunch/Dinner)
            row='sex',        # AND separate row per Sex — full 2×2 grid!
            kind='scatter',
            height=4, aspect=1.1)   # size of EACH facet

# Wrap many categories into multiple rows
sns.relplot(data=tips, x='total_bill', y='tip',
            col='day', col_wrap=2)   # 4 days → 2×2 grid instead of 1×4
💡 The 4-Dimension Scatter
With x, y, hue, size, style all set, a single scatterplot encodes 5 variables at once — 2 positional + 3 aesthetic mappings. Use this power carefully; too many mappings become hard to read. 2-3 mapped dimensions is usually the sweet spot.

lineplot() — Trends with Automatic Confidence Intervals

Seaborn's superpower: statistical aggregation built in

PYTHON
# Basic line plot
sns.lineplot(data=flights, x='year', y='passengers')

# THE KEY FEATURE: when multiple y-values exist per x, Seaborn
# automatically computes the MEAN and a 95% CONFIDENCE INTERVAL band!
fmri = sns.load_dataset('fmri')
sns.lineplot(data=fmri, x='timepoint', y='signal')
# Shaded band = 95% CI computed automatically from repeated measurements
# In pure Matplotlib you would need to manually compute this!

# Multiple lines with hue, styled differently per category
sns.lineplot(data=fmri, x='timepoint', y='signal',
             hue='region',      # separate colored line per region
             style='event',      # separate linestyle per event type
             markers=True, dashes=False)

# Control the confidence interval calculation
sns.lineplot(data=fmri, x='timepoint', y='signal', errorbar='sd')     # show ±1 std dev instead
sns.lineplot(data=fmri, x='timepoint', y='signal', errorbar=('ci', 99))  # 99% CI
sns.lineplot(data=fmri, x='timepoint', y='signal', errorbar=None)     # no band, just the mean line

# estimator — change how repeated y-values are aggregated
sns.lineplot(data=fmri, x='timepoint', y='signal', estimator='median')
💡 This Is Seaborn's Real Power
In Matplotlib, if you have multiple noisy measurements per x-value, you must manually compute mean/CI and draw the shaded band with fill_between(). Seaborn's lineplot() detects duplicate x-values automatically and does this statistical aggregation for you in one function call.

The Objects Interface — seaborn.objects (so)

Seaborn's modern, composable, grammar-of-graphics API

Since Seaborn 0.12, a NEW interface called seaborn.objects (imported as so) offers a more composable, "grammar of graphics" style API — inspired by ggplot2's layered approach. It coexists with the classic function-based API you've learned.

PYTHON
import seaborn.objects as so
import seaborn as sns

tips = sns.load_dataset('tips')

# Classic function-based API (what you've learned all week)
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='time')

# NEW objects interface — build a plot by CHAINING layers together
(
    so.Plot(tips, x='total_bill', y='tip', color='time')
    .add(so.Dot())              # adds a scatter/dot layer
)

# Layer MULTIPLE marks — points AND a regression line, composed explicitly
(
    so.Plot(tips, x='total_bill', y='tip')
    .add(so.Dot(alpha=0.5))
    .add(so.Line(), so.PolyFit(order=1))   # a STAT transform (PolyFit) + a mark (Line)
)

# Faceting in the objects interface
(
    so.Plot(tips, x='total_bill', y='tip')
    .facet(col='time', row='smoker')
    .add(so.Dot())
)

💡 Should You Switch to the Objects API?
The classic function API (scatterplot, relplot, etc.) remains fully supported and is what most existing code/tutorials use — you do NOT need to abandon it. The objects interface is newer, more flexible for combining unusual layer combinations, but has a steeper learning curve. Understanding both is valuable, but the classic API is what you'll encounter most often in practice today.

Building Custom Style Sheets

Reusable branded themes across a whole analysis

PYTHON
# Define a reusable brand configuration function
def apply_brand_theme():
    sns.set_theme(
        style='whitegrid',
        palette=['#0F766E','#B45309','#7C3AED','#BE185D','#0891B2'],
        font='sans-serif',
        rc={
            'axes.titlesize': 15,
            'axes.titleweight': 'bold',
            'axes.labelsize': 11,
            'figure.titlesize': 18,
            'grid.alpha': 0.25,
        }
    )

apply_brand_theme()   # call once, applies to everything after

# rc= dict inside set_theme() gives fine-grained rcParams control alongside style/palette
sns.set_theme(style='ticks', rc={'axes.spines.top':False, 'axes.spines.right':False})

# Save/reuse a specific palette as a named object
brand_palette = sns.color_palette(['#0F766E','#B45309','#7C3AED'])
sns.set_palette(brand_palette)
✅ Wrap Theme Setup in a Function
For any real project spanning multiple notebooks or scripts, wrapping your theme configuration in a function like apply_brand_theme() (rather than repeating the set_theme call everywhere) ensures ONE consistent source of truth for your visual branding — change it once, and every chart across the whole project updates.

Combining Seaborn Grids with Custom Matplotlib Layouts

Embedding figure-level Seaborn output into larger compositions

Figure-level functions (relplot, catplot, pairplot) create their OWN figure — but you can still extract and reposition their content, or build a hybrid dashboard mixing axes-level Seaborn calls into a custom Matplotlib GridSpec.

PYTHON
# The RECOMMENDED pattern: use AXES-LEVEL Seaborn functions inside a custom GridSpec dashboard
fig = plt.figure(figsize=(16, 10))
gs = fig.add_gridspec(2, 3, hspace=0.4, wspace=0.35)

ax1 = fig.add_subplot(gs[0, :2])       # top-left, spans 2 columns
ax2 = fig.add_subplot(gs[0, 2])        # top-right
ax3 = fig.add_subplot(gs[1, 0])
ax4 = fig.add_subplot(gs[1, 1])
ax5 = fig.add_subplot(gs[1, 2])

# Every axes-level Seaborn function accepts ax= — this is the key integration point
sns.lineplot(data=tips, x='day', y='total_bill', ax=ax1)
sns.boxplot(data=tips, x='time', y='tip', ax=ax2)
sns.histplot(data=tips, x='total_bill', kde=True, ax=ax3)
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax4)
sns.heatmap(tips.select_dtypes('number').corr(), annot=True, ax=ax5)

fig.suptitle('Restaurant Analytics Dashboard', fontsize=18, fontweight='bold')
⚠️ Figure-Level Functions Don't Fit This Pattern
Remember: relplot(), catplot(), pairplot(), jointplot(), and lmplot() manage their OWN figure and can't accept ax=. For a custom dashboard combining many chart types into one cohesive layout, use the AXES-LEVEL equivalents (scatterplot, boxplot, histplot, kdeplot, regplot, heatmap) with ax=, exactly as demonstrated above.

Generate a Realistic HR Dataset
STARTER CODE
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

np.random.seed(7)
n = 400

departments = np.random.choice(['Engineering','Sales','Marketing','Support','HR'], n,
                                p=[0.35,0.25,0.15,0.15,0.10])
tenure_years = np.random.exponential(3, n).clip(0.1,20)
base_pay = {'Engineering':95000,'Sales':75000,'Marketing':70000,'Support':55000,'HR':60000}
salary = np.array([base_pay[d] for d in departments]) + tenure_years*2500 + np.random.normal(0,8000,n)
satisfaction = (10 - tenure_years*0.15 + np.random.normal(0,1.5,n)).clip(1,10)
performance = np.random.normal(7,1.3,n).clip(1,10)
gender = np.random.choice(['Male','Female'], n)
remote = np.random.choice(['Remote','Hybrid','Onsite'], n, p=[0.3,0.4,0.3])
attrition_risk = ((10-satisfaction)*0.4 + (10-performance)*0.2 + np.random.normal(0,1,n)).clip(0,10)

hr = pd.DataFrame({
    'department':departments, 'tenure_years':tenure_years.round(1),
    'salary':salary.round(0), 'satisfaction':satisfaction.round(1),
    'performance':performance.round(1), 'gender':gender,
    'work_mode':remote, 'attrition_risk':attrition_risk.round(1)
})
print(hr.describe())

fig = plt.figure(figsize=(18, 11))
gs = fig.add_gridspec(2, 3, hspace=0.45, wspace=0.3)
fig.suptitle('Vantage Corp — People Analytics Report', fontsize=20, fontweight='bold')

ax1 = fig.add_subplot(gs[0, :2])
sns.boxplot(data=hr, x='department', y='salary', hue='gender', ax=ax1)
ax1.set_title('Salary by Department & Gender')

ax2 = fig.add_subplot(gs[0, 2])
sns.heatmap(hr.select_dtypes('number').corr(), annot=True, cmap='coolwarm', center=0, ax=ax2, cbar=False, fmt='.2f')
ax2.set_title('Correlation Matrix')

ax3 = fig.add_subplot(gs[1, 0])
sns.regplot(data=hr, x='tenure_years', y='satisfaction', ax=ax3, scatter_kws={'alpha':0.4})
ax3.set_title('Tenure vs Satisfaction')

ax4 = fig.add_subplot(gs[1, 1])
sns.violinplot(data=hr, x='work_mode', y='attrition_risk', ax=ax4)
ax4.set_title('Attrition Risk by Work Mode')

ax5 = fig.add_subplot(gs[1, 2])
sns.scatterplot(data=hr, x='performance', y='attrition_risk', hue='department', ax=ax5, s=40)
ax5.set_title('Performance vs Attrition Risk')

fig.savefig('vantage_hr_dashboard.png', dpi=200, bbox_inches='tight')

regplot() — Scatter + Automatic Regression Line

Seaborn's one-line linear relationship visualization

regplot() is an axes-level function combining a scatter plot with an automatically FIT regression line and its confidence interval — no manual np.polyfit() needed.

PYTHON
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style='whitegrid')
tips = sns.load_dataset('tips')

# Basic regression plot — scatter + fitted line + 95% CI band
sns.regplot(data=tips, x='total_bill', y='tip')

# Styled version
sns.regplot(data=tips, x='total_bill', y='tip',
            scatter_kws={'alpha':0.5, 'color':'#0E7490'},
            line_kws={'color':'#BE185D', 'linewidth':2},
            ci=95)                    # confidence interval band around the line

# Fit a HIGHER-ORDER polynomial (not just a straight line)
sns.regplot(data=tips, x='total_bill', y='tip', order=2)   # quadratic fit

# Fit a LOGISTIC regression (for a binary 0/1 outcome variable)
sns.regplot(data=titanic, x='age', y='survived', logistic=True)

# Fit a LOWESS (locally weighted) smooth curve instead of a straight line
sns.regplot(data=tips, x='total_bill', y='tip', lowess=True)

# No confidence interval band, no scatter points, just the fit line
sns.regplot(data=tips, x='total_bill', y='tip', ci=None, scatter=False)
💡 regplot() vs Matplotlib's np.polyfit() Approach
In pure Matplotlib, adding a trend line requires: compute coefficients with np.polyfit(), build the fit function with np.poly1d(), generate points, then plot. Seaborn's regplot() does all of this — including the confidence interval band — in ONE function call.

lmplot() — Figure-Level Regression with Faceting

Compare regression relationships across groups automatically

PYTHON
# lmplot is the figure-level version of regplot — same fitting, but with faceting power
sns.lmplot(data=tips, x='total_bill', y='tip')

# Separate regression line PER hue group — reveals if the relationship differs by category
sns.lmplot(data=tips, x='total_bill', y='tip', hue='smoker')
# Two separate fitted lines — do smokers and non-smokers tip differently relative to bill size?

# Faceted into a grid — separate SUBPLOT per category, each with its own regression line
sns.lmplot(data=tips, x='total_bill', y='tip',
            col='time', row='smoker',   # 2×2 grid, each panel with its OWN independent fit
            height=4)

# hue AND col together — compare hue-lines WITHIN each facet
sns.lmplot(data=tips, x='total_bill', y='tip', hue='sex', col='day', col_wrap=2)
FunctionLevelFaceting (col/row)?ax= support?
regplot()Axes-level❌ No✅ Yes
lmplot()Figure-level✅ Yes❌ No
💡 hue= vs col= in lmplot()
hue= overlays multiple fitted lines in the SAME panel (good for 2-3 groups, direct comparison). col=/row= creates SEPARATE panels (good for more groups, or when overlaid lines would be too cluttered to read).

jointplot() — Marginal Distributions + Relationship

Three charts in one: scatter/relationship plus both variables' distributions

jointplot() combines a central relationship plot (scatter, hex, KDE) with marginal distribution plots along the top and right edges — showing both the RELATIONSHIP and each variable's individual DISTRIBUTION at once.

PYTHON
# Default: scatter in the middle, histograms on the margins
sns.jointplot(data=tips, x='total_bill', y='tip')

# Different central plot kinds
sns.jointplot(data=tips, x='total_bill', y='tip', kind='hex')      # hexbin — great for LOTS of overlapping points
sns.jointplot(data=tips, x='total_bill', y='tip', kind='kde')      # 2D density contours + marginal KDEs
sns.jointplot(data=tips, x='total_bill', y='tip', kind='reg')      # adds a regression line to the center
sns.jointplot(data=tips, x='total_bill', y='tip', kind='resid')    # residuals plot

# Color by a categorical hue
sns.jointplot(data=tips, x='total_bill', y='tip', hue='time')

# Access and further customize the underlying axes
g = sns.jointplot(data=tips, x='total_bill', y='tip')
g.ax_joint.set_xlabel('Total Bill (₹)')      # the main central plot
g.ax_marg_x.set_title('Bill Distribution')  # top marginal plot

# Overlay additional detail onto the joint axes
g.plot_joint(sns.kdeplot, color='r', levels=5)   # add contour lines on top of the scatter
💡 kind='hex' for Overplotting
When you have thousands of overlapping data points, a regular scatter becomes a solid blob. kind='hex' bins the 2D space into hexagons colored by point density — revealing the TRUE concentration pattern that a scatter plot would hide.

heatmap() — Matrix Visualization

Correlation matrices and 2D tabular data as color

PYTHON
# Compute a correlation matrix from a DataFrame directly
numeric_cols = tips.select_dtypes(include='number')
corr_matrix = numeric_cols.corr()      # Pandas built-in correlation calculation

# Basic heatmap
sns.heatmap(corr_matrix)

# Fully styled correlation heatmap — the standard EDA pattern
sns.heatmap(corr_matrix,
            annot=True,             # show numeric value in each cell
            fmt='.2f',               # format: 2 decimal places
            cmap='coolwarm',         # diverging colormap (correlation ranges -1 to 1)
            vmin=-1, vmax=1,        # fix the color scale range explicitly
            center=0,               # ensure 0 maps to the neutral midpoint color
            square=True,             # make each cell perfectly square
            linewidths=0.5,          # thin white gridlines between cells
            cbar_kws={'label':'Correlation'})

# Mask the upper triangle — correlation matrices are symmetric, showing both halves is redundant
import numpy as np
mask = np.triu(np.ones_like(corr_matrix, dtype=bool))   # True for upper triangle
sns.heatmap(corr_matrix, mask=mask, annot=True, cmap='coolwarm', center=0)

# Non-correlation heatmap example — pivoted data (e.g., flights by month/year)
flights = sns.load_dataset('flights')
flights_pivot = flights.pivot(index='month', columns='year', values='passengers')
sns.heatmap(flights_pivot, cmap='YlGnBu', annot=True, fmt='d')
⚠️ Always Set center=0 for Correlation Heatmaps
Without center=0, the colormap might not put white/neutral exactly at zero correlation, making it hard to instantly distinguish weak positive from weak negative correlations. Setting center=0 with a diverging colormap like 'coolwarm' or 'RdBu' ensures the visual midpoint matches the meaningful "no correlation" value.

residplot() — Checking Regression Assumptions

Is a linear fit actually appropriate for this data?

A residual plot shows the ERRORS (actual - predicted) of a linear fit. If a straight line is the RIGHT model, residuals should scatter randomly around zero with no pattern. A curved pattern in residuals signals the relationship is NOT actually linear.

PYTHON
# Residual plot — shows leftover error after fitting a straight line
sns.residplot(data=tips, x='total_bill', y='tip')
# A horizontal band of scattered points with NO pattern = good linear fit
# A curved/systematic pattern = a linear model is NOT appropriate; consider order=2, lowess=True

# Add a lowess smoother line through the residuals to spot subtle patterns more easily
sns.residplot(data=tips, x='total_bill', y='tip', lowess=True,
              line_kws={'color':'red'})
📉 Reading a Residual Plot
✅ Random scatter around y=0, roughly constant spread → linear model fits well
❌ Curved/U-shaped pattern → relationship is nonlinear, try order=2 or lowess
❌ Funnel shape (spread grows/shrinks with x) → non-constant variance (heteroscedasticity)

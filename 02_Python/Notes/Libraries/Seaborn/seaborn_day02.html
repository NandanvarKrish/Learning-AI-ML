histplot() & displot() — Distributions

Understanding how a single numeric variable is spread

PYTHON
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style='whitegrid')
tips = sns.load_dataset('tips')
penguins = sns.load_dataset('penguins')

# Basic histogram — axes-level
sns.histplot(data=tips, x='total_bill')

# Styled with bins, KDE overlay, and hue split
sns.histplot(data=tips, x='total_bill',
             bins=25,
             kde=True,              # overlay a smooth density curve on the histogram
             hue='time',            # separate colored histograms per Lunch/Dinner
             multiple='layer')       # 'layer', 'stack', 'dodge', 'fill' — how overlapping hues combine

# Normalize to show density/percentage instead of raw counts
sns.histplot(data=tips, x='total_bill', stat='density')   # 'count','density','probability','percent'

# 2D histogram — joint distribution of TWO variables as a heatmap
sns.histplot(data=tips, x='total_bill', y='tip', cbar=True)

# FIGURE-LEVEL equivalent — displot, supports faceting
sns.displot(data=tips, x='total_bill', col='time', kde=True, kind='hist')
multiple= valueEffect with hue=
'layer' (default)Histograms drawn on top of each other, semi-transparent
'stack'Histograms stacked vertically (totals add up)
'dodge'Bars placed side by side within each bin
'fill'Stacked AND normalized to 100% per bin

kdeplot() — Smooth Density Curves

Continuous distribution shape without binning artifacts

A Kernel Density Estimate (KDE) plots a smooth curve estimating the probability density function of a variable — like a smoothed, continuous version of a histogram.

PYTHON
# Basic KDE
sns.kdeplot(data=tips, x='total_bill')

# Filled area under the curve + multiple groups
sns.kdeplot(data=tips, x='total_bill', hue='time',
            fill=True,             # shade under the curve
            alpha=0.5,
            common_norm=False)      # each group normalized independently (each integrates to 1)

# Control smoothness with bandwidth adjustment
sns.kdeplot(data=tips, x='total_bill', bw_adjust=0.5)   # smaller = more wiggly/detailed
sns.kdeplot(data=tips, x='total_bill', bw_adjust=2)     # larger = smoother/more generalized

# 2D KDE — bivariate density as contour-like shading
sns.kdeplot(data=penguins, x='bill_length_mm', y='bill_depth_mm',
            fill=True, cmap='rocket')

# Combine histogram + KDE together (common pattern)
sns.histplot(data=tips, x='total_bill', kde=True, stat='density')
💡 KDE vs Histogram
A histogram's shape depends heavily on bin width/count choices — the same data can look quite different with 10 vs 50 bins. KDE avoids this "binning artifact" by fitting a smooth curve, though it introduces its OWN parameter (bandwidth) that controls smoothness. Often best used TOGETHER: histogram for raw counts, KDE overlay for the underlying shape trend.

ecdfplot() — Cumulative Distribution

What fraction of data falls below each value

An ECDF (Empirical Cumulative Distribution Function) shows, for every x-value, what PROPORTION of the data is less than or equal to it. Unlike histograms, there's no binning choice needed — it shows every data point exactly.

PYTHON
# Basic ECDF
sns.ecdfplot(data=tips, x='total_bill')

# Compare groups directly — great for comparing distributions precisely
sns.ecdfplot(data=tips, x='total_bill', hue='time')

# Read specific insights directly from the plot:
# "50% of dinner bills are below ₹X" = find y=0.5, read the x-value
# "What % of bills are under ₹20?" = find x=20, read the y-value

# Complementary ECDF (shows P(X > x) instead of P(X <= x))
sns.ecdfplot(data=tips, x='total_bill', complementary=True)
ChartBest ForLimitation
HistogramIntuitive shape at a glanceShape depends on bin choice
KDESmooth shape, good for overlaying groupsDepends on bandwidth choice; can imply data where none exists
ECDFExact, no parameter choices, precise percentile readingLess visually intuitive for shape (no obvious "peak")

The catplot() Family — Categorical Comparisons

One figure-level function, many chart kinds

catplot() is the figure-level umbrella for ALL categorical plot types — switch chart type entirely just by changing kind=.

📦 catplot() kind= Options
'strip' → individual points, jittered (default)
'swarm' → individual points, non-overlapping
'box' → box plot (quartiles)
'violin' → violin plot (density shape)
'bar' → mean + confidence interval bars
'point' → mean as connected point markers
'count' → count of observations per category
PYTHON
# Same data, different kind= — instantly different chart type
sns.catplot(data=tips, x='day', y='total_bill', kind='box')
sns.catplot(data=tips, x='day', y='total_bill', kind='violin')
sns.catplot(data=tips, x='day', y='total_bill', kind='swarm')
sns.catplot(data=tips, x='day', y='total_bill', kind='bar')

# With hue AND faceting — categorical + relationship + facet, all at once
sns.catplot(data=tips, x='day', y='total_bill',
            hue='sex', col='time',
            kind='box', height=5)

# count — great for categorical frequency (no y= needed)
sns.catplot(data=tips, x='day', kind='count', hue='time')

boxplot(), violinplot() & swarmplot() — Axes-Level

The individual functions behind catplot's kind= options

PYTHON
# Axes-level box plot with all the Seaborn conveniences
fig, ax = plt.subplots(figsize=(8,5))
sns.boxplot(data=tips, x='day', y='total_bill', hue='smoker', ax=ax)

# Violin plot with split (compares 2 hue groups within each violin's two halves)
sns.violinplot(data=tips, x='day', y='total_bill',
               hue='sex', split=True,     # each violin split in half by sex — powerful comparison
               inner='quartile')         # show quartile lines inside

# Swarm plot — every individual point, non-overlapping (best for smaller datasets)
sns.swarmplot(data=tips, x='day', y='total_bill', hue='time', size=4)

# Strip plot — like swarm but points can overlap (jittered), faster for big data
sns.stripplot(data=tips, x='day', y='total_bill', jitter=True, alpha=0.5)

# POWERFUL COMBO: overlay swarm points ON TOP of a box plot
fig, ax = plt.subplots(figsize=(8,5))
sns.boxplot(data=tips, x='day', y='total_bill', color='lightgray', ax=ax)
sns.swarmplot(data=tips, x='day', y='total_bill', color='#6D28D9', size=3, ax=ax)
# Shows BOTH the summary statistics AND every individual data point!
💡 Box + Swarm — A Best-Practice Combo
Overlaying individual points (swarmplot/stripplot) on top of a summary chart (boxplot) gives viewers BOTH the statistical summary AND the raw data distribution — showing sample size, gaps, clusters, and outliers that summary statistics alone can hide. This is a very common, highly-regarded pattern in scientific and business reporting.

barplot() & countplot()

Aggregated means and simple frequency counts

PYTHON
# barplot: shows the MEAN of y for each x category, with a confidence interval
sns.barplot(data=tips, x='day', y='total_bill', hue='sex',
            errorbar='ci',          # confidence interval, shown as error bars (whiskers)
            estimator='mean')      # could also be 'median', 'sum', etc.

# countplot: counts OBSERVATIONS per category — no y= needed at all!
sns.countplot(data=tips, x='day', hue='smoker')

# Horizontal orientation — great for many/long category names
sns.barplot(data=tips, y='day', x='total_bill', orient='h')

# Order categories explicitly (instead of alphabetical/appearance order)
sns.barplot(data=tips, x='day', y='total_bill',
            order=['Thur','Fri','Sat','Sun'])   # chronological instead of alphabetical
⚠️ barplot() Shows the MEAN, Not Raw Counts
A common beginner mistake: barplot(x='day', y='total_bill') shows the AVERAGE bill per day (with confidence interval), NOT how many records exist per day. For frequency/count of rows, use countplot() instead, which needs no y= parameter at all.

sns.pairplot() — Every Variable vs Every Other, Instantly

The fastest way to explore a new dataset

sns.pairplot(data=df, hue=, vars=, diag_kind='kde')
Builds a grid: every numeric column plotted against every other, plus each column's own distribution on the diagonal.
hue = color by a category  |  vars = limit to specific columns (avoid clutter)  |  diag_kind = 'hist' or 'kde' for the diagonal
💼 Real-world use

A new analyst joining a bank's fraud team gets a fresh dataset of 6 transaction features — one pairplot() call reveals every relationship AND every distribution AND how fraud vs non-fraud cases differ, in under a second, instead of building 15+ separate charts manually.

PYTHON
penguins = sns.load_dataset('penguins').dropna()

sns.pairplot(penguins,
             hue='species',
             vars=['bill_length_mm','bill_depth_mm','flipper_length_mm'],
             diag_kind='kde')
# One call → a full grid of scatter plots (off-diagonal) + density curves (diagonal),
# colored by species — reveals which measurements best separate the 3 species
⚠️ Limit vars= for Datasets With Many Columns
With 10+ numeric columns, pairplot() creates a 10×10 grid — 100 tiny, hard-to-read panels. Use vars=[...] to select just the 3-6 most relevant columns for a readable, useful result.

Faceting — col= and row= on Any Figure-Level Function

Automatic small-multiples, no manual subplot loop

sns.relplot(data=df, x=, y=, col=, row=, kind='scatter')
Automatically splits your chart into a GRID of subplots, one per category — instead of writing a manual loop.
col = split into separate columns by this category  |  row = ALSO split into rows by a second category
💼 Real-world use

A retailer comparing bill-vs-tip patterns separately for Lunch/Dinner AND Male/Female — instead of 4 manual charts, one line of code builds a clean 2×2 grid automatically.

PYTHON
sns.relplot(data=tips, x='total_bill', y='tip',
            col='time', row='sex', hue='smoker',
            kind='scatter', height=4)
# Produces a 2×2 grid (2 times × 2 sexes), colored further by smoker status
💡 This Works on displot() and catplot() Too
col=/row= faceting isn't unique to relplot() — it works the SAME way on sns.displot() (distributions) and sns.catplot() (categorical charts, with kind='box'/'violin'/'bar' etc). Learn the pattern once, use it everywhere.
🎨

sns.clustermap() — Bonus: Auto-Grouping Similar Rows

A heatmap that reorders itself to reveal hidden clusters

sns.clustermap(df.corr(), annot=True, cmap='coolwarm')
Like heatmap(), but automatically REORDERS rows/columns so similar ones sit next to each other.
💼 Real-world use

A retail analyst with 20 product categories' sales data uses clustermap() to automatically discover which categories tend to sell together seasonally — the reordering visually groups them without manual sorting.

PYTHON
numeric_cols = penguins.select_dtypes(include='number')
sns.clustermap(numeric_cols.corr(), annot=True, cmap='coolwarm', center=0)

Estimated time: 55–70 minutes  |  Difficulty: ⭐⭐⭐⭐  |  Uses all 3 days

📋 Project Brief

Using the built-in 'penguins' dataset, run a complete exploratory analysis a research team could actually use, combining every function from this condensed course.

Day 1: scatterplot, histplot Day 2: boxplot, violinplot, heatmap Day 3: pairplot, faceted relplot
  • sns.set_theme() applied globally
  • pairplot() of key measurements, colored by species, to get the full overview first
  • Faceted relplot(): bill measurements by species (col), split by sex (hue)
  • Boxplot or violinplot: body mass by species
  • Heatmap: correlation matrix of all numeric measurements
  • A short written conclusion: which measurement(s) best distinguish the 3 species?

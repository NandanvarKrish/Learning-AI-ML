Categorical & Regression Charts

Comparing groups and finding trends — the 5 functions analysts reach for constantly, each with a real business scenario.

sns.boxplot() — Compare Groups' Summary Stats

Median, spread, outliers — quick group comparison

sns.boxplot(data=df, x=, y=, hue=)
One box per category, showing median, IQR (25th-75th percentile), and outliers.
hue = split each category further into sub-groups (e.g., by gender within each department)
💼 Real-world use

HR comparing salary ranges across departments, split by seniority level — quickly spotting which department has the widest pay spread or concerning outliers.

PYTHON
tips = sns.load_dataset('tips')
sns.boxplot(data=tips, x='day', y='total_bill', hue='smoker')
# One box per day, split into smoker/non-smoker sub-boxes
🎻

sns.violinplot() — Full Shape Comparison

Reveals patterns box plots hide

sns.violinplot(data=df, x=, y=, hue=, split=True)
Shows the FULL density shape per category, not just summary numbers.
split=True — with exactly 2 hue groups, shows each half of the violin for direct visual comparison
💼 Real-world use

A product team checking if customer satisfaction scores are simply "average" vs actually SPLIT into two groups (very happy + very unhappy, few in between) — a box plot would mask this bimodal pattern; a violin reveals it instantly.

PYTHON
sns.violinplot(data=tips, x='day', y='total_bill', hue='sex', split=True)
📊

sns.barplot() — Compare Group Averages

Not raw counts — the MEAN, with a confidence interval

sns.barplot(data=df, x=, y=, errorbar='ci')
Shows the average of a numeric column per category, with an error bar showing uncertainty.
💼 Real-world use

Comparing average order value across 5 marketing channels — the error bars immediately show which channels have enough data to trust the average, and which are still noisy.

PYTHON
sns.barplot(data=orders_df, x='channel', y='order_value', errorbar='ci')
⚠️ barplot() ≠ Counting Rows
sns.barplot(x='day', y='total_bill') shows the AVERAGE bill per day, NOT how many transactions happened. For raw counts of rows per category, use sns.countplot(x='day') instead — it needs no y= at all.
📈

sns.regplot() — Scatter + Automatic Trend Line

See the relationship AND its statistical fit, in one call

sns.regplot(data=df, x=, y=, ci=95)
Scatter points PLUS a fitted regression line and confidence band — no manual np.polyfit() needed.
ci = confidence band around the fit line (None to hide it)
💼 Real-world use

A real estate analyst checking if house size predicts price, with the fitted line making the trend explicit rather than leaving viewers to eyeball a scatter cloud.

PYTHON
sns.regplot(data=housing_df, x='sqft', y='price',
             scatter_kws={'alpha':0.4}, line_kws={'color':'red'})
🔥

sns.heatmap() — Correlation at a Glance

Which variables move together?

sns.heatmap(df.corr(), annot=True, cmap='coolwarm', center=0)
Colors a correlation matrix, with exact values printed in each cell.
annot=True prints the number in each cell  |  center=0 ensures 0 correlation maps to the neutral middle color
💼 Real-world use

A finance team scanning 15 economic indicators at once to spot which ones move together before building a forecasting model — a table of 15×15 numbers would take minutes to scan; a heatmap reveals it in seconds.

PYTHON
numeric_cols = tips.select_dtypes(include='number')
sns.heatmap(numeric_cols.corr(), annot=True, cmap='coolwarm', center=0, fmt='.2f')
💡 One-Line Correlation Check on Any DataFrame
df.corr() computes ALL pairwise correlations automatically. Feeding that straight into sns.heatmap() is the standard, near-universal first step of exploratory data analysis on any new numeric dataset.

Real-World Task — Employee Compensation Review

Estimated time: 45–55 minutes  |  Difficulty: ⭐⭐⭐

📋 Project Brief

You're presenting to leadership on pay equity and performance. Build 5 charts answering their key questions.

  • Boxplot: salary by department, split by gender (hue)
  • Violinplot: same data as split violins — note anything the boxplot missed
  • Barplot: average bonus by performance rating, with confidence intervals
  • Regplot: years of experience vs salary, with fitted trend line
  • Heatmap: correlation matrix of experience, performance score, salary, and bonus

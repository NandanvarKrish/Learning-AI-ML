The Setup — 3 Lines You'll Write Every Time

Import convention and global theming

import seaborn as sns; sns.set_theme(style=, palette=)
Sets a consistent visual theme for every chart made afterward — colors, gridlines, fonts.
style = 'whitegrid' (clean, good for reports), 'darkgrid' (default)  |  palette = 'deep', 'colorblind', or a custom list of hex colors
💼 Real-world use

A data team puts sns.set_theme(style='whitegrid', palette='colorblind') at the top of every notebook so every chart in every report looks consistent AND is accessible to colorblind viewers.

PYTHON
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

sns.set_theme(style='whitegrid', palette='deep')
💡 The Big Idea Behind Seaborn
Instead of manually pulling columns out of a DataFrame like Matplotlib requires, Seaborn functions take data=df and x='column_name' — pass the WHOLE DataFrame once, then reference columns by NAME. This is the single biggest reason Seaborn is faster to use for real datasets.
⚫

sns.scatterplot() — Relationships, With Extra Dimensions

Seaborn's superpower: encode 3+ variables in one call

sns.scatterplot(data=df, x=, y=, hue=, size=)
Plots points, automatically color-coding and/or sizing by extra columns.
hue = column to color-code by (categories get automatic distinct colors)  |  size = column to size points by
💼 Real-world use

A restaurant chain analyzing bill amount vs tip, colored by day of week and sized by party size — 4 variables, one chart, one line of code.

PYTHON
tips = sns.load_dataset('tips')   # built-in practice dataset

sns.scatterplot(data=tips, x='total_bill', y='tip',
                hue='day', size='size', sizes=(30,200))
# hue='day' auto-colors by weekday; size='size' scales dots by party size
📈

sns.lineplot() — Trends With Automatic Confidence Bands

Trends over time, with statistics built in

sns.lineplot(data=df, x=, y=, hue=, errorbar='ci')
Draws a trend line, and automatically shades a confidence interval if multiple y-values exist per x.
errorbar = 'ci' (95% confidence interval, default), 'sd' (±1 std dev), or None (no band)
💼 Real-world use

A pharma company plotting patient recovery scores over time, across many patients — the shaded band shows how confident we should be in the average trend, without manually computing statistics.

PYTHON
fmri = sns.load_dataset('fmri')
sns.lineplot(data=fmri, x='timepoint', y='signal', hue='region')
# Shaded band = 95% CI computed automatically — in raw Matplotlib you'd compute this yourself
⚠️ This Auto-CI Feature is Seaborn's Real Differentiator
If your data has multiple measurements per x-value (repeated patients, repeated trials), lineplot() automatically aggregates and shows uncertainty — Matplotlib's plot() has NO equivalent built-in behavior.
📊

sns.histplot() — Distribution With a Smooth Overlay

A better default histogram than Matplotlib's

sns.histplot(data=df, x=, bins=, kde=True, hue=)
A histogram with an optional smooth density curve overlay, and easy group comparison via hue.
kde=True overlays a smooth curve  |  hue = compare multiple groups' distributions in one chart
💼 Real-world use

An e-commerce team comparing "time to checkout" distribution between mobile and desktop users, to see if mobile users take noticeably longer.

PYTHON
sns.histplot(data=checkout_df, x='checkout_seconds',
             hue='device', kde=True, bins=25, multiple='layer')
# multiple='layer' overlays both groups semi-transparently; try 'stack' for a different comparison
🌊

sns.kdeplot() — Smooth Distribution Comparison

Cleaner than overlapping histograms for comparing shapes

sns.kdeplot(data=df, x=, hue=, fill=True)
Draws smooth density curves — great for overlaying several groups' distribution SHAPES.
fill=True shades under the curve for easier visual comparison
💼 Real-world use

Comparing exam score distributions across 3 different teaching methods — overlapping histograms would look cluttered with bars; smooth kdeplot curves stay readable even with 3+ groups on one chart.

PYTHON
sns.kdeplot(data=exam_df, x='score', hue='method', fill=True, alpha=0.4)
FunctionBest For
histplot()Actual bin counts, comparing exact frequencies
kdeplot()Comparing overall SHAPE across 2-4+ groups cleanly

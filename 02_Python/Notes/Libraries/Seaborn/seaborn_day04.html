FacetGrid — The Engine Behind relplot/displot/catplot

Build custom faceted grids with ANY plotting function

FacetGrid is the underlying class that powers relplot(), displot(), and catplot()'s faceting. Using it DIRECTLY gives you full control, including the ability to map ANY function — even custom or Matplotlib functions — onto the grid.

PYTHON
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style='whitegrid')
tips = sns.load_dataset('tips')

# Step 1: Create the grid SKELETON — defines rows/cols/hue, but draws nothing yet
g = sns.FacetGrid(tips, col='time', row='smoker', hue='sex', height=4)

# Step 2: .map() applies a plotting function to EVERY facet automatically
g.map(sns.scatterplot, 'total_bill', 'tip')   # positional column names, not data=
g.add_legend()

# map() works with ANY plotting function that takes x, y or a single array — even Matplotlib!
g2 = sns.FacetGrid(tips, col='day', col_wrap=2, height=3.5)
g2.map(plt.hist, 'total_bill', bins=15, color='#B45309')   # plain Matplotlib function works too!

# map_dataframe() — when the function needs the WHOLE row (e.g., for custom multi-column logic)
def custom_annotate(data, **kwargs):
    plt.scatter(data['total_bill'], data['tip'], **kwargs)
    plt.axhline(data['tip'].mean(), color='red', linestyle='--')

g3 = sns.FacetGrid(tips, col='time')
g3.map_dataframe(custom_annotate)   # receives the FULL sub-DataFrame per facet
MethodFunction ReceivesUse When
.map(func, 'x', 'y')Positional arrays for named columnsStandard plotting functions (scatterplot, plt.hist)
.map_dataframe(func)The full facet's DataFrame subsetCustom functions needing multiple columns or row-wise logic
💡 Why Learn FacetGrid Directly?
relplot()/displot()/catplot() cover 90% of use cases, but sometimes you need a chart type they don't support (a custom annotation, a Matplotlib-only function, or unusual per-facet logic). FacetGrid gives you that flexibility while keeping automatic faceting.

PairGrid & pairplot() — Every Variable Against Every Other

The fastest way to explore relationships across an entire dataset

hist A
A×B
A×C
B×A
hist B
B×C
C×A
C×B
hist C

A 3-variable pairplot: diagonal shows each variable's own distribution; off-diagonal cells show every pairwise scatter relationship.

PYTHON
penguins = sns.load_dataset('penguins').dropna()

# pairplot() — the QUICK, one-line way to see EVERY numeric column pair at once
sns.pairplot(penguins)

# Color by species, customize diagonal to KDE instead of histogram
sns.pairplot(penguins, hue='species', diag_kind='kde', palette='Set2')

# Only include SPECIFIC columns (avoid clutter with irrelevant variables)
sns.pairplot(penguins,
             vars=['bill_length_mm','bill_depth_mm','flipper_length_mm'],
             hue='species')

# Different plot kinds for the off-diagonal cells
sns.pairplot(penguins, hue='species', kind='reg')     # adds regression lines to every off-diagonal panel
sns.pairplot(penguins, hue='species', kind='kde')     # 2D density instead of scatter

# ── PairGrid — the underlying class, for FULL manual control ──
g = sns.PairGrid(penguins, hue='species', vars=['bill_length_mm','bill_depth_mm','flipper_length_mm'])
g.map_diag(sns.histplot)              # what goes on the diagonal (self vs self)
g.map_upper(sns.scatterplot)          # what goes ABOVE the diagonal
g.map_lower(sns.kdeplot)              # what goes BELOW the diagonal — can be DIFFERENT from upper!
g.add_legend()
💡 pairplot() vs PairGrid
pairplot() is the quick, one-line convenience function (like relplot vs FacetGrid). PairGrid gives you the power to put DIFFERENT chart types on the diagonal, upper triangle, and lower triangle — e.g., histograms on the diagonal, scatter above, and KDE contours below, all in ONE grid.

clustermap() — Heatmap + Hierarchical Clustering

Reordering rows/columns to reveal hidden groupings

clustermap() combines a heatmap with hierarchical clustering — it automatically REORDERS rows and columns so similar ones are placed next to each other, revealing natural groupings that a fixed alphabetical/original order would hide.

PYTHON
# Basic clustermap on numeric penguin measurements
numeric_penguins = penguins.select_dtypes(include='number')
sns.clustermap(numeric_penguins.corr(), annot=True, cmap='coolwarm', center=0)
# Notice: rows/columns are REORDERED — similar variables cluster together,
# with dendrograms (tree diagrams) shown on the side indicating cluster structure

# Standardize data first (z-score) — often necessary before clustering raw measurements
sns.clustermap(numeric_penguins, standard_scale=1, cmap='viridis')   # standardize by column (axis 1)

# Control clustering method and distance metric
sns.clustermap(numeric_penguins.corr(),
                method='average',    # linkage method: 'average', 'single', 'complete', 'ward'
                metric='euclidean',   # distance metric
                cmap='mako',
                figsize=(8,8))

# Disable clustering on one axis only (e.g., keep columns in original order)
sns.clustermap(numeric_penguins.corr(), col_cluster=False)

# Add a color strip showing species for each row (row_colors)
species_colors = penguins['species'].map({'Adelie':'#B45309', 'Chinstrap':'#0891B2', 'Gentoo':'#7C3AED'})
sns.clustermap(numeric_penguins, row_colors=species_colors, standard_scale=1)
🎨 What the Dendrograms Mean
Tree branches on the side show HOW items were grouped
Items joined at LOWER heights = more similar to each other
Items joined at HIGHER heights = less similar, grouped later
clustermap() is a quick way to spot which variables (or observations) naturally group together, without formal clustering algorithms.

Custom Mapping onto Grids

Combining multiple chart types within one FacetGrid or PairGrid

PYTHON
# Layer MULTIPLE .map() calls to combine chart types in the SAME facets
g = sns.FacetGrid(tips, col='time', height=4.5)
g.map(sns.scatterplot, 'total_bill', 'tip', alpha=0.6)
g.map(sns.regplot, 'total_bill', 'tip', scatter=False, color='red')
# Scatter points AND a regression line, both mapped onto the SAME faceted grid

# Add reference lines to every facet with a custom function
def add_mean_line(x, **kwargs):
    plt.axvline(x.mean(), color='black', linestyle='--', linewidth=1)

g2 = sns.FacetGrid(tips, col='day', col_wrap=2)
g2.map(sns.histplot, 'total_bill')
g2.map(add_mean_line, 'total_bill')     # adds a mean-marker vertical line to EVERY facet

# Set shared titles, axis labels, and limits across ALL facets at once
g2.set_titles('{col_name}')              # use just the value, not 'day = Thur'
g2.set_axis_labels('Total Bill', 'Count')
g2.set(xlim=(0,60))                    # apply xlim to every facet simultaneously
g2.fig.suptitle('Bill Distribution by Day', y=1.02)
✅ The Layering Pattern
Calling .map() multiple times on the SAME grid object layers each new plotting call ON TOP of the previous ones, within every facet simultaneously. This is how you build "scatter + regression line" or "histogram + reference line" combos across an entire faceted grid.

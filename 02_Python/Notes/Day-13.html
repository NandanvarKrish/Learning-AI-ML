Inheritance — Build on What Already Exists

Inheritance lets a child class get all the properties and methods of a parent class, then add or override specific features. This is the DRY principle applied to classes — write shared code once in the parent, specialise in children.

Python — Inheritance Basics
class Animal: def __init__(self, name): self.name = name def speak(self): return "..." def info(self): print(f"{self.name} says: {self.speak()}") # Child classes inherit from Animal class Dog(Animal): # ← inherits Animal def speak(self): # ← overrides parent's speak() return "Woof!" class Cat(Animal): def speak(self): return "Meow!" class Bird(Animal): def speak(self): return "Tweet!" def fly(self): # ← NEW method only in Bird print(f"{self.name} is flying!") # info() is inherited — works for all children! Dog("Rex").info() # Rex says: Woof! Cat("Whiskers").info() # Whiskers says: Meow! b = Bird("Tweety") b.info() # Tweety says: Tweet! b.fly() # Tweety is flying!
🔗 super() — Call the Parent

super() calls the parent class's methods. Use it in __init__ to set up the parent's attributes before adding the child's own.

Python — super() in __init__
class Person: def __init__(self, name, age): self.name = name self.age = age def greet(self): return f"Hi, I'm {self.name}, {self.age} years old" class Student(Person): def __init__(self, name, age, marks): super().__init__(name, age) # ← call Person's __init__ self.marks = marks # ← add Student's own attr def greet(self): # override greet() base = super().greet() # get parent's greet return f"{base}. My marks: {self.marks}" class Teacher(Person): def __init__(self, name, age, subject): super().__init__(name, age) self.subject = subject s = Student("Ali", 18, 88) t = Teacher("Sir Zaid", 35, "ML") print(s.greet()) # Hi, I'm Ali, 18 years old. My marks: 88 print(t.greet()) # Hi, I'm Sir Zaid, 35 years old (inherited)
💡Always call super().__init__() in a child's __init__. Without it, the parent's attributes (self.name, self.age) are never set up, and you'll get AttributeError when any parent method tries to use them.
🔒 @property — Access Methods Like Attributes

The @property decorator lets you access a method without parentheses — like an attribute. It's perfect for computed values that should look like simple data. Used throughout sklearn and Keras.

Without @propertyWith @property
model.get_accuracy()model.accuracy
student.get_grade()student.grade
model.is_trained()model.is_trained
Python — @property decorator
class Student: def __init__(self, name, marks): self.name = name self._marks = marks # _ = convention: "private" @property def marks(self): return self._marks @marks.setter def marks(self, value): if not (0 <= value <= 100): raise ValueError(f"Marks {value} out of range 0-100") self._marks = value @property def grade(self): # computed property — no setter if self._marks >= 80: return "A" elif self._marks >= 60: return "B" else: return "F" s = Student("Ali", 88) print(s.marks) # 88 ← no parentheses! print(s.grade) # A ← computed automatically s.marks = 95 # uses setter — validates! s.marks = 150 # raises ValueError!
🧱 Putting It All Together — ML Layer Example
Python — Keras-style layer hierarchy
class Layer: # Base class (like keras.Layer) def __init__(self, name): self.name = name self.built = False def forward(self, x): raise NotImplementedError("Subclass must implement forward()") @property def is_built(self): return self.built class ReLULayer(Layer): def __init__(self): super().__init__("relu") self.built = True def forward(self, x): return [max(0, v) for v in x] class SigmoidLayer(Layer): def __init__(self): super().__init__("sigmoid") self.built = True def forward(self, x): return [1/(1+2.718**(-v)) for v in x] relu = ReLULayer() sigmoid = SigmoidLayer() print(relu.forward([-2, 0, 3])) # [0, 0, 3] print(sigmoid.forward([-1, 0, 1])) # [0.27, 0.5, 0.73] print(relu.name, relu.is_built) # relu True
💡This IS how Keras works. In Month 3+ you'll write exactly:
class MyLayer(tf.keras.layers.Layer):
    def call(self, x): ...
The parent handles all the boilerplate. You just implement the core logic. Inheritance makes the entire ML framework possible.
🌍 Real World Example

How sklearn's Estimator Hierarchy Works

Every sklearn model (RandomForest, SVM, LogisticRegression) inherits from BaseEstimator. This gives them all free methods like get_params() and set_params() without each model writing them.

Python — sklearn-style estimator hierarchy
class BaseEstimator: """All sklearn models inherit from this.""" def get_params(self): return self.__dict__ def set_params(self, **params): for k, v in params.items(): setattr(self, k, v) return self class MyForest(BaseEstimator): def __init__(self, n_estimators=100, max_depth=5): super().__init__() self.n_estimators = n_estimators self.max_depth = max_depth def fit(self, X, y): print(f"Training {self.n_estimators} trees...") model = MyForest(200, 3) print(model.get_params()) # inherited free! model.set_params(max_depth=10) print(model.max_depth) # 10

📖 Lesson

Making Decisions with if / elif / else

Every AI makes decisions: Is this email spam? Will this patient survive? Is this image a cat? All of that starts with the simple concept of conditions — checking if something is True or False.

Python
marks = 75 if marks >= 80: print("Grade A") elif marks >= 60: print("Grade B") # ← this runs elif marks >= 50: print("Grade C") else: print("Fail")
⚖️ Comparison & Logical Operators
Python
# Comparison operators 5 == 5 # True — equal 5 != 3 # True — not equal 5 > 3 # True — greater 5 >= 5 # True — greater or equal # Logical operators — combine conditions age = 20 marks = 75 if age >= 18 and marks >= 50: print("Eligible for scholarship") if age < 18 or marks < 50: print("Not eligible") if not (marks < 50): print("Passed!")
⚠️Indentation is everything in Python. The code inside if/elif/else MUST be indented by 4 spaces (or 1 Tab). If indentation is wrong, Python throws an IndentationError. This is the most common beginner mistake.
🌍 Real World

How a Bank Loan System Decides

When you apply for a bank loan, an automated system runs your data through conditions exactly like these — income check, credit score check, age check — and makes an instant decision.

Python — loan decision
income = int(input("Monthly income (PKR): ")) credit_score = int(input("Credit score (300-850): ")) age = int(input("Age: ")) if age >= 21 and income >= 50000 and credit_score >= 650: print("✅ Loan APPROVED") elif credit_score >= 600 and income >= 40000: print("⚠️ Conditionally approved — needs guarantor") else: print("❌ Loan REJECTED")

Test Yourself — 3 Questions

No scrolling up. Answer from memory!

QUESTION 1 OF 3
What is wrong with this code? if marks >= 50: print('Pass')
✅ Correct! Python uses indentation (4 spaces) to define blocks. print() must be indented to be inside the if block. Without indentation you get IndentationError. ❌ Wrong. The problem is indentation. print('Pass') must be indented 4 spaces to be inside the if block. This is Python's syntax rule.
QUESTION 2 OF 3
What does 'and' do in: if age >= 18 and marks >= 50:
✅ Correct! 'and' means BOTH must be True. If either is False, the whole condition is False. 'or' means at least one must be True. ❌ Wrong. 'and' requires ALL conditions to be True. If age=17 and marks=75, the 'and' condition fails because age<18.
QUESTION 3 OF 3
elif stands for what?
✅ Correct! elif = 'else if'. Python checks conditions top to bottom and runs the FIRST one that's True. All others are skipped. ❌ Wrong. elif means 'else if'. It checks a new condition only if all previous if/elif conditions were False.

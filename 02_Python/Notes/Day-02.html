📖 Lesson

print(), input() & String Operations

print() shows output. input() reads what the user types. Strings (text) have powerful built-in methods for cleaning, searching and transforming text — critical for NLP in AI.

Python
# print() with multiple values print("Hello", "World") # Hello World print("Score:", 95, "marks") # Score: 95 marks print(f"My name is {name}") # f-string (easiest) # input() — always returns a string name = input("Your name: ") age = int(input("Your age: ")) # convert to int! print(f"Hello {name}, you are {age} years old")
🔤 String Methods
Python
text = " Hello, World! " print(text.strip()) # Remove spaces: "Hello, World!" print(text.upper()) # " HELLO, WORLD! " print(text.lower()) # " hello, world! " print(text.replace("World", "AI")) # " Hello, AI! " print(text.split(",")) # [' Hello', ' World! '] print("World" in text) # True print(len(text)) # 18 (count characters)
💡f-strings are your best friend. Instead of "Hello " + name, write f"Hello {name}". Cleaner, faster, used by every Python developer. You'll use f-strings in every ML project.
🌍 Real World

How Gmail Detects Spam Keywords

Gmail's spam filter uses string methods to scan email text for suspicious words. The same methods you just learned — .lower(), .split(), in — are the building blocks of text analysis in NLP.

Python — basic spam check
email = input("Paste email text: ") keywords = ["free money", "click here", "you won"] clean = email.lower().strip() for kw in keywords: if kw in clean: print(f"🚫 Spam detected: '{kw}'")

Test Yourself — 3 Questions

QUESTION 1 OF 3
What does input() always return, regardless of what the user types?
✅ Correct! input() always returns a string. If you need a number, you must convert: int(input()) or float(input()). ❌ Wrong. input() always returns str (string). Even if the user types 25, you get '25'. Use int(input()) to get the number 25.
QUESTION 2 OF 3
What does 'Hello World'.split() return?
✅ Correct! .split() splits on spaces by default and returns a list of words. 'Hello World'.split() → ['Hello', 'World']. ❌ Wrong. .split() returns a LIST of strings. 'Hello World'.split() → ['Hello', 'World']. Lists use square brackets.
QUESTION 3 OF 3
Which f-string correctly prints: My score is 95
✅ Correct! f-strings use the f prefix and put variable names inside curly braces {}. This is the modern, preferred way to format strings in Python. ❌ Wrong. f-strings need the f prefix before the quote AND curly braces around variables: f"My score is {score}". Without f, {score} is treated as plain text.

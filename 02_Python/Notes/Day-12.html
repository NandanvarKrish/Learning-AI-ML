Classes & Objects — The Blueprint and the Building

A class is a blueprint — it defines what something is and what it can do. An object is a specific instance created from that blueprint. Every sklearn model, every Keras layer, every Pandas DataFrame is an object created from a class.

class Student: def __init__(self, name, marks): self.name = name # instance variable self.marks = marks def grade(self): if self.marks >= 80: return "A" elif self.marks >= 60: return "B" elif self.marks >= 50: return "C" else: return "Fail" def report(self): print(f"{self.name}: {self.marks} → {self.grade()}") def is_passing(self): return self.marks >= 50 # Create objects (instances) s1 = Student("Ali", 88) s2 = Student("Sara", 45) s3 = Student("Usman", 72) s1.report() # Ali: 88 → A s2.report() # Sara: 45 → Fail print(s1.name) # Ali print(s3.is_passing()) # True # Objects in a list — just like a dataset! students = [s1, s2, s3] for s in students: s.report()

🔑 Class Variables vs Instance Variables
📌 Class Variable
Defined inside the class but outside any method. Shared by ALL objects of that class. Change it once, changes everywhere.
Student.school = "Beaconhouse"
All students share this
👤 Instance Variable
Defined with self.x inside __init__. Unique to each object. s1.marks and s2.marks are independent.
self.marks = marks
Each object has its own
Python — Class vs Instance Variables
class Student: school = "Beaconhouse" # CLASS variable — shared pass_mark = 50 # CLASS variable — shared def __init__(self, name, marks): self.name = name # INSTANCE variable — unique self.marks = marks # INSTANCE variable — unique def status(self): # Access class variable via self or Student if self.marks >= Student.pass_mark: return f"Pass at {Student.school}" return "Fail" s1 = Student("Ali", 88) s2 = Student("Sara", 45) print(Student.school) # Beaconhouse (class-level) print(s1.status()) # Pass at Beaconhouse print(s2.status()) # Fail # Change class variable — affects ALL instances Student.pass_mark = 60 print(s1.status()) # Pass at Beaconhouse (88 >= 60) print(s2.status()) # Fail (45 < 60)
🧠 self — What It Means

self refers to the specific object calling the method. When you call s1.report(), Python automatically passes s1 as self. When you call s2.report(), Python passes s2. The same method works for all objects through self.

💡sklearn models ARE classes. When you write model = RandomForestClassifier(n_estimators=100) — that calls __init__ and sets self.n_estimators = 100. When you call model.fit(X, y) — that calls the fit() method with self = model. You now understand sklearn from the inside.
🌍 Real World Example

How sklearn's Classifier Looks Inside

Here's a simplified version of what RandomForestClassifier looks like internally. It's just a class with __init__, fit(), and predict(). You can build your own version today.

Python — Your own classifier class
class SimpleClassifier: def __init__(self, threshold=50): self.threshold = threshold self.trained = False self.n_samples = 0 def fit(self, X, y): # In real ML: learn patterns from data self.n_samples = len(X) self.trained = True print(f"Trained on {self.n_samples} samples") return self # allows chaining: model.fit(X,y).predict(X) def predict(self, X): if not self.trained: raise RuntimeError("Call fit() before predict()!") return [1 if x >= self.threshold else 0 for x in X] def score(self, X, y): preds = self.predict(X) correct = sum(1 for p, t in zip(preds, y) if p==t) return round(correct/len(y)*100, 2) # Use exactly like sklearn model = SimpleClassifier(threshold=60) X = [80, 45, 72, 33, 91] y = [1, 0, 1, 0, 1] model.fit(X, y) print(model.predict([70, 40, 85])) # [1, 0, 1] print(model.score(X, y)) # 100.0
🎯The real RandomForestClassifier has the same structure — just with much more complex logic in fit() and predict(). The API design (fit → predict → score) is identical to what you just built.

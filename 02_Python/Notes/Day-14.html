Write Less, Do More — Pythonic Patterns

Python has elegant one-line patterns that replace verbose loops. NumPy and Pandas use these internally. Knowing them makes your code faster, more readable, and professional — exactly how ML engineers write.

⚡ List Comprehensions

The single most-used Python pattern in data science. Replace a for-loop-with-append in one clean line.

❌ Old Way — 4 lines
scores = [85,45,72,33,91] norm = [] for s in scores: norm.append(s/100)
✅ Pythonic — 1 line
scores = [85,45,72,33,91] norm = [s/100 for s in scores]
Python — List Comprehensions
scores = [85, 45, 72, 33, 91] # Basic: transform every item normalised = [s/100 for s in scores] # [0.85, 0.45, 0.72, 0.33, 0.91] # With condition: filter + transform passed = [s for s in scores if s >= 50] norm_pass = [s/100 for s in scores if s >= 50] # [85, 72, 91] # Conditional expression (ternary) grades = ["Pass" if s>=50 else "Fail" for s in scores] # ['Pass','Fail','Pass','Fail','Pass'] # Nested: flatten 2D list matrix = [[1,2],[3,4],[5,6]] flat = [x for row in matrix for x in row] # [1, 2, 3, 4, 5, 6]
📚 Dict Comprehensions
Python — Dict Comprehensions
names = ["Ali", "Sara", "Usman"] scores = [88, 45, 72] # Create dict from two lists grade_map = {n:s for n, s in zip(names, scores)} # {'Ali': 88, 'Sara': 45, 'Usman': 72} # Filter: only passing students passing = {n:s for n, s in zip(names, scores) if s >= 50} # {'Ali': 88, 'Usman': 72} # Invert a dict (swap keys and values) original = {"a":1, "b":2, "c":3} inverted = {v:k for k, v in original.items()} # {1: 'a', 2: 'b', 3: 'c'}
🔗 zip() and enumerate()
Python — zip() and enumerate()
# zip() — pair two lists together names = ["Ali", "Sara", "Usman"] scores = [88, 45, 72] grades = ["A", "F", "B"] for name, score, grade in zip(names, scores, grades): print(f"{name}: {score} ({grade})") # ML use: pair y_true with y_pred y_true = [1, 0, 1, 1] y_pred = [1, 0, 0, 1] correct = sum(1 for t, p in zip(y_true, y_pred) if t==p) print(f"Accuracy: {correct/len(y_true)*100:.1f}%") # 75.0% # enumerate() — index + value together for i, score in enumerate(scores, start=1): print(f"Student {i}: {score}") # Useful in training loops for epoch, loss in enumerate([2.1,1.4,0.8,0.3], 1): print(f"Epoch {epoch}: loss={loss}")
⚡ Generators — Memory-Efficient Sequences

A generator yields values one at a time instead of creating the whole list in memory. When processing 1 million images, you can't load them all at once — a generator feeds them batch by batch.

📋 List Comprehension
Creates ALL values in RAM immediately. Fast to access but uses lots of memory.
[x**2 for x in range(1000000)]
← 8MB in RAM at once
⚡ Generator Expression
Yields one value at a time. Tiny memory footprint — perfect for large datasets.
(x**2 for x in range(1000000))
← ~120 bytes, yields on demand
Python — Generator Functions with yield
# Generator function — uses yield not return def data_batches(data, batch_size): """Yield data in batches — like Keras DataGenerator.""" for i in range(0, len(data), batch_size): yield data[i:i+batch_size] dataset = list(range(100)) # 100 samples for batch in data_batches(dataset, 10): print(f"Batch: {batch[:3]}... ({len(batch)} items)") # Generator expression — lazy version squares = (x**2 for x in range(10)) # () not [] print(next(squares)) # 0 print(next(squares)) # 1 print(next(squares)) # 4 # Use generator with sum/any/all (no list needed!) total = sum(s/100 for s in dataset[:5]) all_pass = all(s >= 50 for s in [80,60,45]) # False any_fail = any(s < 50 for s in [80,60,45]) # True
💡yield is the foundation of all ML data pipelines. Keras's model.fit(generator, steps_per_epoch=...) works because the generator uses yield. When you build a custom data loader in Month 3, this is exactly the pattern you'll use.
🛠️ Functional Tools: any(), all(), sorted(), min(), max()
Python — Functional built-ins
students = [ {"name":"Ali", "marks":88}, {"name":"Sara", "marks":45}, {"name":"Usman", "marks":72}, ] # sorted() with key — rank students ranked = sorted(students, key=lambda s: s["marks"], reverse=True) top = max(students, key=lambda s: s["marks"]) bottom = min(students, key=lambda s: s["marks"]) print(f"Top: {top['name']} ({top['marks']})") print(f"Bottom: {bottom['name']} ({bottom['marks']})") # any() / all() — check conditions across lists scores = [88, 45, 72] print(all(s >= 50 for s in scores)) # False (45 fails) print(any(s >= 80 for s in scores)) # True (88 passes)
🌍 Real World Example

How Keras DataGenerator Uses yield

Keras's ImageDataGenerator is a generator that yields batches of normalised, augmented images. The batch_size parameter in model.fit() comes from this exact pattern. You now understand the mechanism that makes deep learning training possible.

Python — Keras-style image data generator
def image_data_generator(images, labels, batch_size=32): """Yield normalised batches — like Keras ImageDataGenerator.""" while True: # infinite — Keras controls epochs for i in range(0, len(images), batch_size): batch_X = images[i:i+batch_size] batch_y = labels[i:i+batch_size] # Normalise pixels 0-255 → 0.0-1.0 batch_X = [px/255.0 for px in batch_X] # list comp! yield batch_X, batch_y # Simulate training with generator images = list(range(0, 256, 10)) # 26 fake pixel values labels = [i % 2 for i in range(26)] # 0/1 labels gen = image_data_generator(images, labels, batch_size=8) for step in range(3): # 3 steps per epoch X, y = next(gen) print(f"Step {step+1}: X={X[:2]}... y={y[:2]}...")
🎯Notice how list comprehension (batch_X = [px/255.0 for px in batch_X]) and generator (yield) are used together. In real ML code, these patterns appear side by side constantly — this is Month 3 code you can already understand today.

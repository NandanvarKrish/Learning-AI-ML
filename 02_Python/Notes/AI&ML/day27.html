Variables & Data Types

~2 hours · int, float, string, bool — the building blocks of every program

01 Why this matters for AI/ML

Every dataset you'll ever load is fundamentally made of these four data types repeated millions of times — a customer's age (int), their purchase amount (float), their name (string), whether they're a premium member (bool). Getting comfortable with these now means every future error message about "wrong type" will make immediate sense instead of feeling mysterious.

02 What is a variable? (formalizing yesterday)

A variable is a named container that stores a value. You create one with a single equals sign:

age = 25

Naming rules: variable names can contain letters, numbers, and underscores, but can't start with a number, can't contain spaces, and are case-sensitive (age and Age are different variables). By convention, Python variable names use lowercase with underscores: user_age, not UserAge.

03 The four core data types

int (integer)
Whole numbers, positive or negative
age = 25
score = -10
float (decimal)
Numbers with a decimal point
price = 199.99
gpa = 3.5
str (string)
Text, always inside quotes
name = "Priya"
city = 'Surat'
bool (boolean)
Only two possible values
is_active = True
is_paid = False

Checking a variable's type: Python's built-in type() function tells you exactly what type something is:

print(type(25)) # <class 'int'> print(type(3.5)) # <class 'float'> print(type("hello")) # <class 'str'> print(type(True)) # <class 'bool'>

05 Type conversion (casting)

Sometimes you need to convert between types — Python provides functions for this:

int("25") # converts string "25" to integer 25 float("3.5") # converts string "3.5" to float 3.5 str(100) # converts integer 100 to string "100" bool(1) # converts to True (any nonzero number becomes True)

Why this matters in practice: data read from files (like CSVs) often arrives as strings even when it "looks like" a number — you'll frequently need int() or float() to convert a column of text-looking numbers into something you can actually do math with.

06 Common mistakes to avoid

Mistake 1 — Adding a string number instead of converting it first. "5" + "3" gives "53" (joining text), not 8. You'd need int("5") + int("3") to get actual math.

Mistake 2 — Forgetting Python is case-sensitive for variable names too. Age and age are two completely different variables — a very common source of "why isn't this working" confusion.

Mistake 3 — Using a reserved keyword as a variable name. Words like print, True, False, if, for are reserved by Python — using them as variable names causes errors or breaks their normal function.

Mistake 4 — Confusing True/False (capitalized) with true/false (lowercase). Python booleans must be capitalized exactly: True and False — lowercase versions cause a NameError.

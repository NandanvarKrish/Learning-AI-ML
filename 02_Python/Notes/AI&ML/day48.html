02 Guided project: a small Library System

Build this step by step in the console below. The goal: a Book class, an EBook subclass that extends it, and a simple checkout system.

Step 1 — the Book class

class Book: def __init__(self, title, author, copies): self.title = title self.author = author self.copies = copies def checkout(self): if self.copies > 0: self.copies = self.copies - 1 print(self.title + " checked out. " + str(self.copies) + " left.") else: print(self.title + " is out of stock.")

Step 2 — EBook inherits from Book, adds file_size

class EBook(Book): def __init__(self, title, author, copies, file_size_mb): super().__init__(title, author, copies) self.file_size_mb = file_size_mb def checkout(self): print(self.title + " (ebook, " + str(self.file_size_mb) + "MB) downloaded instantly.")

Notice EBook overrides checkout() completely (ebooks never run out of "copies"), while still reusing Book's __init__ via super() for the shared fields.

Step 3 — use both together

b1 = Book("Dune", "Frank Herbert", 2) e1 = EBook("Dune", "Frank Herbert", 999, 4.2) b1.checkout() # Dune checked out. 1 left. b1.checkout() # Dune checked out. 0 left. b1.checkout() # Dune is out of stock. e1.checkout() # Dune (ebook, 4.2MB) downloaded instantly.

Type all three steps into the console below and run it — then try extending it yourself (e.g., add an AudioBook subclass with a narrator attribute).

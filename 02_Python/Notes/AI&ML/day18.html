What Is a Matrix?

~2 hours · A table of vectors, and the shape behind every dataset and image

01 Why this matters for AI/ML

When you load a dataset into Pandas in a few weeks, what you're loading is, mathematically, a matrix. When a neural network processes an image, that image starts life as a matrix of pixel brightness values. When a model has "weights," those weights are stored as matrices. Understanding a matrix as simply a table of numbers with rows and columns demystifies a huge amount of ML terminology instantly.

02 What is a matrix?

A matrix is a rectangular grid of numbers, arranged in rows and columns:

A = [ [1, 2, 3], [4, 5, 6] ]
123
456

This matrix has 2 rows and 3 columns. We describe its size as 2 × 3 (always rows × columns, in that order — never the reverse).

03 Recall Day 16: a matrix is just stacked vectors

Remember the customer vector from Day 16? [28, 1200, 15] — one customer's age, order value, order count. If you have 500 customers, you have 500 of these vectors. Stack them all as rows, and you get a 500 × 3 matrix — exactly what a spreadsheet or a Pandas DataFrame looks like. This is the single most important mental model in this whole week: a dataset IS a matrix, and each row IS a vector.

04 Indexing — finding a specific element

To refer to a specific number inside a matrix, you give its row and column position, written A[row, column] (row first, always):

For the matrix above: A[1,1] = 1, A[1,3] = 3, A[2,2] = 5

(Note: some languages/libraries, including Python, start counting from 0 instead of 1 — you'll hit this directly once you reach NumPy in Phase 2. For today, we count from 1 to keep things simple.)

05 Real-world example (image as a matrix)

The example that makes computer vision click

A tiny 4×4 grayscale image is literally a 4×4 matrix, where each number (0–255) represents brightness — 0 is pure black, 255 is pure white:

[ [0,0,0,0], [0,255,255,0], [0,255,255,0], [0,0,0,0] ]

Play with the interactive tool below — every image your phone camera takes, and every image a computer vision model processes, is fundamentally this same idea, just with millions of pixels (and 3 layered matrices for Red, Green, Blue in color images) instead of 16.

06 Common mistakes to avoid

Mistake 1 — Reversing rows and columns. A "3×5 matrix" means 3 rows and 5 columns — mixing this up is extremely common and causes real errors once you reach NumPy array shapes.

Mistake 2 — Assuming all matrices are square. A matrix can be any rectangular shape — 2×3, 500×10, 1×1 — it doesn't need equal rows and columns.

Mistake 3 — Confusing a vector with a 1-row or 1-column matrix. They're closely related (a vector is technically a special case of a matrix), but conceptually, keep "one data point" (vector) separate from "many data points stacked" (matrix) while you're building intuition.

Mistake 4 — Getting index order backwards. A[row, column] always means row first — A[2,5] is row 2, column 5, not the reverse.

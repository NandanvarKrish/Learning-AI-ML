Mini Project: Number Guessing Game

~2 hours · Your first complete, playable Python program

01 Why this matters for AI/ML

This project itself isn't ML — but it's the first time you'll combine randomness, loops, conditionals, and user interaction into one complete, working program. That combination (generate/sample something, evaluate a condition, loop until a stopping criterion) is structurally similar to how many training and simulation loops work later. Mostly, though, today is about the genuine confidence boost of finishing something real.

02 New tool: the random module

import random number = random.randint(1, 100) print(number) # a random whole number between 1 and 100, INCLUSIVE of both ends

import random loads Python's built-in random number toolkit. Note: unlike range(), randint(a, b) includes BOTH endpoints — randint(1, 100) can produce 1 or 100 or anything between, a different rule from range()'s exclusive stop.

03 New tool: input()

guess = input("Enter your guess: ") print(guess)

input() pauses the program and waits for the user to type something, returning whatever they typed. Critical detail: input() ALWAYS returns a string, even if the user types a number — you must convert it with int() before comparing it to a number.

04 Building the game, step by step

Step 1: pick a secret number and set up a counter

import random secret = random.randint(1, 100) attempts = 0

Step 2: loop until guessed correctly, using while True + break

while True: guess = int(input("Guess a number (1-100): ")) attempts = attempts + 1 if guess < secret: print("Too low!") elif guess > secret: print("Too high!") else: print("Correct! You got it in " + str(attempts) + " attempts.") break

while True: creates a loop that would run forever — the break inside the else branch is what actually stops it, the moment the guess is correct. This is a genuinely standard Python pattern: "loop forever until a specific condition inside says stop."

05 The complete program

import random secret = random.randint(1, 100) attempts = 0 print("I'm thinking of a number between 1 and 100.") while True: guess = int(input("Your guess: ")) attempts = attempts + 1 if guess < secret: print("Too low!") elif guess > secret: print("Too high!") else: print("Correct! You got it in " + str(attempts) + " attempts.") break

06 Common mistakes to avoid

Mistake 1 — Forgetting int() around input(). Comparing a string guess to an integer secret with < or > causes a TypeError in real Python — always convert immediately: int(input(...)).

Mistake 2 — Forgetting the break. Without it, while True genuinely never stops — the game would loop forever even after a correct guess.

Mistake 3 — Confusing randint's inclusive range with range()'s exclusive one. random.randint(1, 100) CAN produce 100; range(1, 100) stops before 100 — easy to mix these up.

Mistake 4 — Not incrementing the attempt counter, or incrementing it in the wrong place. If placed after the win-check instead of right after getting the guess, a correct final guess wouldn't get counted.

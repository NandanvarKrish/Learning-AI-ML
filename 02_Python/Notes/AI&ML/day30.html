For Loops

~2 hours · How code repeats itself instead of you copy-pasting

01 Why this matters for AI/ML

Loops are everywhere in ML: looping through every row of a dataset, looping through every pixel of an image, and — very literally — looping through "epochs" during model training (an epoch is just one full pass through the training data, repeated in a loop). The word "epoch" you'll see constantly in Phase 4 is quite literally describing a for loop.

02 The for loop and range()

A for loop repeats a block of code a set number of times:

for i in range(5): print(i)

Output:

0 1 2 3 4

Critical detail: range(5) gives 5 numbers starting at 0 (0,1,2,3,4), NOT 1 through 5. The stop value is always excluded. This "off-by-one" surprise trips up nearly every beginner at least once — flag it now so it doesn't cost you debugging time later.

03 range() with start, stop, and step

CallProduces
range(5)0, 1, 2, 3, 4
range(2, 7)2, 3, 4, 5, 6 (starts at 2, stops before 7)
range(0, 10, 2)0, 2, 4, 6, 8 (step of 2)
range(10, 0, -1)10, 9, 8, ... 1 (counting down)

The loop variable (commonly named i, but any valid name works) holds the current value on each pass through the loop, and you can use it inside the block just like any other variable.

04 Real-world example (summing a week of sales)

Business example

daily_sales = [1200, 1500, 900, 1800, 2000, 1100, 1700] total = 0 for i in range(7): total = total + daily_sales[i] print(total)

This loops through each of the 7 days, adding each day's sales to a running total. (You haven't formally learned lists yet — that's Day 34 — but seeing this preview now helps the loop concept click; lists are simply ordered collections indexed starting at 0, similar to what you'll build fully in a few days.)

05 Second example (the "epoch" preview)

Direct foreshadowing of Phase 4

for epoch in range(5): print("Training epoch " + str(epoch) + " complete")

This is, structurally, almost exactly what happens inside every neural network training script you'll write in Phase 4 — a for loop over epochs, with model-improving work happening inside the loop body on each pass. You're not learning a toy concept here; you're learning the literal skeleton of ML training code.

06 Common mistakes to avoid

Mistake 1 — Expecting range(n) to include n. range(5) stops BEFORE 5 — it gives exactly 5 values: 0 through 4.

Mistake 2 — Off-by-one errors when converting "1 to 10" into range(). To loop through the numbers 1 through 10 inclusive, you need range(1, 11), not range(1, 10) — the stop value must be one past your last desired number.

Mistake 3 — Forgetting the colon and indentation rules from Day 29 also apply to loops. Same syntax requirements: colon at the end of the for line, consistent 4-space indentation for the body.

Mistake 4 — Modifying the loop variable inside the loop expecting it to change the iteration. Reassigning i inside the loop body doesn't affect which values range() will produce next — range() has already determined the full sequence in advance.

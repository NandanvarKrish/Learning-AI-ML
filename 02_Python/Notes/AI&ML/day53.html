Pandas: Reading CSVs, Filtering & Sorting

~2 hours · Loading real files, and the most common operations after loading

01 Why this matters for AI/ML

Almost every dataset you'll ever work with starts life as a CSV file. And the very first things you do after loading it — filtering to the rows you care about, sorting to see extremes — are operations you'll repeat constantly throughout any real analysis or ML project.

02 Reading a CSV file

import pandas as pd df = pd.read_csv("customers.csv") print(df.head())

One line loads an entire file into a DataFrame — this replaces the entire manual line.strip().split(",") process you built by hand on Day 43. If the file doesn't exist, you'll get a FileNotFoundError, exactly like Day 43's file handling — the same try/except pattern from Day 44 applies here too.

03 Filtering rows with conditions

df[df["age"] > 30] # only rows where age is over 30 df[df["order_value"] >= 1000] # only high-value orders

This is called boolean indexing: df["age"] > 30 produces a Series of True/False values (one per row), and wrapping the DataFrame in that condition keeps only the True rows. It looks like magic at first, but it's really just Day 28's comparison operators applied to an entire column at once — the vectorization idea from Day 51, now used for filtering.

04 Combining conditions — the #1 pandas gotcha

Critical: use & and |, NOT and/or, when combining pandas conditions. Python's regular and/or don't work correctly on entire columns of values — pandas requires the bitwise operators instead, and each condition needs its own parentheses.
# WRONG — will raise an error df[df["age"] > 30 and df["order_value"] > 1000] # RIGHT df[(df["age"] > 30) & (df["order_value"] > 1000)] # OR condition df[(df["age"] < 25) | (df["order_value"] > 2000)]

05 Sorting

df.sort_values("age") # ascending by default df.sort_values("order_value", ascending=False) # descending

Like most Pandas operations, sort_values() returns a NEW sorted DataFrame — the original is unchanged unless you reassign it: df = df.sort_values(...). This is exactly the same "returns new, doesn't mutate" pattern as Day 41's sorted().

06 Real-world example (filter + sort together)

A genuinely everyday analysis task

df = pd.read_csv("customers.csv") high_value = df[df["order_value"] > 1000] result = high_value.sort_values("age") print(result)

Or chained in one line, which you'll see constantly in real code:

result = df[df["order_value"] > 1000].sort_values("age")

07 Common mistakes to avoid

Mistake 1 — Using and/or instead of &/|. Covered above — this is genuinely the most common Pandas error beginners hit.

Mistake 2 — Forgetting parentheses around each condition. df[df["age"] > 30 & df["x"] > 1] (missing parens) can raise confusing errors due to operator precedence — always wrap each condition: (df["age"] > 30) & (df["x"] > 1).

Mistake 3 — Expecting sort_values() to modify the original DataFrame. It returns a new one — reassign if you want to keep the sorted version.

Mistake 4 — Not handling the file-not-found case. A typo'd filename or wrong folder causes a crash — wrapping pd.read_csv() in try/except (Day 44) is good practice for any real script.

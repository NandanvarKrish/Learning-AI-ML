01 Why this matters for AI/ML

Python is, without much debate, the dominant language for AI and ML — nearly every library, tutorial, and job posting you'll encounter uses it. Today is purely practical setup: getting the tools installed correctly matters more than it seems, since a broken setup causes far more frustration than any actual programming concept in the next 40 days.

02 Installing Python

Download Python

Go to python.org/downloads and download the latest stable version (any recent 3.x version is fine — avoid anything starting with "2.").

Run the installer

Critical step (Windows users especially): on the first install screen, check the box that says "Add Python to PATH" before clicking Install. Skipping this is the single most common setup mistake — it means your computer won't recognize the `python` command afterward.

Verify the installation

Open a terminal (Command Prompt on Windows, Terminal on Mac) and type:

python --version

You should see something like Python 3.12.1. If you get an error instead, the PATH step above was likely missed — reinstall and make sure that box is checked.

03 Installing VS Code

Download VS Code

Go to code.visualstudio.com and download it for your operating system — it's free.

Install the Python extension

Open VS Code, click the Extensions icon on the left sidebar (or press Ctrl+Shift+X), search "Python," and install the official Microsoft extension. This gives you syntax highlighting, error checking, and the ability to run Python files directly.

Alternative if setup is giving you trouble: Google Colab (colab.research.google.com) runs Python entirely in your browser, no installation needed at all. It's genuinely a fine way to do all of Phase 2 if local installation keeps causing issues — many working data scientists use Colab daily. Don't let setup problems block your progress; switch to Colab and come back to local installation later if needed.

04 Your first program

Create a new file in VS Code, save it as hello.py (the .py extension matters — it tells your computer this is a Python file), and type exactly this:

print("Hello, World!")

Run it — in VS Code, click the ▷ (Run) button in the top-right, or right-click the file and choose "Run Python File in Terminal." You should see:

Hello, World!

print() is a function — a reusable block of code that does something (here: display text). The text inside quotes is called a string. This exact function is what you'll use for the rest of this entire plan to see what your code is doing.

05 A few quick syntax notes

Quotes matter: text you want printed literally must be inside quotes — either single 'like this' or double "like this", both work identically in Python.

Python is case-sensitive: print() works; Print() or PRINT() will cause an error. Always lowercase for built-in functions.

Parentheses are required: print "Hello" (no parentheses) was valid in old Python 2 but is an error in modern Python 3 — always use print("Hello").

06 Common mistakes to avoid

Mistake 1 — Forgetting quotes around text. print(Hello) without quotes causes an error — Python thinks "Hello" is a variable name that doesn't exist, not literal text.

Mistake 2 — Mismatched quotes. Mixing double and single quotes on the same string causes a syntax error — start and end with the same type.

Mistake 3 — Saving without the .py extension. A file named just "hello" (no extension) won't be recognized as Python code by your editor or terminal.

Mistake 4 — Not checking "Add to PATH" during install. This causes "python is not recognized" errors that confuse many beginners — if you hit this, simply reinstall and check that box.

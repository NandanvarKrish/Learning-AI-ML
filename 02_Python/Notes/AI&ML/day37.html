Dictionaries

~2 hours · Key-value pairs — arguably the most-used structure in real data work

01 Why this matters for AI/ML

Remember Day 27's customer record, spread across four separate variables (name, age, order value, membership)? A dictionary lets you bundle all of that into ONE structure with named fields — exactly how a single row of real-world data, a JSON API response, or one record in a database naturally looks. This is genuinely one of the most-used data structures you'll touch, constantly.

02 Creating a dictionary

customer = { "name": "Rohan Mehta", "age": 28, "avg_order_value": 1200.50, "is_premium": True }

Each entry is a key: value pair, separated by commas, all inside curly braces — this is the same { } syntax as sets, but the presence of colons makes it a dictionary instead.

03 Accessing values

print(customer["name"]) # Rohan Mehta print(customer["age"]) # 28 print(customer["email"]) # KeyError! "email" doesn't exist print(customer.get("email")) # None — .get() doesn't crash, just returns None print(customer.get("email", "not provided")) # "not provided" — custom default

Use .get() when a key might not exist — it's much safer than direct bracket access, which crashes your program with a KeyError if the key is missing. This distinction matters a lot once you're working with real, messy data where not every record has every field.

04 Adding and updating values

customer["city"] = "Surat" # adds a new key customer["age"] = 29 # updates an existing key

Unlike tuples, dictionaries ARE mutable — you can freely add new keys or change existing values after creation.

05 Key dictionary methods

.keys()
Returns all the keys
.values()
Returns all the values
.items()
Returns key-value pairs together
.get(key, default)
Safe access with a fallback

06 Real-world example (word frequency counter)

A genuinely useful, real pattern — foreshadows NLP in Phase 4

words = ["apple", "banana", "apple", "cherry", "banana", "apple"] word_count = {} for i in range(len(words)): word = words[i] if word in word_count: word_count[word] = word_count[word] + 1 else: word_count[word] = 1 print(word_count) # {'apple': 3, 'banana': 2, 'cherry': 1}

This exact pattern — counting occurrences using a dictionary — is precisely the foundation of "bag of words," one of the earliest and still-relevant techniques for turning text into numbers for NLP models, which you'll meet formally in Phase 4.

07 Common mistakes to avoid

Mistake 1 — Using dict[key] on a key that might not exist. This raises a KeyError and crashes your program — use .get() whenever you're unsure a key is present.

Mistake 2 — Forgetting quotes around string keys. {name: "Asha"} (no quotes on name) is invalid — string keys need quotes just like any other string: {"name": "Asha"}.

Mistake 3 — Confusing an empty dict with an empty set. As covered yesterday, {} is an empty DICTIONARY by default, not a set.

Mistake 4 — Assuming dictionary key order matters for logic. While modern Python dictionaries do preserve insertion order for display purposes, you generally shouldn't rely on order for your program's correctness — access by key name, not by position.

If/Else Conditionals

~2 hours · Where your program starts making decisions

01 Why this matters for AI/ML

Conditionals are how you encode rules and decisions in code — "if this row has a missing value, do X," "if the model's confidence is above 90%, flag it," "if the customer is in group A, apply this treatment." Every branching decision in data cleaning, business logic, and even inside ML libraries themselves is built from exactly what you're learning today.

02 The if statement

An if statement runs a block of code ONLY when a condition is True:

age = 20 if age >= 18: print("You can vote")

Python's biggest quirk for beginners: indentation is not optional. Unlike many languages that use curly braces { }, Python uses consistent indentation (spacing) to define which lines belong inside the if block. The standard is 4 spaces. Get this wrong, and you'll get an IndentationError — this trips up nearly every beginner at least once.

03 if / else

Add an else block to handle the case when the condition is False:

age = 15 if age >= 18: print("You can vote") else: print("Too young to vote")

04 if / elif / else chains

For more than two possibilities, use elif ("else if") to check additional conditions in order:

score = 72 if score >= 90: print("Grade A") elif score >= 75: print("Grade B") elif score >= 60: print("Grade C") else: print("Grade F")

Python checks each condition top to bottom and runs the first one that's True, then skips the rest entirely — even if a later condition would also technically be true. (With score=72: it fails the first two checks, matches "score >= 60", prints "Grade C", and never even evaluates further.)

Why not just use multiple separate `if` statements instead of `elif`?

Multiple separate if statements are each checked independently — ALL of them run their check, even after one has already matched. With elif, once one branch matches, Python skips the rest of the chain entirely. For mutually exclusive categories (like grade bands), elif is both correct and more efficient.

05 Real-world example (loan approval logic)

Reconnects to Day 11's Bayes loan example

credit_score = 720 income = 45000 existing_loans = 1 if credit_score >= 750: print("Auto-approved") elif credit_score >= 650 and income >= 40000: print("Approved with review") elif existing_loans > 2: print("Rejected: too many existing loans") else: print("Manual review required")

With these values: fails the first check (720<750), matches the second (720≥650 AND income≥40000) → prints "Approved with review", and never checks the remaining branches. This is a simplified but genuinely realistic version of the rule-based logic that sits underneath (or alongside) real credit-scoring ML models.

06 Common mistakes to avoid

Mistake 1 — Inconsistent indentation. Mixing tabs and spaces, or using 3 spaces in one line and 4 in another, causes an IndentationError. Stick to 4 spaces consistently (most editors, including VS Code, handle this automatically).

Mistake 2 — Forgetting the colon : at the end of if, elif, and else lines — this is a required part of the syntax, not optional punctuation.

Mistake 3 — Using = instead of == in a condition. Covered on Day 28 — Python will actually throw a syntax error here, which is a helpful safety net compared to some other languages.

Mistake 4 — Assuming all conditions get checked in an elif chain. Once one branch matches, Python stops — if you actually need to check multiple independent conditions regardless of each other, use separate if statements instead, not elif.

Vector Addition & Scalar Multiplication

~2 hours · The two operations everything else in linear algebra builds on

01 Why this matters for AI/ML

Every neural network computation is, at its core, repeated scaling and adding of vectors — multiply each input by a weight (scalar multiplication), then sum everything together (vector addition). You're about to learn, by hand, the two exact operations that a neural network performs millions of times per second.

02 Vector addition

To add two vectors, add their components position by position:

[3, 2] + [1, 4] = [3+1, 2+4] = [4, 6]

Geometric meaning — "tip to tail": draw the first vector, then draw the second vector starting from where the first one ended. The sum is the arrow from the very start to the very end. This is exactly how the interactive tool below will show it.

03 Scalar multiplication

A "scalar" is just a regular single number (as opposed to a vector). To multiply a vector by a scalar, multiply every component by that number:

3 × [2, 5] = [3×2, 3×5] = [6, 15]

Geometric meaning — stretching, shrinking, or flipping:

• Scalar > 1: stretches the vector longer, same direction

• Scalar between 0 and 1: shrinks the vector shorter, same direction

• Scalar negative: flips the vector to point the opposite direction (and scales it too)

See a negative scalar example

-2 × [3, 1] = [-6, -2] — this vector now points in exactly the opposite direction, and is twice as long.

04 Real-world example (adding vectors)

Business example

A shop tracks sales across 3 product categories (Electronics, Clothing, Groceries) as a vector each month:

January: [45000, 30000, 20000]

February: [38000, 42000, 25000]

Q1-so-far total = January + February (vector addition):

[45000+38000, 30000+42000, 20000+25000] = [83000, 72000, 45000]

Add March's vector the same way, and you have the full quarterly total — this is precisely how spreadsheet software sums rows, just framed as vector addition.

05 Second example (scalar multiplication)

Finance example

A household budget vector (rent, food, transport, savings) in ₹: [15000, 8000, 3000, 5000]. Next year, the family expects a 10% raise and wants to scale their entire budget up proportionally.

1.10 × [15000, 8000, 3000, 5000] = [16500, 8800, 3300, 5500]

Every category scaled by the exact same factor — this is scalar multiplication in a completely ordinary financial planning task, no different mathematically from scaling a vector in any ML pipeline.

06 Common mistakes to avoid

Mistake 1 — Adding vectors of different lengths. [3,4] + [1,2,5] is undefined — the number of components must match exactly.

Mistake 2 — Forgetting to scale EVERY component. A common slip is multiplying only the first number by the scalar and leaving the rest unchanged.

Mistake 3 — Sign confusion with negative scalars. Multiplying by -1 doesn't just "shrink" a vector — it fully reverses its direction while keeping the same magnitude.

Mistake 4 — Mixing up vector addition with multiplication. [3,4] + [1,2] = [4,6] (add each position). This is NOT the same operation as multiplying components together (which is a different, less common operation).

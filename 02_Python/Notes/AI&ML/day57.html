02 The standard workflow

Almost every real analysis follows this same sequence. Today you'll run all five steps on one dataset.

Step 1 — Load

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("sales.csv")

Step 2 — Look at it

print(df.head()) print(df.shape) print(df.info())

Step 3 — Check for problems

print(df.isnull().sum()) # missing values? print(df["region"].value_counts()) # imbalanced categories? print(df.describe()) # any impossible min/max values?

Step 4 — Clean

df["revenue"] = df["revenue"].fillna(df["revenue"].mean()) df = df.dropna(subset=["region"]) # drop rows missing a critical field

Step 5 — Explore & visualize

top = df[df["revenue"] > 1000].sort_values("revenue", ascending=False) plt.hist(df["revenue"], bins=8) plt.title("Revenue Distribution") plt.show() plt.scatter(df["ad_spend"], df["revenue"]) plt.xlabel("Ad Spend") plt.ylabel("Revenue") plt.show()

Note step 3. Beginners often skip straight from loading to modeling — checking for missing values, class imbalance, and impossible values first is what separates a reliable analysis from one that silently produces garbage.

Functions: Defining, Calling, Parameters

~2 hours · Bundling reusable code with a name and inputs

01 Why this matters for AI/ML

Every real ML pipeline is organized into functions: a function to load data, a function to clean it, a function to train a model, a function to make predictions. Without functions, you'd be copy-pasting the same code over and over — functions are how you package logic once and reuse it everywhere, which is essential the moment your code grows beyond a few lines.

02 Defining and calling a function

def greet(): print("Hello!") greet() # actually runs the function — "Hello!"

Defining a function (the def block) just teaches Python the recipe — it does NOT run anything by itself. You have to call it (write its name with parentheses) to actually execute the code inside. Forgetting to call a defined function is a common "why isn't anything happening" beginner moment.

Same syntax rules as everything else this week: colon at the end of the def line, consistent indentation for the body.

03 Parameters — giving a function inputs

def greet(name): print("Hello, " + name + "!") greet("Priya") # Hello, Priya! greet("Rohan") # Hello, Rohan!

A parameter (here, name) is a placeholder for a value you'll supply when calling the function. Each call can pass a different value — that's the entire point of making code reusable instead of writing it fresh every time.

Multiple parameters are separated by commas, and arguments are matched to parameters by position:

def describe_customer(name, age): print(name + " is " + str(age) + " years old") describe_customer("Asha", 28) # Asha is 28 years old

04 Real-world example (reusable discount calculator)

Turning a one-off calculation into reusable code

def show_discounted_price(price, discount_percent): discount_amount = price * discount_percent / 100 final_price = price - discount_amount print("Final price: " + str(final_price)) show_discounted_price(1000, 20) # Final price: 800.0 show_discounted_price(500, 10) # Final price: 450.0 show_discounted_price(2500, 15) # Final price: 2125.0

Without a function, you'd need to rewrite this same three-line calculation every single time you wanted a discounted price — the function lets you write the logic once and reuse it for any price and any discount percentage.

05 Second example (Day 1's break-even, now reusable)

Reconnects to Day 1's very first real-world example

def show_breakeven(fixed_cost, price_per_unit, cost_per_unit): profit_per_unit = price_per_unit - cost_per_unit units_needed = fixed_cost / profit_per_unit print("Units needed to break even: " + str(units_needed)) show_breakeven(4000, 90, 40) # the candle shop example — 80.0 units show_breakeven(2000, 50, 30) # a different business — 100.0 units

Notice this is genuinely the same math from Day 1's candle shop — now packaged as a function you can reuse for any business's numbers, instead of solving it by hand each time.

06 Common mistakes to avoid

Mistake 1 — Defining a function but forgetting to call it. The def block alone does nothing when the program runs — you must call the function by name with parentheses.

Mistake 2 — Calling with the wrong number of arguments. If a function expects 2 parameters, calling it with only 1 (or 3) argument raises a TypeError.

Mistake 3 — Forgetting parentheses when calling. Writing greet (no parentheses) just refers to the function itself without running it — you need greet() to actually execute it.

Mistake 4 — Assuming parameter names must match the argument's variable name outside. They don't — show_discounted_price(product_price, 20) works fine even though the outer variable is named differently from the parameter price inside the function.

Note: today's functions only print their results directly. Tomorrow (Day 39) you'll learn return, which lets a function hand a computed value back to whoever called it — far more flexible than printing from inside every function.

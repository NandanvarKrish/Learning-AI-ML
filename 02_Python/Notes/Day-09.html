📖 Lesson

Modules, Imports & the Standard Library

A module is a Python file (.py) containing functions, classes, and variables you can reuse. Instead of writing complex math or file-handling code yourself, you import a module and use its tools instantly. Python's standard library has 200+ built-in modules — and the ML ecosystem has thousands more.

📥 Three Ways to Import
import math
Imports the whole module. Access with prefix: math.sqrt()
import numpy as np
Imports with a shorter alias. Access as: np.array() — universal ML convention
from math import sqrt, pi
Imports specific items only. Use directly: sqrt(16) — no prefix needed
Python — Import Styles
# Style 1: import entire module import math print(math.sqrt(25)) # 5.0 print(math.pi) # 3.14159... print(math.ceil(4.2)) # 5 print(math.floor(4.9)) # 4 print(math.log(100, 10)) # 2.0 # Style 2: import with alias import math as m print(m.sqrt(144)) # 12.0 # Style 3: import specific items from math import sqrt, pi, factorial print(sqrt(81)) # 9.0 (no 'math.' prefix!) print(factorial(5)) # 120

📦 Create Your Own Module

Any Python file is a module. Save functions in a mytools.py file and import them in your main script. This is exactly how ML projects are structured — utility functions in separate files, imported where needed.

mytools.py → your own module
# ── mytools.py ──────────────────────────────────── def normalise(data): """Normalise a list of numbers to 0-1 range""" mn, mx = min(data), max(data) return [(x - mn) / (mx - mn) for x in data] def get_grade(marks): """Return grade letter for a marks value""" for t, g in [(90,"A+"),(80,"A"),(70,"B"),(60,"C"),(50,"D")]: if marks >= t: return g return "F" PI = 3.14159 # module-level constant
main.py → import and use your module
# ── main.py ─────────────────────────────────────── from mytools import normalise, get_grade, PI scores = [45, 78, 91, 33, 85] print(normalise(scores)) # [0.207, 0.793, 1.0, 0.0, 0.897] for s in scores: print(f"{s} → {get_grade(s)}") print(f"Pi = {PI}") # 3.14159
💡import numpy as np follows this exact pattern. numpy is a module (actually a package — a folder of modules). np is the alias. np.array() calls numpy's array function. You'll write this line every single day starting Month 2, Day 1. Today's lesson explains exactly what it means.

Python — Using standard library for ML prep
import random import math import os # Set random seed — reproducible ML experiments random.seed(42) # same seed = same "random" results # Generate synthetic dataset dataset = [{ "x": random.uniform(0, 10), "y": random.randint(0, 1) } for _ in range(100)] # Shuffle and split 80/20 random.shuffle(dataset) split = int(0.8 * len(dataset)) train = dataset[:split] test = dataset[split:] print(f"Train: {len(train)}, Test: {len(test)}") print(f"sqrt(len) = {math.sqrt(len(dataset)):.2f}") # Check if data folder exists if not os.path.exists("data"): os.makedirs("data") print("Created data/ folder")

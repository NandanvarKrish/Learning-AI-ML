Lists, Tuples & Sets

A list stores multiple values in order. It's the most used data structure in ML — datasets, predictions, scores are all lists. Tuples are immutable lists. Sets store unique values only.

Python
# Lists — ordered, mutable, allows duplicates scores = [85, 92, 78, 85, 91] print(scores[0]) # 85 (first item, index 0) print(scores[-1]) # 91 (last item) print(scores[1:4]) # [92, 78, 85] (slicing) scores.append(95) # add to end scores.remove(78) # remove value scores.sort() # sort in place print(len(scores)) # number of items print(sum(scores)) # total print(max(scores)) # highest
📌 Tuples & Sets
Python
# Tuple — ordered, IMMUTABLE (cannot change) rgb = (255, 128, 0) # orange colour pixel print(rgb[0]) # 255 (red channel) # Set — UNIQUE values only, unordered labels = {"cat", "dog", "cat", "bird"} print(labels) # {'cat', 'dog', 'bird'} — no duplicate! # List comprehension — create list in one line squares = [x**2 for x in range(1, 6)] print(squares) # [1, 4, 9, 16, 25] passed = [s for s in scores if s >= 50]
💡List comprehensions are used everywhere in ML. Instead of 3 lines to filter a list, write 1 line. [x for x in data if condition] is the pattern. Every ML engineer uses this daily.
🌍 Real World

How ML Stores Image Pixels

Every image in a computer is a list of pixel values. A 28×28 image (like MNIST digits) is a list of 784 numbers. The CNN you'll build in Month 3 processes these lists. Tuples store RGB colours. Sets find unique labels in a dataset.

Python — image as list
# A tiny 3x3 greyscale image (0=black, 255=white) image = [ [0, 128, 255], [64, 192, 128], [255, 0, 64 ] ] # Normalise: 0-255 → 0.0-1.0 (ML needs this!) normalised = [[p/255 for p in row] for row in image] print(normalised[0]) # [0.0, 0.502, 1.0]

QUESTION 1 OF 3
What is the key difference between a List and a Tuple?
✅ Correct! Lists [] are mutable — you can add, remove, change items. Tuples () are immutable — once created, they cannot be changed. Tuples are faster and safer for fixed data. ❌ Wrong. Lists use [] and ARE mutable. Tuples use () and are IMMUTABLE. The key difference is mutability.
QUESTION 2 OF 3
What does {1, 2, 2, 3, 3, 3} evaluate to?
✅ Correct! Sets store only UNIQUE values. All duplicates are automatically removed. {1, 2, 2, 3, 3, 3} → {1, 2, 3}. ❌ Wrong. Sets contain only unique values. Duplicates are automatically discarded. Result is {1, 2, 3}.
QUESTION 3 OF 3
What does [x**2 for x in range(1,4)] return?
✅ Correct! List comprehension: x**2 for x in [1,2,3]. 1²=1, 2²=4, 3²=9. Result: [1, 4, 9]. ❌ Wrong. range(1,4) gives 1,2,3. x**2 squares each: 1,4,9. Result: [1, 4, 9].

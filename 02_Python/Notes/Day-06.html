📖 Lesson

Dictionaries — Labelled Data Storage

A dictionary stores data as key: value pairs. Instead of accessing data by index number (like lists), you access it by a meaningful name. This makes code readable and self-documenting.

"name"→"Ali"
"marks"→88.5
"passed"→True
"grade"→"A"
Python — Dictionary Basics
# Create a dictionary with {} student = { "name" : "Ali", "marks" : 88.5, "passed" : True } # Access by key print(student["name"]) # Ali print(student.get("grade", "N/A")) # N/A (safe — no KeyError) # Add / Update / Delete student["grade"] = "A" # add new key student["marks"] = 90.0 # update existing del student["passed"] # delete key # Check if key exists if "name" in student: print("Name found!") # Iterate all key-value pairs for key, val in student.items(): print(f"{key}: {val}")

📊 List of Dictionaries — Real Dataset Format

A list of dictionaries is how Python represents a dataset. Each dictionary is one row. This is exactly the format Pandas uses internally.

Python — Dataset as list of dicts
# This IS a dataset — each dict = one student row dataset = [ {"name":"Ali", "hours":5, "marks":88, "passed":1}, {"name":"Sara", "hours":2, "marks":45, "passed":0}, {"name":"Usman", "hours":8, "marks":91, "passed":1}, {"name":"Zara", "hours":1, "marks":32, "passed":0}, ] # Loop through — like iterating a CSV file for row in dataset: status = "✅ Pass" if row["passed"] else "❌ Fail" print(f"{row['name']:8} | {row['hours']} hrs | {row['marks']} marks | {status}") # Filter: only passing students passed = [r for r in dataset if r["passed"] == 1] print(f"\n{len(passed)} passed out of {len(dataset)}") # Average marks avg = sum(r["marks"] for r in dataset) / len(dataset) print(f"Average: {avg:.1f}")
💡Dictionaries ARE datasets. When you load a CSV with Pandas next month, each row becomes a dict-like object. When an ML model returns predictions, it's often a dict. When you call an API, the response is JSON — which is just a dictionary. Master dicts now and everything in Month 2+ feels familiar.
🌍 Real World Example

How Pandas Stores Your Dataset

A Pandas DataFrame is built from a dictionary of lists. This is the exact structure you'll pass to pd.DataFrame() in Month 2, Day 1. You already understand the foundation.

Python — Dict → Pandas DataFrame (Month 2 preview)
# Dict of lists = column-oriented dataset data = { "name" : ["Ali", "Sara", "Usman"], "study_hrs" : [5, 2, 8], "marks" : [88, 45, 91], "passed" : [True, False, True] } # RIGHT NOW — without Pandas: for i in range(len(data["name"])): print(data["name"][i], "->", data["marks"][i]) # MONTH 2 — with Pandas (one line!): # import pandas as pd # df = pd.DataFrame(data) # print(df) ← beautiful table output
🎯The data dictionary above IS what you pass to Pandas. Understanding this dict structure today makes Month 2 feel effortless — you will already know what's happening underneath.

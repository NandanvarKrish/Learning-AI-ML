File I/O — Every Dataset Starts as a File

Before Pandas existed, every data scientist read files manually with Python. Even today, understanding File I/O helps you load non-standard formats, debug Pandas errors, and process data that doesn't fit in memory. The with open() pattern is standard professional Python — always use it.

📂 File Modes
ModeNameWhat it doesFile exists?
"r"ReadRead only. Raises error if file missing.Must exist
"w"WriteWrite from scratch. Overwrites everything.Creates if missing
"a"AppendAdd to end without erasing existing content.Creates if missing
"x"ExclusiveCreate new file. Raises error if file already exists.Must NOT exist
📄 Text Files — Read & Write
Python — Text Files
# WRITE — create or overwrite with open("scores.txt", "w") as f: f.write("Ali,88\n") f.write("Sara,45\n") f.write("Usman,72\n") # READ — entire file with open("scores.txt", "r") as f: content = f.read() print(content) # READ — line by line (memory efficient!) with open("scores.txt", "r") as f: for line in f: name, score = line.strip().split(",") print(f"{name}: {score}") # APPEND — add without erasing with open("scores.txt", "a") as f: f.write("Zara,91\n")
⚠️Always use 'with open()' — never just open(). The with statement automatically closes the file when the block ends — even if an error occurs. Without it, you must call f.close() manually. Unclosed files cause data corruption and memory leaks.
📊 CSV Files — The ML Dataset Format

CSV (Comma Separated Values) is the most common format for ML datasets. The csv module handles all edge cases (commas inside fields, headers, etc.) that plain text reading misses.

📄
.txt
Plain text. Logs, notes, simple data.
📊
.csv
Datasets, tables. Standard ML format. pd.read_csv()
🔧
.json
Model configs, API responses, nested data.
Python — CSV Files
import csv # WRITE CSV students = [ ["name", "marks", "grade"], # header row ["Ali", 88, "A"], ["Sara", 45, "F"], ["Usman", 72, "B"], ] with open("students.csv", "w", newline="") as f: writer = csv.writer(f) writer.writerows(students) # READ CSV as list of dicts (DictReader = best way) with open("students.csv") as f: reader = csv.DictReader(f) # header row becomes keys! for row in reader: print(f"{row['name']}: {row['marks']} ({row['grade']})") # WRITE CSV as dicts (DictWriter) data = [ {"name":"Zara", "marks":91, "grade":"A+"} ] with open("new_student.csv", "w", newline="") as f: w = csv.DictWriter(f, fieldnames=["name","marks","grade"]) w.writeheader() w.writerows(data)
🔧 JSON Files — Model Configs & API Data

JSON (JavaScript Object Notation) stores structured data — dictionaries and lists. Used for ML model configurations, saving predictions, and receiving API responses. JSON is just a Python dict saved to a file.

Python — JSON Files
import json # WRITE JSON — save model config config = { "model" : "RandomForest", "n_estimators" : 100, "max_depth" : 5, "accuracy" : 94.7, "features" : ["age", "income", "score"] } with open("config.json", "w") as f: json.dump(config, f, indent=4) # indent=4 for readable file # READ JSON — load back into Python with open("config.json") as f: loaded = json.load(f) print(loaded["model"]) # RandomForest print(loaded["accuracy"]) # 94.7 print(loaded["features"]) # ['age', 'income', 'score'] # json.dumps — convert to string (no file) json_str = json.dumps(config) print(type(json_str)) # <class 'str'> # json.loads — parse string into dict (no file) back = json.loads(json_str) print(type(back)) # <class 'dict'>
💡dump/load vs dumps/loads:
json.dump(data, file) → writes to file  |  json.load(file) → reads from file
json.dumps(data) → returns string  |  json.loads(string) → parses string
The extra s = string. No s = file.
🌍 Real World Example

How ML Projects Load Datasets Before Pandas

Before Pandas existed, every data scientist loaded CSV datasets with the csv module. Even today, this skill helps when working with non-standard formats or when Pandas isn't available.

Python — Full data loading pipeline
import csv, json, os def load_dataset(filepath): """Load CSV and return list of dicts.""" if not os.path.exists(filepath): print(f"File not found: {filepath}") return [] with open(filepath) as f: return list(csv.DictReader(f)) def save_results(results, filepath): """Save prediction results to JSON.""" with open(filepath, "w") as f: json.dump(results, f, indent=4) print(f"Saved {len(results)} results to {filepath}") # Load → process → save pipeline data = load_dataset("students.csv") results = [] for row in data: marks = int(row["marks"]) status = "pass" if marks >= 50 else "fail" results.append({ "name" : row["name"], "marks" : marks, "status": status }) save_results(results, "results.json") print(f"Processed {len(results)} students")
🎯This load → process → save pipeline is the foundation of every ML project you'll ever build. In Month 2+ the load step becomes pd.read_csv() and the save step becomes df.to_csv(). The structure stays the same forever.

import numpy as np scores = np.array([85, 45, 72, 33, 91, 58]) # Fancy indexing — index with an array of integers indices = np.array([0, 2, 4]) print(scores[indices]) # [85 72 91] # np.where — conditional element-wise labels = np.where(scores >= 50, "Pass", "Fail") print(labels) # ['Pass' 'Fail' 'Pass' 'Fail' 'Pass' 'Pass'] # np.where with numbers — replace values clipped = np.where(scores < 50, 0, scores) print(clipped) # [85 0 72 0 91 58] — failed → 0 # np.where to get indices pass_idx = np.where(scores >= 50)[0] print(pass_idx) # [0 2 4 5] — indices of passing scores # 2D fancy indexing X = np.array([ [5, 80, 1], [2, 50, 0], [8, 90, 1], [1, 40, 0], ]) # Select rows 0 and 2 only print(X[[0, 2]]) # first and third student # Select column 1 (attendance) for all students print(X[:, 1]) # [80 50 90 40] # Select rows where attendance >= 70 print(X[X[:, 1] >= 70]) # rows 0 and 2
💡X[X[:, 1] >= 70] is how Pandas filters rows internally. You're reading: "from X, keep only rows where column 1 ≥ 70." This pattern appears in every single ML data preprocessing step.

📖 Part 2 — Broadcasting

Broadcasting — The Rule Behind Vectorised Ops

Broadcasting is how NumPy handles operations between arrays of different shapes. When you write X - X.mean(axis=0), NumPy automatically expands the smaller array to match the larger one. Understanding this prevents confusing shape errors.

Array A
[[1 2 3]
[4 5 6]
[7 8 9]]
shape: (3, 3)
+
Array B
[10 20 30]

shape: (3,) → expands to (3,3)
=
Result
[[11 22 33]
[14 25 36]
[17 28 39]]
shape: (3, 3)
Python — Broadcasting in Action
# Scalar broadcast — applies to every element a = np.array([1, 2, 3, 4]) print(a + 10) # [11 12 13 14] ← 10 broadcast over all print(a * 2) # [ 2 4 6 8] # 1D + 2D broadcast — most common in ML X = np.array([ [80, 90, 70], [60, 50, 40], [75, 85, 65], ]) # shape (3, 3) col_mean = np.mean(X, axis=0) # [71.7, 75.0, 58.3] shape (3,) centred = X - col_mean # broadcast! shape (3,) → (3,3) print(centred) # Each row has its column mean subtracted # This IS mean-centering (part of StandardScaler) # Z-score standardisation using broadcast col_std = np.std(X, axis=0) X_scaled = (X - col_mean) / col_std # all broadcasts! print(np.round(X_scaled, 2))
💡Broadcasting Rules:
1. Arrays are aligned from the RIGHT in their shapes
2. Dimensions of size 1 are stretched to match the other
3. (3,3) + (3,) → (3,3) + (1,3) → (3,3) + (3,3) ✅
4. (3,3) + (3,1) → row-wise broadcast ✅
5. (3,3) + (4,) → ERROR — 3 ≠ 4 and neither is 1
⚠️ Broadcasting Errors — The #1 NumPy Bug
Python — Understanding Shape Errors
# These work ✅ np.array([1,2,3]) + 10 # (3,) + scalar np.ones((3,3)) + np.array([1,2,3]) # (3,3) + (3,) np.ones(3) + np.ones((4,3)) # (3,) + (4,3) # These FAIL ❌ # np.array([1,2,3]) + np.array([1,2]) # (3,) + (2,) — sizes differ # np.ones((3,3)) + np.ones((4,3)) # 3 != 4 # Fix shape errors with reshape row_vec = np.array([1, 2, 3]) # shape (3,) col_vec = row_vec.reshape(-1, 1) # shape (3, 1) # row_vec + col_vec → outer sum (3,3) print(row_vec + col_vec) # [[2 3 4] # [3 4 5] # [4 5 6]]
📖 Part 3 — Linear Algebra

np.linalg — The Math Engine of Neural Networks

Every neural network forward pass is a series of matrix multiplications. Every ML optimiser solves a linear system. Linear algebra is not optional in ML — it is ML. NumPy makes it one function call.

Python — Linear Algebra
# Dot product — multiply + sum weights = np.array([0.4, 0.3, 0.3]) inputs = np.array([5, 80, 1]) output = np.dot(weights, inputs) print(f"Neuron output: {output}") # 0.4*5 + 0.3*80 + 0.3*1 = 26.3 ← this IS a neuron! # Matrix multiply — multiple neurons at once W = np.array([[0.4, 0.3, 0.3], # neuron 1 weights [0.1, 0.5, 0.4]]) # neuron 2 weights X = np.array([[5, 80, 1], # student 1 [2, 50, 0], # student 2 [8, 90, 1]]) # student 3 Z = X @ W.T # (3,3) @ (3,2) = (3,2) print(Z) # Each row = outputs of both neurons for one student # THIS is a neural network dense layer forward pass! # Transpose print(W.T) # rows become columns print(W.T.shape) # (3, 2) # Norm — vector magnitude v = np.array([3, 4]) print(np.linalg.norm(v)) # 5.0 (Euclidean distance) # Linear regression: solve w = (X^T X)^-1 X^T y A = np.array([[1, 5], [1, 2], [1, 8]]) y = np.array([88, 45, 91]) w = np.linalg.inv(A.T @ A) @ A.T @ y print(f"Weights: {np.round(w, 2)}")
💡Z = X @ W.T is a neural network dense layer. X is your input (n_samples × n_features). W is weights (n_neurons × n_features). W.T is (n_features × n_neurons). X @ W.T = (n_samples × n_neurons). Add a bias and activation function — that's exactly what Keras's Dense(units) does.

🌍 Real World Example

Neural Network Dense Layer — From Scratch

Using only NumPy, here is a complete dense layer with forward pass, activation function, and prediction. This is literally what happens inside Keras's Dense(4, activation='relu').

Python — Dense Layer with NumPy
import numpy as np np.random.seed(42) class DenseLayer: """Single fully-connected neural network layer.""" def __init__(self, in_features, out_features): # Xavier initialisation (standard practice) scale = np.sqrt(2.0 / in_features) self.W = np.random.randn(in_features, out_features) * scale self.b = np.zeros(out_features) def forward(self, X): Z = X @ self.W + self.b # matrix multiply + broadcast bias A = np.maximum(0, Z) # ReLU activation return A @property def param_count(self): return self.W.size + self.b.size # Simulate input: 4 students, 3 features each X = np.array([[5,80,1],[2,50,0],[8,90,1],[1,40,0]], dtype=float) layer1 = DenseLayer(3, 4) # 3 input, 4 hidden layer2 = DenseLayer(4, 1) # 4 hidden, 1 output h = layer1.forward(X) # shape (4, 4) out = layer2.forward(h) # shape (4, 1) print("Predictions:", np.round(out.flatten(), 3)) print(f"Layer 1 params: {layer1.param_count}") # 3*4 + 4 = 16 print(f"Layer 2 params: {layer2.param_count}") # 4*1 + 1 = 5
🎯You just built a 2-layer neural network with only NumPy. Z = X @ W + b is literally the forward pass formula. np.maximum(0, Z) is ReLU. In Month 3 when you write Keras's Dense(4, activation='relu') — you now know exactly what it computes.

Project Brief

Read this first. It defines what you are building and why.

Kestrel Logistics · Network Performance Review

Kestrel ships parcels from six regional warehouses through five carriers. The operations committee meets each month to decide which carriers to keep, where to add capacity, and which lanes are losing money. Today the numbers come from a shipment export that nobody trusts: duplicate rows, weights stored as text, three date formats, status spelled eleven ways, and carrier IDs that do not exist in the carrier master. Your job is to build the pipeline the committee can rely on.

Day 1: Selection & types Day 2: Cleaning Day 3: GroupBy, merge, pivot Day 4: Time series Day 5: Chaining & performance

Rules

  • Read raw data as it arrives. Do not patch the CSV by hand. Every fix must live in code so the pipeline is reproducible.
  • Never silently drop rows. If you remove something, count it and report the count.
  • No iterrows() or Python loops over rows. Use vectorised operations, .str, .dt, groupby, transform, and np.where or np.select.
  • Prefer method chaining for pipelines, with a pipe() call where a helper function makes the chain clearer.
  • Every merge must be checked. Use validate= and indicator= and report unmatched keys.
🧭 Environment
Python 3.10+ with pandas (2.x), numpy, openpyxl (for Excel export), and pytest. Install with pip install pandas numpy openpyxl pytest.

Phase 2 — Clean the Shipment Table

~70 min▼
1
Write parse_dates(series)

Try each known format in turn with pd.to_datetime(..., format=fmt, errors="coerce"), and fill only the rows that are still NaT after the previous attempt. Return the result as one datetime Series. Do not use a single format=None call, because it guesses per value and can silently swap day and month.

2
Write load_clean(path) as one method chain
  • Drop duplicate rows by shipment_id, and report how many were dropped.
  • Strip, upper-case, and validate warehouse_id and carrier_id.
  • Remove the text unit from weight_kg and convert it to float. Invalid values become NaN.
  • Map every status spelling to one of Delivered, Returned, Lost, or Unknown with a mapping dictionary. Do not use chains of if statements.
  • Replace transit values of zero or below with NaN using where.
  • Convert dest_zone to a category dtype.
3
Handle missing dates honestly

Rows with no valid ship_date cannot be placed in time, so drop them, but count them and store the count in a dictionary called cleaning_log. Every rule in the pipeline should append one entry to this log. You will print the log at the end of the run.

✓
Checkpoint 2
  • shipment_id is unique after cleaning
  • weight_kg and transit_days are float columns
  • status has no values outside the four allowed labels
  • ship_date has no NaT, and the cleaning log accounts for every dropped row

Phase 3 — Safe Merges & Feature Engineering

~60 min▼
1
Join the reference tables with checks

Merge shipments with carriers and warehouses. Use validate="many_to_one" so a duplicated reference key raises an error instead of multiplying rows. Use indicator= on the carrier merge and count the left_only rows. Those are shipments that reference a carrier not in the master, and you must report them rather than dropping them silently.

2
Engineer the performance features
  • delay_days = transit_days − promised_days
  • on_time as a float (1.0, 0.0, or NaN when transit is unknown). Use np.where so that NaN stays NaN and the mean ignores it.
  • cost_per_kg = freight_cost ÷ weight_kg
  • weight_band with pd.cut: Light (0–1 kg), Medium (1–5 kg), Heavy (5–20 kg), Bulk (over 20 kg). Decide and document whether each bin is open or closed on each side.
  • service_tier with np.select: "Express" if promised_days ≤ 2, "Standard" if ≤ 3, otherwise "Economy"
  • month (first day of month), quarter (as a period string), and weekday
✓
Checkpoint 3
  • The master row count equals the cleaned shipment count (no duplication from joins)
  • You can state how many shipments had an unknown carrier and how many had no transit value
  • Every feature column is documented in a comment next to its definition

Phase 4 — Carrier & Warehouse Analytics

~75 min▼
1
Build the carrier scorecard with named aggregation

Group by carrier_name and produce: shipment count, on-time rate, mean delay, mean cost per kg, and loss rate (the share of rows with status Lost). Sort by on-time rate, and round to three decimals.

2
Flag cost anomalies inside each lane with transform

Group by warehouse_id and carrier_id. Compute a z-score of cost_per_kg against that lane's own mean and standard deviation, using transform so the result aligns with the original rows. Flag rows where the absolute z-score exceeds 3. Report how many rows were flagged and which lanes they belong to.

Rank carriers within each warehouse

For each warehouse, rank carriers by on-time rate using groupby(...).rank(). Add the rank as a column, then use pivot_table to build a city by carrier grid of on-time rates with margins=True.

Cross-tab the outcomes

Use pd.crosstab to show status counts by service tier, first as raw counts and then with normalize="index" to show each tier's outcome mix. Explain in one sentence which of the two tables the committee should read.

Phase 5 — Time Series & Trend Analysis

import os
import numpy as np
import pandas as pd

rng = np.random.default_rng(2024)
os.makedirs("data", exist_ok=True)
n = 20000

warehouses = pd.DataFrame({
    "warehouse_id": ["WH01", "WH02", "WH03", "WH04", "WH05", "WH06"],
    "city": ["Surat", "Ahmedabad", "Mumbai", "Pune", "Bengaluru", "Delhi"],
    "capacity": [5000, 4000, 8000, 6000, 7000, 9000],
})
carriers = pd.DataFrame({
    "carrier_id": ["C01", "C02", "C03", "C04", "C05"],
    "carrier_name": ["SwiftLine", "Carrio", "RoadRunner", "NorthStar", "Parcelo"],
    "rate_per_kg": [42.0, 38.5, 35.0, 40.0, 33.0],
    "sla_days": [2, 3, 4, 3, 5],
})
carriers.to_csv("data/carriers.csv", index=False)
warehouses.to_csv("data/warehouses.csv", index=False)

wh = rng.choice(warehouses.warehouse_id, n, p=[.2, .15, .25, .15, .15, .10])
car = rng.choice(carriers.carrier_id, n, p=[.3, .2, .2, .15, .15])
ship_date = pd.Series(rng.choice(pd.date_range("2023-01-01", "2024-12-31"), n))
zone = rng.choice(["Local", "Regional", "National"], n, p=[.3, .4, .3])
weight = rng.lognormal(mean=1.2, sigma=0.7, size=n).round(2)

rate = carriers.set_index("carrier_id").loc[car, "rate_per_kg"].to_numpy()
sla = carriers.set_index("carrier_id").loc[car, "sla_days"].to_numpy()
zone_extra = pd.Series(zone).map({"Local": 0, "Regional": 1, "National": 2}).to_numpy()
actual = np.clip(np.round(sla + zone_extra * 0.5 + rng.normal(0, 1.3, n)), 1, None)
freight = weight * rate * (1 + rng.uniform(-0.1, 0.1, n)) * (1 + 0.2 * (zone_extra == 2))

status = rng.choice(["Delivered", "Returned", "Lost"], n, p=[.955, .03, .015])
status_messy = np.where(rng.random(n) < 0.3, np.char.lower(status.astype(str)), status)
status_messy = np.where(rng.random(n) < 0.05, np.char.upper(status_messy.astype(str)), status_messy)
status_messy = np.where(rng.random(n) < 0.02, "rto", status_messy)

fmt = rng.choice(["iso", "dmy", "long"], n, p=[.7, .2, .1])
pattern = {"iso": "%Y-%m-%d", "dmy": "%d/%m/%Y", "long": "%b %d %Y"}
date_text = [d.strftime(pattern[f]) for d, f in zip(ship_date, fmt)]

weight_text = np.where(rng.random(n) < 0.02, [f"{w} kg" for w in weight], weight)
transit = actual.astype(float)
transit[rng.random(n) < 0.04] = np.nan
transit[rng.random(n) < 0.01] = -1

shipments = pd.DataFrame({
    "shipment_id": [f"SHP{i:06d}" for i in range(1, n + 1)],
    "ship_date": date_text,
    "warehouse_id": wh,
    "carrier_id": car,
    "dest_zone": zone,
    "weight_kg": weight_text,
    "freight_cost": freight.round(2),
    "promised_days": sla,
    "transit_days": transit,
    "status": status_messy,
})
shipments.loc[rng.random(n) < 0.01, "warehouse_id"] = shipments["warehouse_id"].str.lower()
shipments.loc[rng.random(n) < 0.01, "carrier_id"] = "C09"
shipments = pd.concat([shipments, shipments.sample(300, random_state=1)], ignore_index=True)
shipments.to_csv("data/shipments_raw.csv", index=False)
print("Wrote", len(shipments), "raw shipment rows to data/")

PYTHON · pipeline.py
"""pipeline.py: Kestrel Logistics operations analytics.

Usage:
    python pipeline.py data --outdir output
"""
import argparse
from pathlib import Path

import numpy as np
import pandas as pd

STATUS_MAP = {"delivered": "Delivered", "returned": "Returned",
              "rto": "Returned", "lost": "Lost"}
DATE_FORMATS = ["%Y-%m-%d", "%d/%m/%Y", "%b %d %Y"]
CLEANING_LOG = {}


def log(rule, count):
    """Record how many rows a cleaning rule touched."""
    CLEANING_LOG[rule] = int(count)


def parse_dates(text):
    """Parse each known format in turn; only retry rows still missing."""
    out = pd.Series(pd.NaT, index=text.index, dtype="datetime64[ns]")
    for fmt in DATE_FORMATS:
        missing = out.isna()
        out[missing] = pd.to_datetime(text[missing], format=fmt, errors="coerce")
    return out


def load_clean(path):
    """Read the raw shipment file and return one clean row per shipment."""
    raw = pd.read_csv(path)
    n_dupes = raw.duplicated(subset="shipment_id").sum()
    log("duplicate shipments removed", n_dupes)

    clean = (
        raw.drop_duplicates(subset="shipment_id")
        .assign(
            ship_date=lambda d: parse_dates(d["ship_date"].astype(str)),
            warehouse_id=lambda d: d["warehouse_id"].str.strip().str.upper(),
            carrier_id=lambda d: d["carrier_id"].str.strip().str.upper(),
            dest_zone=lambda d: d["dest_zone"].str.strip().str.title().astype("category"),
            weight_kg=lambda d: pd.to_numeric(
                d["weight_kg"].astype(str).str.replace("kg", "", regex=False).str.strip(),
                errors="coerce"),
            status=lambda d: d["status"].str.strip().str.lower().map(STATUS_MAP).fillna("Unknown"),
            transit_days=lambda d: pd.to_numeric(d["transit_days"], errors="coerce").where(lambda s: s > 0),
        )
    )
    log("rows without a valid ship_date", clean["ship_date"].isna().sum())
    clean = clean.dropna(subset=["ship_date"])
    return clean


def load_reference(carriers_path, warehouses_path):
    """Load and normalise the carrier and warehouse master tables."""
    carriers = pd.read_csv(carriers_path).assign(
        carrier_id=lambda d: d["carrier_id"].str.upper())
    warehouses = pd.read_csv(warehouses_path)
    return carriers, warehouses


def build_master(shipments, carriers, warehouses):
    """Join reference data with checks and add performance features."""
    master = (
        shipments
        .merge(carriers, on="carrier_id", how="left",
               validate="many_to_one", indicator="carrier_check")
        .merge(warehouses, on="warehouse_id", how="left",
               validate="many_to_one")
    )
    log("shipments with unknown carrier", (master["carrier_check"] == "left_only").sum())
    master = master.drop(columns="carrier_check")

    master = master.assign(
        delay_days=lambda d: d["transit_days"] - d["promised_days"],
        on_time=lambda d: np.where(d["transit_days"].notna(),
                                   (d["transit_days"] <= d["promised_days"]).astype(float),
                                   np.nan),
        cost_per_kg=lambda d: d["freight_cost"] / d["weight_kg"],
        weight_band=lambda d: pd.cut(d["weight_kg"], bins=[0, 1, 5, 20, np.inf],
                                     labels=["Light", "Medium", "Heavy", "Bulk"]),
        service_tier=lambda d: np.select(
            [d["promised_days"] <= 2, d["promised_days"] <= 3], ["Express", "Standard"],
            default="Economy"),
        month=lambda d: d["ship_date"].dt.to_period("M").dt.to_timestamp(),
        quarter=lambda d: d["ship_date"].dt.to_period("Q").astype(str),
        weekday=lambda d: d["ship_date"].dt.day_name(),
    )
    log("shipments with no transit value", master["transit_days"].isna().sum())
    return master


def carrier_scorecard(master):
    """One row per carrier with the committee's headline metrics."""
    return (
        master.groupby("carrier_name")
        .agg(shipments=("shipment_id", "count"),
             on_time_rate=("on_time", "mean"),
             mean_delay=("delay_days", "mean"),
             cost_per_kg=("cost_per_kg", "mean"),
             loss_rate=("status", lambda s: (s == "Lost").mean()))
        .sort_values("on_time_rate", ascending=False)
        .round(3)
    )


def flag_cost_anomalies(master, z_limit=3.0):
    """Z-score cost per kg against each warehouse-carrier lane."""
    lane = master.groupby(["warehouse_id", "carrier_id"])["cost_per_kg"]
    z = (master["cost_per_kg"] - lane.transform("mean")) / lane.transform("std")
    return master.assign(cost_z=z, cost_anomaly=lambda d: d["cost_z"].abs() > z_limit)


def warehouse_carrier_grid(master):
    """On-time rate by city and carrier, with totals."""
    return pd.pivot_table(master, values="on_time", index="warehouse_id",
                          columns="carrier_name", aggfunc="mean", margins=True).round(3)


def monthly_view(master):
    """Monthly volume and freight with MoM, YoY and year-to-date totals."""
    m = master.groupby("month").agg(shipments=("shipment_id", "count"),
                                    freight=("freight_cost", "sum"))
    m["freight_mom_pct"] = m["freight"].pct_change() * 100
    m["freight_yoy_pct"] = m["freight"].pct_change(12) * 100
    m["freight_ytd"] = m.groupby(m.index.year)["freight"].cumsum()
    return m


def weekly_view(master):
    """Weekly on-time rate and its 4-week rolling mean."""
    s = master.set_index("ship_date").sort_index()["on_time"]
    weekly = s.resample("W").mean()
    return pd.DataFrame({"on_time_weekly": weekly,
                         "on_time_4wk": weekly.rolling(4, min_periods=2).mean()})


def export(outdir, master, scorecard, grid, monthly, anomalies):
    """Write the CSV, the Excel workbook, and the HTML scorecard."""
    master.to_csv(outdir / "shipments_clean.csv", index=False)
    with pd.ExcelWriter(outdir / "kestrel_report.xlsx") as xw:
        scorecard.to_excel(xw, sheet_name="Carriers")
        grid.to_excel(xw, sheet_name="Warehouse x Carrier")
        monthly.to_excel(xw, sheet_name="Monthly")
        anomalies.to_excel(xw, sheet_name="Anomalies", index=False)
    styled = (scorecard.style
              .format({"on_time_rate": "{:.1%}", "loss_rate": "{:.1%}",
                       "cost_per_kg": "{:.2f}", "mean_delay": "{:.2f}"})
              .background_gradient(subset=["on_time_rate"], cmap="Greens")
              .highlight_max(subset=["loss_rate"], color="#FECACA"))
    styled.to_html(outdir / "carrier_scorecard.html")


def main():
    ap = argparse.ArgumentParser(description="Kestrel operations analytics")
    ap.add_argument("data_dir")
    ap.add_argument("--outdir", default="output")
    args = ap.parse_args()

    data, out = Path(args.data_dir), Path(args.outdir)
    out.mkdir(parents=True, exist_ok=True)

    carriers, warehouses = load_reference(data / "carriers.csv", data / "warehouses.csv")
    shipments = load_clean(data / "shipments_raw.csv")
    master = build_master(shipments, carriers, warehouses)

    scorecard = carrier_scorecard(master)
    grid = warehouse_carrier_grid(master)
    monthly = monthly_view(master)
    flagged = flag_cost_anomalies(master)
    anomalies = flagged.loc[flagged["cost_anomaly"],
                            ["shipment_id", "warehouse_id", "carrier_id", "cost_per_kg", "cost_z"]]
    log("cost anomalies flagged", len(anomalies))

    export(out, flagged, scorecard, grid, monthly, anomalies)

    print("Cleaning log:")
    for rule, count in CLEANING_LOG.items():
        print(f"  {rule}: {count}")
    print("Master rows:", len(master))
    print("Outputs written to", out.resolve())


if __name__ == "__main__":
    main()

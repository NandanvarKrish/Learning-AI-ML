Project Brief

Read this first. It defines what you are building and why.

Meridian Retail Group · Head Office, Data Analytics

Every month, the Meridian board receives a visual report on sales. Last month the report was assembled by hand in a spreadsheet and took two days. It contained a double-counted region, a pie chart that nobody could read, and a forecast with no uncertainty shown. The board has asked the analytics team to replace it with a reproducible pipeline. You are the analyst who will build it. Your report will be generated by one command and then reviewed by people who have less than five minutes to read it.

Day 1: Figure/Axes & basic charts Day 2: Styling & GridSpec Day 3: Box/Violin/Heatmap/Donut Day 4: Animation Day 5: Layout & PdfPages

Rules

  • Use only Matplotlib for drawing. Pandas and NumPy are allowed for data work. Seaborn and Plotly are not allowed.
  • Use the object-oriented interface (fig, ax = plt.subplots(), ax.plot()) everywhere. Avoid bare plt.plot() calls in the report code.
  • Every chart title must state a takeaway, for example "Gross margin fell to 31.2% in Q4" rather than "Margin by month".
  • Do not use jet or other rainbow colormaps. Use a sequential map for ordered data and a diverging map for correlations.
  • Running python report.py orders_raw.csv --outdir output must rebuild all outputs from scratch with no manual steps.
🧭 Environment
Python 3.10+ with matplotlib (3.8 or newer), pandas, numpy, and pytest. The GIF writer uses Pillow, which Matplotlib installs as a dependency. Install with pip install matplotlib pandas numpy pytest. You do not need ffmpeg for this task.

Phase 1 — Generate the Raw Data & Clean It

~45 min▼
1
Run the provided data generator

Save the code below as make_dataset.py and run it. It creates orders_raw.csv with about 12,000 orders from January 2023 to December 2024. The file is deliberately messy: some regions are lowercase, some channels are missing, 120 rows are duplicates, and about 3% of rows are product returns with negative units and revenue.

PYTHON · make_dataset.py
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 12000
dates = pd.date_range("2023-01-01", "2024-12-31", freq="D")

region = rng.choice(["North", "South", "East", "West"], n, p=[0.30, 0.28, 0.22, 0.20])
category = rng.choice(["Electronics", "Apparel", "Home", "Grocery", "Sports"], n,
                      p=[0.20, 0.25, 0.20, 0.25, 0.10])
channel = rng.choice(["Store", "Online", "Partner"], n, p=[0.50, 0.35, 0.15])
base = pd.Series(category).map({"Electronics": 4500, "Apparel": 1200, "Home": 2200,
                                "Grocery": 250, "Sports": 1800}).to_numpy()
unit_price = base * rng.normal(1.0, 0.12, n).clip(0.6, 1.5)
discount = rng.choice([0, 5, 10, 15, 20], n, p=[0.45, 0.20, 0.15, 0.12, 0.08])
units = rng.poisson(3, n) + 1
revenue = units * unit_price * (1 - discount / 100)
cost = revenue * rng.uniform(0.55, 0.80, n)

df = pd.DataFrame({
    "order_id": np.arange(1, n + 1),
    "order_date": rng.choice(dates, n),
    "region": region,
    "store_id": rng.integers(101, 140, n),
    "category": category,
    "channel": channel,
    "customer_id": rng.integers(10000, 19000, n),
    "units": units,
    "unit_price": unit_price.round(2),
    "discount_pct": discount,
    "revenue": revenue.round(2),
    "cost": cost.round(2),
})

# Product returns: negative units, revenue and cost
ret = rng.random(n) < 0.03
df.loc[ret, ["units", "revenue", "cost"]] *= -1

# Messy inputs: inconsistent casing, missing channel, duplicate rows
mask = rng.random(n) < 0.05
df.loc[mask, "region"] = df.loc[mask, "region"].str.lower()
mask = rng.random(n) < 0.02
df.loc[mask, "channel"] = np.nan
df = pd.concat([df, df.sample(120, random_state=1)], ignore_index=True)

df.sort_values("order_date").to_csv("orders_raw.csv", index=False)
print("Wrote orders_raw.csv with shape", df.shape)

Phase 4 — Forecast Band & Animated Reveal

~60 min▼
1
Linear forecast for six months

Fit a straight line with np.polyfit(x, y, 1) to the monthly revenue, where x is the month index from 0 to 23. Forecast months 24 to 29. Draw the forecast as a dashed gold line.

2
Uncertainty band

Compute the residual standard deviation with ddof=2, because the fit estimates two parameters. Shade the band from forecast minus two standard deviations to forecast plus two standard deviations, using fill_between with a low alpha. In your NOTES.md, explain that this band is a rough guide and not a guarantee.

PYTHON · report.py
"""report.py: Meridian Retail monthly performance report.

Usage:
    python report.py orders_raw.csv --outdir output
"""
import argparse
from pathlib import Path

import matplotlib
matplotlib.use("Agg")  # headless: write files without opening windows
import matplotlib.pyplot as plt
import matplotlib.animation as animation
from matplotlib.backends.backend_pdf import PdfPages
from matplotlib.gridspec import GridSpec
import numpy as np
import pandas as pd

PALETTE = {"navy": "#0F172A", "gold": "#D97706", "teal": "#0891B2",
           "gray": "#94A3B8", "rose": "#E11D48"}


def apply_style():
    """Set global defaults once, so every chart shares one look."""
    plt.rcParams.update({
        "font.size": 10, "axes.titlesize": 11, "axes.titleweight": "bold",
        "axes.spines.top": False, "axes.spines.right": False,
        "axes.grid": True, "grid.alpha": 0.2,
    })


# ---------- Data ----------
def load_clean(path):
    """Read the raw CSV and return a cleaned DataFrame."""
    df = pd.read_csv(path, parse_dates=["order_date"])
    df = df.drop_duplicates(subset="order_id")
    df["region"] = df["region"].str.strip().str.title()
    df["channel"] = df["channel"].fillna("Unknown")
    df["is_return"] = df["units"] < 0
    df["month"] = df["order_date"].dt.to_period("M").dt.to_timestamp()
    df["margin_pct"] = 100 * (df["revenue"] - df["cost"]) / df["revenue"]
    return df


def kpis(df):
    """Headline numbers for the KPI row."""
    yearly = df.groupby(df["order_date"].dt.year)["revenue"].sum()
    net = df["revenue"].sum()
    return {
        "net_revenue": net,
        "margin_pct": 100 * (net - df["cost"].sum()) / net,
        "yoy_pct": 100 * yearly.pct_change().iloc[-1],
        "return_rate_pct": 100 * df["is_return"].mean(),
    }


def monthly(df):
    """One row per month: revenue, cost, margin."""
    m = df.groupby("month").agg(revenue=("revenue", "sum"), cost=("cost", "sum"))
    m["margin_pct"] = 100 * (m["revenue"] - m["cost"]) / m["revenue"]
    return m


# ---------- Panels (each takes an Axes and draws into it) ----------
def add_kpi_cards(fig, gs_row, k):
    cards = [
        ("Net revenue (INR Cr)", f"{k['net_revenue'] / 1e7:.2f}"),
        ("Gross margin", f"{k['margin_pct']:.1f}%"),
        ("YoY growth", f"{k['yoy_pct']:+.1f}%"),
        ("Return rate", f"{k['return_rate_pct']:.1f}%"),
    ]
    for i, (label, value) in enumerate(cards):
        ax = fig.add_subplot(gs_row[i])
        ax.axis("off")
        ax.text(0.5, 0.62, value, ha="center", va="center", fontsize=20,
                fontweight="bold", transform=ax.transAxes)
        ax.text(0.5, 0.18, label, ha="center", va="center", fontsize=9,
                color="gray", transform=ax.transAxes)


def plot_trend_with_forecast(ax, m, horizon=6):
    """Monthly revenue (lakh INR) plus a 6-month linear forecast with a band."""
    x = np.arange(len(m))
    y = m["revenue"].to_numpy() / 1e5
    slope, intercept = np.polyfit(x, y, 1)
    resid_sd = np.std(y - (slope * x + intercept), ddof=2)
    fx = np.arange(len(m), len(m) + horizon)
    fy = slope * fx + intercept
    future = pd.date_range(m.index[-1], periods=horizon + 1, freq="MS")[1:]

    ax.plot(m.index, y, color=PALETTE["navy"], lw=2, marker="o", ms=4, label="Actual")
    ax.plot(future, fy, color=PALETTE["gold"], lw=2, ls="--", label="Forecast")
    ax.fill_between(future, fy - 2 * resid_sd, fy + 2 * resid_sd,
                    color=PALETTE["gold"], alpha=0.15)
    ax.set_ylim(bottom=0)
    ax.set_ylabel("INR lakh")
    ax.set_title("Monthly net revenue with 6-month linear forecast")
    ax.legend(loc="upper left", frameon=False)


def plot_regions(ax, df):
    reg = df.groupby("region")["revenue"].sum().sort_values()
    top = reg.max()
    colors = [PALETTE["gold"] if v == top else PALETTE["gray"] for v in reg.values]
    bars = ax.barh(reg.index, reg.values / 1e5, color=colors)
    ax.bar_label(bars, fmt="%.0f", padding=3, fontsize=9)
    ax.margins(x=0.15)
    ax.set_title("Revenue by region (INR lakh)")


def plot_margin_box(ax, df):
    sales = df[~df["is_return"]]
    cats = sorted(sales["category"].unique())
    data = [sales.loc[sales["category"] == c, "margin_pct"] for c in cats]
    bp = ax.boxplot(data, patch_artist=True, showfliers=False)
    for box in bp["boxes"]:
        box.set_facecolor(PALETTE["teal"])
        box.set_alpha(0.6)
    ax.set_xticks(range(1, len(cats) + 1), cats, rotation=30, ha="right", fontsize=8)
    ax.set_title("Gross margin % by category (outliers hidden)", fontsize=10)


def plot_channel_donut(ax, df):
    ch = df.groupby("channel")["revenue"].sum().sort_values(ascending=False)
    palette = [PALETTE["navy"], PALETTE["teal"], PALETTE["gray"], "#E2E8F0"]
    ax.pie(ch.values, labels=ch.index, autopct="%1.0f%%", startangle=90,
           colors=palette[:len(ch)], pctdistance=0.8,
           wedgeprops=dict(width=0.4), textprops={"fontsize": 8})
    ax.set_title("Revenue share by channel", fontsize=10)


def plot_order_hist(ax, df):
    sales = df.loc[~df["is_return"], "revenue"] / 1e3
    ax.hist(sales, bins=40, color=PALETTE["teal"], alpha=0.85)
    ax.axvline(sales.mean(), color=PALETTE["gold"], ls="--",
               label=f"Mean {sales.mean():.1f}k")
    ax.axvline(sales.median(), color=PALETTE["rose"], ls=":",
               label=f"Median {sales.median():.1f}k")
    ax.legend(fontsize=8, frameon=False)
    ax.set_xlabel("Order value (INR thousand)")
    ax.set_title("Order value distribution", fontsize=10)


def plot_corr_heatmap(ax, df):
    cols = ["units", "unit_price", "discount_pct", "revenue", "margin_pct"]
    corr = df[cols].corr()
    im = ax.imshow(corr.to_numpy(), cmap="RdBu_r", vmin=-1, vmax=1)
    ax.set_xticks(range(len(cols)), cols, rotation=45, ha="right", fontsize=7)
    ax.set_yticks(range(len(cols)), cols, fontsize=7)
    for i in range(len(cols)):
        for j in range(len(cols)):
            v = corr.iloc[i, j]
            ax.text(j, i, f"{v:.2f}", ha="center", va="center", fontsize=6,
                    color="white" if abs(v) > 0.5 else "black")
    ax.grid(False)
    ax.set_title("Correlations", fontsize=10)


# ---------- Outputs ----------
def build_dashboard(df, k):
    """Assemble the executive dashboard. Returns the Figure."""
    apply_style()
    fig = plt.figure(figsize=(16, 10))
    gs = GridSpec(3, 4, figure=fig, height_ratios=[0.6, 1.4, 1.2],
                  hspace=0.55, wspace=0.35)
    fig.suptitle("Meridian Retail: revenue up {:.0f}% YoY, margin at {:.1f}%".format(
        k["yoy_pct"], k["margin_pct"]), fontsize=18, fontweight="bold",
        color=PALETTE["navy"])

    add_kpi_cards(fig, gs[0, :], k)
    plot_trend_with_forecast(fig.add_subplot(gs[1, :3]), monthly(df))
    plot_regions(fig.add_subplot(gs[1, 3]), df)
    plot_margin_box(fig.add_subplot(gs[2, 0]), df)
    plot_channel_donut(fig.add_subplot(gs[2, 1]), df)
    plot_order_hist(fig.add_subplot(gs[2, 2]), df)
    plot_corr_heatmap(fig.add_subplot(gs[2, 3]), df)
    return fig


def animate_trend(m, out_path, fps=12):
    """Reveal the actual revenue line one month at a time and save a GIF."""
    fig, ax = plt.subplots(figsize=(10, 5))
    x = np.arange(len(m))
    y = m["revenue"].to_numpy() / 1e5
    line, = ax.plot([], [], color=PALETTE["navy"], lw=2.5)
    ax.set_xlim(0, len(m) - 1)
    ax.set_ylim(0, y.max() * 1.1)
    ax.set_xticks(x[::3], [d.strftime("%b %y") for d in m.index[::3]])
    ax.set_ylabel("INR lakh")
    ax.set_title("Net revenue, January 2023 to December 2024")

    def update(frame):
        line.set_data(x[:frame + 1], y[:frame + 1])
        return (line,)

    ani = animation.FuncAnimation(fig, update, frames=len(x),
                                  interval=1000 // fps, blit=True, repeat=False)
    ani.save(out_path, writer="pillow", fps=fps)
    plt.close(fig)


def table_page(pdf, df):
    """Regional scorecard as a table on its own page."""
    reg = df.groupby("region").agg(revenue=("revenue", "sum"),
                                   margin=("margin_pct", "mean"),
                                   returns=("is_return", "mean"))
    rows = [[r, f"{v.revenue / 1e5:,.0f}", f"{v.margin:.1f}", f"{100 * v.returns:.1f}"]
            for r, v in reg.iterrows()]
    fig, ax = plt.subplots(figsize=(11, 8.5))
    ax.axis("off")
    ax.set_title("Regional scorecard", fontsize=16, fontweight="bold")
    ax.table(cellText=rows,
             colLabels=["Region", "Revenue (INR lakh)", "Avg margin %", "Return rate %"],
             loc="center")
    pdf.savefig(fig)
    plt.close(fig)


def build_pdf(df, k, out_path):
    """Four-page board pack with metadata."""
    with PdfPages(out_path) as pdf:
        # Page 1: cover (text only, no axes)

Design Mistakes That Lose Points

Each one has cost real analysts credibility with a board

MistakeWhy it misleadsDo this instead
Bar chart with y-axis starting at 80Small differences look hugeStart bars at zero
3D pie or 3D bar chartPerspective distorts the valuesFlat donut or sorted bars
Rainbow colormap for a sequential valueCreates false boundariesviridis or a single-hue map
Forecast drawn in the same style as actualsReaders treat a guess as factDashed line, labelled, with a band
Averaging margin across order rows and calling it the company marginSmall orders get the same weight as large onesCompute margin from summed revenue and cost
Dropping rows with missing channelUnderstates total revenueLabel them "Unknown" and keep them
Title says "Revenue by region"Tells the reader nothing"North leads revenue at 31% of total"
Legend far from the linesEye travels back and forthDirect label at the line end

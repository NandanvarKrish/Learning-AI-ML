The Project: A Library Manager

You'll build a program that tracks books and members, lets members borrow and return books, and reports overdue items.

==== Library Manager ====
1. Add book
2. Register member
3. Borrow book
4. Return book
5. List available books
6. Show overdue books
7. Exit
Choose an option:

Requirements

  1. A Book class with title, author, and an availability flag. Include __repr__ and sorting by title with __lt__.
  2. An EBook subclass that adds a file size and overrides __repr__ to show its format.
  3. A Member class with a name and a list of borrowed books. A member may borrow at most three books.
  4. A Library class that holds the books and members, and provides the main operations. Define __len__ so len(library) gives the number of books.
  5. A decorator log_action that prints each library action before running it. Use @wraps.
  6. A generator overdue_books() that yields books past their due date one at a time.
  7. Comprehensions for listing available books and borrowed titles.

Step-by-Step Build

Create library.py and build it in these steps. Run and test after each one.

Step 1: The Book class

Give each book a title, an author, and an availability flag. Add a due date attribute that's set when it's borrowed.

class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
        self.available = True
        self.due_day = None          # set when borrowed

    def __repr__(self):
        status = "available" if self.available else "borrowed"
        return f"Book({self.title!r} by {self.author}, {status})"

    def __lt__(self, other):
        return self.title.lower() < other.title.lower()

b = Book("Dune", "Frank Herbert")
print(b)
Book('Dune' by Frank Herbert, available)
Note: !r inside an f-string shows the value using its repr, so the title appears in quotes.

Step 2: The EBook subclass

Inherit from Book, call super().__init__(), and add a size. Override __repr__ to include the format.

class EBook(Book):
    def __init__(self, title, author, size_mb):
        super().__init__(title, author)
        self.size_mb = size_mb

    def __repr__(self):
        status = "available" if self.available else "borrowed"
        return f"EBook({self.title!r}, {self.size_mb} MB, {status})"

e = EBook("Python Basics", "A. Author", 5.2)
print(e)
print(isinstance(e, Book))
EBook('Python Basics', 5.2 MB, available) True

Step 3: The Member class

Track a member's name and borrowed books. Enforce the limit of three with a method that returns True or False.

class Member:
    MAX_BOOKS = 3                    # class attribute, shared

    def __init__(self, name):
        self.name = name
        self.borrowed = []

    def can_borrow(self):
        return len(self.borrowed) < Member.MAX_BOOKS

    def __repr__(self):
        return f"Member({self.name!r}, {len(self.borrowed)} borrowed)"

Step 4: The decorator

Write log_action that prints the action name before calling the function, and returns its result. Use @wraps to keep the name intact.

from functools import wraps

def log_action(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[LOG] {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

Step 5: The Library class

Hold the books and members in lists. Decorate the main operations with @log_action. Borrowing sets the availability, due day, and adds the book to the member's list.

class Library:
    LOAN_DAYS = 14

    def __init__(self):
        self.books = []
        self.members = []
        self.today = 0                  # simple day counter for the demo

    def __len__(self):
        return len(self.books)

    @log_action
    def add_book(self, book):
        self.books.append(book)

    @log_action
    def register_member(self, name):
        member = Member(name)
        self.members.append(member)
        return member

    def find_member(self, name):
        for m in self.members:
            if m.name == name:
                return m
        return None

    @log_action
    def borrow(self, member_name, title):
        member = self.find_member(member_name)
        book = next((b for b in self.books if b.title == title and b.available), None)
        if member is None or book is None:
            print("Cannot borrow: check the member and book.")
            return False
        if not member.can_borrow():
            print("Cannot borrow: member has reached the limit.")
            return False
        book.available = False
        book.due_day = self.today + Library.LOAN_DAYS
        member.borrowed.append(book)
        return True

    @log_action
    def return_book(self, member_name, title):
        member = self.find_member(member_name)
        if member is None:
            print("No such member.")
            return False
        for book in member.borrowed:
            if book.title == title:
                book.available = True
                book.due_day = None
                member.borrowed.remove(book)
                return True
        print("That member does not have this book.")
        return False
Watch out: member.borrowed.remove(book) is safe here only because we return immediately after it. Changing a list while looping over it, without returning, is a common source of bugs (Day 5).

Step 6: Comprehensions and the generator

Use comprehensions to list available books and borrowed titles. Write a generator that yields overdue books, which you'll consume one at a time.

    def available_books(self):
        return sorted(b for b in self.books if b.available)

    def borrowed_titles(self):
        return [b.title for m in self.members for b in m.borrowed]

    def overdue_books(self):
        """Yield each book whose due day has passed."""
        for book in self.books:
            if not book.available and book.due_day is not None and book.due_day < self.today:
                yield book
Notice: sorted(...) uses the __lt__ you wrote in Step 1, so the list comes out ordered by title.

Step 7: The menu

Put it together with a menu loop, reading input and calling the library methods. Add a few sample books and members at startup so you can test quickly.

def main():
    lib = Library()
    lib.add_book(Book("Dune", "Frank Herbert"))
    lib.add_book(EBook("Python Basics", "A. Author", 5.2))
    lib.register_member("Sam")

    while True:
        print("\n==== Library Manager ====")
        print("1. Add book")
        print("2. Register member")
        print("3. Borrow book")
        print("4. Return book")
        print("5. List available books")
        print("6. Show overdue books")
        print("7. Exit")
        choice = input("Choose an option: ").strip()

        if choice == "1":
            title = input("Title: ").strip()
            author = input("Author: ").strip()
            lib.add_book(Book(title, author))
        elif choice == "2":
            lib.register_member(input("Member name: ").strip())
        elif choice == "3":
            lib.borrow(input("Member name: ").strip(), input("Title: ").strip())
        elif choice == "4":
            lib.return_book(input("Member name: ").strip(), input("Title: ").strip())
        elif choice == "5":
            for book in lib.available_books():
                print(book)
        elif choice == "6":
            overdue = list(lib.overdue_books())
            print("Overdue:", overdue if overdue else "none")
        elif choice == "7":
            print("Goodbye!")
            break
        else:
            print("Invalid choice, please enter 1 to 7.")

if __name__ == "__main__":
    main()

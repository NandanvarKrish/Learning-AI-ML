Conditionals: Making Decisions

Estimated time: about 1.5 hours · if, elif, else, comparisons, logical operators, nested conditions

Lesson 1: Why Conditionals?

So far, every program ran the same lines in the same order. Real programs need to choose. A login page must check the password. A shop must decide whether a discount applies. A conditional lets the program take one path or another depending on a condition.

Analogy: A traffic light is a conditional. If the light is green, you go. Otherwise, you stop. Python checks a condition the same way. 
temperature = 35

if temperature > 30:
    print("It's hot, drink water")

print("Program continues here either way")
It's hot, drink water Program continues here either way

The if line ends with a colon. The indented lines below it belong to that block and only run when the condition is True. The final print is not indented, so it always runs.

Lesson 3: if, elif, and else

Use if for the first check, elif (short for "else if") for further checks, and else for anything left over. Python checks them top to bottom and runs only the first block that matches.

marks = int(input("Enter your marks: "))

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 50:
    print("Grade C")
else:
    print("Grade F, try harder")

If you enter 82, the program checks 82 >= 90 (False), then 82 >= 75 (True), prints Grade B, and skips the rest.

Order matters: If you wrote marks >= 50 first, every passing score would get Grade C, even 95. Put the strictest condition first.

Only if, no else

The else part is optional. If nothing matches and there's no else, nothing happens.

balance = 500
withdraw = 800

if withdraw > balance:
    print("Insufficient funds")
Insufficient funds

Lesson 5: Truthy and Falsy Values

Python doesn't need an explicit == True in conditions. Some values count as False automatically:

  • 0, 0.0
  • "" (empty string)
  • [] (empty list), {} (empty dictionary)
  • None

Everything else is considered True.

name = ""
if name:
    print(f"Hello {name}")
else:
    print("No name entered")
No name entered
Tip: if name: is shorter and common in real code. It's the same as checking name != "" when the value is a string.

Lesson 6: Nested Conditions

You can place an if inside another if. Indent each level by four spaces. Use nesting only when a second check depends on the first. Too many levels become hard to read.

age = 25
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Welcome in")
    else:
        print("Buy a ticket first")
else:
    print("Sorry, adults only")
Welcome in
Readability tip: If you find yourself three levels deep, combine conditions with and or use early exits, which you'll see later.

Lesson 7: Conditional Expressions (One-Line if)

For a simple choice between two values, Python offers a one-line form: value_if_true if condition else value_if_false.

age = 16
status = "adult" if age >= 18 else "minor"
print(status)
minor

Use this only for short, simple choices. For anything longer, the regular if block is clearer.

Common Mistakes on Day 3

  1. Using = instead of ==: the first is assignment, the second is comparison.
  2. Missing the colon: if x > 5 without a colon is a SyntaxError.
  3. Wrong indentation: the lines under if must be indented consistently. Mixing tabs and spaces causes errors.
  4. Forgetting int() on input: "82" >= 90 raises a TypeError in Python 3.
  5. Wrong order of elif checks: put the most specific or strictest condition first.
  6. Mixing up and / or: age > 18 and age < 65 is different from age > 18 or age < 65. Test both edges of your logic.

Practicals

Try each one before looking at any hints.

Practical 1: Even or Odd

Ask for a number. Print "Even" if it divides by 2 with no remainder, otherwise "Odd". Use % from Day 1.

Practical 2: Grade Calculator

Ask for a marks value from 0 to 100. Print A (90 and above), B (75 to 89), C (50 to 74), or F (below 50). Test with 90, 89, 50, and 49, and check each boundary.

Practical 3: Largest of Three

Ask for three numbers. Print which is largest. Handle the case where two or more are equal.

Practical 4: Leap Year Checker

A year is a leap year if it is divisible by 4, except years divisible by 100, unless they are also divisible by 400. Test with 2000 (leap), 1900 (not leap), and 2024 (leap).

Practical 5: Shop Discount

Ask for a bill amount. If it's 5000 or more, apply a 20% discount. If it's between 2000 and 4999, apply 10%. Otherwise no discount. Print the final amount with 2 decimal places.

Practical 6: Login Check

Store a correct username and password in variables. Ask the user for both. Print "Access granted" only if both match. Print a helpful message if just the username is wrong.

Hint: nest one if inside another, or use and.

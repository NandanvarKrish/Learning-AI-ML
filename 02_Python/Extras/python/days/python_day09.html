Functions in Depth

Estimated time: about 1.5 hours · *args, **kwargs, unpacking, global and nonlocal, closures

Lesson 1: Flexible Arguments with *args

Sometimes you don't know how many values a caller will pass. A parameter named *args collects any extra positional arguments into a tuple.

def total(*numbers):
    print(type(numbers))     # tuple
    return sum(numbers)

print(total(1, 2))
print(total(5, 10, 15, 20))
print(total())
<class 'tuple'> 3 50 0
Analogy: *args is like a bag at the checkout. Whatever the customer hands over goes into the bag, and the cashier counts everything inside.

The name args is a convention. The important part is the single star *.

Rule: Regular parameters come first, then *args. For example, def f(name, *scores) is valid, while def f(*scores, name) needs a keyword argument to call correctly.

Lesson 2: Flexible Keyword Arguments with **kwargs

**kwargs collects extra keyword arguments into a dictionary. Keys are the argument names, and values are what was passed.

def make_profile(**details):
    for key, value in details.items():
        print(f"{key}: {value}")

make_profile(name="Sam", age=25, city="Surat")
name: Sam age: 25 city: Surat

Both can be combined. The conventional order is regular parameters, then *args, then **kwargs.

def report(title, *values, **options):
    print("Title:", title)
    print("Values:", values)
    print("Options:", options)

report("Sales", 10, 20, unit="Rs", round_to=2)
Title: Sales Values: (10, 20) Options: {'unit': 'Rs', 'round_to': 2}

Lesson 3: Unpacking Arguments with * and **

The same star symbols work in the other direction, when calling a function. * spreads a list or tuple into separate positional arguments, and ** spreads a dictionary into keyword arguments.

def add3(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add3(*nums))            # same as add3(1, 2, 3)

settings = {"a": 10, "b": 20, "c": 30}
print(add3(**settings))       # same as add3(a=10, b=20, c=30)
6 60
Memory aid: In a definition, * and ** collect values into a tuple or dictionary. In a call, they spread them out.

Lesson 4: Keyword-Only and Positional-Only Parameters

You can force certain arguments to be passed a particular way. A bare * in the definition means every parameter after it must be passed by keyword.

def send(message, *, urgent=False):
    prefix = "URGENT: " if urgent else ""
    print(prefix + message)

send("Server down", urgent=True)
# send("Server down", True)    # TypeError: takes 1 positional argument
URGENT: Server down

This makes calls clearer. send("Hi", True) is unclear, but send("Hi", urgent=True) explains itself.

Lesson 5: Return Patterns

Good functions return something predictable. These are the patterns you'll see most often.

Returning early (guard clauses)

def discount_for(age):
    if age < 0:
        return None          # invalid input, stop early
    if age >= 60:
        return 0.2
    return 0.0

print(discount_for(65))      # 0.2
print(discount_for(-1))      # None
0.2 None

Guard clauses keep the main logic un-indented and easy to read.

Returning a dictionary for named results

def summary(scores):
    return {
        "count": len(scores),
        "average": sum(scores) / len(scores),
        "best": max(scores),
    }

result = summary([70, 85, 90])
print(result["average"])     # 81.666...
print(result["best"])        # 90
81.66666666666667 90
When to use which: Return one value for a simple result. Return a tuple for a small fixed set of values. Return a dictionary when the caller benefits from named fields.

Lesson 6: Scope in Depth: global and nonlocal

Day 8 showed that assigning to a name inside a function creates a local variable. Two keywords change that behaviour.

global: change a module-level variable

counter = 0

def increment():
    global counter
    counter += 1

increment()
increment()
print(counter)     # 2
2
Use sparingly: Global changes make code harder to test and follow. Prefer passing values in and returning results out, as you practised on Day 8.

nonlocal: change a variable from an enclosing function

def make_counter():
    count = 0
    def step():
        nonlocal count
        count += 1
        return count
    return step

next_number = make_counter()
print(next_number())   # 1
print(next_number())   # 2
print(next_number())   # 3
1 2 3

This is a closure: the inner function remembers count between calls, even though make_counter has finished. Closures power decorators, which you'll meet on Day 20.

Lesson 7: Lambda Functions (Short Preview)

A lambda is a small, unnamed function written in one line. It's useful as a quick key or callback. Full coverage comes on Day 10.

square = lambda x: x * x
print(square(7))             # 49

pairs = [(1, "one"), (3, "three"), (2, "two")]
pairs.sort(key=lambda p: p[0])
print(pairs)
49 [(1, 'one'), (2, 'two'), (3, 'three')]

Common Mistakes on Day 9

  1. Wrong parameter order: *args must come before **kwargs, and regular parameters before both.
  2. Treating args as a list: *args is a tuple, so you can't assign to its items.
  3. Forgetting the star when unpacking: add3(nums) passes one list; add3(*nums) passes three values.
  4. Using global without need: pass arguments and return results instead.
  5. Forgetting nonlocal: count += 1 inside an inner function raises UnboundLocalError unless you declare nonlocal.
  6. Overusing lambda: if a lambda is hard to read, use a normal def with a name.

Practicals

Try each one before looking at any hints.

Practical 1: Flexible Average

Write average(*numbers) that returns the average of any number of arguments. Return 0 if none are given.

Practical 2: Receipt Builder

Write receipt(customer, **items) where each keyword is an item name and its price. Print each item with its price, then the total. Test with receipt("Sam", pen=10, book=150).

Practical 3: Unpacking Practice

Store a list of three numbers. Pass it to a function volume(l, w, h) using the star operator to compute l x w x h. Then store a dictionary with keys l, w, h and call it with **.

Practical 4: Ticket Pricing

Write ticket_price(age, *, student=False) that returns 100 normally, 50 for students, and 0 for children under 5. Use guard clauses. Confirm that calling it with True as a second positional argument raises an error.

Practical 5: Visit Counter

Write make_visit_counter() that returns a function. Each call to that function adds 1 and returns the new total, using nonlocal. Call it three times and print each result.

Practical 6: Sort by Second Item

Given a list of tuples like [("Sam", 82), ("Ali", 95), ("Sara", 70)], sort it by the score using a lambda, then print the names in order from highest to lowest.

The Project: A Command-Line Contact Book

You'll build a program that stores names, phone numbers, and email addresses in a CSV file, so the contacts survive between runs.

==== Contact Book ====
1. Add contact
2. List contacts
3. Search contacts
4. Delete contact
5. Exit
Choose an option:

Requirements

  1. Add a contact with a name, phone number, and email. Clean the name, and reject a phone number that isn't digits.
  2. List all contacts sorted alphabetically by name, numbered.
  3. Search contacts by part of the name, ignoring case.
  4. Delete a contact by its number from the list.
  5. Load contacts from contacts.csv at startup, and save them when the user exits. Handle a missing file on the first run.
  6. Put the file-handling code in its own module called storage.py.
Suggested file layout: 
contact_book/
    storage.py       # load and save CSV
    contact_book.py  # menu and features

Step-by-Step Build

Create the folder, then work through each step. Run the program after each one and check the output.

Step 1: The storage module

Create storage.py. It loads and saves contacts as dictionaries with keys name, phone, and email. A missing file returns an empty list. Use try and except FileNotFoundError from Days 11 and 12.

# storage.py
import csv

FILENAME = "contacts.csv"
FIELDS = ["name", "phone", "email"]

def load_contacts(filename=FILENAME):
    """Return a list of contact dictionaries read from a CSV file."""
    try:
        with open(filename, newline="") as f:
            return list(csv.DictReader(f))
    except FileNotFoundError:
        return []

def save_contacts(contacts, filename=FILENAME):
    """Write all contacts to a CSV file, replacing the old contents."""
    with open(filename, "w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=FIELDS)
        writer.writeheader()
        writer.writerows(contacts)

if __name__ == "__main__":
    # quick self-test, runs only when this file is run directly
    test = [{"name": "Test", "phone": "123", "email": "t@example.com"}]
    save_contacts(test, "test_contacts.csv")
    print(load_contacts("test_contacts.csv"))
[{'name': 'Test', 'phone': '123', 'email': 't@example.com'}]
Why the __name__ check: Without it, the self-test would run every time another file imports storage.

Step 2: Validating input

Add a function that asks for a phone number until it contains only digits. Use isdigit() from Day 2 and a loop from Day 4.

def ask_phone():
    """Keep asking until the user enters only digits."""
    while True:
        phone = input("Phone (digits only): ").strip()
        if phone.isdigit():
            return phone
        print("Please enter digits only.")

Step 3: Adding a contact

Write add_contact(contacts). It gathers the fields, cleans the name with strip() and title(), and appends a dictionary to the list. Note that the function changes the list it receives, so the caller sees the change.

def add_contact(contacts):
    name = input("Name: ").strip().title()
    if name == "":
        print("Name cannot be empty.")
        return
    phone = ask_phone()
    email = input("Email (optional): ").strip().lower()
    contacts.append({"name": name, "phone": phone, "email": email})
    print(f"Added {name}.")

Step 4: Listing sorted contacts

Use sorted() with a lambda key (Day 10) to sort by name without changing the original list. Format the columns with f-string alignment (Day 2).

def list_contacts(contacts):
    if not contacts:
        print("No contacts yet.")
        return
    print(f"{'No.':<5}{'Name':<20}{'Phone':<15}{'Email'}")
    print("-" * 60)
    for i, c in enumerate(sorted(contacts, key=lambda c: c["name"].lower()), start=1):
        print(f"{i:<5}{c['name']:<20}{c['phone']:<15}{c['email']}")

Step 5: Searching

Search by part of the name, ignoring case. This is the in check from Day 2 combined with lower().

def search_contacts(contacts):
    term = input("Search name: ").strip().lower()
    matches = [c for c in contacts if term in c["name"].lower()]
    if not matches:
        print("No matching contacts.")
    for c in matches:
        print(f"{c['name']}  {c['phone']}  {c['email']}")

Step 6: Deleting by number

The user sees a sorted, numbered list, so the delete function must use the same sorted order. Check the number is valid with try and except ValueError, then check the range. Remove the item with pop() from Day 5.

def delete_contact(contacts):
    list_contacts(contacts)
    if not contacts:
        return
    try:
        number = int(input("Number to delete: "))
    except ValueError:
        print("Please enter a number.")
        return
    ordered = sorted(contacts, key=lambda c: c["name"].lower())
    if not 1 <= number <= len(ordered):
        print("That number is not in the list.")
        return
    target = ordered[number - 1]
    contacts.remove(target)
    print(f"Deleted {target['name']}.")
Important: The number refers to the sorted view, not the stored order. Mapping the number to the item through ordered prevents deleting the wrong contact.

Step 7: The menu and startup

Load contacts at the start, run the menu loop, and save when the user exits. Import the storage functions with from storage import ....

from storage import load_contacts, save_contacts

def main():
    contacts = load_contacts()
    print(f"Loaded {len(contacts)} contacts.")
    while True:
        print("\n==== Contact Book ====")
        print("1. Add contact")
        print("2. List contacts")
        print("3. Search contacts")
        print("4. Delete contact")
        print("5. Exit")
        choice = input("Choose an option: ").strip()
        if choice == "1":
            add_contact(contacts)
        elif choice == "2":
            list_contacts(contacts)
        elif choice == "3":
            search_contacts(contacts)
        elif choice == "4":
            delete_contact(contacts)
        elif choice == "5":
            save_contacts(contacts)
            print("Contacts saved. Goodbye!")
            break
        else:
            print("Invalid choice, please enter 1 to 5.")

if __name__ == "__main__":
    main()
Design point: The if __name__ == "__main__" guard lets you import contact_book.py later without the menu starting.

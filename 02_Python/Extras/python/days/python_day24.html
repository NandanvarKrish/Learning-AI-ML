Regular Expressions

Estimated time: about 1.5 hours · The re module, patterns, search, findall, groups, substitution, common patterns for real data

Lesson 1: What Is a Regular Expression?

A regular expression (regex) is a compact pattern that describes text. Instead of writing code to check every character, you describe the shape you want, and the regex engine finds matches for you.

Analogy: A regex is like a search with wildcards. Typing *.pdf in a file search means "any name ending in .pdf". Regex is the same idea, with far more power.

Typical uses: checking that an email or phone number looks valid, pulling dates or prices out of messy text, and replacing patterns across a document.

Lesson 2: The re Module and Raw Strings

Python's regex tools live in the re module. Write patterns as raw strings, prefixed with r, so backslashes are passed to the regex engine unchanged.

import re

pattern = r"\d+"              # \d means "a digit"
print(re.findall(pattern, "Room 12, floor 3"))
['12', '3']
Always use raw strings: Without the r, "\d" is treated as an escape code by Python first, which causes warnings and wrong patterns. Get into the habit of writing r"..." for every pattern.

Lesson 4: Searching with search, match, and findall

FunctionWhat it does
re.search(p, s)Finds the first match anywhere in the string
re.match(p, s)Matches only at the start of the string
re.findall(p, s)Returns a list of all matched strings
re.fullmatch(p, s)The entire string must match
import re

text = "Order 88 shipped on 2026-10-20"

m = re.search(r"\d{4}-\d{2}-\d{2}", text)
if m:
    print("Found date:", m.group())      # group() returns the matched text

print(re.match(r"\d+", text))            # None: text doesn't start with a digit
print(re.fullmatch(r"\d+", "12345"))     # matches the whole string
Found date: 2026-10-20 None <re.Match object; span=(0, 5), match='12345'>
Tip: search() returns a match object or None. Always check for None before calling .group(), which avoids an AttributeError.

Lesson 5: Groups

Parentheses create groups. Each group captures part of the match, so you can pull out pieces separately.

import re

text = "Price: Rs 450, Tax: Rs 81"
m = re.search(r"Price: Rs (\d+)", text)
print(m.group(0))     # whole match
print(m.group(1))     # first group: the number only

pairs = re.findall(r"(\w+): Rs (\d+)", text)
print(pairs)
Price: Rs 450 450 [('Price', '450'), ('Tax', '81')]

When findall has groups, it returns a list of tuples, one tuple per match.

Named groups

m = re.search(r"(?P<day>\d{2})/(?P<month>\d{2})/(?P<year>\d{4})", "Born 15/08/1990")
print(m.group("day"), m.group("month"), m.group("year"))
15 08 1990
Readability: Named groups make code self-explaining. m.group("year") is clearer than m.group(3).

Lesson 6: Replacing Text with sub

re.sub(pattern, replacement, text) replaces every match. Use backreferences like \1 to reuse captured groups.

import re

phone = "98-7654-3210"
print(re.sub(r"\D", "", phone))                  # remove non-digits

date = "15/08/1990"
print(re.sub(r"(\d{2})/(\d{2})/(\d{4})", r"\3-\2-\1", date))
9876543210 1990-08-15
Remember: Use the replacement string as a raw string, r"\3-\2-\1", so the backslashes reach the engine correctly.

Lesson 7: Compiling and Flags

If you use the same pattern many times, compile it once. Flags change how a pattern behaves, for example ignoring case.

import re

word_re = re.compile(r"python", re.IGNORECASE)
print(word_re.findall("Python, PYTHON and python"))

multi = re.compile(r"^\w+", re.MULTILINE)
print(multi.findall("first line\nsecond line"))
['Python', 'PYTHON', 'python'] ['first', 'second']

Other useful flags include re.VERBOSE, which lets you spread a complex pattern across lines with comments.

Lesson 8: Common Patterns for Real Data

These patterns are good starting points. Real-world rules are often stricter, so test them with your own data.

PurposePattern
Simple emailr"[\w.+-]+@[\w-]+\.[\w.]+"
10-digit Indian mobile number starting with 6 to 9r"[6-9]\d{9}"
Date DD/MM/YYYYr"\d{2}/\d{2}/\d{4}"
Time HH:MM (24-hour)r"([01]\d|2[0-3]):[0-5]\d"
Amount with optional decimalsr"\d+(?:\.\d{1,2})?"
import re

mobile = re.compile(r"[6-9]\d{9}")
for value in ["9876543210", "1234567890", "98765"]:
    print(value, "valid" if mobile.fullmatch(value) else "invalid")
9876543210 valid 1234567890 invalid 98765 invalid
Note: (?:...) is a non-capturing group. It groups for repetition without saving the match, which keeps group numbers tidy.

Common Mistakes on Day 24

  1. Forgetting the r prefix: backslashes are processed by Python before the regex sees them.
  2. Calling .group() on None: check the result of search() or match() first.
  3. Confusing match and search: match only checks the start of the string, while search looks anywhere.
  4. Greedy surprises: .* grabs as much as it can. Use .*? to match as little as possible.
  5. Over-complicated patterns: for simple checks, string methods like in or startswith are clearer.

Tuples, Sets, and Dictionaries

Estimated time: about 1.5 hours · Choosing the right collection and working with key-value data

Lesson 1: Choosing a Collection

You've used lists. Python has three other built-in collections, and each one fits a different job:

CollectionSyntaxOrdered?Changeable?Duplicates?Best for
List[1, 2]YesYesAllowedAn ordered sequence of items
Tuple(1, 2)YesNoAllowedFixed records, like coordinates
Set{1, 2}NoYesNot allowedUnique items, fast membership tests
Dictionary{"a": 1}Yes (3.7+)YesKeys uniqueLooking up values by name
Analogy: A list is a queue of people in order. A tuple is a printed ID card: fixed details you don't edit. A set is a guest list where each name appears once. A dictionary is a phone book: you look up a name and get a number.

Lesson 2: Tuples

A tuple looks like a list but uses round brackets, and it cannot be changed after creation. Use tuples for data that should stay fixed.

point = (10, 20)
rgb = (255, 128, 0)
print(point[0])        # 10
print(len(rgb))        # 3

point[0] = 5           # TypeError: 'tuple' object does not support item assignment
10 3

Single-item tuples need a comma

not_a_tuple = (5)      # this is just the number 5
a_tuple = (5,)         # the comma makes it a tuple
print(type(not_a_tuple))  # int
print(type(a_tuple))      # tuple
<class 'int'> <class 'tuple'>

Unpacking

Unpacking assigns each item of a tuple to its own variable in one line. You'll use this often with loops and function return values.

x, y = (10, 20)
print(x, y)            # 10 20

name, age, city = ("Sam", 25, "Surat")
print(f"{name} is {age} from {city}")

a, b = b, a            # swap two variables in one line
10 20 Sam is 25 from Surat
Why tuples? They are slightly faster than lists, and they signal to anyone reading your code that the data is meant to stay the same. Dictionary keys must be immutable, so tuples can be keys where lists cannot.

Lesson 3: Sets

A set holds unique values with no guaranteed order. Adding the same value twice has no effect.

colours = {"red", "green", "red", "blue"}
print(colours)                 # duplicates removed (order may vary)
print(len(colours))            # 3
print("green" in colours)      # True: very fast check

colours.add("yellow")
colours.discard("red")         # removes if present, no error if missing
print(colours)
{'red', 'green', 'blue'} 3 True {'green', 'blue', 'yellow'}
Careful: {} creates an empty dictionary, not a set. For an empty set, write set().

Set operations

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)    # union: everything in either  -> {1, 2, 3, 4, 5, 6}
print(a & b)    # intersection: in both       -> {3, 4}
print(a - b)    # difference: in a, not in b  -> {1, 2}
{1, 2, 3, 4, 5, 6} {3, 4} {1, 2}

Removing duplicates from a list

votes = ["Ali", "Sara", "Ali", "Ravi", "Sara"]
unique = set(votes)
print(len(unique))             # 3 unique voters
3

Note that the order is not kept. If order matters, you need a different approach, which you practised on Day 5.

Lesson 4: Dictionaries

A dictionary stores key-value pairs. You look up a value by its key, not by its position. Keys must be unique and immutable (strings, numbers, and tuples work; lists do not).

student = {
    "name": "Sam",
    "age": 25,
    "city": "Surat",
    "courses": ["Python", "Networking"],
}

print(student["name"])        # Sam
print(student["courses"][0])  # Python
print(len(student))           # 4 key-value pairs
Sam Python 4

Adding, changing, and removing

student["age"] = 26           # change an existing value
student["email"] = "sam@example.com"   # add a new key
del student["city"]           # remove a key
print(student)
{'name': 'Sam', 'age': 26, 'courses': ['Python', 'Networking'], 'email': 'sam@example.com'}

Safe lookups with get()

Using [] on a missing key raises KeyError. The get() method returns None, or a default you provide, instead.

print(student.get("phone"))            # None, no error
print(student.get("phone", "Not given"))  # Not given
# print(student["phone"])              # KeyError: 'phone'
None Not given

Checking keys and looping

prices = {"pen": 10, "book": 150, "bag": 900}

if "book" in prices:           # checks keys, not values
    print("Book price:", prices["book"])

for item in prices:            # loops over keys
    print(item)

for item, price in prices.items():   # keys and values together
    print(f"{item:<6} Rs {price}")
Book price: 150 pen book bag pen Rs 10 book Rs 150 bag Rs 900
Tip: .keys(), .values(), and .items() give you views of the dictionary. .items() is the one you'll use most in loops.

Counting with a dictionary

text = "banana"
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
{'b': 1, 'a': 3, 'n': 2}

This counting pattern appears in almost every data task, and it's a good one to memorise.

Nested dictionaries

school = {
    "Ali": {"maths": 90, "science": 85},
    "Sara": {"maths": 78, "science": 92},
}
print(school["Sara"]["science"])   # 92
92

Common Mistakes on Day 6

  1. Using {} for an empty set: it creates an empty dictionary. Use set().
  2. Forgetting the comma in a single-item tuple: (5) is just 5.
  3. KeyError from missing keys: use get() when a key might not exist.
  4. Trying to use a list as a dictionary key: lists are mutable, so they cannot be keys. Use a tuple.
  5. Assuming set order: sets have no reliable order, so don't rely on it.
  6. Looping over a dictionary without .items(): you get keys only, not values.

Practicals

Try each one before looking at any hints.

Practical 1: Contact Card

Create a dictionary with keys for name, phone, and email. Print each value with a label, then change the phone number and print the updated card.

Practical 2: Word Frequency

Ask for a sentence. Count how many times each word appears, ignoring case. Print each word with its count.

Hint: use .lower() and split() from Day 2, then the counting pattern from this lesson.

Practical 3: Unique Visitors

Given the list ["ip1", "ip2", "ip1", "ip3", "ip2"], print how many unique visitors there are, and check whether "ip4" has visited.

Practical 4: Common Friends

Store two sets of friends for Sam and Ali. Print the friends they share, the friends only Sam has, and every friend the two have between them.

Practical 5: Shop Inventory

Create a dictionary of products and stock counts. Ask the user for a product name, then print its stock, or "Not found" using get(). Then loop over all products and print any with stock below 5.

Practical 6: Grade Book

Build a nested dictionary of three students and their marks in three subjects. Print each student's average mark.

Decorators

Estimated time: about 1.5 hours · Functions as objects, wrapping functions, @syntax, functools.wraps, decorators with arguments

Lesson 1: Functions Are Objects

In Python, a function is a value like any other. You can store it in a variable, pass it to another function, and return it from a function. This idea is the foundation of decorators.

def shout(text):
    return text.upper() + "!"

say = shout              # store the function in a variable (no parentheses)
print(say("hello"))      # HELLO!

def apply(func, value):  # pass a function as an argument
    return func(value)

print(apply(shout, "hi"))
HELLO! HI!
Analogy: A function is like a tool in a shop. You can keep it on a shelf, hand it to a colleague, or return it to the shelf. Passing shout around is like handing over the tool, not using it.

Lesson 2: Functions Defined Inside Functions

You can define a function inside another function. The inner function can see the outer function's variables, which you met as closures on Day 9.

def make_greeter(greeting):
    def greet(name):
        return f"{greeting}, {name}!"
    return greet          # return the inner function itself

hello = make_greeter("Hello")
namaste = make_greeter("Namaste")
print(hello("Sam"))
print(namaste("Ali"))
Hello, Sam! Namaste, Ali!

Each returned function remembers the greeting it was created with.

Lesson 3: Writing a Decorator by Hand

A decorator is a function that takes a function, wraps it with extra behaviour, and returns the wrapper. The original function is not changed, but calls to it now go through the wrapper.

def log_call(func):
    def wrapper():
        print("Calling", func.__name__)
        result = func()
        print("Finished", func.__name__)
        return result
    return wrapper

def say_hi():
    print("Hi there!")

say_hi = log_call(say_hi)   # wrap it manually
say_hi()
Calling say_hi Hi there! Finished say_hi

The line say_hi = log_call(say_hi) is what decorators automate.

Lesson 4: The @ Syntax

Writing @log_call above a function definition does the same thing as say_hi = log_call(say_hi). The @ line must come directly before the def.

@log_call
def say_bye():
    print("Goodbye!")

say_bye()
Calling say_bye Goodbye! Finished say_bye
Key idea: @decorator is shorthand. It means "replace this function with decorator(this function)".

Lesson 5: Decorators with Arguments

A wrapper should accept any arguments the original function receives. Use *args and **kwargs from Day 9 so the wrapper works with any signature.

def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__} with {args} {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    return a + b

print(add(2, 3))
print(add(a=10, b=5))
Calling add with (2, 3) {} 5 Calling add with () {'a': 10, 'b': 5} 15
Important: Always return the result of func(...) from the wrapper. Forgetting return makes the decorated function return None.

Lesson 6: Preserving Function Names with functools.wraps

Without help, the wrapper replaces the original function's name and docstring. Use functools.wraps to copy them across.

from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("Calling", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log_call
def multiply(a, b):
    """Multiply two numbers."""
    return a * b

print(multiply.__name__)
print(multiply.__doc__)
multiply Multiply two numbers.
Always use @wraps: It keeps debugging output, documentation, and help() accurate. Without it, multiply.__name__ would read "wrapper".

Lesson 7: A Practical Decorator: Timing

This decorator measures how long a function takes. It uses time.perf_counter(), a precise clock.

import time
from functools import wraps

def timed(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} took {elapsed:.4f} seconds")
        return result
    return wrapper

@timed
def slow_sum(n):
    return sum(range(n))

print(slow_sum(1_000_000))
slow_sum took 0.0231 seconds 499999500000

The exact time will differ on your computer, but the pattern is the same.

Lesson 8: Decorators That Take Arguments

Sometimes a decorator needs its own settings, such as "repeat this function 3 times". Add one more layer: an outer function that receives the settings and returns the decorator.

from functools import wraps

def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            result = None
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def hello():
    print("Hello!")

hello()
Hello! Hello! Hello!
Three layers: repeat(3) receives the settings, decorator receives the function, and wrapper runs each call. Work through them from the outside in.

Lesson 9: Stacking Decorators

You can apply several decorators. They run from the closest to the function outwards.

@log_call
@timed
def compute():
    return 42

compute()

Here timed wraps compute first, and log_call wraps the result. The order can change behaviour, so keep track of it when stacking.

Common Mistakes on Day 20

  1. Forgetting return in the wrapper: the decorated function silently returns None.
  2. Calling the function in the decorator line: write @log_call, not @log_call(), for a simple decorator.
  3. Skipping @wraps: names and docstrings get lost, which confuses debugging and help().
  4. Hardcoding arguments in the wrapper: use *args, **kwargs so the wrapper fits any function.
  5. Forgetting the third layer: a decorator with arguments needs an extra outer function.

Practicals

Try each one before looking at any hints.

Practical 1: Greeting Wrapper

Write a decorator announce that prints "Starting..." before and "Done." after the wrapped function. Apply it to a function that prints a greeting.

Practical 2: Preserve Metadata

Apply your announce decorator with @wraps. Print the decorated function's name and docstring to check they are preserved.

Practical 3: Argument Logger

Write a decorator that prints the arguments each time a function is called, then runs it. Test it on a function with two positional and one keyword argument.

Practical 4: Simple Login Check

Create a decorator require_login that checks a global variable logged_in. If False, it prints "Please log in first" and does not run the function. Test with both values.

Practical 5: Retry Decorator

Write retry(times), a decorator with an argument, that calls the function again if it raises an exception, up to the given number of times. Test it on a function that fails randomly.

Practical 6: Cache Results

Write a decorator that caches results in a dictionary keyed by the arguments, so repeated calls with the same input return the stored result. Test it on a slow function, such as one computing a large sum, and time the difference.

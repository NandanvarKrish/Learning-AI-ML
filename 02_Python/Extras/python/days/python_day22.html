Lesson 1: Why Dates Need Care

Dates look simple, but they hide complexity: months have different lengths, leap years add a day, and time zones shift clocks. Python's datetime module handles these details so you don't have to.

Analogy: Storing a date as plain text is like writing a recipe in pencil on a napkin. Using datetime is like using a calendar app that knows which months have 30 days and when February has 29.
import datetime

today = datetime.date.today()
print(today)
print(today.year, today.month, today.day)
2026-10-20 2026 10 20

Your output shows the date on your own computer when you run it.

Lesson 3: Date Arithmetic with timedelta

A timedelta represents a duration. Subtracting two dates gives a timedelta, and adding a timedelta to a date moves it forward or back.

from datetime import date, timedelta

borrowed = date(2026, 10, 1)
due = borrowed + timedelta(days=14)
print("Due:", due)

days_late = (date(2026, 10, 20) - due).days
print("Days late:", days_late)
Due: 2026-10-15 Days late: 5
Careful: (later - earlier) gives a timedelta, which can be negative if the order is reversed. Use .days to get the whole number of days.

Lesson 4: Formatting with strftime

strftime turns a date into text using format codes. strptime does the reverse, turning text into a date.

CodeMeaningExample
%YFour-digit year2026
%mMonth, two digits01
%dDay, two digits26
%BFull month nameJanuary

%H:%MHour and minute, 24-hour14:30
from datetime import datetime

moment = datetime(2026, 1, 26, 14, 30)
print(moment.strftime("%d/%m/%Y"))        # 26/01/2026
print(moment.strftime("%A, %B %d, %Y"))   # Monday, January 26, 2026

parsed = datetime.strptime("15-08-2026", "%d-%m-%Y")
print(parsed.date())                      # 2026-08-15
26/01/2026 Monday, January 26, 2026 2026-08-15
Tip: Always pass the exact format to strptime. If the text doesn't match, Python raises ValueError, which you can catch with the Day 12 pattern.

Lesson 5: Dates in Comparisons and Sorting

Date objects compare and sort correctly, just like numbers. This makes them useful with the __lt__ and sorted() ideas from Day 17.

from datetime import date

dates = [date(2026, 5, 1), date(2025, 12, 25), date(2026, 2, 14)]
print(sorted(dates))
print(date(2026, 1, 1) < date(2026, 6, 1))
[datetime.date(2025, 12, 25), datetime.date(2026, 2, 14), datetime.date(2026, 5, 1)] True

Don't sort dates stored as text such as "15-08-2026", because the text sorts by the first characters, not by the actual date. Convert to date objects first.

Lesson 6: What Is JSON?

JSON (JavaScript Object Notation) is a text format for structured data. It's the most common format for sending data between programs on the web. It looks very much like a Python dictionary and list.

{
    "name": "Sam",
    "age": 25,
    "courses": ["Python", "Networking"],
    "active": true,
    "manager": null
}
JSONPython
object {}dict
array []list
stringstr
numberint or float
true, falseTrue, False
nullNone
Watch the difference: JSON uses lowercase true, false, and null. Python uses True, False, and None. The json module converts between them for you.

Lesson 7: Reading and Writing JSON

The json module has two pairs of functions. The ones ending in s work with text strings, and the others work with files.

FunctionDirection
json.dumps(obj)Python object to JSON string
json.loads(text)JSON string to Python object
json.dump(obj, f)Python object to JSON file
json.load(f)JSON file to Python object
import json

person = {"name": "Sam", "age": 25, "active": True}

text = json.dumps(person, indent=2)
print(text)

back = json.loads(text)
print(back["name"])
{ "name": "Sam", "age": 25, "active": true } Sam

Writing to and reading from a file uses the same idea with dump and load:

import json

contacts = [{"name": "Ali", "phone": "9876543210"}]

with open("contacts.json", "w") as f:
    json.dump(contacts, f, indent=2)

with open("contacts.json") as f:
    loaded = json.load(f)

print(loaded[0]["name"])
Ali
Compared with CSV (Day 11): JSON keeps nested structures, such as a list inside a dictionary. CSV is flat, with one row per record. Use JSON when your data has nesting.

Lesson 8: Handling Bad JSON and Dates

Input from users or other programs is not always valid. Catch the errors, as you learned on Day 12.

import json
from datetime import datetime

try:
    data = json.loads("{name: 'Sam'}")    # invalid: keys need double quotes
except json.JSONDecodeError as e:
    print("Bad JSON:", e)

try:
    day = datetime.strptime("2026-13-01", "%Y-%m-%d")
except ValueError:
    print("Bad date: month 13 does not exist")
Bad JSON: Expecting property name enclosed in double quotes: line 1 column 2 (char 1) Bad date: month 13 does not exist

json.JSONDecodeError is a subclass of ValueError, which is why the earlier ideas on inheritance from Day 16 apply here.

Common Mistakes on Day 22

  1. Confusing the datetime module and class: datetime.datetime and datetime imported by name refer to different things.
  2. Wrong strptime format: the format must match the text exactly, including separators.
  3. Sorting date text: convert to date objects before sorting.
  4. Writing Python values as JSON by hand: use json.dumps so True becomes true automatically.
  5. Forgetting that JSON keys are strings: a dictionary with integer keys comes back with string keys after a round trip.
  6. Dates are not JSON-serializable by default: convert with .isoformat() before dumping.

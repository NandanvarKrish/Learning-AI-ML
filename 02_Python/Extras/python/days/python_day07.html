The Project: A Command-Line Expense Tracker

You'll build a program that records expenses, shows them, and reports totals by category. The user sees a menu like this:

==== Expense Tracker ====
1. Add expense
2. View all expenses
3. Show totals by category
4. Exit
Choose an option:

Requirements

  1. Add an expense with a name, amount, and category. Reject amounts that are zero, negative, or not numbers.
  2. Clean the name and category text (remove extra spaces, consistent capitalisation).
  3. Show all expenses, numbered, with aligned columns and a grand total.
  4. Show the total spent in each category.
  5. Keep the menu running until the user chooses Exit.

Step 1: Set up the data

Create the storage. Each expense will be a dictionary, and all expenses will live in one list.

expenses = []   # list of dictionaries, one per expense

Step 2: Add a function to read a valid amount

Functions are formally taught on Day 8, but this short helper uses only Day 3 and Day 4 ideas: a loop that repeats until input is valid. Try it before reading the explanation.

def read_amount():
    while True:
        text = input("Amount: ").strip()
        try:
            amount = float(text)
        except ValueError:
            print("Please enter a number.")
            continue
        if amount <= 0:
            print("Amount must be greater than zero.")
            continue
        return amount
What's new here: def defines a reusable block of code, and return sends a value back. try and except catch errors so the program doesn't crash when the user types letters. You'll learn these properly on Days 8 and 12.

Step 3: Add an expense

Ask for the name, amount, and category, clean the text, then store everything as a dictionary inside the list.

def add_expense():
    name = input("Expense name: ").strip().title()
    amount = read_amount()
    category = input("Category (food, travel, bills, other): ").strip().lower()
    if category == "":
        category = "other"
    expenses.append({"name": name, "amount": amount, "category": category})
    print(f"Added: {name} - {amount:.2f}")
Expense name: lunch with friends Amount: 450 Category (food, travel, bills, other): Food Added: Lunch With Friends - 450.00

Step 4: View all expenses

Loop through the list with enumerate to number each row, and use f-string alignment from Day 2 to line up the columns.

def view_expenses():
    if not expenses:
        print("No expenses recorded yet.")
        return
    print(f"{'No.':<5}{'Name':<22}{'Category':<12}{'Amount':>10}")
    print("-" * 49)
    total = 0
    for i, e in enumerate(expenses, start=1):
        print(f"{i:<5}{e['name']:<22}{e['category']:<12}{e['amount']:>10.2f}")
        total += e["amount"]
    print("-" * 49)
    print(f"{'Total':<39}{total:>10.2f}")
No. Name Category Amount ------------------------------------------------- 1 Lunch With Friends food 450.00 2 Bus Pass travel 120.00 ------------------------------------------------- Total 570.00

Step 5: Totals by category

Use a dictionary to add up each category, and a set to list the distinct categories. This is the Day 6 counting pattern.

def category_totals():
    if not expenses:
        print("No expenses recorded yet.")
        return
    totals = {}
    for e in expenses:
        cat = e["category"]
        totals[cat] = totals.get(cat, 0) + e["amount"]
    print("Totals by category:")
    for cat in sorted(totals):
        print(f"  {cat:<10} {totals[cat]:>10.2f}")
    print(f"Categories used: {len(set(e['category'] for e in expenses))}")
Totals by category: food 450.00 travel 120.00 Categories used: 2

Step 6: The menu loop

Put it together. The while True loop keeps the menu running, and if / elif / else picks the action.

def main():
    print("Expense tracker started")
    while True:
        print("\n==== Expense Tracker ====")
        print("1. Add expense")
        print("2. View all expenses")
        print("3. Show totals by category")
        print("4. Exit")
        choice = input("Choose an option: ").strip()

        if choice == "1":
            add_expense()
        elif choice == "2":
            view_expenses()
        elif choice == "3":
            category_totals()
        elif choice == "4":
            print("Goodbye! Your expenses were not saved to a file.")
            break
        else:
            print("Invalid choice, please enter 1 to 4.")

main()
Note: The data lives only in memory, so it is lost when the program closes. File saving is covered on Day 11, and you'll add it as an extension later.

Comprehensions in Depth

Estimated time: about 1.5 hours · List, set, and dictionary comprehensions, filters, nesting, readability

Lesson 1: Recap of List Comprehensions

On Day 5 and Day 10 you saw that a comprehension builds a list from a loop in one line. The general form is:

[expression for item in iterable if condition]

Read it left to right as a sentence: "give me this expression, for each item in the iterable, if the condition holds."

squares = [n * n for n in range(1, 6)]
print(squares)

evens = [n for n in range(10) if n % 2 == 0]
print(evens)
[1, 4, 9, 16, 25] [0, 2, 4, 6, 8]
Analogy: A comprehension is a sieve. Everything from the iterable passes through, the condition decides what is kept, and the expression decides what shape each kept item takes.

Lesson 2: Conditions in Two Places

A comprehension can have a filter (if at the end) or a conditional expression (if ... else inside the expression). They do different jobs.

nums = [1, 2, 3, 4, 5]

# Filter: keeps only some items, others are dropped
big = [n for n in nums if n > 2]
print(big)

# Conditional expression: every item is kept, but its value changes
labels = ["even" if n % 2 == 0 else "odd" for n in nums]
print(labels)
[3, 4, 5] ['odd', 'even', 'odd', 'even', 'odd']
Common mistake: Putting if ... else at the end. The filter form has only if, and the else must go in the expression at the start.

Lesson 3: Working with Strings and Lists of Data

names = ["  sam ", "ALI", "  sara"]
clean = [n.strip().title() for n in names]
print(clean)

prices = {"pen": 10, "book": 150, "bag": 900}
expensive = [item for item, price in prices.items() if price > 100]
print(expensive)
['Sam', 'Ali', 'Sara'] ['book', 'bag']

When iterating over a dictionary's items, unpack each pair directly in the for clause, just as you did in a normal loop on Day 6.

Lesson 4: Set and Dictionary Comprehensions

Change the brackets to make a different collection. Curly brackets with a colon make a dictionary, and curly brackets without a colon make a set.

words = ["apple", "Banana", "apple", "cherry"]

# Set comprehension: unique lowercase words
unique = {w.lower() for w in words}
print(unique)

# Dictionary comprehension: word to its length
lengths = {w: len(w) for w in words}
print(lengths)
{'banana', 'apple', 'cherry'} {'apple': 5, 'Banana': 6, 'cherry': 6}
Note: In the dictionary example, the duplicate key apple is written only once, because later entries overwrite earlier ones with the same key. Sets and dictionaries never keep duplicates.

Swapping keys and values

codes = {"IN": "India", "US": "United States"}
reversed_codes = {v: k for k, v in codes.items()}
print(reversed_codes)
{'India': 'IN', 'United States': 'US'}

Lesson 5: Nested Comprehensions

A comprehension can contain another for. The first for is the outer loop, and the second is the inner loop. Read them in the same order as normal nested loops.

# Same as two nested for loops
pairs = [(x, y) for x in range(3) for y in range(2)]
print(pairs)

# Flatten a list of lists
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [n for row in matrix for n in row]
print(flat)
[(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)] [1, 2, 3, 4, 5, 6]
Readability limit: Two nested for clauses are usually fine. Three or more, or a complex condition, is a sign to switch to an ordinary loop.

Lesson 6: Comprehensions Versus Loops

Comprehensions are shorter and often faster, but a loop is clearer when the logic has several steps. Compare:

orders = [120, 45, 300, 80]

# Comprehension: clear, one idea
discounted = [round(o * 0.9, 2) for o in orders if o > 100]

# Loop: better when you need several steps
discounted_loop = []
for o in orders:
    if o > 100:
        final = o * 0.9
        final = round(final, 2)
        discounted_loop.append(final)

print(discounted)
print(discounted_loop)
[108.0, 270.0] [108.0, 270.0]
Rule of thumb: If you can read the comprehension aloud as one sentence, use it. If you need to pause and work out what it does, use a loop with clear names.

Lesson 7: Generator Expressions (Preview)

Replace the square brackets with round ones and you get a generator expression. It produces values one at a time, which saves memory on large data. Day 19 covers this in full.

total = sum(n * n for n in range(1000))
print(total)
332833500

Passing a generator expression straight into sum(), max(), or any() doesn't need extra brackets.

Common Mistakes on Day 18

  1. Wrong position for else: if ... else belongs in the expression, not after the loop.
  2. Reversed nested loop order: the outer for comes first, then the inner one.
  3. Expecting a set to keep order: set comprehensions don't guarantee order.
  4. Overly complex comprehensions: readability matters more than brevity.
  5. Side effects: comprehensions are for building values. Calling print() or changing other variables inside one hides what is happening.

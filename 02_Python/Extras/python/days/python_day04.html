Loops: Repeating Work

Estimated time: about 1.5 hours · for, while, range, break, continue, nested loops

Lesson 1: Why Loops?

Imagine printing the numbers 1 to 100. Writing 100 print lines is impractical. A loop repeats a block of code automatically. Python has two main kinds: for loops, which repeat over a sequence of items, and while loops, which repeat as long as a condition stays True.

Analogy: A loop is like a teacher calling out names from a register. The teacher goes through each name in turn, does the same action for each one, then stops when the list is finished. 
for i in range(3):
    print("Hello", i)
Hello 0 Hello 1 Hello 2

The indented line runs once for each value of i. When the loop finishes, the program continues with the next unindented line.

Lesson 2: The for Loop

A for loop takes each item from a sequence and runs the block once per item. Strings, lists, and ranges are all sequences.

for letter in "Python":
    print(letter)
P y t h o n
fruits = ["apple", "mango", "grape"]
for fruit in fruits:
    print("I like", fruit)
I like apple I like mango I like grape

The variable name after for (here fruit) can be anything. Choose a name that describes one item.

Lesson 3: The range() Function

range() produces a sequence of numbers. It follows the same rule as slicing: the start is included, and the stop is excluded.

CallNumbers produced
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(0, 10, 2)0, 2, 4, 6, 8
range(10, 0, -2)10, 8, 6, 4, 2
for n in range(1, 6):
    print(n * n)
1 4 9 16 25
Common mistake: range(1, 5) stops at 4, not 5. If you want 5 included, write range(1, 6).

Looping by index

colours = ["red", "green", "blue"]
for i in range(len(colours)):
    print(i, colours[i])
0 red 1 green 2 blue
Tip: If you need both the index and the value, enumerate() is cleaner: 
for i, colour in enumerate(colours):
    print(i, colour)

Lesson 4: Accumulating Results

Loops are often used to build up a total or a result. Set a variable before the loop, update it inside, and use it after.

total = 0
for n in range(1, 11):
    total = total + n
print("Sum of 1 to 10 is", total)
Sum of 1 to 10 is 55
word = "hello"
vowels = 0
for ch in word:
    if ch in "aeiou":
        vowels += 1
print("Vowels:", vowels)
Vowels: 2

This pattern (initialise, loop, update, use) appears constantly in real programs.

Lesson 5: The while Loop

A while loop checks a condition before each pass. It keeps running while the condition is True. Use it when you don't know in advance how many times to repeat.

count = 1
while count <= 3:
    print("Count is", count)
    count += 1
print("Done")
Count is 1 Count is 2 Count is 3 Done

Waiting for valid input

password = ""
while password != "python123":
    password = input("Enter the password: ")
print("Access granted")

The loop keeps asking until the correct password is entered.

Infinite loops: If the condition never becomes False, the loop never ends. Make sure something inside the loop changes the condition. For example, while count <= 3: without count += 1 runs forever. Press Ctrl+C in the terminal to stop it.

Lesson 6: break and continue

break exits the loop immediately. continue skips the rest of the current pass and moves to the next item.

for n in range(1, 10):
    if n == 5:
        break          # stop the loop completely
    print(n)
print("Loop ended")
1 2 3 4 Loop ended
for n in range(1, 8):
    if n % 2 == 0:
        continue       # skip even numbers
    print(n)
1 3 5 7
Analogy: break is leaving a queue early. continue is letting one person skip their turn while everyone else still goes.

Lesson 7: Loops with else

A loop can have an else block. It runs only if the loop finished normally, meaning no break happened. This is useful for search tasks.

numbers = [4, 7, 9, 12]
for n in numbers:
    if n > 10:
        print("Found a number above 10:", n)
        break
else:
    print("No number above 10 was found")
Found a number above 10: 12

If none of the numbers were above 10, the else would run instead.

Lesson 8: Nested Loops

A loop inside another loop runs the inner loop completely for each pass of the outer loop. This is common for tables and grids.

for row in range(1, 4):
    for col in range(1, 4):
        print(row * col, end="\t")
    print()
1 2 3 2 4 6 3 6 9

end="\t" stops print() from starting a new line, and the empty print() at the end moves to the next row.

Watch the cost: Two nested loops over 1,000 items each run 1,000,000 times. Keep nesting to what the problem really needs.

Common Mistakes on Day 4

  1. Off-by-one in range: range(1, 5) gives 1 to 4.
  2. Infinite while loops: forgetting to update the condition variable inside the loop.
  3. Changing a list while looping over it: removing items during a loop skips elements. Build a new list instead.
  4. Forgetting indentation: only the indented lines belong to the loop.
  5. Resetting the accumulator inside the loop: total = 0 placed inside the loop wipes the running total each time.

Practicals

Try each one before looking at any hints.

Practical 1: Multiplication Table

Ask the user for a number and print its multiplication table from 1 to 10 using a for loop.

Practical 2: Sum of Even Numbers

Find the sum of all even numbers from 1 to 100. Print the result.

Hint: use range(2, 101, 2) or an if with %.

Practical 3: Countdown with while

Start at 10 and count down to 1 using a while loop. Print "Liftoff!" at the end.

Practical 4: Guess the Number

Store a secret number, for example 7. Keep asking the user to guess with a while loop. Print "Too high" or "Too low" as hints, and "Correct" when they win. Count and print the number of attempts.

Practical 5: Digit Counter

Ask for a whole number, then count how many digits it has. Use len(str(number)), then do it again with a while loop using // and a counter.

Practical 6: Star Pyramid

Print a pyramid of stars with 5 rows. Row 1 has one star, row 2 has two, and so on. Use nested loops with print("*", end="").

Lesson 1: What Is Python?

A programming language is a set of rules for giving instructions to a computer. Python is one of the most popular because its rules read almost like English. Compare these two lines, which both tell the computer to show a message:

// Java
System.out.println("Hello");

# Python
print("Hello")

Python is an interpreted language. That means the Python program (the interpreter) reads your code one line at a time and runs it. You don't have to compile the whole program first. This makes it quick to try things out.

Analogy: Think of the interpreter as a translator at a meeting. You speak one sentence, and the translator immediately acts on it before you say the next.

Installing Python

  1. Go to python.org/downloads and download the latest Python 3 version.
  2. On Windows, tick "Add Python to PATH" during installation. Skipping this is the most common setup problem.
  3. Open a terminal (Command Prompt, PowerShell, or Terminal on Mac) and type python --version. You should see something like Python 3.12.x.

Lesson 2: Your First Program

The print() function displays text on the screen. Anything inside the parentheses is what gets shown.

print("Hello, World!")
print("Welcome to Python")
Hello, World! Welcome to Python

Text inside quotes

Text in Python is called a string, and it must be wrapped in quotes. Single or double quotes both work, but be consistent.

print("Double quotes work")
print('Single quotes work too')
print("It's fine to put a ' inside double quotes")
Double quotes work Single quotes work too It's fine to put a ' inside double quotes

Printing numbers and maths

Numbers don't need quotes. Python calculates the expression before printing the result.

print(2 + 3)       # Python calculates 5 and prints it
print("2 + 3")     # The quotes make it text, so it prints exactly 2 + 3
5 2 + 3
Common mistake: Forgetting the quotes around text gives an error: 
print(Hello)   # NameError: name 'Hello' is not defined
Python thinks Hello is a variable name, because it has no quotes.

Comments

A comment starts with #. Python ignores everything after it on that line. Use comments to explain why your code does something, not what it does.

# This line is ignored by Python
print("This line runs")  # Comments can go at the end of a line too

Lesson 3: Variables

A variable is a name that stores a value so you can use it later. The = sign means "store the value on the right in the name on the left". It does not mean "equal" as in maths.

name = "Sam"
age = 25
height = 5.9
is_student = True

print(name)
print(age)
print(height)
print(is_student)
Sam 25 5.9 True
Analogy: A variable is a labelled box. age = 25 puts the number 25 into a box labelled age. Later you can open the box, read the value, or replace it with a new value.

Changing a variable

score = 10
print(score)      # 10
score = 20        # the box now holds 20 instead
print(score)      # 20
score = score + 5 # read 20, add 5, store 25
print(score)      # 25
10 20 25

Naming rules

  • Use letters, numbers, and underscores only (user_name, total2).
  • Cannot start with a number (2nd_place is invalid; second_place is fine).
  • Cannot use spaces (first name is invalid; use first_name).
  • Case matters: Age and age are two different variables.
  • Avoid reserved words such as class, if, for, and True.

By convention, use snake_case for variable names, with lowercase words joined by underscores.

Lesson 4: Data Types

Every value in Python has a type, which tells Python what you can do with it. You can add two numbers, but you can't add a number to a word without converting first.

TypeNameExampleUse it for
intInteger42, -7Counting: ages, stock, scores
floatDecimal3.14, 0.5Measurements, prices, averages
strString"Python", 'hi'Names, messages, text
boolBooleanTrue, FalseYes/no decisions
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

Why types matter

print(5 + 3)        # 8   (numbers add)
print("5" + "3")    # 53  (text joins together)
print("5" + 3)      # Error! can't join text and a number
Watch out: "5" looks like a number but is text, because the quotes make it a string. Python will refuse to mix them.

Converting between types

print(int("42") + 8)      # 50: text "42" becomes number 42
print(float("2.5") * 2)   # 5.0
print(str(100) + " marks")  # "100 marks"
print(int(3.9))           # 3: int() chops off the decimal, it does NOT round
50 5.0 100 marks 3

Lesson 5: Operators

Operators are symbols that perform operations on values.

Arithmetic operators

OperatorMeaningExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division (always float)7 / 23.5
//Floor division (whole part)7 // 23
%Remainder7 % 21
**Power7 ** 249
Remainder tip: % is very useful. n % 2 == 0 means n is even. Real uses include checking every 10th row in a list or wrapping an index around.

Order of operations

Python follows normal maths rules: brackets first, then **, then * / // %, then + -. Use brackets whenever you're unsure.

print(2 + 3 * 4)     # 14, multiplication happens first
print((2 + 3) * 4)   # 20, brackets happen first
14 20

Assignment shortcuts

count = 5
count += 1    # same as count = count + 1  -> 6
count *= 2    # same as count = count * 2  -> 12
print(count)
12

Lesson 6: Strings in Detail

Strings are more than just text. Python gives you ways to build them and combine them.

Three ways to insert values into text

name = "Sam"
age = 25

# 1. Concatenation with +
print("I am " + name + " and I am " + str(age))

# 2. Comma inside print (adds spaces automatically)
print("I am", name, "and I am", age)

# 3. f-string (the recommended way)
print(f"I am {name} and I am {age}")
I am Sam and I am 25 I am Sam and I am 25 I am Sam and I am 25

f-strings are the most readable, so use them for almost everything. The f before the quotes tells Python to replace anything in { } with its value.

Useful f-string tricks

price = 49.5
print(f"Total: {price * 2}")          # calculations inside braces
print(f"Price: {price:.2f}")          # 2 decimal places -> 49.50
print(f"Math: {2 + 2 = }")            # shows the expression and result (Python 3.8+)
Total: 99.0 Price: 49.50 Math: 2 + 2 = 4

Repeating text

print("-" * 20)
print("Hello " * 3)
-------------------- Hello Hello Hello

Lesson 7: Taking Input from the User

input() pauses the program, waits for the user to type something and press Enter, then gives you back what they typed.

name = input("What is your name? ")
print("Hello,", name)
Important: input() always returns a string, even if the user types 25. Convert it if you need a number: 
age = int(input("Enter your age: "))     # now it's a number
print(f"Next year you will be {age + 1}")

Example run (what the user types is shown in bold in the explanation): if you type 25, the program prints Next year you will be 26.

Decimal input

price = float(input("Enter price: "))
quantity = int(input("Enter quantity: "))
print(f"Total cost: {price * quantity:.2f}")

Common Mistakes on Day 1

  1. Forgetting quotes around text: print(hello) instead of print("hello").
  2. Mixing text and numbers: "Age: " + 25 fails. Use f"Age: {25}" or "Age: " + str(25).
  3. Forgetting int() on input: input("2") + 3 fails. Use int(input("2")) + 3.
  4. Using = to compare: = stores a value. Comparing equality uses ==, which you'll learn on Day 3.
  5. Reading errors wrongly: Read the last line of an error first. It names the problem, and the line number shows where.

Practicals

Try each one yourself before looking at any hints. Struggling is part of learning.

Practical 1: Personal Introduction

Store your name, city, and favourite number in variables. Print a sentence such as "Hi, I'm Sam from Surat and my lucky number is 7" using an f-string.

Practical 2: Simple Calculator

Ask for two numbers using input(), convert them with float(), and print their sum, difference, product, and quotient.

Hint: you'll need four print lines. Use :.2f in the f-string to keep the results neat.

Practical 3: Temperature Converter

Ask for a temperature in Celsius and print the Fahrenheit value using F = C * 9 / 5 + 32.

Test: 100 Celsius should give 212.0, and 0 should give 32.0.

Practical 4: Shopping Bill

Ask for the name of an item, its price, and how many you're buying. Print the total cost with 2 decimal places. Then add a 18% tax and print the final amount.

Practical 5: Type Detective

Create five variables of different types. Print each one with its type. Predict the output on paper first, then run it and check.

Practical 6: Even or Odd Preview

Ask for a number, then print its remainder when divided by 2. Write a comment explaining what the result tells you.

Practical 7: Counter

Start with count = 0. Add 1 to it five times, printing it each time. Then multiply it by 10 and print the result.

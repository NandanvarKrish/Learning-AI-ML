Inheritance

Estimated time: about 1.5 hours · Subclasses, super(), method overriding, isinstance, when to inherit

Lesson 1: What Is Inheritance?

Inheritance lets a new class reuse everything from an existing class and then add or change parts. The existing class is the parent (or base class). The new class is the child (or subclass).

Analogy: A child inherits their parent's eye colour and family name, then adds their own hobbies. They don't need to be given everything again from scratch.

Without inheritance, you'd copy the same attributes and methods into several classes. Inheritance removes that duplication, so a change in one place applies everywhere it's needed.

Lesson 2: A First Subclass

Put the parent class name in brackets after the child's name.

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "Some sound"

class Dog(Animal):          # Dog inherits from Animal
    pass

d = Dog("Rex")
print(d.name)               # inherited attribute
print(d.speak())            # inherited method
Rex Some sound

Dog has no code of its own, yet it has name and speak(), because both come from Animal.

Lesson 3: Overriding Methods

A child can replace a parent's method by defining one with the same name. This is called overriding. Python uses the child's version for child objects.

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

for pet in [Dog("Rex"), Cat("Tom"), Animal("Generic")]:
    print(pet.name, "says", pet.speak())
Rex says Woof! Tom says Meow! Generic says Some sound
Key idea: One loop works for all three types, because each object knows which speak() to use. This is called polymorphism, meaning "many forms".

Lesson 4: super() to Extend the Parent

Often you want the child to do everything the parent does, plus a little more. super() calls the parent's version of a method, so you don't repeat its code.

class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Dog(Animal):
    def __init__(self, name, age, breed):
        super().__init__(name, age)   # let Animal set name and age
        self.breed = breed            # then add the extra attribute

d = Dog("Rex", 4, "Labrador")
print(d.name, d.age, d.breed)
Rex 4 Labrador
Common mistake: Forgetting to call super().__init__(). The parent's attributes are then never set, and you get an AttributeError later.

You can also extend a method rather than replace it:

class Dog(Animal):
    def speak(self):
        return super().speak() + " ... actually, Woof!"

print(Dog("Rex", 4, "Lab").speak())
Some sound ... actually, Woof!

Lesson 5: Checking Types with isinstance()

isinstance(obj, Class) returns True if the object belongs to that class or any of its subclasses.

d = Dog("Rex", 4, "Lab")
print(isinstance(d, Dog))      # True
print(isinstance(d, Animal))   # True: a Dog is also an Animal
print(isinstance(d, str))      # False
True True False

Use isinstance when you need to check a type. Often you don't need to check at all, because the methods you call will work for any type that has them.

Lesson 6: Multiple Inheritance (Brief)

Python allows a class to inherit from more than one parent. It's useful but can get complicated, so use it carefully.

class Swimmer:
    def swim(self):
        return "swimming"

class Flyer:
    def fly(self):
        return "flying"

class Duck(Animal, Swimmer, Flyer):
    pass

duck = Duck("Donald", 2)
print(duck.swim(), duck.fly())
swimming flying
Guideline: Prefer a single parent for most classes. Mixins like Swimmer, which add small pieces of behaviour, are the most common safe use of multiple inheritance.

Lesson 7: When to Inherit (and When Not To)

Ask: "Is a [child] a kind of [parent]?" If the answer is yes, inheritance may fit. If the answer is "has a", use composition instead, meaning one object holds another as an attribute.

RelationshipUseExample
is aInheritanceA Dog is an Animal
has aCompositionA Car has an Engine
class Engine:
    def __init__(self, horsepower):
        self.horsepower = horsepower

class Car:
    def __init__(self, model, horsepower):
        self.model = model
        self.engine = Engine(horsepower)   # Car HAS an Engine

c = Car("Swift", 82)
print(c.engine.horsepower)
82
Warning: Inheritance is easy to overuse. A deep chain of parent classes is hard to follow. Keep hierarchies shallow, usually one or two levels.

Common Mistakes on Day 16

  1. Forgetting super().__init__(): the parent's attributes are never set.
  2. Forgetting self in the override: every method still needs self as its first parameter.
  3. Inheriting when you should compose: a Car is not a kind of Engine.
  4. Deep hierarchies: long chains of parents make code hard to read and change.
  5. Using the wrong parent name: the class must be defined before you can inherit from it.

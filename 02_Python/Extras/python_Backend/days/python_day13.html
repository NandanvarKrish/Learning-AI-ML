Modules and pip

Estimated time: about 1.5 hours · import, the standard library, your own modules, packages, installing with pip

Lesson 1: What Is a Module?

A module is a Python file containing code you can reuse. Python ships with hundreds of ready-made modules, called the standard library. Any .py file you write is also a module. You load a module with import.

Analogy: Modules are like toolboxes. The standard library is the toolbox that comes with your house. pip lets you buy extra toolboxes from a shop. Your own files are toolboxes you build yourself. 
import math

print(math.sqrt(16))     # 4.0
print(math.pi)           # 3.141592653589793
4.0 3.141592653589793

The dot tells Python to look inside the module. math.sqrt means "the sqrt function from the math module".

Lesson 2: Ways to Import

StyleExampleWhen to use
Whole moduleimport mathMost cases; names stay clearly labelled
Aliasimport pandas as pdLong module names with common short forms
Specific namesfrom math import sqrt, piWhen you use just a few items often
Everythingfrom math import *Avoid. It hides where names come from.
import random as rnd
from math import sqrt

print(sqrt(81))          # 9.0
print(rnd.randint(1, 6)) # a random number from 1 to 6
9.0 4 (a random value from 1 to 6)
Warning: Avoid naming your own file the same as a standard module, such as random.py or math.py. Python will import your file instead of the real module, and you'll get confusing errors.

Lesson 4: Getting Help on a Module

You can explore any module from inside Python without looking anything up online.

import math

print(dir(math))            # list of names in the module
help(math.sqrt)             # full documentation for one function

dir() shows what's available. help() shows the docstring you learned about on Day 8. Python's official documentation at docs.python.org is the authoritative reference.

Lesson 5: Your Own Modules

Any .py file in the same folder can be imported by its name without the extension. This is how you split a large program into parts.

Create a file called greetings.py:

# greetings.py
def hello(name):
    return f"Hello, {name}!"

PI_APPROX = 3.14   # a constant by convention: UPPERCASE

Then create main.py in the same folder:

# main.py
import greetings

print(greetings.hello("Sam"))
print(greetings.PI_APPROX)
Hello, Sam! 3.14

The __name__ check

Every module has a __name__ value. When you run a file directly, its __name__ is "__main__". When it's imported, it's the module name. This check lets a file act as both a script and a reusable module.

# greetings.py
def hello(name):
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(hello("Test"))   # runs only when this file is run directly
Good habit: Put demo or test code under if __name__ == "__main__":. Then importing the file won't run that code.

Lesson 6: Packages

A package is a folder of modules with an __init__.py file (it can be empty). Packages group related modules.

shop/
    __init__.py
    cart.py
    payment.py
from shop.cart import add_item
from shop import payment

Larger projects, including Django, are built as packages. Learning this structure now prepares you for Django's project layout.

Lesson 7: pip, the Package Installer

pip downloads and installs third-party packages from the Python Package Index (PyPI). Run pip commands in your terminal, not inside Python.

CommandWhat it does
pip install requestsInstalls the requests package
pip install requests==2.31.0Installs one specific version
pip install --upgrade requestsUpgrades to the latest version
pip uninstall requestsRemoves the package
pip listShows installed packages
pip show requestsShows details about one package
pip freeze > requirements.txtSaves installed packages to a file
pip install -r requirements.txtInstalls everything listed in that file
# In the terminal
pip install requests

# Then in a Python file
import requests
print(requests.__version__)
2.31.0 (your version may be different)
Watch out: If pip is not recognised, try python -m pip install requests. On Windows, this usually means Python was installed without "Add Python to PATH" (Day 1).

Common Mistakes on Day 13

  1. Naming your file after a standard module: random.py will hide the real random module.
  2. Using from module import *: it hides where names come from.
  3. Forgetting the module prefix: sqrt(16) fails unless you imported it by name.
  4. Running pip inside Python: type pip commands in the terminal.
  5. Import errors after installing: the package may be installed for a different Python version. Check with python -m pip install ....
  6. Circular imports: two modules importing each other can fail. Restructure so one doesn't depend on the other.

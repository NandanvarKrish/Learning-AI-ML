Strings in Depth

Estimated time: about 1.5 hours · Indexing, slicing, methods, formatting, and text cleaning

Lesson 1: What Is a String?

A string is a sequence of characters: letters, digits, spaces, and symbols, wrapped in quotes. Python treats the whole thing as one value, but it also lets you reach inside it character by character.

word = "Python"
print(word)
print(len(word))
Python 6

len() counts the characters. Spaces count too.

Quotes and special characters

Use triple quotes for text that spans several lines. To include a quote inside a string, either mix quote types or escape it with a backslash \.

print("She said 'hello'")
print('He said "hi"')
print("Line one\nLine two")     # \n means new line
print("Column\tTwo")            # \t means tab
print("Quote: \" inside")       # escaped quote

poem = """Roses are red,
Violets are blue."""
print(poem)
She said 'hello' He said "hi" Line one Line two Column Two Quote: " inside Roses are red, Violets are blue.
Analogy: A string is like a row of seats in a cinema. Each seat has a number, starting from 0, and you can ask for a seat by its number.

Lesson 2: Indexing

Each character has an index, its position number. Python counts from 0, not 1.

word = "Python"
#  P  y  t  h  o  n
#  0  1  2  3  4  5
print(word[0])    # P
print(word[3])    # h
print(word[-1])   # n  (negative counts from the end)
print(word[-2])   # o
P h n o
Common mistake: word[6] raises IndexError: string index out of range, because "Python" only has indexes 0 to 5.

Strings are immutable, which means you can read characters but not change them in place. This fails:

word = "Python"
word[0] = "J"   # TypeError: 'str' object does not support item assignment

To change a string, create a new one:

word = "Python"
word = "J" + word[1:]   # build a new string from parts
print(word)
Jython

Lesson 3: Slicing

Slicing takes a piece of a string. The syntax is text[start:stop]. The start character is included, and the stop character is excluded.

word = "Python"
print(word[0:2])    # Py  (indexes 0 and 1)
print(word[2:5])    # tho (indexes 2, 3, 4)
print(word[:3])     # Pyt (from the start up to index 2)
print(word[3:])     # hon (from index 3 to the end)
print(word[:])      # Python (the whole string)
print(word[::2])    # Pto (every 2nd character)
print(word[::-1])   # nohtyP (reversed!)
Py tho Pyt hon Python Pto nohtyP
Tip: Think of indexes as the gaps between letters, not the letters themselves. word[2:5] cuts at gap 2 and gap 5.

[::-1] is a common trick for reversing text. You'll use it for palindrome checks on Day 3.

Lesson 4: Essential String Methods

Methods are actions you call on a string using a dot. They return a new string; the original stays unchanged.

text = "  Hello, Python World  "

print(text.strip())          # remove spaces from both ends
print(text.lower())          # all lowercase
print(text.upper())          # ALL UPPERCASE
print(text.title())          # Each Word Capitalised
print(text.replace("Python", "Java"))
print(text.count("l"))       # how many times 'l' appears
print(text.find("Python"))   # index where it starts, or -1
print("a,b,c".split(","))    # split into a list
print(",".join(["a", "b", "c"]))  # join a list into a string
Hello, Python World hello, python world HELLO, PYTHON WORLD Hello, Python World Hello, Java World 3 9 ['a', 'b', 'c'] a,b,c

Notice that text.strip() and friends don't change text. You must store the result if you want to keep it:

text = text.strip()   # now text holds the cleaned version

Checking content

email = "sam@example.com"
print("@" in email)              # True
print(email.startswith("sam"))   # True
print(email.endswith(".org"))    # False

Lesson 5: Formatting Text

f-strings from Day 1 handle most formatting. Here are the options you'll use most often.

price = 1234.5
name = "Sam"

print(f"{name:>10}|")        # right-align in 10 characters
print(f"{name:<10}|")        # left-align
print(f"{name:^10}|")        # centre
print(f"{price:,.2f}")       # thousands separator and 2 decimals
print(f"{0.4567:.1%}")       # as a percentage -> 45.7%
print(f"{42:05d}")           # pad with zeros -> 00042
Sam| Sam | Sam | 1,234.50 45.7% 00042
Why this matters: Invoices, reports, and tables all need aligned, consistently formatted numbers. These options produce that without extra code.

Lesson 6: Searching and Checking Membership

The in keyword checks whether one string appears inside another. It's the simplest way to search text.

sentence = "Python is fun to learn"
if "fun" in sentence:
    print("Found it!")
print("java" in sentence)       # False: case matters
print("java" in sentence.lower())  # False, but this pattern is useful for case-insensitive checks
Found it! False False

Remember that "Python" != "python". Convert both sides to lowercase before comparing when case should not matter.

Lesson 7: Cleaning User Input

Real user input is messy. People add extra spaces, mixed capitals, and stray characters. A standard cleaning step prevents bugs.

raw = "   SaM@Example.COM  "
clean = raw.strip().lower()
print(clean)
sam@example.com
# Save a name typed by the user, making it neat
name = input("Enter your name: ").strip().title()
print(f"Welcome, {name}!")

If the user types aLi , the program prints Welcome, Ali!

Common Mistakes on Day 2

  1. Off-by-one with indexes: the last index is len(word) - 1, not len(word).
  2. Expecting in-place change: text.upper() alone does nothing visible. Use text = text.upper().
  3. Forgetting the slice end is excluded: word[0:3] gives 3 characters, not 4.
  4. Case mismatch in comparisons: "yes" == "Yes" is False. Normalise with .lower() first.
  5. Joining numbers: "Total: " + 5 fails. Use f"Total: {5}" or str(5).

Practicals

Attempt each one before opening any hints.

Practical 1: First and Last

Ask the user for a word. Print its first character, its last character, and its length.

Practical 2: Palindrome Check

Ask for a word and print whether it reads the same backwards. Test with "level" (yes) and "python" (no).

Hint: compare the cleaned word with word[::-1].

Practical 3: Username Maker

Ask for a first name and a last name. Create a username made of the first letter of the first name followed by the full last name, all lowercase. Example: "Sam" and "Khan" gives "skhan".

Practical 4: Vowel Counter

Ask for a sentence and count how many vowels (a, e, i, o, u) it contains. Ignore case.

Hint: use .lower() and .count() for each vowel, then add the results.

Practical 5: Clean Receipt

Store an item name with extra spaces and mixed case, such as " bLUE pEN ". Clean it, then print a receipt line with the price (use :>12 alignment and :.2f).

Practical 6: Email Masker

Given an email like "sam@example.com", print only the part after the "@" sign. Use find() or split("@").

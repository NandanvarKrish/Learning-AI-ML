Lesson 1: What Is pandas?

pandas is a third-party library for working with tabular data, the kind you'd see in a spreadsheet. It handles thousands or millions of rows efficiently, and it provides readable methods for cleaning, filtering, and summarising. You installed third-party packages on Day 13, and you'll use a virtual environment for this one, as on Day 25.

Analogy: If a list is a single column of numbers, a pandas DataFrame is an entire spreadsheet: rows, named columns, and tools for sorting and totalling across them.

Lesson 2: Series and DataFrame

pandas has two core types:

TypeWhat it isLike
SeriesOne labelled column of valuesA single column in a spreadsheet
DataFrameA table of rows and named columnsA whole spreadsheet
import pandas as pd

marks = pd.Series([82, 95, 70], name="marks")
print(marks)

df = pd.DataFrame({
    "name": ["Sam", "Ali", "Sara"],
    "marks": [82, 95, 70],
    "city": ["Surat", "Pune", "Surat"],
})
print(df)
0 82 1 95 2 70 Name: marks, dtype: int64 name marks city 0 Sam 82 Surat 1 Ali 95 Pune 2 Sara 70 Surat
Convention: import pandas as pd is the standard alias. Every pandas tutorial and most projects use it.

Lesson 3: Reading a CSV File

Day 11 taught you the csv module. pandas reads a CSV in a single line, and it turns the columns into the right types automatically.

import pandas as pd

df = pd.read_csv("students.csv")
print(df.head())      # first 5 rows
print(df.shape)       # (rows, columns)
print(df.dtypes)      # type of each column
name marks city 0 Sam 82 Surat ... (3, 3) name object marks int64 city object dtype: object
Note: object in dtypes usually means text. Numbers that pandas reads as text are a common cleaning task, which you'll handle with pd.to_numeric later in the course.

Lesson 4: Selecting Columns and Rows

import pandas as pd

df = pd.DataFrame({
    "name": ["Sam", "Ali", "Sara"],
    "marks": [82, 95, 70],
    "city": ["Surat", "Pune", "Surat"],
})

print(df["name"])              # one column, as a Series
print(df[["name", "marks"]])   # several columns, as a DataFrame
print(df.iloc[0])              # first row, by position
print(df.loc[1, "marks"])      # row with label 1, column marks
0 Sam 1 Ali 2 Sara Name: name, dtype: object name marks 0 Sam 82 1 Ali 95 2 Sara 70 name Sam marks 82 city Surat Name: 0, dtype: object 95
MethodSelects by
df["col"]Column name
df.iloc[i]Position (integer location)
df.loc[label, col]Row label and column name

Lesson 5: Filtering Rows

A condition on a column gives a True or False value for each row. Using that inside square brackets keeps only the rows that are True. This works like the list comprehension filter from Day 18.

import pandas as pd

df = pd.DataFrame({
    "name": ["Sam", "Ali", "Sara"],
    "marks": [82, 95, 70],
    "city": ["Surat", "Pune", "Surat"],
})

high = df[df["marks"] >= 80]
print(high)

surat_high = df[(df["city"] == "Surat") & (df["marks"] > 75)]
print(surat_high)
name marks city 0 Sam 82 Surat 1 Ali 95 Pune name marks city 0 Sam 82 Surat
Important: Combine conditions with & (and) and | (or), not and and or. Wrap each condition in parentheses, because & binds more tightly than comparisons.

Lesson 6: Adding and Changing Columns

Assign to a new column name to create it. Calculations apply to every row at once, so you don't write a loop.

import pandas as pd

df = pd.DataFrame({"name": ["Sam", "Ali"], "marks": [82, 95]})

df["percent"] = df["marks"] / 100
df["grade"] = df["marks"].apply(lambda m: "A" if m >= 90 else "B")
print(df)
name marks percent grade 0 Sam 82 0.82 B 1 Ali 95 0.95 A
Connection to Day 10: .apply(lambda ...) works like map, applying a function to each value in the column.

Lesson 7: Summaries with describe and value_counts

import pandas as pd

df = pd.DataFrame({
    "name": ["Sam", "Ali", "Sara", "Ravi"],
    "marks": [82, 95, 70, 88],
    "city": ["Surat", "Pune", "Surat", "Surat"],
})

print(df["marks"].mean())          # average
print(df["marks"].max())           # highest
print(df.describe())               # summary of numeric columns
print(df["city"].value_counts())   # how often each value appears
83.75 95 marks count 4.00 mean 83.75 std 10.47 min 70.00 25% 79.00 50% 85.00 75% 89.75 max 95.00 city Surat 3 Pune 1 Name: count, dtype: int64

value_counts() is the counting pattern from Day 6, done for you in one method call.

Lesson 8: Grouping Data with groupby

groupby splits rows into groups by a column, applies a calculation to each group, and combines the results. It's the pandas version of the "totals by category" pattern from Day 7.

import pandas as pd

sales = pd.DataFrame({
    "city": ["Surat", "Pune", "Surat", "Pune", "Surat"],
    "amount": [500, 300, 700, 200, 400],
})

totals = sales.groupby("city")["amount"].sum()
print(totals)

print(sales.groupby("city")["amount"].mean())
city Pune 500 Surat 1600 Name: amount, dtype: int64 city Pune 250.0 Surat 533.333333 Name: amount, dtype: float64
Analogy: groupby is like sorting your receipts into piles by shop, then adding up each pile.

Lesson 9: Saving Results

import pandas as pd

df = pd.read_csv("students.csv")
top = df[df["marks"] >= 80]
top.to_csv("top_students.csv", index=False)    # index=False avoids an extra column

You can also use to_excel for spreadsheet files, but that needs an additional package. CSV needs nothing extra.

Common Mistakes on Day 27

  1. Using and or or in filters: use & and |, with parentheses around each condition.
  2. Forgetting index=False when saving: the row numbers are written as an extra column.
  3. Confusing iloc and loc: iloc uses positions, and loc uses labels.
  4. Expecting in-place changes: many methods return a new DataFrame. Assign the result back, or use inplace=True.
  5. Numbers stored as text: dtype object for a numeric column means the values need converting.

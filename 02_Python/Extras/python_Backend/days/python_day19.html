Iterators and Generators

Estimated time: about 1.5 hours · iter() and next(), writing generators with yield, lazy processing of large data

Lesson 1: How for Loops Really Work

When you write for x in something, Python does three things behind the scenes: it asks the object for an iterator, repeatedly asks that iterator for the next value, and stops when the iterator says there is nothing left.

nums = [10, 20, 30]
it = iter(nums)        # ask the list for an iterator
print(next(it))        # 10
print(next(it))        # 20
print(next(it))        # 30
# print(next(it))      # StopIteration: nothing left
10 20 30
Analogy: An iterator is like a bookmark in a book. next() turns to the next page. Once you reach the last page, there are no more pages to turn to.

A for loop is simply iter() and next() with the StopIteration handled for you.

Lesson 2: Iterable versus Iterator

These two words are easy to mix up:

TermMeaningExamples
IterableSomething you can loop over. It can give you an iterator.list, string, dict, range, file
IteratorAn object that remembers its position and gives the next item with next().the result of iter(list)
nums = [1, 2, 3]
print(hasattr(nums, "__next__"))   # False: a list is iterable, not an iterator
it = iter(nums)
print(hasattr(it, "__next__"))     # True: the iterator can call next()
False True
Important: An iterator can be used only once. After it's exhausted, it stays empty. That's the same behaviour you saw with map on Day 10.

Lesson 3: Generators with yield

A generator is a function that uses yield instead of return. Each yield hands back one value and pauses the function. When the next value is requested, the function resumes from where it paused.

def countdown(n):
    while n > 0:
        yield n
        n -= 1
    print("Liftoff!")

for value in countdown(3):
    print(value)
3 2 1 Liftoff!

Calling countdown(3) doesn't run the body. It creates a generator object, and the body runs step by step as values are requested.

gen = countdown(2)
print(type(gen))       # generator
print(next(gen))       # 2
print(next(gen))       # 1
<class 'generator'> 2 1
Key idea: return ends a function and gives back one result. yield pauses it and gives back one value, keeping its state so it can continue later.

Lesson 4: Why Generators Save Memory

A list holds every value in memory at once. A generator produces each value when it's needed, so it can handle sequences that would be too large to store.

def squares_list(n):
    return [i * i for i in range(n)]

def squares_gen(n):
    for i in range(n):
        yield i * i

big_list = squares_list(1_000_000)      # all million values stored now
big_gen = squares_gen(1_000_000)        # nothing computed yet

print(sum(big_gen))                     # computed one value at a time
print(len(big_list))
333332833333500000 1000000
Analogy: A list is a full warehouse, storing every item in advance. A generator is a conveyor belt that makes each item only when a customer asks for it.

Lesson 5: Generator Expressions

Round brackets around a comprehension create a generator expression, which you previewed on Day 18. It works the same way as a generator function, and it's shorter for simple cases.

gen = (n * n for n in range(5))
print(next(gen))        # 0
print(list(gen))        # [1, 4, 9, 16]  -- the rest
0 [1, 4, 9, 16]

Generator expressions are ideal for passing straight into functions like sum(), max(), any(), and all().

has_big = any(n > 100 for n in range(1000))
print(has_big)          # True, stops as soon as it finds one
True

any() stops at the first match, so the rest of the values are never computed. This is laziness working in your favour.

Lesson 6: Infinite Generators and Pipelines

Because a generator computes values on demand, it can describe an endless sequence. You take only as many values as you need.

def naturals():
    n = 1
    while True:
        yield n
        n += 1

def evens(source):
    for n in source:
        if n % 2 == 0:
            yield n

first_five_evens = []
for e in evens(naturals()):
    first_five_evens.append(e)
    if len(first_five_evens) == 5:
        break
print(first_five_evens)
[2, 4, 6, 8, 10]
Careful: A for loop over naturals() without a break would run forever. Always make sure an infinite generator is stopped by the consumer.

Lesson 7: Reading Large Files Lazily

Files are iterators too. You met this on Day 11. Looping over a file reads one line at a time, so a multi-gigabyte log file never has to fit in memory.

def errors_in(path):
    with open(path) as f:
        for line in f:
            if "ERROR" in line:
                yield line.strip()

# Use it: only matching lines are read and returned
for error in errors_in("server.log"):
    print(error)
Combining ideas: This function is a generator (yield), it iterates over a file (lazy reading), and it uses a condition (Day 3). Real data tools work the same way.

Common Mistakes on Day 19

  1. Reusing an exhausted iterator: a second loop over the same generator produces nothing.
  2. Using return instead of yield: the function gives back only one value and doesn't become a generator.
  3. Expecting generator code to run on creation: calling countdown(3) only creates the object. The body runs when values are requested.
  4. Converting an infinite generator to a list: list(naturals()) never finishes.
  5. Forgetting that next() raises StopIteration: use next(gen, default) to provide a fallback value.

Practicals

Try each one before looking at any hints.

Practical 1: Manual Iteration

Create an iterator from the list ["a", "b", "c"] and call next() four times. Use next(it, "done") for the fourth call, and explain what changed.

Practical 2: Countdown Generator

Write a generator countdown(n) that yields n, n-1, and so on down to 1. Print the values using a for loop.

Practical 3: Fibonacci Generator

Write a generator fibonacci() that yields an endless series starting 0, 1, 1, 2, 3, 5. Take the first ten values using itertools.islice or a loop with break.

Practical 4: Memory Comparison

Write a list comprehension and a generator expression that both produce the squares of numbers up to one million. Use sys.getsizeof() to compare their sizes, and check how long sum() takes for each.

Practical 5: Filter Generator

Write a generator long_words(text, min_length) that yields each word in a text longer than min_length. Test it on a sentence.

Practical 6: Log Reader

Create a text file with ten lines, some containing "WARNING". Write a generator that yields only those lines, and print the first two using next().

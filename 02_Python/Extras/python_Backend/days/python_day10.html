Lambda, map, and filter

Estimated time: about 1.5 hours · Short functions, transforming and selecting data without loops

Lesson 1: Lambda Functions in Depth

A lambda is a small function written in one expression, with no name and no return keyword. It's useful when a function is short and you only need it once, such as a sort key.

def double(x):
    return x * 2

double_lambda = lambda x: x * 2

print(double(5))          # 10
print(double_lambda(5))   # 10
10 10

The general form is lambda parameters: expression. The expression's value is returned automatically.

Lambda with several parameters

add = lambda a, b: a + b
print(add(3, 4))          # 7

full_name = lambda first, last: f"{first} {last}"
print(full_name("Sam", "Khan"))   # Sam Khan
7 Sam Khan
Limits: A lambda can contain only one expression. No statements such as if blocks, loops, or assignments. If you need more than one line, use def.
Good practice: Assigning a lambda to a name, as in square = lambda x: x * x, is discouraged by the style guide. Use def for named functions and reserve lambdas for places where a function is passed in directly.

Lambda with a conditional

label = lambda n: "even" if n % 2 == 0 else "odd"
print(label(7))           # odd
print(label(10))          # even
odd even

Lesson 2: map() Transforms Every Item

map(function, iterable) applies a function to every item in a sequence. It returns a map object, which is lazy: it produces results as you need them. Wrap it in list() to see all results at once.

nums = [1, 2, 3, 4]

doubled = list(map(lambda x: x * 2, nums))
print(doubled)            # [2, 4, 6, 8]

names = ["sam", "ali", "sara"]
capitalised = list(map(str.title, names))
print(capitalised)        # ['Sam', 'Ali', 'Sara']
[2, 4, 6, 8] ['Sam', 'Ali', 'Sara']

map() with a named function

def to_fahrenheit(c):
    return c * 9 / 5 + 32

temps_c = [0, 25, 100]
temps_f = list(map(to_fahrenheit, temps_c))
print(temps_f)            # [32.0, 77.0, 212.0]
[32.0, 77.0, 212.0]

map() with two lists

prices = [10, 20, 30]
qty = [2, 1, 4]
totals = list(map(lambda p, q: p * q, prices, qty))
print(totals)             # [20, 20, 120]
[20, 20, 120]
Analogy: map is a factory conveyor belt. Every item passes the same machine, and you get a new item out the other end for each one that went in.

Lesson 3: filter() Selects Items

filter(function, iterable) keeps only the items for which the function returns True. Like map, it returns a lazy object, so wrap it in list().

nums = [3, 8, 11, 14, 17, 20]

evens = list(filter(lambda n: n % 2 == 0, nums))
print(evens)              # [8, 14, 20]

big = list(filter(lambda n: n > 10, nums))
print(big)                # [11, 14, 17, 20]
[8, 14, 20] [11, 14, 17, 20]

filter() with None

Passing None as the function removes every falsy value. This is a quick way to clean a list.

messy = [0, "", "Python", None, 42, False, "Day 10"]
clean = list(filter(None, messy))
print(clean)
['Python', 42, 'Day 10']
Connection to Day 3: Truthy and falsy values decide which items filter(None, ...) keeps. Empty strings, zero, None, and empty collections are removed.

Lesson 4: Lazy Evaluation

A map or filter object computes each result only when you ask for it. This saves memory with large data. Once consumed, the object is empty.

nums = [1, 2, 3]
result = map(lambda x: x * 10, nums)

print(list(result))       # [10, 20, 30]
print(list(result))       # []  -- already used up
[10, 20, 30] []
Common mistake: Printing a map object directly shows something like <map object at 0x...>, not the values. Convert it with list() or loop over it.

Lesson 5: Comparing map and filter with Loops

Every map or filter can be written as a loop, and list comprehensions (Day 5) are often the most readable choice in Python. Compare the three styles:

nums = [1, 2, 3, 4, 5, 6]

# Loop
squares_loop = []
for n in nums:
    if n % 2 == 0:
        squares_loop.append(n * n)

# map and filter together
squares_mf = list(map(lambda n: n * n, filter(lambda n: n % 2 == 0, nums)))

# List comprehension
squares_lc = [n * n for n in nums if n % 2 == 0]

print(squares_loop, squares_mf, squares_lc)
[4, 16, 36] [4, 16, 36] [4, 16, 36]
Which should you use? All three are correct. Choose the one that reads most clearly to someone else. For simple cases, a comprehension is usually the easiest to read. map and filter are common in functional-style code and appear in many libraries.

Lesson 6: reduce() and sorted() with key

reduce() combines items into one value

reduce lives in the functools module. It repeatedly combines pairs of items until one value remains.

from functools import reduce

nums = [1, 2, 3, 4]
product = reduce(lambda a, b: a * b, nums)
print(product)            # 24  (1*2*3*4)
24

For sums and maximums, use sum() and max() instead. They're clearer. Use reduce only for combinations that don't have a built-in function.

sorted() with a key function

You met key on Day 5. A key function tells sorted what to compare by.

students = [("Sam", 82), ("Ali", 95), ("Sara", 70)]

by_score = sorted(students, key=lambda s: s[1], reverse=True)
print(by_score)

by_name_length = sorted(["Zara", "Bo", "Alexander"], key=len)
print(by_name_length)
[('Ali', 95), ('Sam', 82), ('Sara', 70)] ['Bo', 'Zara', 'Alexander']

Common Mistakes on Day 10

  1. Forgetting list(): map and filter return lazy objects. Print values with list().
  2. Reusing an exhausted map or filter: the second list() returns an empty list.
  3. Writing multi-line logic in a lambda: use def instead.
  4. Assigning lambdas to names: prefer def for named functions.
  5. Making code unreadable: nested lambdas and maps are harder to follow than a simple loop or comprehension.
  6. Expecting filter to change the original: it creates a new sequence and leaves the original list as it was.

Practice the core operations: adding a new key, updating an existing one, and deleting a key.

Starter Dataset 
student = {
    "name": "Ali",
    "roll": 101,
    "marks": 85,
    "attendance": 90,
    "city": "Lahore"
}

Your Goal: 1. Add a new key "grade" with value "A".
2. Update "marks" to 92.
3. Delete the "city" key.
4. Print the final dictionary.

Show Solution 
# 1. Add a new key
student["grade"] = "A"

# 2. Update an existing key
student["marks"] = 92

# 3. Delete a key
del student["city"]

# 4. Print the result
print(student)
# Output: {'name': 'Ali', 'roll': 101, 'marks': 92, 'attendance': 90, 'grade': 'A'}

Real-world data is often missing information. Practice safely checking for keys without causing a KeyError.

Starter Dataset 
user_profile = {
    "name": "Krish",
    "age": 25,
    "role": "Student"
}

Your Goal: 1. Use the in keyword to check if "email" exists. Print "Email exists" or "Email missing".
2. Use .get() to try and get the "city". If it doesn't exist, return "Unknown" as the default. Print the result.

Show Solution 
# 1. Check if key exists
if "email" in user_profile:
    print("Email exists")
else:
    print("Email missing")

# 2. Safe access with .get() and a default value
city = user_profile.get("city", "Unknown")
print(f"City: {city}") 
# Output: City: Unknown

Looping through a dictionary is essential for reading configurations or printing summaries.

Starter Dataset 
car = {
    "brand": "Toyota",
    "model": "Corolla",
    "year": 2020,
    "color": "Silver"
}

Your Goal: Write a for loop using .items() to print every key-value pair in the exact format: KEY → VALUE.

Show Solution 
# Loop through .items() to get both key and value
for key, value in car.items():
    print(f"{key} → {value}")

# Output:
# brand → Toyota
# model → Corolla
# year → 2020
# color → Silver

A list of dictionaries is how Python represents a dataset (like a CSV file). Practice looping, filtering, and calculating averages.

Starter Dataset 
dataset = [
    {"name": "Ali", "hours": 5, "marks": 88, "passed": 1},
    {"name": "Sara", "hours": 2, "marks": 45, "passed": 0},
    {"name": "Usman", "hours": 8, "marks": 91, "passed": 1},
    {"name": "Zara", "hours": 1, "marks": 32, "passed": 0}
]

Your Goal: 1. Count how many students passed (where "passed" == 1).
2. Calculate the average marks of all students.
3. Print both results.

Show Solution 
passed_count = 0
total_marks = 0

for row in dataset:
    if row["passed"] == 1:
        passed_count += 1
    total_marks += row["marks"]

avg_marks = total_marks / len(dataset)

print(f"Students passed: {passed_count}")
print(f"Average marks: {avg_marks}")
# Output: Students passed: 2
# Output: Average marks: 64.0

In Month 2, you will learn Pandas. Pandas DataFrames are built from a "dictionary of lists" (column-oriented data). Let's practice reading one.

Starter Dataset 
data = {
    "names": ["Ali", "Sara", "Usman"],
    "scores": [85, 92, 78]
}

Your Goal: Write a for loop using range() and len() to print each person's name alongside their score. (Hint: Use the index i to access both lists).

Show Solution 
# Get the total number of items (which is 3)
num_students = len(data["names"])

for i in range(num_students):
    name = data["names"][i]
    score = data["scores"][i]
    print(f"{name} scored {score}")

# Output:
# Ali scored 85
# Sara scored 92
# Usman scored 78

Simulate a real-world lookup tool. Dictionaries are perfect for this because they provide instant O(1) lookups by key.

Starter Dataset 
phonebook = {
    "Ali": "0300-1234567",
    "Sara": "0321-7654321",
    "Usman": "0333-9876543",
    "Zara": "0345-1122334",
    "Bilal": "0312-5566778"
}

# Simulate user input
search_name = "Sara"  # Try changing this to "Krish" to test the fallback!

Your Goal: Use .get() to look up the search_name in the phonebook. If the name exists, print their number. If not, print "Not found".

Show Solution 
# Use .get() with a default fallback value
number = phonebook.get(search_name, "Not found")

print(f"Lookup for '{search_name}': {number}")

# If search_name = "Sara" → Output: Lookup for 'Sara': 0321-7654321
# If search_name = "Krish" → Output: Lookup for 'Krish': Not found

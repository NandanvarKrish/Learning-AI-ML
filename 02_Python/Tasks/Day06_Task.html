✅ What you learned today: dict {} — stores data as key: value pairs. Access by name, not index. d["key"] — access value (raises KeyError if missing). d.get("key", default) — safe access — returns default if key not found. d["key"] = val — add new key OR update existing. del d["key"] — delete a key-value pair. d.keys() · d.values() · d.items() — iterate the dictionary. "key" in d — check if key exists. List of dicts = dataset. Each dict = one row. This IS how Pandas works internally.

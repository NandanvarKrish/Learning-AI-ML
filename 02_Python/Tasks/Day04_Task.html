✅ What you learned today: for item in list: — loops over every item in a sequence. for i in range(n): — repeats n times (0 to n-1). range(start, stop, step) — stop is NEVER included. while condition: — repeats as long as condition is True — ALWAYS update the counter! break — exit the loop immediately. continue — skip this iteration, go to next. Nested loops — a loop inside a loop (for multiplication tables, image pixel processing). AI training IS a while loop — it runs until loss is small enough.

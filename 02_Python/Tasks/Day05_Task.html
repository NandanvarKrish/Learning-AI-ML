Your AI Task:
Lists, Tuples & Sets

Today you learned Python's most important data structures. Every ML dataset is a list. Every image pixel is stored in nested lists. Every unique class label is a set. Every fixed configuration is a tuple. These structures ARE the containers of AI.

Task Progress3%
✅ What you learned today: list [] — ordered, mutable, allows duplicates. Most used structure in ML. tuple () — ordered, immutable (cannot change after creation). Faster, safer for fixed data. set {} — unordered, unique values only, no duplicates. Indexing: list[0] = first, list[-1] = last. Slicing: list[1:4] = items at index 1, 2, 3 (stop excluded). List methods: .append() .remove() .sort() len() sum() max() min(). List comprehension: [x**2 for x in range(5)] — build a list in one line.

📊 Reference Table

List vs Tuple vs Set — Side by Side

This is the most important table in Day 05. Memorise the key differences — they come up in every AI interview and every ML project.

Property List [ ] Tuple ( ) Set { }
Ordered?✅ Yes✅ Yes❌ No
Mutable?✅ Yes — can add/remove/change❌ No — fixed forever✅ Yes — can add/remove
Duplicates?✅ Allowed✅ Allowed❌ Removed automatically
Indexing?✅ list[0]✅ tuple[0]❌ Not supported
SpeedNormalFaster than listVery fast for lookup
ML Use CaseDataset rows, predictions, scoresRGB pixel, model config, coordinatesUnique class labels, vocabulary
Syntax[85, 92, 78](255, 128, 0){"cat", "dog"}
💡Rule of thumb: Use a list when data will change. Use a tuple when data is fixed (RGB values, coordinates, model hyperparameters). Use a set when you need unique values only (class labels, vocabulary, unique IDs).

How Python Reads if / elif / else

Python reads conditions top to bottom and stops at the FIRST one that is True. All others below it are completely skipped — even if they are also true.

if marks >= 90:
✅ True
print("A") → STOP
❌ False → check next
elif marks >= 70:
✅ True
print("B") → STOP
❌ False → check next
elif marks >= 50:
✅ True
print("C") → STOP
❌ All False
else: print("F")
💡Key insight: Once Python finds a True condition, it runs that block and JUMPS PAST all remaining elif/else. This is why order matters — put the most specific condition first!

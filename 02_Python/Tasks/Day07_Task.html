Functions — def, Parameters & Return

Today you learned the most fundamental concept in software engineering: functions. Every sklearn model method (.fit(), .predict()), every Pandas operation, every piece of production AI code runs on functions. Write once, use forever — this is DRY.

✅ What you learned today: def name(params): — define a reusable function. return value — sends a value BACK to the caller (stores it, usable in expressions). print() — only displays on screen, value is lost. Default parameters: def f(x, unit="metric"): — used when caller doesn't provide that argument. Multiple return: return a, b, c — Python packs as tuple, unpack: a, b, c = func(). DRY: Don't Repeat Yourself — write logic once, call from anywhere. ML connection: Every model IS a function. train_test_split() returns 2 values. RandomForestClassifier(n_estimators=100) uses default params.

🖨️ print() vs ↩️ return — The Most Critical Distinction

🖨️ print() inside a function
Shows text on screen. The value disappears after the function ends. You CANNOT store it, pass it to another function, or add it to a list. Dead end — useful for debugging only.
↩️ return inside a function
Sends the value back to the caller. You CAN store it (grade = get_grade(75)), pass it to another function, add it to a list. Essential for real programs.
grade = get_grade(75)
caller stores result
→
get_grade(75)
executes logic
return "B"
→
grade = "B"
✅ stored & usable!
⚠️Critical mistake: If you use print() instead of return, then grade = get_grade(75) will store None — not "B". This is the #1 Day 07 bug in student code!

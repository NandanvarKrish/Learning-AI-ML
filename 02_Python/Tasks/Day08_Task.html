🔬 Concept Overview

Three Advanced Function Patterns — Side by Side

📦
*args
Any number of positional arguments. Collected into a tuple. Good for: functions that work on any number of values.
average(80, 90, 70, 95)
→ args = (80, 90, 70, 95)
🏷️
**kwargs
Any number of keyword arguments. Collected into a dict. Good for: flexible config functions (like sklearn).
config(lr=0.01, epochs=50)
→ kwargs = {"lr":0.01, "epochs":50}
⚡
lambda
Anonymous one-line function. Implicit return. Best as an argument to map(), filter(), sorted().
lambda x: x**2
→ same as def f(x): return x**2

⚡ Lambda — Full Pattern Reference

Lambda ExpressionEquivalent defML Use Case
lambda x: x**2def f(x): return x**2Square activation, feature engineering
lambda x: max(0, x)def relu(x): return max(0,x)ReLU activation function
lambda x: x/255def norm(x): return x/255Pixel normalisation (0→1)
lambda x: 1 if x>0.5 else 0def thresh(x): ...Binary classification threshold
lambda s: s["marks"]def key(s): return s["marks"]Sort students by marks
lambda x, mn, mx: (x-mn)/(mx-mn)def minmax(x,mn,mx): ...Min-max normalisation
lambda r: r["marks"]>=50 and r["att"]>=75def eligible(r): ...Filter eligible students
⚠️ Key type facts: *args gives you a tuple — so you can use sum(args), len(args), loop with for. **kwargs gives you a dict — so you can use .items(), .get(), and all dict methods.

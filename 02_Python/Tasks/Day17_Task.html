📡 Concept 1 — Broadcasting

Broadcasting: How NumPy Handles Different-Sized Arrays

Broadcasting is the rule that makes operations like X - X.mean(axis=0) work — even though X has shape (3,3) and X.mean(axis=0) has shape (3,). How can you subtract them if they have different shapes? Broadcasting is the answer.

🎯 Analogy — The School Bell
Imagine 5 teachers each saying "add 10 bonus marks to everyone." They don't say it for each student — just once. But it applies to ALL 100 students. That's broadcasting: one instruction applies to many.

In NumPy: X + 10 — the scalar 10 is "broadcast" across every element of X. You don't need 10 copies of 10.
Array A — shape (3,3)
[[1 2 3]
[4 5 6]
[7 8 9]]

Array B — shape (3,) → stretched to (3,3)
[10 20 30]

Result — shape (3,3)
[[11 22 33]

📋 Broadcasting Rules (Simple Version)
1
Shapes are compared right to left. (3,3) and (3,) → compare 3 vs 3 → they match ✅
2
If one dimension is 1, it stretches. (3,1) + (3,3) → the 1 stretches to 3 ✅
3
If dimensions differ AND neither is 1, it fails. (3,3) + (4,) → 3≠4 and neither is 1 → ERROR ❌
🎯 The most common broadcasting in ML: (X - X.mean(axis=0)) / X.std(axis=0) — Z-score standardisation. X has shape (n_samples, n_features). X.mean(axis=0) has shape (n_features,). Broadcasting subtracts each feature's mean from each row automatically. This is what sklearn's StandardScaler does internally.
✖️ Concept 2 — Matrix Multiplication

Matrix Multiply @ — The Engine of Every Neural Network

Matrix multiplication (the @ operator) is the single most important operation in deep learning. Every neural network forward pass is a series of matrix multiplications. Understanding this means understanding how neural networks actually compute things.

🧠 Analogy — Voting System
Imagine 3 judges, each scoring a student's work (study hours, attendance, textbook). Judge 1 cares 40% about study, 30% attendance, 30% textbook. Judge 2 cares 10% study, 50% attendance, 40% textbook. The dot product computes each judge's final score for one student. Matrix multiplication does this for MULTIPLE students and MULTIPLE judges AT ONCE.
Shape rule: (m, k) @ (k, n) → (m, n) — inner dimensions MUST match
X — 4 students × 3 features
shape (4, 3)
@
W.T — 3 features × 2 neurons
shape (3, 2)
=
Z — 4 students × 2 neuron outputs
shape (4, 2)
Inner dimensions 3 == 3 ✅ must match! Outer dims 4,2 = result shape
⚠️ Most common beginner error: ValueError: matmul shape mismatch. When you see this, print both shapes: print(X.shape, W.shape). The inner dimensions must match. If X is (4,3) and W is (2,3), you need W.T (which flips to (3,2)) before multiplying: X @ W.T.
🧠 What This Has to Do With Neural Networks

A neural network "dense layer" does exactly this:

1
Matrix multiply: Z = X @ W + b — each neuron computes a weighted sum of all inputs. If you have 4 students and 3 features going into 2 neurons: X(4,3) @ W(3,2) + b(2,) = Z(4,2)
2
Activation function: A = np.maximum(0, Z) — ReLU. Negative values become 0. Positive stay. This is what makes neural networks non-linear.
3
Stack layers: output of layer 1 becomes input of layer 2. Deep learning = many such layers stacked together. When you write Keras.Dense(64, activation='relu') — this is what it does.
🔢 Concept 3 — np.where() and Advanced Indexing

np.where() — A Vectorised if/else for Entire Arrays

In Python Month 1, you used list comprehensions: ["Pass" if s>=50 else "Fail" for s in scores]. NumPy's version is faster and works on arrays: np.where(scores>=50, "Pass", "Fail").

💡 Think of it like a conditional column in Excel
In Excel: =IF(A2>=50, "Pass", "Fail") — you write this ONCE in one cell, then copy it to 1000 rows.
In NumPy: np.where(scores>=50, "Pass", "Fail") — you write it ONCE, it applies to ALL 1000 elements at once, using C speed.

🔢 np.where() — Label Data Without Any Loop
Use np.where() to create labels, replace values, and find positions — all without writing a single for loop. This is the NumPy equivalent of an IF formula in Excel, applied to an entire array at once.

What to do:
1. Create: scores = np.array([85, 45, 72, 33, 91, 58, 76, 64])
2. Create text labels: np.where(scores >= 50, "Pass", "Fail")
3. Create binary (0/1) labels: np.where(scores >= 50, 1, 0)
4. Replace failing scores with 0: np.where(scores < 50, 0, scores)
5. Get INDICES of passing scores: np.where(scores >= 50)[0]
6. Fancy indexing: select specific rows from 2D array
Why this matters in AI:
np.where() is how you quickly create labels for ML models:
• y = np.where(scores >= 50, 1, 0) — binary classification labels (this IS your y array for training!)
• np.where(predictions > 0.5, 1, 0) — threshold a model's probability outputs to get class predictions
• np.where(X[:, 2] == 1)[0] — find indices of students who have a textbook (select a subset of your dataset)

np.where(scores >= 50, 1, 0) and np.where(scores >= 50)[0] look similar. What is the key difference between them?
A No difference — both return the same result
B np.where(cond, 1, 0) returns an array of values (1 or 0 for EVERY element). np.where(cond)[0] returns only the INDICES where condition is True — not the values themselves.
C np.where(cond)[0] is faster because it skips elements
D They are the same but np.where(cond, 1, 0) is the older syntax

📡 Broadcasting — Z-Score Standardisation
Use broadcasting to perform Z-score standardisation on a 2D dataset. This is one of the most important operations in ML data preprocessing — and it's just 2 lines of NumPy.

What to do:
1. Create a 2D dataset X with shape (4, 3) — 4 students, 3 features
2. Compute column means: col_mean = np.mean(X, axis=0)
3. Compute column stds: col_std = np.std(X, axis=0)
4. Standardise: X_scaled = (X - col_mean) / col_std
5. Verify: mean of each column in X_scaled should be ≈ 0, std ≈ 1
6. Also try: min-max normalisation with broadcasting
Why this matters in AI:
The formula (X - col_mean) / col_std uses broadcasting twice:
• X - col_mean: X is (4,3), col_mean is (3,) → broadcasting subtracts each feature's mean from each row
• / col_std: divided by each feature's standard deviation

Result: each feature now has mean≈0 and std≈1. This is called Z-score standardisation. Without this, features with large values (like income = 50,000) dominate over small ones (like age = 25). sklearn's StandardScaler().fit_transform(X) does EXACTLY this with the same math.

Solve puzzle → unlock solution code
In X_scaled = (X - col_mean) / col_std, X is shape (4,3) and col_mean is shape (3,). Why does this work without any error?
A NumPy automatically converts col_mean to a list and loops through X
B Broadcasting! NumPy aligns shapes from the right: (4,3) and (3,) → rightmost dims match (3==3) → col_mean is "stretched" to (4,3) by repeating the row 4 times. Each row of X gets the same subtraction.
C NumPy only uses the first 3 rows of X to match col_mean's length
D It only works if you use axis=1 explicitly

✖️ Dot Product & Matrix Multiply — What a Neuron Computes
Build intuition for dot products and matrix multiplication from scratch. First understand what ONE neuron computes, then scale to many neurons and many students at once.

What to do:
1. Manually compute a dot product: weights × inputs, then verify with np.dot()
2. Create weights matrix W (2 neurons, 3 features each)
3. Compute Z = X @ W.T — verify the shapes at each step
4. Apply ReLU: A = np.maximum(0, Z)
5. Try np.linalg.norm() on a vector — understand what it means
The dot product IS one neuron:
weights = [0.4, 0.3, 0.3] (how much the neuron cares about each feature)
inputs = [5, 80, 1] (study hours, attendance, textbook)
output = 0.4×5 + 0.3×80 + 0.3×1 = 2 + 24 + 0.3 = 26.3

This is ONE neuron for ONE student. Matrix multiply X @ W.T computes this for MULTIPLE neurons AND MULTIPLE students at once. That's why neural networks are fast — one matrix multiplication replaces millions of individual dot products.
np.dot()@ matrix multiplyReLU⭐⭐ Intermediate

Solve puzzle → unlock solution code
X has shape (3, 3) and W has shape (2, 3). What does Z = X @ W.T produce, and why do we need .T?
A Z has shape (3,2) — but we don't need .T, just X @ W works fine
B Z has shape (3,2) — 3 students × 2 neuron outputs. .T is needed because matrix multiply (m,k)@(k,n) requires inner dims to match. X is (3,3) and W is (2,3) — inner dims are 3 and 2 (don't match!). W.T flips W to (3,2), so X@W.T = (3,3)@(3,2) = (3,2) ✅
C Z has shape (2,3) — .T just rotates the final result
D ValueError — (3,3) and (2,3) are always incompatible

🧠 Build a Neural Network Dense Layer From Scratch!
This is the most exciting task in Month 2 so far. You will build an actual neural network layer using ONLY NumPy. When you later use Keras.Dense(4, activation='relu'), you will know exactly what's happening inside.

What to do:
1. Create a DenseLayer class with __init__(in_features, out_features)
2. Initialise: self.W = np.random.randn(in_features, out_features) * scale
3. Initialise: self.b = np.zeros(out_features)
4. Write forward(X): Z = X @ self.W + self.b, then A = np.maximum(0, Z)
5. Create 2 layers (3→4 and 4→1) and pass data through both
6. Print shapes at each step
Understanding each line:
• self.W: weight matrix — random numbers (neurons start with random connections)
• self.b: bias — zeros initially (no bias at the start)
• Z = X @ self.W + self.b: linear transform. X (4,3) @ W (3,4) = (4,4), then + b(4,) via broadcasting
• A = np.maximum(0, Z): ReLU activation. Kills all negative values. This is what makes deep networks powerful — without it, stacking layers would be pointless.

When you train with sklearn or Keras, this forward pass runs thousands of times. You just built it from scratch.

Key concept puzzle — unlock the DenseLayer code
In the forward pass: Z = X @ self.W + self.b. If X is (4,3), W is (3,4), and b is (4,), what is the shape of Z and how does b get added?
A Z is (4,3) — W must be square for matrix multiply to work
B Z is (4,4) but + self.b fails because shapes don't match
C X@W = (4,3)@(3,4) = (4,4). Then + b: b is (4,) which broadcasts to (4,4) — each row gets the bias added. Z is (4,4). This is the pre-activation output for 4 students and 4 neurons.
D Z is (3,4) — matrix multiply preserves the first dimension of W

import numpy as np np.random.seed(42) # reproducible! class DenseLayer: """A fully-connected neural network layer — just NumPy.""" def __init__(self, in_features, out_features): # Xavier initialisation — prevents gradients from vanishing/exploding scale = np.sqrt(2.0 / in_features) self.W = np.random.randn(in_features, out_features) * scale self.b = np.zeros(out_features) # bias starts at 0 print(f" Layer init: W={self.W.shape}, b={self.b.shape}") def forward(self, X): # ① Linear transform: weighted sum for each neuron Z = X @ self.W + self.b # shape: (n_samples, out_features) # ② ReLU activation: negative → 0, positive → unchanged A = np.maximum(0, Z) print(f" forward: X{X.shape} @ W{self.W.shape} → Z{Z.shape} → A{A.shape}") return A @property def param_count(self): return self.W.size + self.b.size # ── INPUT DATA ──────────────────────────────────── # 4 students, 3 features (study_hrs, attendance, textbook) X = np.array([ [5, 80, 1], [2, 50, 0], [8, 90, 1], [1, 40, 0] ], dtype=float) # ── BUILD THE NETWORK ───────────────────────────── print("\n=== Building 2-Layer Network ===") layer1 = DenseLayer(3, 4) # 3 inputs → 4 hidden neurons layer2 = DenseLayer(4, 1) # 4 hidden → 1 output neuron # ── FORWARD PASS ───────────────────────────────── print(f"\n=== Forward Pass (input: {X.shape}) ===") h1 = layer1.forward(X) # shape (4, 4) — 4 students, 4 hidden outputs out = layer2.forward(h1) # shape (4, 1) — 4 students, 1 output each print(f"\nPredictions: {np.round(out.flatten(), 3)}") print(f"Layer 1 params: {layer1.param_count}") # 3×4 + 4 = 16 print(f"Layer 2 params: {layer2.param_count}") # 4×1 + 1 = 5 # ── COMPARE WITH KERAS ──────────────────────────── # from tensorflow import keras # model = keras.Sequential([ # keras.layers.Dense(4, activation='relu', input_shape=(3,)), # keras.layers.Dense(1) # ]) # Keras does EXACTLY the same Z = X@W + b computation!

What is the difference between np.random.rand(3,3) and np.random.randn(3,3)?
A No difference — both generate random numbers between 0 and 1
B rand() generates uniform random values between 0 and 1. randn() generates values from a normal distribution (mean=0, std=1) — so values can be negative and most cluster near 0. randn() is used for weight initialisation in neural networks.
C rand() is random, randn() is not random — it follows a pattern
D rand() creates floats, randn() creates integers

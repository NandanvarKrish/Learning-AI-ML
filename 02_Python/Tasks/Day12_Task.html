📌 Class Variable vs 👤 Instance Variable

📌 Class Variable
Defined OUTSIDE methods. Shared by ALL objects. Change Student.pass_mark — every Student object sees the new value instantly.
Student.school = "Beaconhouse"
s1.school → "Beaconhouse"
s2.school → "Beaconhouse"
👤 Instance Variable
Defined with self.x inside __init__. Unique to each object. s1.marks and s2.marks are completely independent.
self.marks = marks
s1.marks → 88 (Ali's own)
s2.marks → 45 (Sara's own)

📦 Objects — Each One Is Independent

s1 — Ali
name = "Ali"
marks = 88
grade() → A
passing() → True
s2 — Sara
name = "Sara"
marks = 45
grade() → Fail
passing() → False
s3 — Usman
name = "Usman"
marks = 72
grade() → B
passing() → True
💡 self explained: When you call s1.report(), Python automatically passes s1 as self. When you call s2.report(), Python passes s2. The same method works for ALL objects because self.name and self.marks refer to that specific object's data.

SimpleClassifier — Build Your Own sklearn-style Model

The real RandomForestClassifier is a class with __init__, fit(), predict(), and score(). You can build your own version today.

Python — SimpleClassifier (sklearn-style)
class SimpleClassifier: def __init__(self, threshold=50): self.threshold = threshold # instance variable self.trained = False self.n_samples = 0 def fit(self, X, y): self.n_samples = len(X) self.trained = True print(f"Trained on {self.n_samples} samples") return self # enables chaining: model.fit(X,y).predict(X) def predict(self, X): if not self.trained: raise RuntimeError("Call fit() before predict()!") return [1 if x >= self.threshold else 0 for x in X] def score(self, X, y): preds = self.predict(X) correct = sum(1 for p, t in zip(preds, y) if p==t) return round(correct/len(y)*100, 2) # Use it just like sklearn: model = SimpleClassifier(threshold=60) # calls __init__ model.fit([80,45,72,33,91], [1,0,1,0,1]) print(model.predict([70, 40, 85])) # [1, 0, 1] print(model.score([80,45,72], [1,0,1])) # 100.0
🎯 The real RandomForestClassifier has the same structure — just with much more complex fit() logic. model = RFC(n_estimators=100) calls __init__ setting self.n_estimators=100. model.fit(X, y) trains. model.predict(X_test) predicts. model.score(X_test, y_test) evaluates.

✅ What you learned today: try: — the code that MIGHT raise an error. Always runs first. except ValueError: — runs ONLY if a ValueError occurred in the try block. except Exception as e: — catch-all with the error message stored in e. finally: — runs ALWAYS, error or not. Used for cleanup (close files, release locks). raise ValueError("message") — deliberately trigger an error when data is invalid. Bare except: is dangerous — catches KeyboardInterrupt and SystemExit — never use it. ML rule: wrap each record in try/except → log error → skip → continue with all other records.

💡 The production Python pattern:
errors = []
for i, record in enumerate(dataset):
  try:
    result = process(record)
  except Exception as e:
    errors.append({"row": i, "error": str(e)})
    continue # skip to next record

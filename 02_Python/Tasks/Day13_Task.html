⬆️ super() — Why It Is Non-Negotiable

Without super().__init__()With super().__init__()
class Dog(Animal):
  def __init__(self, name, breed):
    self.breed = breed
    ← Animal.__init__ never called!
  def info(self):
    print(self.name) ← AttributeError!		 class Dog(Animal):
  def __init__(self, name, breed):
    super().__init__(name) ← ✅
    self.breed = breed
  def info(self):
    print(self.name) ← ✅ works!
⚠️ Rule: Call super().__init__() as the FIRST line in any child's __init__. Without it, the parent's instance variables (self.name, self.age) are never created — any parent method that uses them raises AttributeError.

🏷️ @property — Access Methods Like Attributes

Python — @property
class Student: def __init__(self, name, marks): self.name = name self.marks = marks @property def grade(self): # Accessed as s.grade — no () needed! if self.marks >= 80: return "A" elif self.marks >= 60: return "B" else: return "Fail" @property def is_passing(self): return self.marks >= 50 s = Student("Ali", 88) print(s.grade) # "A" — no () ! property used print(s.is_passing) # True — no () ! property used # df["grade"] = df.apply(lambda s: s.grade) ← Pandas-style
🎯 sklearn uses @property constantly: model.n_features_in_, model.classes_, model.feature_importances_ are all @property methods. You access them like attributes but Python runs the method internally.

🎯 What inheritance gives sklearn: All 30+ models get get_params() and set_params() for FREE — written once in BaseEstimator, inherited by everything. Each model only needs to implement fit() and predict(). DRY at the library scale.
Python — Your Own BaseModel
class BaseModel: def __init__(self): self.fitted_ = False self.n_samples_ = 0 def get_params(self): # shared by ALL children! return self.__dict__ @property def is_fitted(self): return self.fitted_ class ThresholdClassifier(BaseModel): def __init__(self, threshold=50): super().__init__() # ← MUST call parent self.threshold = threshold def fit(self, X): self.n_samples_ = len(X) self.fitted_ = True return self def predict(self, X): # overrides BaseModel (if it had one) return [1 if x>=self.threshold else 0 for x in X] clf = ThresholdClassifier(60) clf.fit([80,45,70]) print(clf.get_params()) # inherited from BaseModel! print(clf.is_fitted) # @property — True print(isinstance(clf, BaseModel)) # True!
